# Balencia Native Mobile App — Screen 72 Design Specification

## 1. Header
*   **Screen ID:** 72
*   **Name:** Knowledge Graph
*   **Route(s) Covered:** `/intelligence/knowledge-graph`
*   **Tab:** CIA
*   **Source:** Functional Content Brief (Knowledge Graph)
*   **Batch:** 7

## 2. Purpose
To provide a visual, interactive map of the user's life correlations, rendering CIA’s discovered connections across health and life domains into an explorable network. It transforms abstract data into a tangible, personal intelligence layer, allowing users to explore how behaviors impact outcomes.

## 3. Entry & Exit
*   **Entry Paths:** 
    *   Intelligence Dashboard [48] via the "Explore your health knowledge graph" link card.
*   **Exit Paths:**
    *   Intelligence Dashboard [48] (via Back button stack pop).
    *   CIA Chat [09] (via "ask *CIA*" button, carries node context).
    *   Domain Dashboards [26-36] (via "go to [domain]" button).
    *   Help Bottom Sheet (modal presentation).

## 4. Layout Anatomy
The screen is a full-bleed interactive canvas overlaid with floating glass system controls and a bottom sheet. 

**Regions Top-to-Bottom:**
1.  **Atmosphere & Base:** `--bg-base` with mandatory top-center warm radial glow. 
2.  **Top Navigation (TopBar):** Transparent on entry, dynamically adopting `.glass-pill` on scroll. Includes back chevron, title, and help glyph.
3.  **Graph Canvas (Hero):** Full-viewport interactive network. It floats directly on the base canvas without a card container for maximum visual impact.
4.  **Floating UI Layer:** 
    *   Bottom-left: Legend Pill (expandable).
    *   Bottom-right: Graph Controls (stacked vertical buttons for zoom/reset).
5.  **Node Detail Panel (Sheet):** A `.glass-frost` bottom sheet (~45% screen height) that slides up over the graph canvas when a node is tapped.
6.  **Global Navigation (GlassNavBar):** Floating bottom pill.

## 5. Components
*   **TopBar** — Transparent over atmosphere; gains `.glass-pill` backdrop once content scrolls under.
*   **GlassNavBar** — Floating bottom pill (CANON §6). 
*   **Legend & Controls** — Uses `.glass-pill` for background and sizing.
*   **Sheet** — `.glass-frost` top-radius 28, grabber pill, scrim `rgba(10,10,15,.6)`.
*   **CIAInsightCard** — Used inside the sheet for per-node observations. 
*   **StrengthListRow (NEW:)** — A ListRow variant needed for the detail panel. It pairs domain metadata with a `ProgressBar` and percentage fill to accurately reflect the correlation strength data.
*   **GraphControlsStack (NEW:)** — A grouped set of BtnSecondary icons. Grouping zoom/controls into a continuous floating pill respects the 60/30/10 rule and avoids cluttering the canvas with standalone buttons.

## 6. Visual Treatment
*   **Glass Tiers:** The canvas itself is pure atmosphere; no card container. The Legend and Controls use `.glass-pill`. The Node Detail Panel uses `.glass-frost` (immersive, high blur) so the graph remains softly visible behind it during exploration.
*   **Semantic Inner-Glow (One per card, meaning-driven):**
    *   *Selected Node:* `--glow-you` (#FF5E00) — Indicates the user's active selection and focus.
    *   *Inferred Nodes/Edges (Visualized via stroke):* `--glow-cia` (#7F24FF) — Dashed stroke represents the AI's projection/hypothesis without relying on color alone.
    *   *Confirmed Edges (Visualized via stroke):* `--glow-done` (#34A853) — Subtle green halo on hub nodes with 3+ confirmed strong edges.
*   **Background Atmosphere:** Deep `--bg-base` with the mandatory soft warm radial glow top-center. 
*   **Hero Type Moment:** The H1 title "Knowledge Graph" scales into a "Display NM Medium 52" state during the loading animation, gracefully shrinking to 34 as the network settles beneath it.

## 9. All States
*   **Default:** Full interactive graph (20-50 nodes). Data confirmed/provenance verified.
*   **Skeleton:** 3 staggered purple dots pulsing. Transitions to Error state after 10 seconds.
*   **Empty (Cold-Start):** Never an empty canvas. Shows 3-5 ghosted domain placeholder nodes at 20% opacity, no edges. Features centered growing text and a calm 3-dot purple pulse. 
*   **Error:** Centred glyph, error copy, orange retry link. Header/controls persist; controls dimmed to 40%. Graph drops to 0% opacity.
*   **Success:** Node selection successfully draws Sheet and highlights local network (haptic medium).
*   **Disabled:** Floating "Ask *CIA*" button is disabled when Offline. 

## 10. Motion & Interaction
*   **Easing & Timing:** Physical easing only (never linear). Feedback (scale, opacity) occurs strictly within 150-250ms.
*   **Entrance Choreography:** Nodes fade in staggered (20ms/node max). Once settled, edges "draw" outward via `stroke-dashoffset` over 400ms. Legend and controls fade in last.
*   **Glow Behavior:** Selected edges feature an opacity pulse loop (60→80→60% over 2s). Selected nodes scale to 1.2× with an intensified `--glow-you` bottom-anchored radial blur.
*   **Haptics:** 
    *   Node Pressed (Pre-selection): Light impact.
    *   Node Selection: Medium impact.
    *   Connection Row Tap (Re-center): Light impact.
*   **Gestures:** Pan (drag), Zoom (0.3-3.0× pinch, double-tap), Deselection (tap empty canvas, drag down on sheet).
*   **Reduced Motion (`prefers-reduced-motion`):** Graph renders instantly at its final settled frame. The entrance draw-in and continuous opacity pulse loops are completely disabled. No information is lost.

## 11. Motivation-Tier Adaptation
To prevent cognitive overload, the screen respects user motivation/density settings:
*   **Low Motivation:** Defaults to a simplified, flat, accessible list view rather than the 2D interactive canvas. Grouped by domain to ensure linear readability.
*   **Medium Motivation:** Standard visual graph (Solid = confirmed, Dashed = inferred). Base UI. 
*   **High Motivation:** Exposes premium-level analytics overlays on the graph (e.g., cluster density indicators, data-point count scaling on edges). Gates the "Deep dive" context routing to CIA Chat behind premium logic.

## 12. Accessibility
*   **Contrast:** All text and glyph pairs hit AA+ contrast against the dark base (`--bg-base`) and `.glass-frost` sheet backgrounds.
*   **Targets:** 44×44px minimum hit area applied universally to all floating controls, list rows, and graph nodes (via an invisible hit-box).
*   **Screen Reader (VoiceOver):** When active, the dynamic visual graph instantly suppresses and renders as a flat, expandable list of nodes sorted by connection count to ensure linear navigation.
*   **Focus Indicators:** 2pt solid orange focus rings applied to all interactive targets during keyboard/Switch access.
