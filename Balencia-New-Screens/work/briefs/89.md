# Functional Content Brief: Wellbeing Hub (`/wellbeing`)

## 1. Purpose
Serves as the daily command center for mental, emotional, and physical recovery. It aggregates vital wellbeing KPIs (mood, stress, energy, sleep) and provides quick-launch access to deep-dive modules, journaling, and AI-driven correlations.

## 2. Entry and Exit Paths
*   **Entry Paths:** Global navigation menu (Primary), "Wellbeing" widgets on the Today Dashboard (`/dashboard`), quick actions, or AI Coach (`/ai-coach`) hyperlinks.
*   **Exit Paths:** Deep-link routes to modules (`/wellbeing/journal`, `/wellbeing/mood`, `/wellbeing/stress`, `/wellbeing/breathing`, `/wellbeing/energy`, `/wellbeing/insights`), Today Dashboard, or global Profile/Settings.

## 3. Information Architecture (Mobile-Inferred)
*   **Screen Header:** Title and Date context.
*   **Module 1: KPI Row (Horizontal Scroll/Slider)** 
    *   Mood Score, Stress Level, Energy Level, Sleep/Recovery Score.
*   **Module 2: AI Insight Strip (CIA)**
    *   Contextual prompt or correlation summary generated by CIA.
*   **Module 3: Action Grid (2x3 or dynamic tiles)**
    *   Journal, Mood, Stress, Breathing, Energy, Insights.
*   **Module 4: Schedule & Habits (Inferred)**
    *   Timeline of today's wellbeing activities and habit triggers.

## 4. Features and Capabilities
*   **KPI Dashboarding:** At-a-glance viewing of current mental and physical states with source-aware data badges.
*   **Quick Capture & Logging:** 1-tap access to log mood, check-in emotionally, or start a voice/text journal entry.
*   **Active Regulation Tools:** On-demand access to guided breathing exercises and soundscape/pulse audio.
*   **Scheduling & Vision:** Access to wellbeing calendar/schedule and the eye-health "Vision" tool (color tests, eye exercises).
*   **AI Correlation & Analytics:** Deep-dive into trends via the "Insights" module powered by CIA.

## 5. UI Copy (Verbatim Strings)
*   **Hub Title:** "Wellbeing"
*   **Nav Labels:** "Wellness", "Journal", "Mood", "Insights"
*   **Sub-page Titles:** "Breathing", "Energy", "Stress", "Habits", "Emotional Check-in", "Schedule", "Vision"
*   **Historical Labels:** "Sleep", "Water" *(Note: these are mapped as sub_pages of `/nutrition` and `/wellbeing` in source; inferred as shared metrics on the hub).*

## 6. Data Fields and Metrics
*   **Mood Score/Status:** User self-reported input.
*   **Stress Level:** User input / biometric inference.
*   **Energy Level:** User input / biometric inference.
*   **Sleep / Recovery Score:** *Source:* Wearable device (Whoop, Oura, etc.) via Health Connections.
*   **Readiness / HRV:** *Source:* Wearable device (raw metrics vs. proprietary house score).
*   **Journal Entry Count (Inferred):** *Source:* Local database / quick-notes BFF.
*   **Habit Completion State (Inferred):** *Source:* User input.

## 7. Screen States
*   **Loading / Syncing:** Skeleton loaders for KPI row; spinner indicating wearable data sync in progress.
*   **Empty:** Prompts to "Log your first mood" or "Start a journal entry".
*   **Error / Stale:** Warning indicators on data cards if wearable API sync fails or data is outdated.
*   **Disconnected:** Fallback UI prompting user to connect a health device to populate recovery/sleep metrics.
*   **Success / Active:** Completion animations after logging a mood or finishing a breathing exercise.

## 8. Interactions and Gestures
*   **Swipe/Scroll:** Horizontal scrolling through the KPI row (Mood, Stress, Energy, Sleep).
*   **Tap:** Grid tile navigation to deep-dive modules; tapping KPI cards for metric detail views.
*   **Long-press (Inferred):** Quick-actions on grid tiles (e.g., long-press "Mood" to instantly log a 5-star rating without leaving the hub).
*   **Motion Intents:** Smooth, calming transitions for breathing/mindfulness tool launches; haptic feedback on mood check-ins.

## 9. Free vs. Premium Gating
*   **Free Tier:** Basic mood logging, simple journaling, standard breathing exercises.
*   **Premium Gating:** Advanced CIA Insights (correlations between mood, sleep, and habits), provider-specific biometric score breakdowns, advanced mind constellation/observatory view for journal history. *(Note: Exact entitlement matrix requires final product slicing).*

## 10. Cross-Domain Hooks
*   **CIA Insights (AI Layer):** Strip at the top of the screen dynamically displaying correlations (e.g., "Your stress drops 20% on days you journal").
*   **Health Connections:** Bi-directional link to the health/wearable domain to pull sleep, HRV, and recovery data into the Wellbeing KPI row.
*   **Nutrition Domain:** Shared "Sleep" and "Water" metrics impact both energy and stress scores.
*   **Knowledge Graph:** Saving journal reflections or CIA wellbeing insights directly to the Wiki/Knowledge base.

### ⚠️ Source Contradictions & Flags
1.  **Coach Persona Naming:** Source documents mention `SIA`, `Sage`, and "AI life coach". Per brief instructions, all have been consolidated strictly to **CIA**.
2.  **Route Mapping Ambiguity:** The "Mentionable Product Pages" matrix defines "Sleep" and "Water" as `sub_page` types of `/nutrition`, while logically they belong on a `/wellbeing` hub. Inferred as shared KPIs.
3.  **Provider Neutrality:** Source documents explicitly note the current app is heavily tied to `/whoop`, but directives state the redesign must be provider-neutral ("Health Connections"). IA has been adjusted to reflect generic health data sources rather than Whoop-specific tiles.
