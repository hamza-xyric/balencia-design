# Balencia Native App — Screen 08: Initial Plan Summary

## 1. Header
- **Screen ID:** 08-initial-plan-summary
- **Name:** Initial plan summary
- **Route(s) covered:** `/onboarding/plan-summary`
- **Tab:** Hidden (Onboarding stack)
- **Source:** Functional Content Brief: Initial Plan Summary
- **Batch:** 1

## 2. Purpose
To reveal the user’s AI-generated, cross-domain life plan for the first time. This screen transforms conversational onboarding inputs into a structured, gamified roadmap. It acts as the emotional "reveal" moment to motivate the user to accept their baseline and enter the main app.

## 3. Entry & exit
- **Entry paths:** 
  - Standard user: Crossfade transition from the CIA Onboarding Conversation (Screen 07).
  - Edge case: Direct route if user skips conversation (generates a starter plan with minimal axes).
- **Exit paths:**
  - Primary exit: Tap "start your journey" CTA → triggers a root reset (onboarding stack destroyed). Lands on Home Screen (Screen 12) in the Today tab.
  - Secondary exit: Tap "customize" to enter inline editing mode, or tap individual edit icons to adjust specific goals before continuing.

## 4. Layout anatomy

**Regions (top-to-bottom):**
1. **Status Bar Zone:** Transparent overlay for native time/battery.
2. **Top Bar:** Back chevron for returning to the conversation.
3. **CIA Header:** Small CIA avatar, Display headline, and coaching preamble note.
4. **Hero Constellation Radar:** Top focal point. A multi-axis radar showing the user's baseline across chosen domains, anchored by the central Life Power score.
5. **RPG Status Band:** A horizontal glass pill containing the starting Level, 0 XP, and the MomentumBar.
6. **Starting Domain StatBars:** A compact, legible companion list mapping precise baseline values beneath the radar.
7. **Goal Plan Cards (Vertical Stack):** One SolidCard per established goal containing domain tags, an inline edit pencil, expandable action lists, a milestone timeline, and a cross-domain connection tooltip.
8. **CTA Area:** Primary action button ("start your journey") with secondary text link ("customize") beneath.

## 5. Components
*   **TopBar** — Transparent header with back chevron (44px target).
*   **CIAInsightCard** — Used for the hero header area to introduce the CIA's work; houses the `CIAPresenceOrb` and introductory copy.
*   **GlassCard (hero)** — Container for the Constellation Radar.
*   **NEW: ConstellationRadar** — *Rationale:* The standard `TrendChart` is linear. The hero of this screen requires a custom radial chart mapping multi-axis baseline data to a central "Life Power" metric, with a dashed CIA projection vector.
*   **GlassStatCard (ring variant)** — Nested in the center of the radar to display the "Life Power" score using a `ProgressRing`.
*   **KPIRow** — Container for the RPG Status Band (Level, XP, Momentum).
*   **MomentumBar** — Embedded in the KPIRow to visualize the 0 XP starting state with a "ready" shimmer.
*   **ListRow** — Used sequentially to render the domain baseline stat bars (domain icon, name, value).
*   **SolidCard** — Base container for each Goal Plan Card to ensure text legibility of actions and milestones.
*   **ChipDomainTag** — Denotes the life area of each goal.
*   **NEW: MilestoneTimeline** — *Rationale:* A highly specific horizontal visual mapping out goal steps (○─○─◉─○). Standard progress bars do not illustrate discrete future steps and the "you are here" node state.
*   **BtnPrimary** — "start your journey" CTA.
*   **BtnGhost** — "customize" secondary link.

## 6. Visual treatment
*   **Background atmosphere:** `--bg-base` with the mandatory warm radial glow top-center. Because this is a CIA moment, an additional soft purple radial pool (`rgba(127, 36, 255, 0.12)`) sits behind the hero radar. 3-4% soft-light grain overlay applied globally.
*   **CIA Insight Header:** `.glass-frost` to elevate it above the base. Inner-glow: `--glow-cia` (#7F24FF). *Meaning:* Highlights the AI-driven generation of the plan.
*   **Hero Constellation Radar:** `.glass-card` (radius 40). Inner-glow: `--glow-you` (#FF5E00). *Meaning:* Represents the user's current effort and baseline reality. The radar shape itself uses a solid orange fill (12% opacity) for the baseline, with a dashed purple vector pointing toward the 90-day AI projection. Unassessed domains render as ghosted axes (`rgba(255,255,255,.05)`), never as zero values. 
*   **RPG Status Band:** `.glass-pill` shape. No inner glow (to preserve the 1-glow-per-card hierarchy, deferring to the radar above it).
*   **Goal Plan Cards:** SolidCard (`--surface-2`). No blur. Inner-glow: `--glow-done` (#34A853). *Meaning:* Represents completion, growth, and the actionable path forward. 
*   **CTA Area:** BtnPrimary pulses softly. Upon success (tap), the glow flashes `--glow-done` (#34A853) just before the root reset transition.
*   **The one hero type moment:** The Display H1 "here's your plan." set in Neue Montreal Medium 500, with the word "*plan*" wrapped in Tiempos Medium italic to spotlight the transition from conversation to structure.

## 8. Data & honesty states
Every metric ships 3 states to maintain the honesty invariant. No fabricated numbers.

**1. Life Power Score**
*   *Real:* `72` via `onboarding calculation`
*   *Low-confidence:* `~70` (muted 64%) via `estimated · low confidence`
*   *Honest-null:* `--` via `Not enough data yet — 3 more days`

**2. Domain Baselines (e.g., Fitness)**
*   *Real:* `18` via `you logged`
*   *Low-confidence:* `~15` (muted 64%) via `estimated · low confidence`
*   *Honest-null:* `Ghost Axis` (no score rendered, axis line hidden/dashed at 5% opacity) via `unassessed`

**3. RPG Experience (XP)**
*   *Real:* `0 XP` via `app state`
*   *Low-confidence:* N/A (Static deterministic state)
*   *Honest-null:* N/A (Static deterministic state)

## 9. All states
*   **Default:** Clean UI as specified. Radars mapped, timelines populated, CTA glowing softly.
*   **Skeleton:** Radial shimmer morphs into drawn data. Radar spokes and timeline paths are visible prior to data fill. RPG bar shows sweeping `--surface-3` blocks.
*   **Empty:** Renders 1-2 CIA starter goals. Radar shows minimal axes. Non-shaming microcopy: "Here's a starting point. I'll *learn* more about you as we go."
*   **Error:** Plan data hidden. `ErrorState` component centers the CIA error message: "I'm having trouble loading your plan. Give me a moment." with a BtnSecondary "retry".
*   **Success:** CTA glow flashes green (`--glow-done`), screen crossfades to Home Screen (Screen 12).
*   **Disabled:** If offline and attempting CTA, queue locally. If editing input is invalid, BtnPrimary drops to 40% opacity and ignores taps.

## 10. Motion & interaction
*   **Physical easing:** All entry animations use spring physics (stiffness 250, damping 25). Never linear.
*   **Feedback timing:** 150-250ms for all tap, expand, and toggle interactions (e.g., expanding goal actions, toggling checkbox previews).
*   **Glow behavior:** 
    - *Hero radar:* "Breathes" (slow 4s opacity pulse 55% -> 70% -> 55%) to signify living data.
    - *CTA:* Subtle 3s idle pulse to draw the eye. 
    - *Milestone nodes:* The first "next" node maintains a looping concentric ring pulse (orange).
*   **Draw-First Choreography:** Upon entry, ConstellationRadar strokes draw first, then Life Power score counts up (tabular-nums), then RPG MomentumBar shimmer travels left-to-right. Goal cards fade-up staggered (50ms offset) as they enter viewport.
*   **Haptics:** Light impact haptic on checkbox toggle. Medium impact haptic on full goal expansion.
*   **Reduced-motion path:** All draws and pulses resolve instantly to final state. Staggered card entries become a single 150ms crossfade.

## 11. Motivation-tier adaptation
*   **Low density:** Defaults to collapsed action lists. Milestone timelines hide intermediate steps, showing only Start and End nodes. Focuses on the immediate next step.
*   **Medium density (Default):** Shows 2-3 actions per card, with "+ and N more actions" expansion. Displays full 5-node milestone timeline.
*   **High density:** Automatically expands all action lists. Milestone timelines reveal sub-steps and detailed CIA connection tooltips by default to show the full roadmap.

## 12. Accessibility
*   **AA+ contrast pairs:** Paper-100 (`#FEFAF3`) on `--surface-2` (`#211008`) > 12:1. Paper-50 on BtnPrimary (`#FF5E00`) > 4.5:1. 
*   **44px targets:** All milestone nodes, edit icons, and the back chevron maintain a 44x44px minimum invisible tap target radius.
*   **Screen-reader labels:** The milestone timeline and radar chart expose explicit `accessibilityLabel` summaries (e.g., "Radar chart. Baseline fitness 18. Projected target 30."). Glyph-only buttons like the edit pencil announce as "Edit goal: Run a half marathon".
