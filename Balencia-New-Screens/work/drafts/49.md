# 5. Components
- **TopBar**: Transparent background, back chevron, RPG badge target.
- **CIAInsightCard**: `.glass-card` with `glow-cia` (purple), spark glyph, CIA voice.
- **TrendChart**: Embedded in SolidCard. Solid orange line (past), dashed purple line (projected), green dots (milestones).
- **KPIRow**: 3-column layout using `SolidCard` base.
- **GlassStatCard**: Used inside KPIRow to house specific metrics with provenance chips.
- **ListRow**: Used for measurements, includes value and green/orange delta arrows.
- **NEW: PhotoTimelineTrack**: A `SolidCard` containing a vertical line linking circular image thumbnails and date/AI data. *Rationale: Native vertical journey mapping requires a bespoke track element to visualize chronological progress effectively.*
- **SectionHeader**: Overline text with trailing `BtnGhost` (e.g., "compare").
- **FABQuickLog**: 56px orange circle bottom-right.
- **GlassNavBar**: Floating bottom pill.

# 6. Visual treatment
- **Glass tiers:** Selective glass. The `CIAInsightCard` uses `.glass-card`. The `TrendChart`, `KPIRow`, and `Measurements` use `SolidCard` (`--surface-2`) because they are data-dense regions requiring high legibility.
- **Semantic glow:** The `CIAInsightCard` uses a bottom-anchored `--glow-cia: #7F24FF` meaning *AI insight / cross-domain connection*. `GlassStatCard` for weight uses `--glow-you: #FF5E00` meaning *active user metric*.
- **Background atmosphere:** `--bg-base: #0A0A0F`. Mandatory warm radial gradient at top-center. CIA purple pool added beneath the coaching note.
- **Hero type moment:** The word "*Sleep*" in the CIA coaching note, rendered in Tiempos Medium italic.

# 9. All states
- **Default:** Fully populated data as laid out in wireframe.
- **Skeleton:** Depth-preserving `SkeletonState` blocks matching layout geometry; chart skeleton appears as axis + ghost line.
- **Empty (Cold-start):** Chart axes visible with empty containers. Stats rows show HonestNullStates. UI invites logging.
- **Error:** Component-specific failure messages with cached data retained. `ErrorState` rendering inside the failed card.
- **Success:** Toasts: "Photo saved and encrypted.", "Weight logged. Your trend will update shortly.", "Measurement saved."
- **Disabled:** The "compare" button (BtnGhost) is disabled (40% opacity) until ≥2 photos exist. Pro-tier AI features are gated via `PaywallLock` (blurred preview).

# 10. Motion & interaction
- **Chart scrubbing:** Touch-and-hold on `TrendChart` triggers a vertical crosshair tooltip with exact weight/date (spring 200ms).
- **Row expansion:** Tap `ListRow` to expand height and draw a 7-point sparkline inline (height transition 250ms, ease-out).
- **Comparison slider:** Drag circular handle horizontally over side-by-side photos to reveal "before/after" states.
- **FAB auto-hide:** `FABQuickLog` translates down + fades out on scroll-down; returns on scroll-up/stop (150ms).
- **Glow behavior:** `glow-cia` on the CIAInsightCard breathes (4s ease-in-out infinite) to signify AI activity.
- **Draw-first choreography:** On entrance, the `TrendChart` line and the vertical path of `PhotoTimelineTrack` physically draw themselves left-to-right/top-to-bottom over 600ms, emphasizing the journey.
- **Haptics:** Subtle impact on expanding rows, sliding comparison handle, and logging data.
- **Reduced-motion path:** Chart line and timeline track fade-in instantly (opacity only). FAB auto-hide is disabled (remains fixed). CIA glow stops breathing (static opacity).

# 11. Motivation-tier adaptation
- **Low:** UI simplifies. Hides BMI/Body Fat KPIs (reducing cognitive load). Chart range limited to 1M view. AI badge hidden. `FABQuickLog` label changes to "Quick log". CIA tone shifts: "You showed up. That's what matters."
- **Medium:** Default layout as specified.
- **High:** Surfaces lean mass estimates in KPIs. Reveals all-time min/max ranges on the chart. Adds phase grouping labels (e.g., "Cutting Phase") to the timeline. Surfaces highly specific statistical correlations in CIA copy.

# 12. Accessibility
- **Contrast:** Paper-100 (#FEFAF3) on `--bg-base` (#0A0A0F) and `--surface-2` (#211008) exceeds AA+ (16:1+). Paper-64% on `--surface-2` passes AA for body text.
- **Targets:** TopBar icons, FAB, Nav items, and `BtnGhost` elements ("compare") strictly maintain 44x44px hitboxes.
- **Screen-reader labels:** Chart scrubber has `Accessibility.Range` label ("Weight trend graph, 72 kilograms on October 12"). Glyph-only buttons (back, settings) have `aria-labels`. Disabled "compare" button announces "Compare photos, disabled, take at least two photos to compare".
