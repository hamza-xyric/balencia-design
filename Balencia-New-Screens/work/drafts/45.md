# Balencia Glass Design Spec: 45-daily-checkin

## 1. Header
- **Screen ID:** 45-daily-checkin
- **Name:** Daily check-in
- **Route(s) covered:** /today/check-in
- **Tab:** Today
- **Source:** Functional Content Brief: Daily Check-in (Morning / Evening)
- **Batch:** 5

## 2. Purpose
The Daily Check-in is Balencia’s emotional pulse—a gentle, reflective ritual that bookends the user’s day to capture mood, energy, stress, and intention. The captured data feeds CIA’s understanding of emotional patterns, enabling cross-domain insights and correlations. 

## 3. Entry & exit
*Note: Corrected brief contradiction. The brief specified auto-triggering the check-in as a full screen "Stack push" from Habits, while simultaneously defining drag-to-dismiss modal gestures. Auto-triggers must use a modal sheet to avoid jarring full-screen takeovers and respect the defined drag-down dismissals.*
- **Entry paths:** Modal presentation. 
  - Home Screen [12]: Time-aware prompt card.
  - CIA Chat [09]: Deep-link via "how are you feeling?".
  - Habits [38]: Evening habit row.
  - System Notifications / Auto-trigger: First app open before 12:00 PM, or after 6:00 PM if morning check-in exists.
- **Exit paths:**
  - **Submit:** Saves data, dismisses modal, returns to origin screen with success toast.
  - **Cancel / Drag-Down:** Dismisses without saving. Prompts unsaved confirmation if content exists.

## 4. Layout anatomy
**Regions top-to-bottom:**
1. **Modal Header:** Scrim grabber, cancel button, title, save/update button.
2. **Hero / Time-Aware Greeting:** Warm radial atmosphere, CIA breathing orb (passive), dynamic greeting, streak meta. 
3. **Mood & Energy Metrics:** Solid data cards containing selectors, inputs, and premium trend sparklines. 
4. **Intention / Reflection:** Glass card with text input for morning focus or evening reflection. 
5. **Tomorrow / Insight (Evening only):** CIA insight card previewing the next day.
6. **System & Actions:** Submit CTA, safety layer, fixed bottom nav.

- **GlassPillInput** (Multiline variant for context notes & intentions).

- **GlassNavBar** (Floating bottom pill).

  - *Rationale:* The catalog lacks a continuous scrubbing input with dual-end labels and snapping ticks specifically for visceral 1-10 emotional scaling. 

## 6. Visual treatment
- **Glass tiers:** 
  - `.glass-frost` on the Hero Greeting card to immersive effect over the purple pool atmosphere.
  - `--surface-2` (SolidCard) used heavily for the data-dense metric selectors (Mood, Energy, Stress) to maximize legibility.
  - `.glass-pill` for the EmotionScaleBar track.
- **Semantic glow:** 
  - Hero Greeting: `--glow-cia` (CIA presence, empathetic tone).
  - Intention/Reflection Card: `--glow-you` (User focus, active input).
  - Tomorrow/Insight Card: `--glow-done` (Closure, looking forward).
- **Background atmosphere:** Base `--bg-base` (`#0A0A0F`) overlaid with the mandatory soft warm radial glow at top-center. A secondary purple pool is rendered at the 40% mark to anchor CIA moments.
- **Hero type moment:** "Good evening. Let's close out your day." in NM Medium 34pt. The word *evening* is set in Tiempos italic for the single editorial hero moment of the screen.

## 8. Data & honesty states
Every metric on this screen honors the 3-state honesty invariant:

1. **Mood Emoji & Rating (`mood_logs.mood_emoji`)**
   - **Real:** 😐 (Meh) selected, highlighted ring. ChipProvenance reads `you logged`.
   - **Low-confidence:** Not applicable (Direct user input bypasses confidence estimation).
   - **Honest-null:** Dashed outline ring around emojis. Caption reads: `Select a mood to save`.
2. **Energy Level (`daily_checkins.energy`)**
   - **Real:** Scrubber set to 7. ChipProvenance reads `you logged`.
   - **Low-confidence:** Not applicable (Direct user input).
   - **Honest-null:** Scrubber sits at 0. Ghosted track. Caption reads: `Slide to set energy`.
3. **Trend Sparklines (High Motivation only)**
   - **Real:** Solid orange 7-pt line. ChipProvenance reads `last 7 days`.
   - **Low-confidence:** Dashed purple line. ChipProvenance reads `estimated`.
   - **Honest-null:** Ghosted baseline. Caption reads: `Not enough data yet — 3 more days`.
4. **Tomorrow's Events (Calendar Sync)**
   - **Real:** "Big presentation at 9:00 AM". ChipProvenance reads `via Calendar`.
   - **Low-confidence:** Not applicable.
   - **Honest-null:** Empty state reads: `nothing on the calendar tomorrow.`

## 9. All states
- **Default:** Standard interactive state with solid metric cards and glass hero.
- **Skeleton:** Sheet slides up; content staggers in. Shimmer blocks match input geometries. Sparklines animate via stroke-draw.
- **Empty / Cold Start:** Sparklines omitted. Emojis rendered 15% larger. Hero copy changes: "This is your first check-in. It takes less than a minute."
- **Error:** Red border flash on inputs/CTA (280ms) with toast copy. All user input is preserved locally. 
- **Success:** BtnPrimary flashes green (`--glow-done`) for 600ms. Sheet springs down. Success toast spawns on Home Screen.
- **Disabled:** Save button remains at 40% opacity, no glow, unclickable. Copy reads: `Select a mood to save`.
- **Offline:** `.glass-pill` banner pinned to top: `offline — showing last sync 2h ago`. Inputs remain active. CTA changes to `save locally`.

## 10. Motion & interaction
- **Physical easing:** Standard `cubic-bezier(0.32, 0.72, 0, 1)` for sheet slide-up (520ms) and component staggering.
- **Feedback:** 150-250ms scale `.98` and glow brighten on Emojis and Tags.
- **Glow behavior:** `.glass-card` utilizes a continuous 4s ease breathing animation on the CIA Orb. 
- **Haptics:** Light `impact` on tick snap during EmotionScaleBar drag. Medium `impact` on successful save.
- **Reduced motion:** Stroke draws, staggers, and orb breathing are completely bypassed. Elements appear instantly in their final canonical state. Sheet slide-up drops to a 150ms crossfade.

## 11. Motivation-tier adaptation
- **Low density:** Radically simplified. Viewport restricts to Mood Emojis + Save CTA. Sub 10-second completion. Background atmosphere is static.
- **Medium density (Default):** Full text inputs, context tags, energy/stress sliders, and CIA reflections active.
- **High density:** Optional trend sparklines render above metrics. "Compare to yesterday" indicator appears. Context note is expanded by default.

## 12. Accessibility
- **AA+ contrast pairs:** Paper-100 (`#FEFAF3`) on `--bg-base` (`#0A0A0F`). Orange active icons on `--surface-2` validated for minimum 4.5:1 text contrast.
- **44px targets:** All mood emojis, tags, and sliders feature a minimum 44x44px invisible touch padding. Bottom nav items strictly adhere to 44px height minimums.
- **Screen-reader labels:** The `EmotionScaleBar` announces localized values (e.g., "Energy level, 7 out of 10, high"). The `CIAPresenceOrb` is grouped and hidden from VoiceOver to prevent spam. The multiline inputs use explicit `accessibilityLabel` matching their overline.
