## Contracts (implement exactly)

**API** (in `pilot.ts`):
```ts
export type SendCiaChatArgs = { message: string; sessionId?: string; isOnboarding?: boolean; goal?: string };
export async function sendCiaChat(args: SendCiaChatArgs): Promise<AiCoachChatResponseDto>;
```
- POST `/ai-coach/chat`, body `{sessionId?, message, goal: args.goal ?? 'overall_optimization', isOnboarding: args.isOnboarding ?? false}`.
- **Idempotency-Key header on every send** (entitlement middleware `consumeCredits` requires it once enforcement leaves shadow mode): generate `cia-${Date.now()}-${Math.random().toString(36).slice(2)}`.
- No retry (mutation; the user retries explicitly via UI).

**Adapter** (`adapters/cia.ts`):
```ts
export type CiaGate = 'feature_disabled' | 'credits_exhausted' | 'plan_upgrade_required' | 'client_error' | null;
export type CiaMessageVM = {
  id: string; role: 'user' | 'cia'; text: string;
  phase?: string; suggestedActions?: string[];
  pending?: boolean; failed?: boolean;
};
export function toCiaMessage(dto: AiCoachChatResponseDto): CiaMessageVM;  // role 'cia', text = dto.message, id = `cia-${dto.sessionId}-${counter or timestamp}`
export function classifyCiaError(err: unknown): { gate: CiaGate; userMessage: string };
```
`classifyCiaError` mapping (from `ApiError.status` + `.code`):
- 402 + `FEATURE_DISABLED` → gate `feature_disabled`, copy: "Cia coaching isn't part of your current plan."
- 402 + `CREDITS_EXHAUSTED` → gate `credits_exhausted`, copy: "You've used all your coaching credits for now."
- 400 + `MISSING_IDEMPOTENCY_KEY` → gate `client_error`, copy: "Something went wrong sending that. Try again." (and this is a client bug — the header must always be sent)
- 402 + `PLAN_UPGRADE_REQUIRED` → gate `plan_upgrade_required`, copy: "This needs a plan upgrade."
- anything else → gate `null` (transient failure), copy: "Cia couldn't reply just now. Tap to retry."
Each gate gets DISTINCT honest copy — never a fake Cia reply, never a dead end.

**Hook** (`use-cia-chat.ts`):
```ts
export type CiaChatState = { messages: CiaMessageVM[]; sessionId: string | null; sending: boolean; gate: CiaGate; gateMessage: string | null };
export function useCiaChat(opts?: { isOnboarding?: boolean; starter?: CiaMessageVM }): CiaChatState & {
  send(text: string): Promise<void>;
  retry(messageId: string): Promise<void>;   // re-send a failed user message
};
```
- `useReducer` internally. `send`: append user msg + a `pending` Cia placeholder immediately (<100ms feedback); on response replace placeholder via `toCiaMessage` and store `sessionId` (threaded into subsequent sends); on error mark the user message `failed`, remove placeholder, set `gate`/`gateMessage` via `classifyCiaError`.
- `retry` re-sends a failed message's text (clears its failed flag while in flight).
- All visible copy uses **Cia** (exact casing).
