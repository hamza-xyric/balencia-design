# 2. Purpose
A browsable, honest discovery catalog answering "what else can I do in this app?" without forcing the user to ask CIA. Surfaces cross-domain intelligence via a single, authoritative focal point (the Life Constellation), followed by an AI-driven rail and a dense, navigable grid of domains and standalone tools.

# 3. Entry & exit
**Entry:**
- Pushed from Me Main `[17]` via the "see all" link in the Explore preview section.

**Exit:**
- **Primary:** Tap any module card → pushes specific domain dashboard `[26-36]`, standalone feature `[37-41, 45-48, 59, 61-62]`, or wellbeing feature `[44, 49, 52-58, 60, 63]` to the stack.
- **Secondary:** Tap Back button or screen edge swipe → pops stack back to Me Main `[17]`.
- **Tertiary:** Search filter → hides UI to show only matching modules.

# 8. Data & honesty states
Every metric renders through three explicit states. Provenance chips are mandatory on real data.

**Metric 1: Domain Stat (0-99) & Level**
- **Real:** KPI 87 · `Lv. 12` · `ChipProvenance`: "synced today"
- **Low-confidence:** 87 at 64% opacity · `estimated · low confidence`
- **Honest-null:** `Not enough data yet — 3 more days` (Metric completely hidden)

**Metric 2: AI Suggested Modules**
- **Real:** Suggested Module Card · `ChipProvenance`: "via CIA · 99% match"
- **Low-confidence:** Suggested Module Card · Caption: `estimated · low confidence`
- **Honest-null:** Silent UI swap to static `Popular with Balencia` cards.

**Metric 3: Constellation Radar (Life Power Shape)**
- **Real:** Polygon fully drawn with green milestone dots on active domains. `ChipProvenance`: "cross-domain sync"
- **Low-confidence:** Polygon dashes set to purple, 64% opacity. `estimated · low confidence`
- **Honest-null:** Polygon hidden, replaced with quiet glyph: `Not enough data yet — explore 2 more areas`

# 9. All states
- **Default:** Radar drawn, domains listed with XP progress, AI rail populated.
- **Skeleton:** Layout geometry preserved. AI rail and Domain rows are `SkeletonState` shimmer blocks (`--surface-3` base, 1.2s sweep). Radar shows axis rings + ghost line.
- **Empty (Day 1 / Cold Start):** Full catalog visible, no locks. AI rail shows 3 "start here" cards. Radar shows only the center hub, with copy: "Explore what Balencia can *help* with."
- **Error (Network):** Surfaces remain navigable via cached data. `OfflineBanner` shows "You're offline — showing your last cache." Pull-to-refresh dimmed.
- **Success:** Upon tapping a module, card scales to `.98` and routes to the next screen.
- **Disabled:** Premium modules render via `PaywallLock`. The underlying layout is blurred 20px, accompanied by a lock glyph, tier text ("Plus"/"Pro"), and a single orange `BtnPrimary` "Unlock with premium".

# 10. Motion & interaction
- **Physical Easing:** `cubic-bezier(0.32, 0.72, 0, 1)` used universally. No linear motion.
- **Entrance Choreography:** Search bar fades up (150ms). Radar polygon self-draws (`stroke-draw` 1200ms). Suggested cards stagger (40ms delay each). Domain sections fade sequentially.
- **Feedback:** 150-250ms. Tapping a card scales it to `.98` + brightens its semantic glow.
- **Glow Behavior:** The HeroConstellationCard uses a slow 4s breathing scale (1.0 to 1.02) on its inner glow.
- **Haptics:** Light selection haptic on domain row tap. Medium success haptic when AI suggestions finish loading.
- **Reduced Motion (`prefers-reduced-motion: reduce`):** All elements snap to final state instantly. Radar renders as a completed static polygon. No card scaling.

# 11. Motivation-tier adaptation
- **Low Density:** Hides XP numbers, stat levels, and radar polygon. Shows only a 1-line sub-copy and the domain title, reducing cognitive load to simple journaling entries.
- **Medium Density (Default):** Shows radar, domain levels (e.g., `Lv. 8`), and 8px progress bars. 
- **High Density:** Replaces the radar with a dense 2-column grid of `KPIRow` components showing exact tabular XP numbers (e.g., `1,240 / 1,500 XP`), `% to next level`, and continuous 12px multi-segment progress bars.

# 12. Accessibility
- **AA+ Contrast Pairs:** `#FEFAF3` (paper-100) on `#0A0A0F` (bg-base). `#FF5E00` (Burnt Orange) on `--surface-2` meets AA for UI components.
- **Targets:** All list rows, bottom nav tabs, and search bars strictly maintain the 44px minimum touch target.
- **Screen-reader:** Glyph-only controls in the TopBar have `accessibilityLabel` overrides (e.g., "Search modules"). Lock icons on PaywallLock announce "Premium feature locked."
