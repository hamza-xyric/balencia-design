# 1. Header
- **Screen ID:** 15
- **Name:** Create / edit mission
- **Route(s) covered:** `/missions/new`, `/missions/edit/:id`, `/missions/chain/:parentId`
- **Tab:** Goals (Modal full-screen overlay)
- **Source:** Brief: 15-create-edit-goal
- **Batch:** 6

# 2. Purpose
Transforms a user's natural-language intention into a structured, actionable mission plan. CIA decomposes the text into mission type, domain assignments, tactical actions, milestones, and tracking signals, while allowing the user absolute editing control to maintain honesty and agency over their path.

# 3. Entry & exit
- **Entry paths:** 
  - Create: Slides up from Mission Board [13] FAB "+".
  - Edit: Slides up from Mission Detail [14] "edit" button.
  - Chain: Slides up from Mission Detail [14] chain "modify" action.
- **Exit paths:**
  - Cancel: Drag down (>120pt) or tap "✕" to dismiss without saving.
  - Create success: Slides down to Mission Board [13] after green flash + haptic.
  - Edit/Chain success: Slides down to respective Mission Detail [14] after green flash + haptic.

# 4. Layout anatomy
**Regions (Structured Result State):**
1. **Header:** Drag grabber, Title, Close button.
2. **Chain Context:** Conditional banner showing parent mission link.
3. **Prompt Summary:** Collapsed text input of the user's goal.
4. **Mission Type & Domains:** CIA classification, reasoning, and life domain tags.
5. **Actions & Milestones:** CRUD tactical steps with target dates.
6. **Tracking & Connections:** Toggles for metrics and cross-domain visual links.
7. **Preview & CTA:** Settings (Strictness/Difficulty), gamification preview, and primary save button.

# 5. Components
- `Sheet` (variant: `full`) - Base modal container with scrim.
- `TopBar` - Handles standard navigation and close glyph.
- `SolidCard` (variants: `default`, `elevated`) - Used for dense data regions (Type/Domains, Tracking/Connections, Actions).
- `GlassCard` (variant: `hero`) - Reserved strictly for the Mission Preview to emphasize the gamification payout.
- `SegmentedTabs` - Used for Strictness and Difficulty selections.
- `ChipDomainTag` - Domain color mapping (Fitness, Nutrition).
- `ListRow` (variant: custom inline edit) - Actions and milestones list.
- `Toggle` - Tracking signal opt-ins.
- `ProgressRing` & `ProgressBar` - Live XP and level-up visualizations.
- `HonestNullState` - Used gracefully if estimated XP curve data is missing.
- `EmptyState` - First-use state replacing the cycling text examples.
- `BtnPrimary` - CTA ("create mission" / "save changes").
- `NEW: ReorderableListRow` - A drag-handle enabled `ListRow` variant native to iOS/Android. *Rationale: The catalog lacks a list item explicitly supporting native drag-and-drop reordering which requires an anchored trailing handle.*

# 9. All states
- **Default (Cold-Start):** `EmptyState` component centered with the prompt copy. BtnPrimary is disabled (40% opacity).
- **Processing:** Input shrinks and locks. `IntelligenceTimeline` renders with staged Caption lines ("analyzing domains..."). Background atmosphere pools purple.
- **Structured Result:** Full layout populated. Sections stagger in (80ms). BtnPrimary active.
- **Empty Actions:** Action list empty. BtnPrimary disables. Hint copy shows beneath list.
- **Error:** Modal shakes lightly ( xOffset ±2px, 150ms ). Input re-expands preserving text. `ErrorState` copy inline above input.
- **Offline:** User attempts save. `OfflineBanner` appears (`offline — mission not saved. Check your connection.`). Data persists locally.
- **Success:** BtnPrimary flashes green (`--glow-done`). Modal slides down. Haptic triggers.

# 10. Motion & interaction
- **Easing:** Physical, spring-based easing for all modal presentations and state morphs (`spring(stiffness: 300, damping: 30)`). No linear transitions.
- **Feedback:** 150ms scale `.98` on all tappable targets (Cards, SegmentedTabs, Actions).
- **List Reordering:** Long press drag handle lifts the row (shadow expands, neighboring rows ease apart via translateY). Haptic light tick on lift and drop.
- **Mission Preview Choreography:** 
  - Ring draws clockwise (520ms).
  - XP number counts up using `tabular-nums` (280ms).
  - Level-up ProgressBar eases to new width (520ms, ease-out).
- **Reduced Motion (`prefers-reduced-motion: reduce`):** 
  - Processing timeline dots pulse opacity only (no rotation/shimmer).
  - Staggered section entry becomes instant fade.
  - Mission preview counts and rings snap to final state (0ms).
