# Garmin Connect — UI Reference

Companion app for Garmin watches; broad multi-sport + health hub. Dark, card/widget-grid, very dense. **22 screenshots** (`app-store/` 8 · `google-play/` 8 · `community/` 6). Sources: `sources.md`, `community-sources.md`.

## Screens captured & features shown

| Screen | Key UI / features visible |
|--------|---------------------------|
| **Home dashboard** | Today's Activity (e.g. running), "In Focus" Sleep Score chart, customizable widget feed |
| **At a Glance cards** | Reorderable summary cards: steps, HR, body battery, intensity minutes, etc. |
| **Activity detail** | Per-workout metrics (pace, HR zones, map, splits) |
| **Health metric detail** | Drill-down chart for a single metric over time |
| **Training / performance** | Training status, load, VO₂ max, performance metrics |
| **Hydration tracking** | 1d/7d/4w/1y views, **Quick Add** water logging |

## Patterns relevant to Balencia
- **Customizable widget/card feed** — user reorders what matters; relevant to Balencia's modular home and life-area cards.
- **"At a Glance"** stacked-card pattern = the dashboard-of-dashboards model Balencia uses across domains.
- **Hydration with Quick Add + multi-range chart** — Balencia *does* spec water intake (`44-water-intake`); good direct comparator.
- Breadth over polish: Garmin shows how to surface *many* metrics, but the UI is busy — a cautionary contrast to Balencia's premium bar.
- Deepest **training/performance science** (VO₂ max, training load) of the set.
