# 2. Purpose
Provides a gateway to guided yoga practice, surfacing streaks, filterable sessions, and instructional poses. Manages the full session lifecycle from browsing to active practice and post-session summary. 

# 3. Entry & exit
- **Entry paths:** Stack push from Explore [18], Fitness [26], CIA Chat [09] (deep-link), or Home Screen [12].
- **Primary exit:** Forward to Active Session mode (full-screen takeover, tab bar hidden).
- **Secondary exits:** Stack pop back to origin, tap on CIA note to route to CIA Chat [09], tap RPG badge to route to RPG Character [19], tap pose card to expand Pose Detail modal.

# 4. Layout anatomy

1. **TopBar:** Transparent over atmosphere, gains `.glass-pill` on scroll. Holds back chevron, H1 "Yoga sessions", and RPG level badge.

# 5. Components
- **TopBar**: Standard transparent to pill header.
- **GlassCard**: `hero` variant for the streak banner.
- **CalendarStrip**: Used inside the hero card to show the 7-day heatmap.
- **CIAInsightCard**: Standard purple-tinted card with spark glyph.
- **SegmentedTabs**: Difficulty filter.
- **SolidCard**: `default` and `elevated` variants for sessions and stats.
- **ProgressRing**: Embedded in stats SolidCard for "Poses mastered".
- **KPIRow**: Embedded in stats SolidCard for sessions/hours.
- **TrendChart**: Weekly practice sparkline.
- **GlassNavBar**: Bottom navigation.
- **FABQuickLog**: Global quick action.
- **Sheet**: Used for Post-Session Summary and Pose Detail.
- **GlassPillInput**: Used for session notes in Summary sheet.
- **BtnPrimary, BtnSecondary, BtnGhost**: Action buttons.
- **NEW: SessionCard**: A `SolidCard` list item optimized for media thumbnails, metadata rows, and inline actions. Rationale: Standard `ListRow` is too text-heavy and doesn't support a large leading media thumbnail gracefully. 
- **NEW: PoseTimerRing**: A specialized massive `ProgressRing` (stroke 12px) with a tabular-nums timer inside, built for the active session takeover. Rationale: The standard ProgressRing is too small for full-screen timer UX.

# 9. All states
- **Default:** Fully populated data, beginner filter pre-selected.
- **Skeleton:** Depth-preserving layout. Heatmap cells, gauge arcs, and card lines shimmer (`--surface-3` base, 1.2s sweep). Text reads "Loading your *practice*...".
- **Empty (Day-1):** Stats display a true "0". CIA note reads: "Yoga builds strength and calm. Let's start with a *beginner* session." Gauge is ghosted (track only).
- **Error:** Graceful per-section degradation. Cached data shown if available. Streak error: "Couldn't load your streak. Pull to refresh." Sessions error: "No sessions at this level right now. Try beginner or refresh." Active session timer continues on local device clock if network drops.
- **Success (Active -> Paused):** Timer freezes, background dims to 40% opacity, "Pause" button toggles to "Resume".
- **Disabled:** Post-session "Done" BtnPrimary remains at 40% opacity with no glow until a difficulty rating is selected. Prompt: "Select a rating to *continue*."

# 10. Motion & interaction
- **Easing:** Physical easing only (`cubic-bezier(0.4, 0.0, 0.2, 1)`), never linear.
- **Feedback timing:** 150-250ms for all taps, haptic taps on button presses and filter changes.
- **Glow behavior:** Hero streak card glow "breathes" (4s ease-in-out subtle opacity pulse). Active PoseTimerRing flashes `--glow-done` (green) for 250ms upon completing a hold.
- **Motion intent (Browse):** Elements stagger entry (fade-in + 12pt slide-up). Line charts draw left-to-right.
- **Motion intent (Session):** Pose transitions use a 280ms crossfade. Timer sweeps counterclockwise.
- **Motion intent (Summary):** XP badge scales up with a green glow. Stat numbers count up from 0 to final value using tabular-nums.
- **Reduced-motion path:** Crossfades become instant cuts. Glows remain static. Count-up animations jump directly to final value.

# 11. Motivation-tier adaptation
- **Low density:** Pose library and bottom Stats Grid are hidden to reduce cognitive load. Focus is placed entirely on the Streak Hero, CIA recommendation, and the next single guided session.
- **Medium density (Default):** Layout exactly matches Section 4 wireframe. Stats are condensed to one row; Pose Library shows 6 items (2x3).
- **High density:** Stats Grid expands to show the Library Mix Donut. Pose Library grid expands to 9 items (3x3). Last 10 sessions are visible without scrolling.
*(Correction noted: Brief originally demanded a strict 6-pose UI limit while simultaneously calling for a 9-pose expansion in high-motivation. The grid component is now flexibly designed to handle 6 or 9 without breaking layout).*
