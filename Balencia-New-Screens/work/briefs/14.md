# Functional Content Brief: Mission Detail

## 1. Purpose
The Mission Detail screen provides a deep, single-view of a user’s specific objective. It answers “am I on track?” via a scannable summary, and “what’s the complete picture?” via expandable progressive disclosures, always highlighting the immediate next physical action.

## 2. Entry and Exit Paths
*   **Entry Paths:**
    *   **Mission Board [13]:** Stack push via tapping a mission card.
    *   **Home Screen [12]:** Stack push via tapping a pinned mission card.
*   **Exit Paths:**
    *   **Mission Board [13] / Home Screen [12]:** Stack pop via back button or iOS swipe-right-from-edge.
    *   **Create Mission [15]:** Modal present via tapping the edit button (opens in edit mode).
    *   **CIA Chat [09]:** Tab switch via tapping "Ask CIA" shortcut.
    *   **Domain Dashboards [26-36]:** Stack push via tapping domain tag chips.
    *   **Other Mission Details [14]:** Stack push via tapping cross-domain connections or chain mission links.

## 3. Complete Information Architecture
**Top-to-bottom hierarchy:**
1.  **Navigation Bar:** Back, center title (fades in on scroll), Pin toggle (max 3 limit), Edit.
2.  **Hero Progress Ring:** The single dominant visual element communicating completion percentage.
3.  **Mission Identity Block:** Center-aligned Mission Name, Type Badge, and tappable Domain Tags.
4.  **Stats Row:** KPI tiles showing Action count, Life Area count, Streak, XP, and Difficulty.
5.  **CIA Coaching Card / Stalled Nudge:** Contextual intelligence card. Conditionally displays either standard coaching or a stalled intervention if 7+ days inactive.
6.  **Next Action Card:** The primary call-to-action and most prominent interactive element. Displays the immediate next step.
7.  **Expandable Detail Sections:** Collapsed by default, revealing depth on demand:
    *   All Actions (Sub-goal StatBars)
    *   Milestones (TimelineAgenda)
    *   Mission Chain (ChainProgressBar + next steps)
    *   CIA's Reasoning (Text)
    *   Cross-Domain Links (Connected Mission Cards)
    *   Progress Over Time (XP Living Line Chart)
8.  **Ask CIA Card:** Conversational escape hatch at the bottom.

## 4. Features and Capabilities
*   **Action Completion:** Tap large checkboxes on the Next Action card or within the All Actions list to complete actions. Triggers ring animation.
*   **Home Pinning:** Toggle home screen visibility (subject to a 3-pin maximum).
*   **Mission Editing:** Full edit capabilities via Create Mission modal.
*   **Stalled Mission Resolution:** If stalled, users can adjust timeline, reduce scope, pause, or archive directly from CIA's intervention card.
*   **Chain Progression:** View past, current, and future linked missions. Users can accept, modify, or dismiss CIA’s suggestion for the next chain step.
*   **Cross-Domain Navigation:** Deep link between connected missions across different life domains.
*   **Data Scrubbing:** Long-press/scrub the Progress Over Time chart to see exact weekly metrics.
*   **CIA Chat Integration:** Open the chat interface with the mission context pre-loaded.
*   **Archive Management:** Restart archived missions, delete them permanently, or add reflection notes.

*   **CIA Coaching (Variants):** "Strong momentum this week. Your tempo runs are paying off." / "You're 2 days behind schedule. Ready to adjust, or just keep the pace steady." / "On track to finish 2 weeks early."

## 6. Data Fields and Metrics
*   **Mission Completion %:** *Source: `mission.progress`* (Drives hero GaugeRing).
*   **Action Count & Life Area Spread:** *Source: `missionActions`* (Drives KPI tiles and 3-segment life-area donut).
*   **Streak (Days) & XP Earned:** *Source: `mission.streak`, `mission.xp`* (Drives KPI tiles).
*   **Difficulty Tier (Easy/Moderate/Hard):** *Source: `mission.difficulty`* (Drives difficulty dot/label).
*   **Days Since Last Action:** *Source: `mission.days_since_last_action`* (Triggers CIA Stalled Nudge if ≥ 7).
*   **Sub-Goal Completion:** *Source: `missionActions`* (Drives StatBars inside All Actions).
*   **Milestone Status & Dates:** *Source: `missionMilestones`* (Drives TimelineAgenda).
*   **Chain Step Data:** *Source: `mission.chainPosition`, `missionChain`* (Drives ChainProgressBar).
*   **XP Trend & Projection:** *Source: `mission.xpTrend`* (Drives Living Line chart and dashed projection).

## 7. Screen States
*   **Cold-start / Day-1:** 0% ring with ghosted track, all stats zero, CIA suggests first action. Timeline shows future nodes only. Chart reads "Calibrating".
*   **Loading / Partial:** Skeleton shimmers that morph into drawn data. Unsynced milestones appear dashed.
*   **Stalled (≥7d):** Non-shaming hold. Ring retains calm orange fill. CIA nudge card replaces standard note. Chart flat-trails.
*   **100% Complete:** Ring turns green, completion card replaces Next Action, chain "What comes next" auto-shows.
*   **Archived:** Ring turns neutral gray, Next Action replaced by Restart/Delete options, partial XP awarded.
*   **Error / Offline:** Local cache shown, "Chart unavailable" scoped locally to charts.

## 8. Interactions, Gestures, and Motion
*   **Gestures:** Standard tap for all buttons/checkboxes. iOS swipe-from-edge for back. Long-press chart for crosshair scrub.
*   **Motion Intents:** 
    *   *Hero Ring:* Sweeps 0→% on mount (520ms), re-sweeps on action completion.
    *   *Chart Drawing:* Lines draw left-to-right (never fade in). Dashed CIA projection draws *after* actual line. Timeline spine draws downward.
    *   *Next Action:* On completion, old card slides down/fades, new card slides up.
    *   *Section Expand:* Chevron rotates, content height opens. 
*   *Reduced Motion:* All drawing/stagger animations bypass; static final states rendered immediately.

## 10. Cross-Domain Hooks
*   **Cross-Domain Links Section:** Explicit module showing how the current mission connects to others (e.g., "This connects to your Finance goal because consistent exercise reduces healthcare costs"). Tappable mini-cards allow recursive navigation.
*   **CIA Reasoning:** CIA explicitly breaks down cross-domain strategy in its reasoning module.
*   **Life Area Donut:** Visualizes the spread of actions across 1, 2, or 3 different life areas within the Stats Row.
