# FUNCTIONAL CONTENT BRIEF: Data Sources Screen

## 1. Purpose
Establishes trust and transparency by displaying the health of external data integrations and visualizing how raw data from these sources is transformed into actionable coaching signals by the CIA.

## 2. Entry & Exit Paths
**Entry Paths (Arrives from):**
- Me Main Screen [17]
- Connected Services [22]
- Intelligence Dashboard [48]
- Knowledge Graph [72]
- CIA Chat [09] (via explanation deep-links)

**Exit Paths:**
- **Primary:** Tap "Connect source" → Provider Picker/OAuth flow [22].
- **Secondary (Source Detail):** Tap a data source row → Source detail sheet (permissions, sync history, disconnect/refresh).
- **Secondary (Correlation Detail):** Tap a correlation row/cell → Correlation detail sheet deep-linking to Knowledge Graph [72] or Intelligence Dashboard [48].
- **Back:** Returns to origin screen.

## 3. Information Architecture (Top-to-Bottom)
1. **Sticky Header:** "Data sources" title, labeled 44pt Back button.
2. **Correlation Engine Hero:** Explains the value proposition of connecting data.
3. **Connected Sources (Module):** Vertical list of active, stale, or errored data provider cards.
4. **Detected Correlations (Module - Focal Area):** A two-tier matrix showing the strength and direction of relationships between different data sources.
5. **Source Health Note:** A disclaimer explaining how CIA handles stale or unhealthy data.
6. **Footer Action:** Fixed "Connect source" primary CTA.
7. **Tab Bar:** Global navigation (Me tab active).

## 4. Features & Capabilities
- **Source Health Monitoring:** Real-time visibility into connection status (Healthy, Stale, Needs Attention/Failed) and last sync timestamp.
- **Data Source Management:** Ability to tap into a specific source to view sync history, manage data permissions, revoke access (disconnect), or force a refresh.
- **OAuth Provider Connection:** Initiation of secure connection flows for new data providers via a bottom sheet picker.
- **Cross-Source Correlation Detection:** Automated AI analysis identifying how variables in one domain (e.g., Calendar density) affect another (e.g., Stress/Tempo).
- **Correlation Matrix Interaction:** Explorable N×N grid of data sources; tapping cells provides specific correlation tooltips.
- **Data Confidence Transparency:** Visible indicators of the underlying sample size (days synced) validating each correlation.
- **Offline Mode:** Ability to view cached data when disconnected, with clear visual downgrading of the data's freshness.

## 7. Screen States
- **Cold-Start (No Sources):** Hero invites connection ("Connect your first source..."). Matrix shows ghosted cells. No purple CIA signal is present.
- **Loading / Analyzing (< 2 weeks):** Depth-preserving skeleton grid (pulsing). Copy explains the honest timeline.
- **Empty / Too-Few Sources:** Matrix renders sparsely; un-computed pairs are ghosted/dashed; prompts user to connect more sources.
- **Partial:** Computed correlation cells are shown alongside ghosted, un-computed cells.
- **Error (Sync Failed):** Failed source is explicitly named. Error copy provides a specific recovery action (e.g., "pull to refresh"). *Red text is never used for errors; red is reserved exclusively for the operational "Needs attention" glyph.*
- **Offline:** "Showing last synced data" banner appears. Data remains visible but is visually downgraded (opacity 0.7) to indicate staleness. 
- **Success (Refresh):** Brief green flash on the refresh action indicating "Stats refreshed".

## 8. Interactions, Gestures & Motion Intents
- **Tap Source Row:** Opens bottom detail sheet (permissions, history, refresh, disconnect). Disconnect requires explicit confirmation.
- **Tap Correlation Row:** Opens deep-link detail sheet for Knowledge Graph [72] or Intelligence [48].
- **Tap Correlation Cell:** Yields a tooltip pill detailing the specific source-to-source relationship.
- **Motion Intent (Draw vs. Fade):** Visual data strictly "draws" rather than fades.
  - Source health tiles stagger in; freshness numbers count up.
  - Correlation matrix cells fade/scale-in row-by-row on scroll.
  - Purple strength bars *rise* horizontally (0 to target width).
- **Reduced Motion:** All animations instantly snap to their final, settled canonical frame.

## 9. Free vs. Premium Gating
- The baseline trust-and-control surface (viewing source health, connection management, and detecting high-level correlations) is standard functionality.
- **Premium Hook:** CIA-driven deep-dive analysis of progress photos and specific AI insights routed to the Knowledge Graph [72] or Intelligence Dashboard [48] operate on a premium opt-in basis.

## 10. Cross-Domain Hooks (Correlations & CIA Insights)
This screen acts as the literal bridge between disparate life domains by showing how data bleeds over:
- **Sleep → Physical/Music:** "Sleep affects tempo pace" (WHOOP → Music tracking).
- **Work/Life → Stress:** "Calendar density stress" (Google Calendar → biometric tracking).
- **AI Explanation Hooks:** Tapping correlations routes the user to the CIA Chat [09] or Knowledge Graph [72] to explain *why* these cross-domain relationships exist (e.g., "On days you sleep 7+ hours, you maintain a steadier tempo").
