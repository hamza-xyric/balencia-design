# Functional Content Brief: Finance / Money Map Dashboard

## 1. Purpose
Provides a comprehensive, at-a-glance view of the user's financial health (income, expenses, budgets, savings). Integrates CIA’s life-system intelligence to connect spending patterns with other life domains, making this a holistic life-system dashboard, not just a standalone finance tracker.

## 2. Entry & Exit Paths
*   **Entry Paths:**
    *   *Explore Section (Screen 18):* Stack push.
    *   *CIA Deep-Link (Screen 09):* Stack push from CIA chat tab.
*   **Exit Paths:**
    *   *Transaction / Budget Detail (Screen 31):* Stack push via tapping a row.
    *   *CIA Tab (Screen 09):* Tab switch via tapping the CIA coaching note.
    *   *Goal Detail (Screen 14):* Stack push via finance-tagged goals.
    *   *RPG Character Screen (Screen 19):* Stack push via the domain level badge.
    *   *Modals:* Receipt scanner or Add Transaction modal triggered by the FAB.

## 3. Complete Information Architecture (Top-to-Bottom)
The screen uses a vertical ScrollView (~2.5 viewport heights). 

1.  **Domain Header:** Orientation context with back button, title, and domain level badge.
2.  **CIA Coaching Note:** Warm preamble card containing a cross-domain financial insight. Acts as a quiet introduction, not the visual focal point.
3.  **Spend by Category (Focal Hero):** A donut chart visualizing the part-of-whole composition of the user's total spend. 
4.  **Monthly Overview KPI Strip:** Three side-by-side tiles (Income, Spent, Saved) with an inline net summary footer.
5.  **Budget Categories Card:** A list of 3-4 budget tracking rows with capped progress bars and leading status dots, followed by a "view all" link.
6.  **Recent Transactions List:** A scannable list of 3-5 recent transactions, followed by a "view all" link.
7.  **Savings Goals Card:** Flat progress bar for primary savings target with an optional momentum sparkline.
8.  **Spending Trend Chart:** "Living Line" visualizing period spend with a projected forecast.
9.  **Net Worth Chart:** Ambient visual showing running balance over time.
*   **Overlaid Element:** Floating Action Button (FAB) positioned above the bottom tab bar.

## 4. Features & Capabilities
*   **Financial Health Tracking:** Full income, expense, budget, and savings monitoring.
*   **Spend Composition Analysis:** Interactive donut chart showing exactly where money went, omitting zero-spend categories.
*   **Budget Management:** Visual tracking of spend-vs-limit. Handles over-budget states non-shamingly (caps visual at 100% + alerts via text/glyph). Supports quick category creation (via chips).
*   **Transaction Scanning:** Quick-add functionality via FAB to manually add entries or scan receipts.
*   **Swipe-to-Delete:** Quick deletion of recent transactions via swipe gesture.
*   **Interactive Trend Forecasting:** Scrubbing time-series charts for exact daily amounts. Toggle between 7-day and 30-day views.
*   **Cross-Domain AI Insights:** CIA connections between financial habits and other life metrics (e.g., stress).
*   **Motivation Adaptation:** 
    *   *Low:* Simplified 2-card KPIs, top 2 budgets only, sections collapsed, gentler CIA tone.
    *   *Medium:* Default experience (3 KPIs, 3-4 budgets, 5 transactions).
    *   *High:* Expanded KPIs (daily average/projected), full inline budget list, dual-chart overlays, cross-domain spending breakdown.

## 7. Screen States
*   **Cold-Start / Day-1:** No fabricated arrows (KPIs read `$0` with `—` delta). Ghosted donut outline with "Log spending..." prompt. No trends drawn. Option to create budgets via suggestion chips.
*   **Established / Zero State:** Fresh month reset (bars at true 0%).
*   **Loading:** Depth-preserving skeletons that morph into drawn data (lines draw, donut arcs sweep, bars rise). "CIA is reading your month..."
*   **Empty / Partial:** Visibly-labeled ghosted remainder arcs for uncategorized spend; ghosted/dashed MacroBars for un-synced categories. 
*   **Error:** Specific section failure messages (e.g., "Couldn't load budgets") independent of other sections. Hidden CIA note (never shown empty). Red error tints paired with warning glyphs.
*   **Offline:** Cached data retained. Dimmed charts (50% opacity). "You're offline — showing your last sync."
*   **Reduced Motion:** All charts instantly render at final state; static forms preserved.
*   **Transaction Pending:** Amount shown at 50% opacity with "pending" label.

## 8. Interactions, Gestures & Motion
*   **Gestures:**
    *   *Tap:* Row/Card to push details; KPI tiles to scroll-to-relevant section; Donut slice to cross-highlight budget row + show tooltip; CIA note to open chat.
    *   *Swipe-Left:* Transaction row to reveal delete.
    *   *Long-Press:* FAB (expand to mini-FABs), Savings goal (edit), CIA note (view insight sources).
    *   *Touch-and-Hold:* Trend chart to trigger scrubbing crosshair tooltip.
    *   *Pull-to-Refresh:* Force reload all financial data.
    *   *Scroll:* FAB hides on scroll-down, reappears on scroll-up.
*   **Motion Intent:**
    *   *Hero First:* Donut arcs sweep largest-to-smallest.
    *   *Draw-Not-Fade:* Trend charts draw left-to-right; solid lines precede dashed projections.
    *   *Rise:* KPI numbers count up; budget/savings bars rise from 0 upon scroll-into-view.

### ⚠️ Contradictions & Source Conflicts Flagged
1.  **AI Persona Name:** The source text frequently refers to the AI as **"SIA"** (e.g., "ask SIA", "SIA coaching note"). Per the critical instruction, this has been functionally renamed to **CIA** throughout this brief. Copy strings in the source doc containing "SIA" must be updated to "CIA" during implementation.
2.  **Over-Budget Visuals:** Initial source text (IA section) implies flat 2-tone progress bars, while later Visualization/Audit sections explicitly flag this as a defect, requiring **capped MacroBars (100% max)** plus an explicit **glyph (`!`)** and non-shaming copy. The latter (capped + glyphed) is the locked resolution.
3.  **Spent Delta Alarms:** The initial source text suggests coloring the KPI "Spent" delta orange "to alert", but the Visualization section strictly resolves this: spend *decreasing* is a good direction (Green ▼), and spend *increasing* is neutral/muted. Red/alarm colors on standard deltas are strictly retired.
4.  **Focal Hierarchy Conflict:** The IA section claims both the CIA note ("the differentiator") and the KPI strip ("at-a-glance") are focal. The Premium Craft section resolves this: the **Spend-by-Category Donut** is the single, undisputed focal hero. The CIA note is a quiet preamble, and the KPI strip is a flat support row.
