# FUNCTIONAL CONTENT BRIEF: Journal Screen (Spec 37)

## 1. Purpose
Serves as the user's private, AI-guided reflection space, answering "what happened today and what does it mean?" CIA (Coach) surfaces daily prompts and analyzes entries to enrich cross-domain coaching.

## 2. Entry and Exit Paths
*   **Entries (In):** Explore screen [18] via "Journal" card; CIA Chat [09] via deep-link; Learning [35] or Creativity [36] dashboards via "reflect" chip (pre-loads specific prompt); Daily Check-in [45] via "view in journal" link.
*   **Exits (Out):** Back button (stack pop) to previous screen; Forward to CIA Chat [09] (low-motivation prompt variant); Full Entry View (stack push); Daily Check-in [45] (read-only view via mode toggle); Entry Editor/Writing Mode (modal presentation); Image Viewer [67] (via attachment tap).

## 3. Information Architecture (Top-to-Bottom)
**Main View:**
1.  **Screen Header:** Title and back navigation.
2.  **CIA Reflection Prompt Card:** Emotional hook; daily generated prompt. 
3.  **Mode Toggle:** Segmented control switching between "Entries" (text journal) and "Check-ins" (daily check-in history).
4.  **Entries/Check-ins List:** Virtualized chronological archive of continuous row cards.
5.  **Floating Action Button (FAB):** Persistent global creation action.

**Modals (Bottom Sheets):**
*   **Writing Mode:** Editor, CIA prompt echo, domain tags, mood selector.
*   **Voice Recording Mode:** Waveform, timer, transcription interface.
*   **Full Entry View:** Stack push screen for reading a single entry entirely.

## 4. Features and Capabilities
*   **Text Journaling:** Rich-text distraction-free editor supporting bold/italic, auto-growing text area.
*   **Voice Journaling:** Native voice recording with live waveform, transcribed to text automatically via AssemblyAI. Audio is preserved alongside text.
*   **CIA Daily Prompts:** AI-generated specific reflection questions (curious, not prescriptive horoscopes) that can be prefilled into the editor.
*   **Domain Tagging:** Entries can be tagged with 1 or multiple life domains (Fitness, Nutrition, Finance, Career, Relationships, Spirituality, Learning, Creativity, Wellbeing).
*   **Mood Tracking:** 5-point mood scale selection per entry (Happy, Calm, Neutral, Sad, Frustrated).
*   **Check-in History Browsing:** Toggle to view morning/evening daily check-ins (energy, stress, intentions) in read-only format.
*   **Drafts & Offline Writing:** Unsaved changes warning on dismiss; local queuing for entries written offline.
*   **Data Controls:** Explicit privacy opt-in/out for CIA memory and voice retention guidelines.

## 5. UI Copy (Verbatim Strings)
*   **Screen Titles/Buttons:** "Journal", "write", "cancel", "save", "Retry".
*   **Toggle:** "entries", "check-ins".
*   **Action Chips:** "write about this", "+ add tag".
*   **Prompts (Examples):** "What made today different from yesterday?", "One word to describe today.", "What pattern have you noticed between your energy levels and your creative output this week?"
*   **Editor Placeholder:** "start writing..." or "Start writing…"
*   **Empty/Cold Start:** "Your journal is private and for you alone. CIA can offer prompts, or you can write whatever's on your mind. No rules." / "Your entries will appear here."
*   **Privacy/Boundaries:** "Let CIA remember your entries", "CIA uses your journal to give better coaching. You can turn this off anytime in Settings.", "Writing and browsing entries are free. CIA prompts and analysis are Plus."
*   **Loading:** "CIA is finding today's prompt — one moment.", "CIA is updating your prompt — showing your last entries.", "transcribing..."
*   **Errors:** "Couldn't load your entries. Try again.", "Couldn't save your entry. Try again.", "Your entry is empty. Write something to save.", "Couldn't transcribe your audio. Try again.", "You're offline — entries will sync when reconnected."
*   **Success/Delete:** "Entry saved.", "Delete this entry?", "This can't be undone."
*   **Stats:** "12 entries this month — your most reflective month yet"

## 6. Data Fields and Metrics
*   **Entry ID / Date / Timestamp:** System/Device time (Format: "May 20, 2026" - absolute, no relative dates).
*   **Entry Text Content:** User input / AssemblyAI transcription API.
*   **CIA Prompt Source Text:** CIA generative AI (mapped to entry if prompt-driven).
*   **Mood Indicator:** User selection (5-state categorical: 😊 Happy, 😌 Calm, 😐 Neutral, 😔 Sad, 😤 Frustrated). *Visualized as emoji + `StatusDotMeter` (5 dots, lit dot = categorical position).*
*   **Domain Tags:** User selection (Mapped to 9 standard domains).
*   **Voice Metadata:** AssemblyAI API (Microphone icon + "voice" badge flagged on entry row).
*   **Check-in Metrics (View Only):** Energy ratings, stress ratings, intention text (Sourced from Daily Check-in [45]).
*   **Monthly Reflection Stat:** System calculation (e.g., "12 entries this month").

## 7. Screen States Mentioned
*   **Main UI Variants:** Default (Entries), Check-ins Mode, High/Medium/Low Motivation Variants (alters CIA prompt text/stats).
*   **Cold Start / Day 1:** Extra prominent CIA prompt, warmer copy, writing icon outline, absence of Mode Toggle (nothing to toggle).
*   **Empty / Partial Refresh:** Skeleton shimmer for CIA prompt, cached entries shown at 50% opacity (ghosted, non-interactive).
*   **Loading:** Depth-preserving skeleton morphs (no blank spinners).
*   **Error:** Entries fail to load (inline alert), Save fails (network/validation), Voice transcription fails.
*   **Offline:** Sticky top banner, list at 100% opacity, FAB available for local queuing.
*   **Save Success:** Green text flash, sheet slides down, new entry fades/rises into list.
*   **Disabled:** Save button (white/lightened state) until text content exists.

## 8. Interactions, Gestures, Motion Intents
*   **Gestures:** Pull-to-refresh (fetches prompt + entries); Long-press FAB (triggers haptic, opens Voice Mode); Long-press Entry Row (opens context menu); Drag down on sheet handle (dismisses keyboard/editor); Swipe right edge (iOS back).
*   **Motion Choreography:** Staggered fade-in for prompt and rows; Bottom sheets slide up from Y=screenHeight (520ms ease-out); Mood emoji scales 1.2x with radial background fade; Domain tags scale 0-1 on addition; Entry deletion collapses height.
*   **Accessibility Focus Order:** Back button -> Mode toggle -> CIA Prompt Card -> Entry Rows (top-bottom) -> FAB.

## 9. Free vs. Premium Gating
*   **Free Tier:** Basic writing, browsing past entries, manual domain tagging, and manual mood selection.
*   **Premium (Plus) Tier:** CIA-generated daily reflection prompts, CIA cross-domain analysis/insights, and Voice Recording/Transcription features.

## 10. Cross-Domain Hooks
*   **CIA Memory Enrichment:** Journal entries actively feed CIA's understanding of the user, enriching coaching dialogues across *all* domains.
*   **Tag Linkages:** Domain tags visually link journal entries to specific life areas.
*   **Deep-Linking:** CIA Chat [09] can suggest journaling about a specific topic currently being discussed.
*   **Dashboard Reflections:** Learning [35] and Creativity [36] dashboards push users into the journal via "reflect" chips to contextualize their metrics.

*Note: The persona/coach is consistently named **CIA** throughout this brief per instructions. The spec contained an internal naming conflict (referencing both "CIA" and "SIA"). All UI copy, features, and visual references resolve to "CIA" as requested.*

### *Flagged Source Contradictions:*
*   **Touch Target Violations:** The spec lists strict WCAG AA 44x44pt minimums, but defines several components smaller than this (e.g., Domain Tag Chips at 24pt height, "+ add tag" chip at 24pt height, and the "write about this" chip at 32pt height). 
*   **Primitive Naming Conflict:** The spec names the visual mood meter `VK-014 StatusDotMeter`, but cross-references indicate the global design catalog defines VK-014 as `TimelineAgenda`. Functional intent (a 5-dot positional categorical meter) is preserved in this brief.
*   **Typography Discrepancy:** The spec lists microcopy font sizes in one section as 13pt/15pt, but later overrides them to 16pt under "Premium Craft / Typographic rhythm". The brief assumes 16pt as the source of truth for production.
