## Contracts (implement exactly)

**keys.ts**:
```ts
export const queryKeys = {
  all: ['balencia'] as const,
  overview: () => [...queryKeys.all, 'overview'] as const,
  missions: (filter?: string) => [...queryKeys.all, 'missions', filter ?? 'all'] as const,
  gamification: () => [...queryKeys.all, 'gamification'] as const,
  lifeAreas: () => [...queryKeys.all, 'life-areas'] as const,
  fitness: () => [...queryKeys.all, 'fitness'] as const,
  preferences: () => [...queryKeys.all, 'preferences'] as const,
  onboardingStatus: () => [...queryKeys.all, 'onboarding-status'] as const,
};
```

**client.ts**: exported singleton `queryClient = new QueryClient({...})` with defaults:
- queries: `retry: (failureCount, error) => error instanceof ApiError && error.status >= 500 && failureCount < 3` (never retry 4xx — 401 is already handled inside apiFetch; `SessionExpiredError` must NOT be retried), `retryDelay: (attempt) => Math.min(1000 * 2 ** attempt, 4000)`, `staleTime: 60_000`, `throwOnError: false`, `refetchOnWindowFocus: false`.
- mutations: `retry: 0`.
Also export `onSignedIn = () => queryClient.invalidateQueries({ queryKey: queryKeys.all })` and `onAuthCleared = () => queryClient.clear()`.

**_layout.tsx** provider order (exact nesting):
```
QueryClientProvider(client=queryClient)
  └─ SessionProvider(onSignedIn={onSignedIn} onAuthCleared={onAuthCleared})
       └─ existing SafeArea/Stack content unchanged
```

**Domain hooks** — each returns the query result typed to the DTO for now; keep an explicit seam comment `// P5 swaps this to the adapter view-model`:
| Hook | queryKey | fetch | staleTime |
|---|---|---|---|
| `useOverview()` | `queryKeys.overview()` | `apiFetch<OverviewDashboardResponse>('/v1/overview/dashboard')` | 60_000 |
| `useMissions()` | `queryKeys.missions()` | `apiFetch<UnifiedGoalsResponseDto>('/v1/goals/unified')` | 60_000 |
| `useGamification()` | `queryKeys.gamification()` | `apiFetch<GamificationStatsResponseDto>('/gamification/stats')` | 60_000 |
| `useLifeAreas()` | `queryKeys.lifeAreas()` | `apiFetch<LifeAreasSummaryResponseDto>('/life-areas/summary')` | 60_000 |
| `useFitness()` | `queryKeys.fitness()` | `apiFetch<WorkoutPlansResponseDto>('/workouts/plans')` | 60_000 |
| `usePreferences()` | `queryKeys.preferences()` | `apiFetch<PreferencesResponseDto>('/preferences')` | 300_000 |
| `useOnboardingStatus()` | `queryKeys.onboardingStatus()` | `apiFetch<OnboardingStatusDto>('/auth/onboarding-status')` | Infinity |
All hooks: `enabled: status === 'authenticated' || status === 'refreshing'` using `useSession()` — data queries never fire unauthenticated.

## Acceptance criteria
- `tsc --noEmit` clean; keys typed `as const`; hooks compile against the vendored DTOs.
- Sign-out clears the entire cache (`queryClient.clear()`); sign-in invalidates `queryKeys.all`.
- No query retries on 4xx/SessionExpiredError; 5xx retries ≤3 with exponential delay.
- `_layout.tsx` keeps all existing behavior (fonts/splash/etc.) — only the provider nesting changes.
