# 2. Purpose
Provide transparent, honest management of subscription tiers, usage limits, and billing. Connects the user's functional usage (AI limits) to tier value without utilizing loss-aversion dark patterns (e.g., color escalation or false scarcity). Empowers premium upgrades through clear feature visibility and straightforward syntax.

# 4. Layout anatomy

1.  **Atmosphere & TopBar:** Warm radial glow, back chevron, H1 title.

5.  **Billing Group:** `ListRow` components for payment method, billing history (`TrendChart`), and restore purchases.
6.  **Destructive Actions:** Quiet `BtnGhost` links for downgrade/cancel.
7.  **Bottom Navigation:** Floating `GlassNavBar`.

**Metric 3: Billing History (Last Charge)**

*Correction Note:* The original brief mentioned "Billing history (with data visualizations)" and "7-point Charge History". On a mobile screen, cramming a 7-point chart into a `ListRow` is crowded and non-premium. I have reduced this to a 1-spark `TrendChart` sparkline showing the last charge delta. If the user expands the row, a full `Sheet` can display the 7-point history safely.

# 9. All states
- **Default:** Paid Pro tier. Usage at 80%. Healthy account.
- **Skeleton:** Shimmer blocks over `--surface-3` mirroring the layout. Prices replaced by `--surface-2` bars. Usage meter shows ghost track. "Loading your plan…" text in `HonestNullState` format.
- **Empty (Cold-Start Free):** `Current Plan` shows "Your plan: Free. All features listed below — upgrade anytime." Billing section hidden entirely. Downgrade/Cancel hidden.
- **Error:** Grid structure collapses to a single `SolidCard` containing `ErrorState`: "Could not load plans. Pull to retry." Usage meter hides.
- **Success (Restored):** Native IAP success triggers a 250ms `BtnSuccess` morph (orange to green) on the CTA, then auto-dismisses.
- **Disabled:** "Current plan" CTA on the active tier card in the horizontal rail. 40% opacity, no glow.

# 10. Motion & interaction
- **Physical easing:** Standard iOS `/ Android` spring easing on horizontal tier rail swipe. 
- **Timing:** 150-250ms for all CTA presses (scale .98). 
- **Draw-first:** On screen mount, `ChargeMeter` sweeps 0 → 80% over 400ms (orange fill). 
- **Scroll reveal:** When the CompareGrid scrolls into the viewport, row items settle top-to-bottom with a 15ms stagger (transform/opacity only).
- **Toggle slide:** Monthly/Annual `SegmentedTabs` slides smoothly (no cross-fade), updating prices via a quick 100ms opacity swap.
- **Glow behavior:** `glow-you` on the recommended column breathes subtly (4s ease).
- **Haptics:** Light selection haptic on `SegmentedTabs` toggle. Success haptic on purchase restore.
- **Reduced motion:** Glows freeze. Meter jumps to final value. Grid stagger renders simultaneously. 

# 11. Motivation-tier adaptation
- **Low density:** User prefers minimal UI. Tier Rail is collapsed into a `SegmentedTabs` selector (Free, Plus, Pro, Max). CompareGrid reduces to 2 columns (Current vs Target). 
- **Medium density:** (Default Spec). Full horizontal scroller. 3-column matrix. 
- **High density:** Tier Rail hidden. Matrix expands to 4 columns to show all tiers simultaneously in a dense data-optimized grid, appealing to analytical users.

# 12. Accessibility
- **AA+ Contrast:** All text uses Paper-100/50 on `--surface-2` (hex `#211008`), ensuring >7:1 contrast. 
- **Targets:** All CTAs (`BtnPrimary`) strictly 52px height. `ListRow` targets are 56px. 
- **Screen-reader:** Usage meter provides `aria-valuenow="800" aria-valuemax="1000"`. The "Current plan" disabled button is read as `aria-disabled="true"`. Matrix checkmarks are labeled `aria-label="Included"`.
