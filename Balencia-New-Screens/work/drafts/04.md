### 2. Purpose
Facilitate fast, frictionless, and secure re-entry for returning users. Enforces strict validation and explicit trust preferences (session persistence) prior to granting access to the main application environment.

### 3. Entry & exit
* **Entry paths:** 
  * Stack push from Welcome / Sign Up [03] (via "Already have an account? sign in").
* **Exit paths:**
  * **Primary:** Home Screen [12] via root reset (successful authentication).
  * **Secondary:** Forgot Password [05] via stack push (tap "Forgot password?").
  * **Tertiary:** Welcome / Sign Up [03] via stack pop (tap "sign up" or back gesture/chevron).

### 8. Data & honesty states
While traditional metrics are not displayed on this utility screen, the **Biometric Cooldown Timer (429 Error)** behaves as a functional metric and adheres strictly to the 3-state honesty invariant:
* **Real:** Biometric button disabled; Toast with a continuous progress bar depleting toward re-enable. Displays exact minutes remaining, updates dynamically. Provenance chip text: `system rate-limit`.
* **Low-confidence:** *N/A* (Rate limits are exact, API-driven values; estimation is not permitted).
* **Honest-null:** If API fails to return rate-limit timer, UI displays honest copy: `Too many attempts. Try again later.` Never fabricates a countdown.

### 9. All states
* **Default (Cold-start / Day-1):** Form is blank. "sign in" CTA is disabled (40% opacity, no glow). Biometrics are hidden.
* **Disabled:** CTA renders at 40% opacity, no haptic feedback. Triggers when fields are empty, email format is invalid, or during 429 rate-limit cooldown.
* **Loading:** CTA text crossfades to a spinner (width locked). Loading toast: "Signing you in — one moment".
* **Success:** Form collapses upward and fades out. Root resets to Home Screen [12].
* **Error (Network):** OfflineBanner slots in at the top. Form remains fully visible and interactive.
* **Error (Wrong Credentials):** 2pt red borders and `✗` glyph on inputs. Error text below fields: "That email or password doesn't match." 
* **Error (429 Biometric):** CTA/Biometric disabled; red left-border Toast with continuous depleting progress bar.
* **Skeleton:** *N/A* (Screen is entirely local UI state; no skeleton loaders needed).

### 10. Motion & interaction
* **Gestures:** Tap to focus, native edge-swipe right to pop stack.
* **Easing & Timing:** Physical easing only (`ease-flow`). UI feedback strictly between 150-250ms.
* **Screen Mount:** Staggered fade-in: logo (0ms) -> heading/form (100ms) -> alternative paths (200ms).
* **Signature Animation:** The `CTAContinuousStroke` draws itself as an animated outline (520ms) upon screen mount. Inner fill materializes on completion.
* **Biometric Flow:** Form smoothly dims to 40% opacity (160ms) when OS prompt activates. Snaps back to 100% on dismiss. Red icon pulse (400ms) on failure.
* **Glow behavior:** "sign in" CTA glows softly when enabled; `--glow-cia` breathes on the Biometric button to invite touch.
* **Reduced-motion path:** Staggered mount snaps to visible instantly. Signature stroke draws instantly (0ms). Biometric dim transition snaps (0ms). Glow breathing halts.

### 11. Motivation-tier adaptation
* **Low density:** Only email/password fields and primary CTA are visible. Social/biometric routes are tucked behind a ghost button: "more options".
* **Medium density:** (Default spec). Standard vertical rhythm with all primary and secondary auth paths visible.
* **High density:** Inputs reduce in height (44pt) to bring the "Remember me" toggle, recovery link, and primary CTA into the immediate native viewport without scrolling.

### 12. Accessibility
* **Contrast:** Paper-100 (#FEFAF3) on dark base ensures AA+ (>7:1). Tertiary text caps at 64% opacity to preserve AA for essential placeholders and toggle labels.
* **Targets:** All interactive elements (inputs, buttons, toggle, visibility eye) strictly honor the 44x44px touch target minimum.
* **Screen-reader labels:** Glyph-only buttons possess explicit `aria-label`s (e.g., Back chevron: "Return to welcome screen", Visibility eye: "Hide password", Biometric icon: "Sign in with biometrics").
