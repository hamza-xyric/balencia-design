# FUNCTIONAL CONTENT BRIEF: Water Intake Tracker

## 1. Purpose
The Water Intake Tracker is the user's daily hydration command center, answering: "How much water have I had today and am I on track?" It provides a satisfying glanceable view of progress against a personalized target with one-tap logging, trend visualization, and RPG-style XP rewards.

## 2. Entry and Exit Paths
**Entry Paths:**
*   **Today Tab / Home Screen [12]:** Via wellbeing action card or water widget (Stack push)
*   **Explore Section [18]:** Via wellbeing module card (Stack push)
*   **Habits [38]:** Via "drink water" habit deep-link (Stack push)
*   **CIA Chat [09]:** Via hydration reminder deep-link (Stack push)

**Exit Paths:**
*   **Back button:** Returns to previous screen (Stack pop)
*   **CIA Chat [09]:** Via CIA coaching note tap (Tab switch)
*   **Target Setting:** Modal bottom sheet triggered by gear icon
*   **Celebration Overlay [42]:** Triggered inline on goal achievement

## 3. Information Architecture (Top-to-Bottom)
1.  **Domain Dashboard Header (Fixed):** Back chevron, title "Water intake", settings gear icon.
2.  **Daily Progress Ring:** Large hero circular visualization (consumed vs. target).
3.  **Momentum & Reserve Meters:** Linear companion reads directly beneath the ring.
4.  **Quick Add Row:** 4 pill buttons for instantaneous logging.
5.  **Today's Log Card:** Chronological ledger of the day's entries.
6.  **Weekly Bar Chart Card:** 7-day trend vs. target line.
7.  **Stats Card:** 3-column display for streak, average, and best day.
8.  **High-Motivation Analytics Block (Conditional):** Ambient consistency heatmap and 30-day micro-trend sparkline.
*Bottom Tab Bar visible.*

## 4. Features and Capabilities
*   **Frictionless Logging:** One-tap logging via preset amount buttons.
*   **Custom Amount Input:** Numeric keypad modal for exact entry.
*   **Target Adjustment:** Modal to manually adjust the daily water goal.
*   **Unit Toggling:** Tap the progress ring to toggle the primary display unit between "glasses" and "ml".
*   **Data Deletion:** Swipe left on log entries to delete individual records.
*   **Data Visualization:** Daily progress ring, MomentumBar (path of progress), ChargeMeter (reserve level), weekly bar chart, calendar heatmap, and 30-day sparkline.
*   **Adaptive Targeting:** Target adjusts dynamically based on user feedback, activity level, and weather context (via CIA).
*   **Gamification & Rewards:** Hitting the daily target triggers a celebration (confetti/glow), earns +25 XP, and updates the streak count.
*   **Trend Navigation:** Horizontal swipe within the weekly chart to view previous weeks.
*   **Offline Queuing:** Manual logging remains functional offline; logs queue locally and sync when connectivity returns.

## 7. Screen States
*   **Cold-Start / Day-1:** Ring ghosted (no fill), reads "0 / 8 · building capacity." Momentum bar hidden. Log shows "Your drinks will appear here." Chart shows ghosted bars. Stats show "—". Optional CIA note present.
*   **Loading:** Ring track pulses (opacity 4%→8%). Skeleton shimmers across text, bar charts grow into data, stats shimmer. Copy: "Updating your hydration…"
*   **Partial:** Real data bars mixed with ghosted/dashed placeholders for future/unsynced days.
*   **Error:** Ring renders last cached data with an amber warning icon. Banners read "Could not load latest data. Showing cached from [timestamp]." Specific retry links for chart/stats.
*   **Offline:** Renders cached data. Quick-add buttons remain enabled. Timestamp on queued entries shows "—" or pending icon.
*   **Goal Achieved (100%):** Ring crossfades teal→green. Center text turns green. Pulsing green glow. Confetti burst. "Goal achieved. +25 XP at [Time]" text replaces percentage.
*   **Over Target (>100%):** Green fill with lighter green overlay, "+N over target" label.
*   **Disabled State:** Quick-add buttons dim to 0.4 opacity momentarily during celebration animation.
*   **Midnight Rollover:** Ring animates counterclockwise to 0%. Log entries fade out. Today indicator dot slides to the new day.

## 8. Interactions, Gestures, and Motion
*   **Tap (Quick Add):** Logs amount instantly. Button flashes green, checkmark replaces text, "+1 glass" floats up. Ring re-sweeps to new fill.
*   **Tap (Ring Center):** Crossfades primary unit (glasses ↔ ml).
*   **Tap (Bar Chart Bar):** Reveals value tooltip above the bar.
*   **Swipe (Horizontal on Chart):** Paginates to previous weeks.
*   **Swipe (Left on Log Entry):** Reveves red "delete" button.
*   **Swipe / Pull (Down on ScrollView):** Pull-to-refresh data.
*   **Long-Press (Quick Add Preset):** Edit preset amount.
*   **Drag (Bottom Sheet Modals):** Dismiss target setting or custom amount modals.
*   **Motion (Entrance Draw-Order):** Ring fills first → Momentum bar fills → Quick-add buttons settle → Log entries rise L→R → Bar chart bars grow L→R (staggered) → Heatmap cells shimmer → Sparkline draws. *(All strokes draw; nothing fades in).*
*   **Motion (Goal Celebration):** Teal→green ring crossfade, 40-particle confetti burst (2s), pulsing green glow loop (5s), achievement text floats up. *Reduced motion fallback:* Skips confetti, replaces with a 280ms static green-glow settle.

## 9. Free vs. Premium Gating
*   **Free Tier:** Manual logging, visual progress ring, and weekly chart are available to all users.
*   **Plus (Premium) Tier:** Unlocks CIA coaching notes, adaptive daily targets (driven by activity, weather, etc.), and the High-Motivation Analytics Block (ambient calendar consistency heatmap and 30-day sparkline).

## 10. Cross-Domain Hooks
*   **CIA Insights & AI Adaptation:** CIA deep-links into the screen from chat reminders. CIA proactively adjusts the user's daily target based on external life data (e.g., physical activity tracked in the Fitness Dashboard, local weather context). If a user consistently exceeds their goal for 7+ days, CIA recommends an increased target.
*   **Habits Domain:** Syncs directly with the Habits [38] tracker via the "drink water" habit deep-link.
*   **RPG / Gamification Engine:** Tightly integrated with the celebration overlay system [42] and global XP accumulation to reinforce daily loops.
*   **Health Integrations (3rd Party):** Syncs hydration data in the background from Apple Health to automatically fill missing entries.
