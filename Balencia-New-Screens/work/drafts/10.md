# 2. Purpose
Provides a frictionless, hands-free voice input method directly within the CIA chat interface. It captures cross-domain raw data (e.g., life logs, spontaneous thoughts) quickly, transcribing speech to text in real-time without breaking conversational context. 

# 3. Entry & exit
- **Entry:** Activated by tapping the `VoiceMicGlow` inside the `ChatComposer` on screen [09]. The keyboard (if open) dismisses, and the voice panel springs up. This is a UI state change, not a standard navigation push.
- **Primary exit:** 
  - Tap send to finalize transcript and return to text mode.
  - Swipe down or tap cancel to discard the draft and return to text mode.
- **Secondary exit:** 
  - Auto-send after 3 seconds of continuous silence.
  - Auto-cancel after 8 seconds of total silence from start.
  - Auto-send at the 60-second maximum recording limit.
- **Tertiary exit:** Tapping the dimmed `GlassNavBar` gracefully cancels the voice mode and navigates away.

# 4. Layout anatomy
The screen is an overlay state of the standard chat view. Top-to-bottom:
1. **Top atmosphere & TopBar:** Unchanged from standard chat. Displays "CIA" title and highlighted voice icon.
2. **Chat History Area:** Compressed upward to accommodate the voice panel. Retains conversational history, auto-scrolling as needed.
3. **Draft Bubble:** A dynamically sizing provisional chat bubble pinned just above the voice panel, showing streaming transcription.
4. **Voice Interface Panel:** Replaces the standard keyboard area (~200pt height). Contains the status label, waveform, and action controls.
5. **Bottom Nav:** Floating `GlassNavBar`, dimmed to 40% opacity to maintain focus on the voice task.

# 9. All states
- **Default:** Panel active, draft bubble empty with dashed border, status "listening.", waveform idle.
- **Skeleton:** Not applicable. (The state transition from text-to-voice is instant and native; a skeleton block implies data loading from a server, which misrepresents the instant device-level mic activation).
- **Empty:** Mic is active, but no sound detected. Waveform rests flat.
- **Error (Transcription Failed):** Waveform greys out; status reads "Couldn't hear that. Try again."
- **Error (No Speech Detected):** Auto-cancels at 8s; toast appears at top.
- **Error (Permission Denied):** Waveform greys out; Stop button disabled; status reads "Microphone access needed." with an orange "Enable in settings" BtnGhost.
- **Error (Offline):** Waveform freezes; status reads "Connection lost."; Stop button disabled; partial draft text retained for manual sending later.
- **Success:** Transcript finalized; panel slides down; chat bubble snaps from dashed to solid; CIA thinking indicator appears.

# 10. Motion & interaction
- **Easing & timing:** Physical easing (`cubic-bezier(0.32, 0.72, 0, 1)`). Panel slides up 200pt over 280ms. Feedback on taps is 150ms.
- **Glow behavior:** The Royal Purple `--glow-cia` breathes at a 4s ease interval while listening, reacting to amplitude. 
- **Haptics:** 
  - Light tick on mic activation (Entry).
  - Medium bump when text is successfully sent (Success).
- **Reduced-motion path:** Waveform draws as a solid, static block that changes height every 500ms (stepped, no smooth animation). The panel fades in/out instead of sliding. No breathing glow; remains static.

# 11. Motivation-tier adaptation
*Correction applied:* The base spec incorrectly stated voice mode doesn't adapt by tier. Any data input absolutely scales with the user's preferred information density.
- **Low Density:** Status label hidden (relies on aural device feedback). Waveform uses thicker bars (less granular visual noise). Send button relies purely on standard styling.
- **Medium Density:** Default state. Status label visible, waveform animates smoothly, timer ring visible on the send button.
- **High Density:** Adds an explicit, quiet `Caption` timer "00:03 / 01:00" below the waveform. Low-confidence transcriptions highlight in paper-64% as they stream, rather than waiting for the end of the sentence.

# 12. Accessibility

- **Contrast:** Text (paper-100 `#FEFAF3`) on `.glass-card` dark background exceeds AA. Status label (paper-64%) meets AA for large text/UI components.
- **Targets:** Cancel and Stop/Send buttons map to 64px circular touch targets, safely exceeding the 44px minimum. Dimmed `GlassNavBar` hits 44px bounds.
- **Gestures:** Swipe down to dismiss is supported by standard iOS/Android predictive-back or sheet-grabber interactions.
