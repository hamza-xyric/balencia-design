Here is the functional content brief for the Call Summary screen, distilled from the provided specifications. Visual styling, color tokens, typography metrics, and outdated component nomenclature have been intentionally excluded to isolate pure functional requirements.

### 1. Purpose
Turns a completed voice coaching session into durable action items, transcript highlights, and mood/status signals, providing a calm debrief rather than a dense transcript archive. Converts call insights into a scheduled follow-up.

### 2. Entry & Exit Paths
*   **Entry Paths:** Stack push after Voice Mode [11] ends; accessed from Voice Call History [51].
*   **Primary Exit:** Schedule Follow-Up CTA (opens scheduling sheet from Voice Call History [51]).
*   **Secondary Exits:** Back button (returns to history/originating flow); Action item tap (routes to Reminders & Tasks [61] or Mission Detail [14]); Transcript highlight tap (opens expanded transcript view).

### 3. Information Architecture
**Scroll Behavior:** Vertical scroll with a fixed sticky header, fixed bottom CTA, and visible global tab bar.
1.  **Header Region:** Back navigation and screen title.
2.  **Hero Region:** Post-call identity (title, metadata, privacy/status signals) and focal sentiment visualization.
3.  **Metrics Region:** Horizontal strip of key call metrics (duration, items, emotion shift).
4.  **Call Composition Region:** Visual breakdown of topics discussed.
5.  **Call Arc Region:** Sequential timeline of major decisions/moments.
6.  **Action Items Region:** List of follow-up tasks generated.
7.  **Transcript Region:** Verbatim text snippets from key moments.
8.  **Fixed Bottom Action:** Scheduling CTA.

### 4. Features & Capabilities
*   **Sentiment Analysis Visualization:** Displays an open-dial gauge representing the call's emotional tone (0–100) with an accompanying descriptive label.
*   **Topic Breakdown:** Visual representation of minutes spent per topic, summing exactly to the total call duration.
*   **Key Moments Timeline:** A horizontal progress path mapping the sequence of major decisions, rules saved, or insights (max 6 nodes).
*   **Call Metrics:** Display of duration, action item count (with conversion status), and within-call emotion arc shift.
*   **Action Item Conversion:** Tappable rows to convert call insights into tasks or update linked missions.
*   **Transcript Expansion:** Deep-linking from specific transcript lines, timeline nodes, or topic slices to an anchored expanded transcript view.
*   **Follow-up Scheduling:** Bottom anchored modal/sheet to book the next coaching call.
*   **Privacy Controls:** Explicit explanation tooltips for call privacy and recording status.

### 6. Data Fields & Metrics
| Field / Metric | Description | Source / Data Point |
| :--- | :--- | :--- |
| **Call Duration** | Total length of the voice call | `callSummary.duration` |
| **Call Sentiment** | Overall call tone (0–100) | `callSummary.sentiment.value` |
| **Sentiment Label** | Word/glyph defining the tone | `callSummary.sentiment.label` + `.glyph` |
| **Emotion Arc Delta** | Shift in tone from start to end of call | `callSummary.sentiment.start` / `.end` |
| **Topic Allocation** | Minutes spent per topic category | `callSummary.topics[]` (`label`, `minutes`) |
| **Key Moments** | Pivotal call events (rules saved, decisions) | `callSummary.keyMoments[]` (`label`, `atMinute`, `speaker`, `kind`) |
| **Action Items** | Follow-up tasks generated from the call | `callSummary.actionItems.length` |
| **Speaker Tag** | Attribution for transcript lines (SIA vs. User) | Transcript object `speaker` attribute |

### 7. Screen States
*   **Cold-start / Day-1 / Mid-generation:** True empty state. Hero shows ghosted 0-foot visualizations without filling with a zero value. Skeletons morph into drawn data.
*   **Loading (Depth-preserving):** Track visible with shimmer sweeps that morph into drawn data. No blank discs.
*   **Partial:** Sentiment, topics, and duration render normally. Timeline and transcript sections show ghosting with processing copy.
*   **Error (Summary Generation Failed):** All charts default to ghost state; hero replaced with a Retry CTA. Cached partial summaries shown below if available.
*   **Offline:** Cached summary fully renders. Schedule CTA visually dimmed/disabled (50% opacity) with reasoning overlay.
*   **Disabled:** Offline state disables schedule booking natively.

### 8. Interactions, Gestures & Motion Intents
*   **Tap (Sentiment Gauge):** Expands a one-line explainer on how SIA read the tone (never frames low values as failure).
*   **Tap (Topic Slice):** Reveals topic minutes and deep-links to that specific transcript section.
*   **Tap (Timeline Node):** Anchors the expanded transcript view to that exact moment.
*   **Tap (Action Item Row):** Opens task conversion flow or mission update.
*   **Tap (Transcript Snippet):** Opens expanded transcript.
*   **Tap (Private Pill):** Opens privacy explanation tooltip.
*   **Motion Intent (Draw-First):** Hero draws first, followed by topic arcs sweeping clockwise, KPI metrics counting up, and the timeline path drawing left-to-right. Action and transcript rows stagger in last.

### 10. Cross-Domain Hooks
*   **Reminders & Tasks [61] / Mission Detail [14]:** Action items generated here push directly into the user's goal and task management life areas.
*   **Voice Call History [51]:** Reuses scheduling architecture, anchoring the user's voice coaching progression over time.
*   **AI Insights:** SIA captures "rules saved" and behavioral nudges (e.g., pacing rules, nutrition changes) that directly inform future AI coaching and correlation logic across the app.
