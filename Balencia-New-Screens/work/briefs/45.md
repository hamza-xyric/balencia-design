# Functional Content Brief: Daily Check-in (Morning / Evening)

## 1. Purpose
The Daily Check-in is Balencia’s emotional pulse—a gentle, reflective ritual that bookends the user’s day to capture mood, energy, stress, and intention. The captured data feeds CIA’s understanding of emotional patterns, enabling cross-domain insights and correlations. 

## 2. Entry and Exit Paths
*   **Entry Paths (Modal or Stack Push):**
    *   **Home Screen [12]:** Time-aware prompt card (Modal presentation).
    *   **CIA Chat [09]:** Deep-link from CIA via the prompt "how are you feeling?" (Modal presentation).
    *   **Habits [38]:** Evening habit row (Stack push).
    *   **System Notifications:** Tap on morning/evening reminder (Modal presentation).
    *   *Automatic Trigger:* Morning variant auto-triggers on first app open before 12:00 PM (dismissable); evening variant triggers after 6:00 PM if morning check-in exists.
*   **Exit Paths:**
    *   **Submit:** Saves data, dismisses modal/pops stack, returns to previous screen with success toast.
    *   **Cancel / Drag-Down:** Dismisses without saving. Prompts unsaved confirmation if content exists.
    *   **Back Button:** Pops stack (stack push variant only).

## 3. Information Architecture
**Hierarchy (Top-to-Bottom):**
1.  **Modal Header:** Navigation controls (drag handle, cancel, save).
2.  **Time-Aware Greeting:** Emotional anchor (greeting, subtext, streak note).
3.  **Mood Emoji Selector:** Fast, visceral input (6 options + inline 5-segment mood level meter). *[High-Motivation: 7-point historical mood sparkline appears above this]*.
4.  **Energy Level Input:** 10-segment level meter. *[High-Motivation: 7-point historical energy sparkline appears below]*.
5.  **Stress Level Input:** 10-segment level meter. *[High-Motivation: 7-point historical stress sparkline appears below]*.
6.  **Daily Intention (Morning) / Intention Reflection (Evening):** Core purposeful text input. Evening variant displays the morning's text, a fulfillment toggle, and an evening reflection input.
7.  **Emotion Tags:** Nuanced, multi-select text chips.
8.  **Context Note:** Optional, expandable freeform text area (collapsed by default on low/med motivation).
9.  **Gratitude Prompt (Evening Only):** Positive reflective text close.
10. **Tomorrow Preview (Evening Only):** Forward-looking schedule items + CIA micro-insight.
11. **Submit CTA:** Primary action button at the bottom.

## 4. Features and Capabilities
*   **Time-Slanting:** Screen dynamically switches between Morning (intention setting) and Evening (reflection/gratitude) flows.
*   **Motivation Adaptation:**
    *   *Low Motivation:* Radically simplified to Mood + Energy Level + Submit CTA (fits one viewport, under 10 seconds).
    *   *Medium Motivation (Default):* Full text inputs, tags, and context notes (30-60 seconds).
    *   *High Motivation:* Adds optional trend sparklines (mood/energy/stress), default-expanded context notes, and a "Compare to yesterday" mood indicator (2-3 minutes).
*   **Streak Tracking:** Non-shaming streak indicator (e.g., "Day 14 of checking in"). Missed days show constructive framing ("Your streak paused — pick it back up today").
*   **Offline Mode:** Fields remain functional; data caches locally and auto-syncs when reconnected.
*   **Duplicate Prevention:** If a user checks in twice in one period, the form pre-populates existing data and switches to an "update" state.

## 6. Data Fields and Metrics
*   `mood_logs.mood_emoji` & `mood_logs.mood_rating`: Derived from the 6 selected emojis (Happy=5, Meh=3, Sad=2, Angry=1, Anxious=2, Tired=2).
*   `daily_checkins.energy` & `mood_logs.energy_rating`: 1-10 scale.
*   `daily_checkins.stress` & `mood_logs.stress_rating`: 1-10 scale.
*   `daily_intentions.intention_text`: Free text (Max 120 chars).
*   `daily_intentions.fulfilled`: Boolean (derived from toggle).
*   `daily_intentions.reflection`: Free text.
*   `mood_logs.emotion_tags`: JSON array of selected text chips (e.g., ["grateful", "anxious"]).
*   `daily_checkins.notes` / `mood_logs.context_note`: Free text (Context & Gratitude sections).
*   *Read-Only Data:* User Profile (First Name), Device Clock, Check-in Streak Count, Calendar API (Tomorrow's events).
*   *High-Motivation Derived Metrics:* `dailyCheckin.moodTrend` (7-point array), `dailyCheckin.energyTrend` (7-point array), `dailyCheckin.stressTrend` (7-point array).

## 7. Screen States
*   **Variants:** Morning, Evening.
*   **Cold-Start / Day 1:** No historical trends shown. Includes specialized warm microcopy and larger emoji touch targets to invite interaction.
*   **Empty / Partial Data:** Evening variant gracefully handles a missing morning check-in by hiding the reflection card and showing a warm prompt. Missing sparkline data renders a ghosted/dashed line.
*   **Loading:** Modal slides up (520ms). Content staggers. Optional sparklines "draw" themselves morphing from a faint baseline.
*   **Error:** Red border flash on inputs/CTA (280ms) with toast copy. All user input is preserved locally.
*   **Offline:** Persistent banner at top ("You're offline..."). Check-in is cached; submission is deferred until reconnection.
*   **Success:** CTA flashes green (600ms), sheet dismisses, success toast appears on the Home Screen.
*   **Disabled:** Save/Submit buttons remain at 40% opacity until a mood is selected.

## 8. Interactions, Gestures, and Motion
*   **Gestures:** 
    *   *Drag Down:* On modal handle to dismiss (prompts unsaved confirmation).
    *   *Tap:* Select emojis, toggle tags, expand context note.
    *   *Scrub/Drag:* Level inputs for Energy/Stress scrub continuously and snap to a tick on release.
    *   *Edge Swipe:* iOS back gesture (stack push variant only).
*   **Motion Choreography:** 
    *   Strict draw-first, focal-to-support staggering (Greeting -> Mood -> Energy -> Stress -> Text -> Tags -> CTA).
    *   Optional sparklines use a `stroke-draw` animation (520ms) rather than a fade.
    *   *Accessibility (Reduced Motion):* All draws and staggers are bypassed; elements appear instantly in their final canonical state.

## 9. Free vs Premium Gating
*   **Free Tier:** Includes core mood, energy, and stress logging, alongside basic completion tracking.
*   **Premium (Plus) Tier:** Unlocks CIA coaching notes, advanced emotion analysis, historical trend sparklines (high-motivation variant), and tomorrow preview insights.

## 10. Cross-Domain Hooks
*   **Schedule Integration:** The Evening "Tomorrow Preview" pulls data from the Calendar/Schedule [41], allowing users to mentally prepare for the next day. Tapping it navigates to the Schedule screen.
*   **CIA Chat Deep-Linking:** Check-in data directly feeds CIA Chat [09], establishing the baseline for the AI's contextual understanding of the user's emotional state.
*   **Habit Correlations:** The CIA insights surface cross-domain behavioral correlations (e.g., "You tend to feel calmer on days you exercise in the morning"), directly linking Wellbeing inputs to Habits [38] and Fitness data.
