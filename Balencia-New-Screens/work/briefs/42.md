# Functional Content Brief: Celebration / Achievement Overlay

## 1. Purpose
Delivers the emotional payoff of the gamification system upon completing a milestone, mission, or streak. It reinforces the XP loop, validates consistency, and scales dynamically from a full-screen cinematic event for major milestones to lightweight toasts for everyday actions.

## 2. Entry and Exit Paths
**Entry Paths (System-Triggered):**
*   Mission completion (Screen 14)
*   Workout finish (Screen 27)
*   Habit streak achieved (Screen 38)
*   Action completion on Home (Screen 12)
*   Overall or Domain level-up threshold crossed
*   Successful IAP purchase (Subscription variant)

**Exit Paths:**
*   **Primary:** Tap anywhere (or Escape key/VoiceOver Z-scrub) → Dismisses overlay, returns to underlying trigger screen.
*   **Secondary:** Tap "Share" → Opens native share sheet → Returns to overlay to be dismissed.
*   **Tertiary (Toasts):** Auto-dismiss after 3 seconds (extends to 5s if VoiceOver is active) or swipe up to dismiss early.

## 3. Information Architecture
The overlay exists across three distinct scales (Full Screen, Toast, Inline Pulse).

**Full-Screen Overlay (Top-to-Bottom):**
1.  **Backdrop Layer:** Focuses attention; captures tap-to-dismiss events.
2.  **Confetti Layer:** Atmospheric particle animation.
3.  **Hero Visual:**
    *   *Level-up state:* Concentric progress ring blooming around the badge.
    *   *Standard state:* The achievement badge alone.
4.  **XP Counter:** Tangible reward display with count-up animation.
5.  **Level Progress (Conditional):** Linear progress bar tracking XP to the next level.
6.  **Achievement Title Block:** Achievement type label + specific source name.
7.  **Continuous Stroke Divider:** Decorative separator.
8.  **CIA Congratulatory Message:** Personalized, data-specific text + attribution.
9.  **Action Buttons:** Share button (and "Explore" CTA for subscription variant).
10. **Dismiss Hint:** Text instructing user how to close.

**Toast Variants (Top-aligned, overlaying status bar area):**
*   **Small Win Toast:** Checkmark icon + Action Name + XP earned.
*   **Domain Level-Up Toast:** Domain Icon + "[Domain] Level [N]" + XP earned.

**Inline Element (On Screen 16):**
*   **Radar Vertex Pulse:** Domain-colored glow ring + polygon morph on the radar chart.

## 4. Features and Capabilities
*   **Dynamic Milestone Scaling:** Automatically adjusts UI intensity based on the event (Full screen for major milestones/overall level-ups; toasts for domain level-ups/everyday wins).
*   **Delayed Dismissal Lock:** Prevents accidental dismissal during the ~1.2s entrance animation (blocked for standard users, but bypassable immediately via assistive tech escape gestures).
*   **Motivation Adaptation Engine:** Dynamically adjusts celebration frequency and CIA copy tone based on user's motivation tier:
    *   *Low Motivation:* Lower thresholds for full-screen celebrations (e.g., 3-day streaks); copy is highly encouraging ("every step matters").
    *   *High Motivation:* Reserved for major milestones; suppresses everyday toasts in favor of inline popups; replaces confetti with clean data summary cards.
*   **Queued Offline Achievements:** If achievement data fails to load, the overlay queues and triggers on next app foreground/screen load.
*   **Share Card Generation:** Compiles achievement data into an image for the native OS share sheet.
*   **Auto-Dismiss Failsafe:** If the overlay dismiss fails to register and no interaction is detected for 10 seconds, it auto-dismisses.

## 6. Data Fields and Metrics
*   **XP Amount Earned** (*Source: Achievement API*): Displayed as "+ NNN XP".
*   **Total XP / Progress to Next Level** (*Source: User Profile / RPG API*): Drives the linear momentum bar fill percentage.
*   **Previous Level & New Level** (*Source: User Profile / RPG API*): Drives the transition text and concentric ring threshold crossing.
*   **Domain Name & Associated Color/Icon** (*Source: Domain Config API*): Populates toast identification and badge styling.
*   **Action/Habit Name** (*Source: Activity/Task API*): Populates toast context ("Habit done").
*   **CIA Contextual Metrics** (*Source: Health/Analytics Data API*): Real user data (e.g., recovery %, streak count) injected dynamically into the CIA message.

## 7. Screen States
*   **Big Milestone (Default):** Full screen, confetti, badge focal point.
*   **Level-Up Variant:** Full screen, concentric gauge ring around badge, progress bar.
*   **Small Win Toast:** Minimal slide-down bar.
*   **Domain Level-Up Toast:** Proportionate slide-down bar with domain specifics.
*   **Dual Level-Up Variant:** Two stacked toasts (4pt gap, 80ms entrance stagger).
*   **Subscription Success Variant:** Gold/confetti theme, no XP/Level data, specific IAP copy, primary CTA replaces standard share button.
*   **Loading State:** If CIA message is delayed, UI renders with badge, XP, and "CIA is thinking..." text.
*   **Empty State (CIA Failure):** If CIA message fails permanently, the CIA section and divider are hidden entirely; UI collapses gracefully without blank gaps.
*   **Error State (Share/XP Failure):** Share button shows red border/"sharing failed". If XP data is missing, XP section is hidden but overlay proceeds.

## 8. Interactions, Gestures, Motion Intents
*   **Tap (Anywhere on backdrop):** Dismiss overlay (active after 1.2s entrance delay).
*   **Tap (Share Button / CTA):** Trigger native share sheet or navigate to Explore screen.
*   **Tap (Toast):** Navigate to achievement history (Small Win) or domain sub-stats (Domain Level-Up).
*   **Swipe Up (Toast):** Dismiss early.
*   **Motion - Choreographed Entrance:** ~4.5s total sequence. Backdrop fades → Confetti falls → Badge scales in with spring overshoot → XP counts up → Title rises → Progress ring/bar fills → Stroke line draws left-to-right → CIA message fades in → Dismiss hint pulses.
*   **Motion - Reduced Motion:** All animations disabled. Elements appear instantly at final state. Strokes are fully drawn, confetti is removed/static, count-ups show final numbers. Immediate dismissal allowed.

## 9. Free vs Premium Gating
*   **Free Users:** Standard celebration overlays, toasts, XP popups, and domain level-ups.
*   **Premium (Plus) Users:** Unlocks the "Subscription Success Variant" overlay upon successful IAP purchase. Also, spec notes that activation of accountability/social competitions (which may yield unique achievements) requires Plus.

## 10. Cross-Domain Hooks
*   **Correlative AI Insights:** CIA explicitly calls out correlations across different life domains (e.g., "consistency across fitness and finance is coming together").
*   **Radar Chart Symbiosis:** Ties individual actions directly to overarching character growth via the `VK-005 ConstellationRadar` vertex pulse on Screen 16, showing immediate visual feedback on the life areas polygon.
*   **RPG Ecosystem Integration:** Domain level-ups link directly to the RPG Character Screen (Screen 19) for deep dives into sub-stats.
