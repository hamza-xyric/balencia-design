# 2. Purpose
To serve as the central hub for mental wellbeing practices, answering: "what should I do right now, and how consistent have I been?" The screen bridges a browsable library with a full-screen, distraction-free active session, culminating in feedback that feeds CIA's recommendation engine and the broader cross-domain RPG system.

# 3. Entry & exit

*   **Entry Paths:**
    *   Explore Screen [18]: Stack push via "Meditation" grid card.
    *   Home Screen [12]: Stack push via mindfulness action card.

*   **Exit Paths:**

# 5. Components
*   `TopBar` (default): Transparent over atmosphere.
*   `CIAInsightCard` (default): Purple-tinted glass with cross-domain mood/stress data context.
*   `SegmentedTabs` (variant: `scroll-chips`): Horizontal pill filter.
*   `NEW: PracticeListCard`: A `SolidCard` optimized for vertical lists. Rationale: The catalog lacks a dedicated vertical list item with leading icon, trailing duration, and embedded context chips without the intense padding of a standard GlassCard. 
*   `StreakCard` (default): Contains the 7-day strip and heatmap.
*   `KPIRow` (default): Shared `SolidCard` for metrics.
*   `GlassNavBar` (default): Floating pill.
*   `FABQuickLog` (default): For logging mood alongside meditation.
*   `Sheet` (variant: `full`): Used for the Active Session and Post-Session states (detailed in Sections 9 & 10).

# 8. Data & honesty states
Every metric ships with three explicit states. 
*   **Practice Minutes (Trend):**
    *   *Real:* Solid orange sparkline. (Provenance chip: `app log`)
    *   *Low-confidence:* Dashed orange line. (Provenance chip: `estimated · low confidence`)
    *   *Honest-null:* Empty chart frame with: "Not enough data yet — 3 more days for a trend."
*   **Current Streak:**
    *   *Real:* "12 day streak" with full heatmap blocks. (Provenance chip: `app log`)
    *   *Low-confidence:* N/A (Streak is an absolute count, not estimated).
    *   *Honest-null:* "0 days" with muted dots. "Your mindfulness streak starts with your first session."
*   **Consistency Heatmap:**
    *   *Real:* Mapped squares (Low to High intensity: `rgba(255,255,255, .04)` to `#FF5E00`).
    *   *Low-confidence:* N/A.
    *   *Honest-null:* Quiet grid of faint outlines. No fabricated intensity.

# 9. All states
*Note on brief: The brief calls for a "Full-Screen Takeover" for Active Session. We implement this as a `Sheet` (variant: `full`) using `.glass-frost` for true visual separation and scim blocking.*
*   **Default:** Library view visible, data loaded.
*   **Skeleton:** `SkeletonState` matches the geometry of the list cards and KPI tiles. Heatmap renders as a faint grid. Sparklines render as axis + ghost line.
*   **Empty (Cold Start):** Library is populated. `CIAInsightCard` reads: "Welcome to mindfulness. Let's start *simple* — a 3-minute breathing exercise." Heatmap shows honest-null.
*   **Error (Library):** `ErrorState` replaces list: "Couldn't load practices. Check your connection." with BtnSecondary "Retry".
*   **Error (Feedback Save):** Toast overlay: "Couldn't save feedback. Try again."
*   **Active Session State:** `Sheet` (full) slides up. Ambient background (`--bg-warm`). Centered `VoiceMicGlow` (repurposed as a breathing visual, pulsing 0.92 to 1.08 scale). `ProgressRing` wrapped around it.
*   **Post-Session State:** `Sheet` (half). "Session complete. +50 XP." 1-5 Rating scale (Stepper UI). `GlassPillInput` for notes. `BtnPrimary`: "Done".
*   **Disabled (Premium Gate):** `PaywallLock` applies *only* to the post-session rating input and advanced CIA recommendations. Renders as a blurred glass overlay on the rating row with "Plus only" and a `BtnPrimary` to unlock.

# 10. Motion & interaction
*   **Physical Easing:** `cubic-bezier(0.32, 0.72, 0, 1)` for all sheet slides and card scales. 150-250ms timing.
*   **Library Motion:** Staggered fade-ins for cards on load. KPI numbers count up (tabular-nums). Sparkline physically draws itself (stroke-dasharray).
*   **Gestures:** Swipe-from-edge to go back. Swipe-left on `CIAInsightCard` to dismiss recommendation. Double-tap anywhere on Active Session `Sheet` to toggle pause.
*   **Session Motion:** Breathing circle scales continuously (8s loop). `ProgressRing` sweeps smoothly.
*   **Post-Session Motion:** Rating circles cascade-fill left-to-right. Tapping "Done" triggers a 250ms `glow-done` (green) flash across the screen before dismissal.
*   **Reduced Motion:** All breathing loops freeze. Sheets appear instantly (opacity fade only). Sparklines and rings render at their final drawn state immediately.

# 11. Motivation-tier adaptation
*   **Low Density:** `KPIRow` and `StreakCard` are hidden to reduce performance pressure. Filter chips default to "Quick reset" (practices under 5 mins). UI focuses entirely on the single CIA recommendation.
*   **Medium Density:** (Default state). All modules active. Balanced presentation of habit history and future practice.
*   **High Density:** Introduction of a `TrendChart` (7-day minute breakdown) inside the stats module. The `PracticeListCard` expands inline to reveal detailed instructions ("why it helps") without requiring a tap. Longer (15+ min) practices prioritized in the list.

# 12. Accessibility
*   **Contrast:** Paper-100 (#FEFAF3) on `--bg-base` (#0A0A0F) and `--surface-2` (#211008) exceeds 16:1 (AAA). Paper-64% on dark surfaces exceeds AA for secondary text.
*   **Targets:** All filters, practice cards, and session controls strictly adhere to the 44px minimum touch target.
*   **Screen-reader labels:** The breathing orb in the Active Session state is purely decorative; `accessibilityLabel` on the container dynamically announces "Time remaining: 4 minutes, 12 seconds. Double tap to pause."

# 13. Premium checklist (14-point gate)
1.  **Connects:** CIA explicitly pulls cross-domain data (stress/mood) to drive the primary library recommendation.
2.  **Honest:** Every stat handles real, low-confidence, and honest-null gracefully. No fabricated heatmaps.
3.  **Premium:** `.glass-frost` sheet for the session, semantic glows, and Tiempos italic emphasis elevate this above a standard utility timer.
4.  **Selective Glass:** SolidCards used for dense list items and stats; Glass reserved for CIA and the Session overlay.
5.  **60/30/10:** Orange drives primary actions and streaks; Green flashes for completion; Purple isolates CIA.
6.  **Semantic Glow:** `glow-cia` (insight), `glow-you` (effort), `glow-done` (history) map perfectly to the 3 primary modules.
7.  **One Hero Type Moment:** "*stress*" in Tiempos italic anchors the visual hierarchy.
8.  **One BtnPrimary:** "Done" on post-session / "Unlock with premium" on paywalls. Secondary actions use ghost pills.
9.  **CIA Voice:** Sentence case, no exclamations, uses "your", leads with meaning.
10. **Data Viz:** Heatmap uses restrained single-color intensity scale, not a rainbow gradient.
11. **Safety/Consent:** Tapping the FAB to log mood ensures crisis resources are always one tap away from this wellbeing screen.
12. **Paywall:** Implemented as inline blur+unlock, never a dead end.
13. **A11y Floor:** Exceeds AA contrast; double-tap to pause provides motor-friendly session control.
14. **Reduced Motion:** Honored perfectly by freezing the ambient breathing loop and auto-drawing charts.
