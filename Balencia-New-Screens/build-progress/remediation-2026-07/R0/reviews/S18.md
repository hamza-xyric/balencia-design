## Dimension notes
1. Spec conformance — issue: spec's Components list + ASCII composition call for a "ConstellationRadar mini variant" ("small constellation radar") to recap active domains; build substitutes a `DonutHub` donut+legend widget — the codebase's actual shared radar component for this exact "domain recap" concept, `MiniRadar` (kit/data.tsx), is already reused across S12/S13/S16/S19 but not used here.
2. Canon fidelity — ok apart from #5 below (glow applied uniformly/decoratively across catalog tiles rather than meaning-driven per card).
3. Data honesty — issue: "Your active domains" donut segments (5 segments, 22/18/20/20/20=100%) don't reconcile with the adjacent legend (4 rows, 42/28/18/20=108%) in either count or value; on top of that the segment/dot color classes don't even paint (see #4), so no version of this card's number is visually trustworthy.
4. Cross-cutting — issue: `DonutHub` segments and the CIA Sessions legend dot use `bg-*`/`text-*` Tailwind classes on SVG elements that only read `stroke-*` (confirmed by the base ring's own `stroke-white/[0.07]` and by every other correct call site), so the ring and dot render uncolored; ConsentRail (shared kit) renders only 5 of the 8 chip types the spec names for this surface (missing category/scope/freshness).
5. Composition craft — issue: donut reads as a flat, undifferentiated ring in the screenshot (see #4); separately, every catalog tile (Workouts 68%, Yoga 0%, Journal 32%, Habits 0%) carries the identical orange "you/effort" glow regardless of real progress, which is decorative rather than meaning-driven.
6. Copy voice — ok apart from known CIA casing (A24-008, see below).
