# 96-health-data-view

## 1. Header
- **Screen ID:** 96
- **Name:** Health data view
- **Route(s) covered:** `/health-data` (Mobile native, 390x844 reference frame)
- **Tab:** Today / Health & fitness
- **Source:** Functional Content Brief: 96-Health-Data-View
- **Batch:** 12

## 2. Purpose
A provider-neutral dashboard providing users with a clear, unified view of their wearable health metrics. It resolves proprietary data into a single source of truth, manages device connections, and routes deep physiological insights directly to the CIA (Coach) for actionable guidance.

## 3. Entry & exit
**Entry Paths:**
- **Primary Navigation:** Tapping the "Health & fitness" tab (legacy `/whoop` route mapped invisibly to `/health-data`).
- **Deep Link:** OAuth Callback success (`/auth/whoop/callback`, etc.).
- **Dashboard Hook:** Tapping a syncing/readiness widget on the Today screen.

**Exit Paths:**
- **"Talk to CIA"** (Navigates to `/ai-coach` with full health context attached).
- **"Manage Devices"** (Navigates to `/settings` integrations tab).
- **Metric Tap** (Expands metric into a full-screen detail breakdown).
- **Standard browser back** or bottom navigation.

*Correction Note (Section 1 & 3):* Per the explicit contradiction in the brief, the "Whoop" brand name has been entirely abstracted from the UI to maintain a provider-neutral stance, while the legacy backend routes remain supported silently under the hood. 

## 4. Layout anatomy

**Regions top-to-bottom:**
1. **TopBar:** Transparent header for back navigation, screen title, and manual sync control.
2. **Hero Metric (Unified Readiness):** Large interactive dial displaying the Balencia composite score. Pulses when live.
3. **Vital Metrics Bento Grid:** Dense, 2-column data grid for HRV, RHR, Strain, and Sleep, utilizing source-aware provenance chips.
4. **CIA Insight Strip:** Purple-tinted glass card bridging health data and daily action.
5. **Trends & Deep Dives:** Tabbed interface for viewing historical chart data (gated to 7 days for free users).
6. **Data Control & Compliance:** Consent management, data source prioritization, and revoke options.
7. **Bottom Nav:** Floating glass pill with global Quick-Log FAB.

## 5. Components

- **TopBar** (Variant: title-on-scroll) — Transparent over atmosphere.
- **GlassCard** (Variant: hero, radius 40) — Container for the unified readiness score.
- **ProgressRing** — Stroke 8px, orange fill, tabular-nums center for the House Readiness score.
- **BentoGrid** — 2-col layout for dense metric display.
- **GlassStatCard** (Variant: metric, states: real/low/null) — Used for HRV, RHR, Strain, and Sleep.
- **KPIRow** — Mini inline stats for device-native scores.
- **CIAInsightCard** — Purple-tinted glass for bridging health data to coach.
- **BtnCoach** — Purple fill CTA inside the CIA card.
- **SegmentedTabs** — Glass pill track for chart swapping.
- **TrendChart** — Solid orange past line, dashed purple projection, green dots.
- **PaywallLock** — Locked-feature gate applied to long-term trend charts for free users.
- **ListRow** — Data source management and settings list.
- **GlassNavBar** — Floating bottom navigation.
- **FABQuickLog** — Global quick log action.
- **NEW: PrimaryDeviceToggle** — A bespoke segmented control built inside `ListRow` to prioritize data sources (e.g., Whoop vs Apple Health) when conflicts exist. Rationale: The catalog lacks a specific row-level mutually exclusive toggle for multi-source provider routing.
- **NEW: SyncFailureBanner** — A specialized `SolidCard` warning state for cloud sync errors or missing native bridges (Apple/Samsung). Rationale: Honesty invariant requires an explicit, distinct visual for broken provider pipelines rather than a generic quiet error.

## 9. All states

- **Default:** Primary device connected, real data streaming into Bento grid and Hero card.
- **Skeleton:** Shimmer blocks (`--surface-3` base, 1.2s sweep) matching layout geometry. Chart displays axis + ghost line only.
- **Empty (No Connections):** `EmptyState`. Quiet glyph. Copy: `Connect your first device to populate your *whole* health picture.` Button: `BtnPrimary` "Connect device".
- **Error / Sync Failure:** `SyncFailureBanner`. "Sync failure" body text. Plain language, no codes. `BtnSecondary` retry.
- **Stale Data:** `OfflineBanner / SyncStatus` variant. "Offline — showing last sync 14h ago."
- **Success:** `ProgressRing` hits 100% on a daily goal target, stroke flips orange to green with a 250ms sweep.
- **Disabled:** `BtnPrimary` (Connect) renders at 40% opacity, no glow, if a provider OAuth service is down.

## 10. Motion & interaction

- **Physical Easing:** Standard ease-out quintic for all enters and feedback transitions. Never linear.
- **Feedback Duration:** 150-250ms for UI scale responses (e.g., `.98` press scale on metric cards).
- **Glow Behavior:** Hero Readiness Card features a 4-second "breathing" amplitude on `--glow-you` to signify active/live status. 
- **Gestures:** Pull-to-refresh triggers manual background sync. Swiping left/right on the Historical Trends chart scrubs through previous days.
- **Haptics:** Light physical tick haptic on the exact moment a chart scrubber crosses a day boundary.
- **Reduced-Motion Path:** The 4-second continuous breathing glow degrades to a static fill. Chart scrubbing requires a tap to load the day rather than a continuous swipe drag.

## 11. Motivation-tier adaptation

- **Low Density:** Bento grid hides, displaying only the Hero Readiness score and the CIA insight strip. Minimizes cognitive load.
- **Medium Density (Default):** Hero Readiness, 4-tile Bento Grid (HRV, RHR, Strain, Sleep), and the CIA strip.
- **High Density:** Bento Grid expands to a 6-tile view (adds Respiratory Rate and Sleep Performance). Pulled-to-front data provenance chips and micro-trends (sparklines) embedded inside the stat cards.
