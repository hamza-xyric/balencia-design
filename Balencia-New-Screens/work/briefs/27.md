# Functional Content Brief: Workout Detail / Active Workout

## 1. Purpose
Serves as a multi-mode tracker allowing users to preview a workout plan, interactively log exercises in a focused state, and review post-session performance metrics and rewards.

## 2. Entry and Exit Paths
**Entry Paths:**
*   **Stack Push:** Screen 26 (Fitness Dashboard) via "Start workout" CTA or workout card tap.
*   **Deep-link:** Screen 12 (Home dashboard) via action card.
*   **Action:** Floating Action Button (FAB) "Log workout" (established users).
*   **System Resume:** App relaunch prompt ("Resume your workout?") if the app was killed during an active session.

**Exit Paths:**
*   **Stack Pop:** Back button (Planning mode) or "Done" CTA (Summary mode) returns to Screen 26.
*   **Modal Present:** Screen 42 (Celebration overlay) if a level-up milestone is reached.

## 3. Information Architecture
The screen operates as a state machine with three primary layouts.

**Planning Mode** *(Scrollable)*
1.  **Detail Header:** Workout name, metadata, back, and overflow menu.
2.  **CIA Coaching Note:** Contextual planning tip.
3.  **Exercise List:** Numbered rows with sets, reps, rest times, and coach notes.
4.  **Duration Label:** Estimated time.
5.  **Primary CTA:** "Start workout".
6.  **Tab Bar:** Visible.

**Active Mode** *(Fixed/Immersive - Tab Bar Hidden)*
1.  **Progress Bar + Controls:** Current exercise index, elapsed time, pause, and end buttons.
2.  **MomentumBar:** Whole-session set completion visual.
3.  **HR Card (Conditional):** Live heart rate trend.
4.  **KPI Tiles:** Live pace/cadence.
5.  **Current Exercise Display:** Name and current set progress.
6.  **Set Tracker Card:** Weight/rep inputs, previous set reference, and completion CTA.
7.  **Rest Timer (Dynamic):** Appears after set completion.
8.  **CIA Real-Time Note:** Motivational rotating message.
9.  **Next Exercise Preview:** Upcoming routine details.

**Post-Workout Summary Mode** *(Scrollable)*
1.  **Header:** "Workout complete."
2.  **KPI Tiles Strip:** Duration, exercises, calories.
3.  **Effort Hero (ArcGauge):** Session effort score.
4.  **Reward Ring & Donut:** XP progress ring + time-in-zone split.
5.  **CIA Feedback Card:** Data-driven insights.
6.  **Primary CTA:** "Done".
7.  **Tab Bar:** Returns.

## 4. Features and Capabilities
*   **Workout Preview:** View prescribed exercises, sets, reps, and rest times before starting.
*   **Interactive Set Logging:** Editable weight and repetition inputs with auto-focus numeric keyboards.
*   **Auto-Progression:** Completing a set logs data, updates progress bars, and automatically triggers the rest timer.
*   **Rest Timer Management:** Visual countdown with the ability to "Skip rest".
*   **Session Controls:** Pause (locks screen into a resume/discard overlay), End (triggers confirmation).
*   **State Persistence:** If app is killed, workout state is saved locally for seamless resumption.
*   **Manual Workout Logging:** Established users can bypass planned routines and manually input a past workout via a blank template.
*   **Live Health Metrics:** Real-time integration of heart rate, pace, and cadence (requires wearable sensor).
*   **Post-Workout Analytics:** Automated calculation of effort score, XP earned, and heart-rate zone splits.
*   **Offline Support:** Queues set logs locally if network drops and syncs automatically upon reconnection.

## 6. Data Fields and Metrics
| Field / Metric | Data Source |
| :--- | :--- |
| Exercise details (sets/reps/rest) | Predefined workout plan / User manual input |
| Last set reference (weight/reps) | User's previous set log for that exercise |
| Live Heart Rate (bpm) & HR Zones | Wearable sensor via device health API |
| Live Pace / Cadence | Wearable sensor / Device GPS |
| Session Effort Score (0-100) | Derived metric (HR zones + RPE + volume) |
| Time-in-Zone (Z1-Z5 minutes) | Wearable sensor API |
| XP Earned & Level Progression | Gamification engine based on workout completion/volume |
| Duration / Exercises / Calories | Internal app timer / Log count / Caloric estimation algorithm |
| Volume lifted (High Motivation) | Calculated: Σ (Weight × Reps) |

## 7. Screen States & Variants
*   **Planning State:** Default view, scrollable list.
*   **Active State:** Immersive UI, tab bar hidden, screen wake likely active.
*   **Paused State:** Semi-transparent overlay; timers freeze.
*   **Summary State:** Post-completion analytics view.
*   **Cold-Start / Day-1:** CIA generates a 5-exercise starter workout; HR metrics hidden; Summary omits "vs last" deltas; effort labeled "estimated".
*   **Low Motivation Variant:** Shortened workout plan (2-3 exercises); CIA copy adjusted to be highly encouraging; metrics minimized.
*   **High Motivation Variant:** Expanded form cues; adds live volume tracker; summary includes comparative volume BarChart.
*   **Loading State:** Depth-preserving skeleton rings and input outlines.
*   **Empty / No Sensor:** HR card completely omitted (not zeroed); Pace/Cadence tiles display "—".
*   **Error / Offline State:** "Complete set" button shows red border; toast notification for offline queue state.

## 8. Interactions, Gestures, Motion
*   **Gestures:** 
    *   *Swipe right edge:* Back navigation (Planning/Summary only; disabled in Active to prevent accidental exit).
    *   *Pull down:* Refresh workout plan (Planning).
    *   *Long-press (HR Chart):* Scrub crosshair to view past HR data points.
    *   *Tap:* Expand exercise rows, interact with inputs, trigger CTAs.
*   **Motion Intents:**
    *   *Mode Transitions:* 520ms ease-out-soft crossfade.
    *   *Set Completion:* Button provides medium haptic feedback, flashes green glow (600ms), text swaps, and the interface smoothly expands the Rest Timer ring (height 0 to 200pt).
    *   *Rest Timer Ring:* Depletes counter-clockwise utilizing a 3D conic-gradient. Flashes green and triggers medium haptic upon reaching 0.
    *   *Summary Entrance Choreography:* Sequenced draw-in: Header fades -> KPI tiles count up -> Effort ArcGauge sweeps -> Donut draws clockwise -> XP Ring scales and glows -> CIA card fades in.
    *   *Accessibility:* `prefers-reduced-motion` instantly renders all visualizations to their final static states.

## 9. Free vs. Premium Gating
*   **AI Form & Knowledge Analysis:** Basic CIA planning notes are free; deep AI video/form analysis and advanced progressive overload tracking are Premium.
*   **Advanced Metrics:** Standard summary (duration, calories, XP) is free. Advanced deeper analytics (Heart Rate zone splits, precise effort ArcGauge, and cross-domain correlations) require Premium.
*   *(Note: Source documents indicate AI insights and OAuth/health data syncing are earmarked for premium tiers, though exact UI gating boundaries are not explicitly bounded for every metric).*

## 10. Cross-Domain Hooks
*   **CIA Adaptive Intelligence:** CIA (Coach Persona) dynamically alters UI copy based on life context (e.g., "Good pairing with yesterday's **cardio**").
*   **Knowledge Graph Integration:** Deep-linking to guided insight maps (V1) for form cues and muscle groups.
*   **Achievement System:** Pushes XP and level-up triggers to the global user profile, potentially triggering the Celebration overlay (Screen 42).
*   **Health App Sync:** Pulls live data from external health/OAuth domains; explicitly relies on accurate scope and revocation clarity.

---
### ⚠️ Source Contradiction Flag
*   **Persona Name:** The source text intermittently references the coach persona as "SIA" (e.g., "SIA Coaching Note", "SIA Real-Time Note"). Per the critical instruction, this has been explicitly mapped to **CIA** universally in this brief.
*   **Typography / Visual Styling:** The source text includes extensive pixel-level typography metrics (e.g., 24pt Bold, 13pt Regular) and color hex codes. Per the functional extraction constraint, these have been omitted in favor of semantic visual intents (e.g., "focal pair", "warm-glow surface", "secondary text").
*   **Rest Timer Progression:** Early layout notes describe the rest ring as a "120pt circular countdown" that fills/depletes, while later audit resolutions clarify it must be a true 0→1 completion bounded ring (GaugeRing). The functional spec treats it strictly as a bounded completion visual.
