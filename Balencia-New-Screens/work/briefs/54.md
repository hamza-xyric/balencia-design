# FUNCTIONAL CONTENT BRIEF: Meditation & Mindfulness [Screen 54]

## 1. Purpose
This screen serves as the user's meditation and mindfulness hub, answering "what mindfulness practice should I do right now, and how consistent have I been?" It bridges a browsable library of practices with a focused, full-screen active session, culminating in RPG rewards and effectiveness feedback that feed back into CIA’s recommendation engine.

## 2. Entry and Exit Paths
**Entry Paths:**
*   **Explore Screen [18]:** Stack push via "Meditation" grid card.
*   **Home Screen [12]:** Stack push via mindfulness action card ("CIA recommends a 5-min body scan").
*   **CIA Chat [09]:** Deep-link via chat suggestion ("Try this breathing exercise").

**Exit Paths:**
*   **Explore [18]:** Stack pop via back button.
*   **CIA Chat [09]:** Tab switch via tapping the CIA Recommended Card body.
*   **Active Session (Overlay):** Full-screen takeover when a practice is started.
*   **Celebration Overlay [42]:** Modal trigger on streak milestone or RPG level-up.
*   **RPG Character Screen [19]:** Stack push via tapping the domain Level Badge.

## 3. Complete Information Architecture
The screen operates via a strict 3-state mode architecture: Library, Active Session, and Post-Session.

**Library View (Scroll View):**
1.  **Domain Header:** Sticky. Back button, Domain Title, RPG Level Badge.
2.  **Filter Chips:** Horizontally scrolling category filters.
3.  **CIA Recommended Card:** AI-personalized contextual prompt.
4.  **Practices Library:** Vertically scrolling list of practice cards.
5.  **Mindfulness Streak Module:** 7-day dot strip and consistency heatmap.
6.  **Stats Module:** KPI tiles (sessions, minutes, streak) and favorite category momentum bar.

**Active Session View (Full-Screen Overlay):**
1.  **Ambient Background:** Calming, subtle gradient wash.
2.  **Pulsing Circle:** Visual anchor simulating a breathing rhythm.
3.  **Progress Ring:** Honest, continuous arc wrapping the pulse circle.
4.  **Timer & Meta:** Countdown timer and practice name.
5.  **Controls:** Pause/Play, Skip (if multi-section), End Session.

**Post-Session View (Full-Screen Overlay):**
1.  **Header & XP:** Completion message and RPG XP earned badge.
2.  **Practice Summary:** Name and duration completed.
3.  **Effectiveness Rating:** Interactive 1-5 scale input.
4.  **Note Input:** Optional text field for qualitative feedback.
5.  **Primary CTA:** Dismiss feedback and return to the library.

## 4. Every Feature and Capability
*   **Practice Library Browsing:** Users can browse a curated list of guided practices featuring metadata (category, duration, benefits, contextual timing).
*   **Category Filtering:** Horizontally scrolling chips to filter the library (All, Meditation, Quick Reset, Movement, Evening Wind-down).
*   **AI Recommendations:** Dynamic, context-aware practice recommendations generated by CIA based on mood, stress, and behavioral patterns.
*   **Card Expansion:** Tapping a practice card expands it in place to reveal detailed instructions.
*   **Quick Actions:** Long-pressing a practice card opens a menu (Begin, Add to Favorites, Ask CIA).
*   **Guided Active Sessions:** Full-screen, distraction-free timer with ambient pulsing visuals and honest progress tracking.
*   **Session Controls:** Pause/resume, skip section, and end session early (with inline confirmation).
*   **Accessibility Shortcuts:** Double-tap anywhere on the active session screen to toggle pause.
*   **Effectiveness Feedback:** Post-session, users can rate the practice 1-5 and leave an optional note.
*   **Streak Tracking:** Visualization of consecutive days of practice, including a 7-day strip and a 28-day consistency heatmap.
*   **Cumulative Metrics:** Tracking total sessions, total minutes, longest streak, and category distribution.
*   **Motivation Adaptation:** The UI dynamically adjusts visible content (e.g., hiding stats, showing shorter practices) based on the user's current motivation tier (Low/Medium/High).

## 7. All Screen States Mentioned
*   **Cold-Start / Day 1:** Library pre-populated with system practices. CIA offers a simplified 3-min practice. Streak dots empty (today dashed). Stats read "0"; sparkline & favorite row hidden.
*   **Established (Zero Session Today):** CIA prompts based on time of day. Library shows green checkmarks on completed practices. Streak visualizes momentum accurately.
*   **Post-Session (Just Completed):** CIA card updates with a relevant follow-up. Completed practice card retains a green checkmark.
*   **Loading:** Depth-preserving skeletons on cards, heatmap cells, and stat tiles. Sparklines draw into shape. Toast: "finding practices tailored for you...".
*   **Empty / Sparse:** "no practices in this category" if filter yields no results. Sparklines with <7 data points show individual dots, not a fabricated line.
*   **Error:** Graceful degradation. Individual chart failures show "—" instead of 0. Toast: "couldn't load practices". Feedback save failure: "couldn't save feedback. try again."
*   **Offline:** Cached data shown. Banner: "you're offline -- practices available, stats may not update." Audio-gated practices prompt: "This practice requires a connection."
*   **Disabled:** Premium-gated elements muted with "Plus only" badge.
*   **Expanded:** Practice card grows in place to reveal instructions.

## 8. Interactions, Gestures, and Motion Intents
*   **Navigation:** Standard swipe-from-edge to go back. Pull down to refresh data.
*   **Taps & Presses:** Tap card to expand; long-press card for quick action menu.
*   **Swipes:** Swipe left on the CIA card to dismiss the recommendation.
*   **Active Session Gestures:** Double-tap anywhere to toggle pause. Tap 'End' for inline confirmation.
*   **Motion Intents (Library):** Staggered fade-ins for cards. KPI Stat Tiles count up from 0 on scroll-into-view. Streak heatmap cells stagger in. Minutes sparkline physically draws itself (stroke-draw).
*   **Motion Intents (Session):** Full-screen overlay scales in. Breathe circle continuously scales 0.92 to 1.08 (8s loop). Progress ring sweeps continuously in real-time. Pause halts the ring and animation without changing color (no alarm).
*   **Motion Intents (Post-Session):** Content crossfades in. XP badge scales in. Rating circles cascade-fill left-to-right. 'Done' triggers a green glow flash before dismissal.
*   **Motion Intent (Reduced Motion):** Loops freeze. Overlays appear instantly. Sparklines and rings render at their final drawn state immediately.

## 9. Free vs Premium Gating
*   **Free Tier:** Practice library browsing, filtering, viewing stats/streaks, and the Active Session timer are universally available.
*   **Premium (Plus) Tier:** CIA personalized recommendations, the ability to execute post-session effectiveness ratings, and contextual qualitative notes require Plus. Missing premium features are visually muted with a "Plus only" badge.

## 10. Cross-Domain Hooks (Correlations, AI Insights, Links)
*   **CIA Chat [09]:** Direct link from the library's emotional anchor card. Tapping the CIA card body opens a deep-linked conversation in the chat tab with full mindfulness context.
*   **RPG System & Home:** Session completion triggers the Celebration Overlay [42], driving overall life balance scores and domain XP, which feeds back into action cards on the Home Screen [12].
*   **Mood/Stress Context:** The CIA recommendation engine explicitly pulls cross-domain data (current mood, stress level, time of day) to formulate its localized suggestions (e.g., "Your stress has been elevated since this morning").
*   **Domain DNA:** The visual logic and state machine established here (Library -> Active Session Timer -> Post-Session Feedback) directly feeds shared component patterns for both Spirituality [34] and Fitness/Workouts [27].
