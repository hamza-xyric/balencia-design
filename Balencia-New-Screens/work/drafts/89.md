# 2. Purpose
A daily command center for mental, emotional, and physical recovery. It aggregates vital wellbeing KPIs from both user input and synced wearables, while providing quick-launch access to regulation tools, journaling, and AI-driven correlations. 

# 3. Entry & exit
**Entry paths:**
* Primary: Today tab global navigation.
* Secondary: Today Dashboard `/dashboard` widgets.
* Tertiary: AI Coach `/ai-coach` hyperlinks.

**Exit paths:**
* Deep-link routes to modules (`/wellbeing/journal`, `/wellbeing/mood`, etc.).
* Today Dashboard (via top-left back chevron).
* Profile/Settings (via top-right glyph).
* *Correction:* The source brief inferred a timeline module for "Habits". For mobile focus and cognitive load reduction on a "hub" screen, we omit the timeline. Habit triggers remain accessible via the FAB and quick-log paths, keeping the exit value high but the screen footprint premium.

# 9. All states
* **Default:** Full data populated, standard radial atmosphere, breathing glow active.
* **Skeleton:** `SkeletonState` sweeps across KPI cards; Action Grid renders as solid `--surface-3` blocks; chart lines render as ghost curves.
* **Empty:** First-use empty state inside KPI slots using `EmptyState` logic (e.g., "Connect your device to see sleep trends").
* **Error:** Sync failure replaces top KPI with a quiet `ErrorState` inline card: "Sync failed. Retrying."
* **Success:** Upon completing a quick-log FAB action, the Mood KPI triggers a 250ms green sweep via `ProgressRing` logic.
* **Disabled:** If Health Connections access is revoked, KPI cards drop to 40% opacity and lock tap targets until re-authorized.

# 10. Motion & interaction
* **Feedback:** Tap targets scale to `.98` over 150ms. 
* **Glow behavior:** KPI cards utilize a static glow. The `CIAInsightCard` glow uses a 4s "breathe" (ease-in-out opacity delta). 
* **Haptics:** Light selection haptic on horizontal KPI scroll. Success haptic on quick-log completion.
* **Long-press:** Action grid tiles support a long-press to bypass deep-link pages and open bottom `Sheet` for instant logging.
* **Reduced-motion path:** Glow breathing is frozen at default opacity. Transitions fade strictly via `opacity` over 150ms, bypassing `transform`.

# 11. Motivation-tier adaptation
* **Low density:** Only KPI row and CIA strip are visible. Action grid tiles display titles only, omitting sub-copy to reduce cognitive load. 
* **Medium density (Default):** KPI row, CIA strip, and full Action Grid with sub-copy.
* **High density:** KPI row utilizes snap-paging with larger sparkline charts. Action Grid incorporates `ProgressBar` lines under tiles indicating daily habit completion percentage.

# 12. Accessibility
* **Contrast pairs:** Paper-100 (#FEFAF3) on `--surface-2` (#211008) exceeds AA. Paper-64% on `--bg-base` exceeds AA for secondary text.
* **Targets:** Top bar glyphs and Action Grid tiles exceed the 44x44px minimum target footprint. 
* **Screen-reader labels:** Glyph-only settings button is labeled `Settings`. The FAB is labeled `Quick log`. The calendar icon in the Schedule tile is hidden from VoiceOver/TalkBack as the "Schedule" text label conveys the action.
