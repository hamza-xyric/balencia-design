# 2. Purpose
To serve as the user's identity hub and central navigation gateway. It answers "who am I in this app?" at a glance via RPG progression and identity stats, while providing structured pathways to personal sub-screens and AI-driven feature discovery.

# 3. Entry & Exit
* **Entry:** "Me" tab tap in `GlassNavBar` or back navigation (stack pop) from any `/me/*` sub-screen.
* **Exits:** 
  * `Settings` [21] via top-right gear (glyph-only).
  * `Profile Edit` [50] via avatar tap.
  * `RPG Character` [19] via level badge tap.
  * `Mission Journal`, `Personal Wiki`, `Connected Apps`, `Subscription`, etc., via `QuickLinkTile` taps.
  * Domain dashboards via Explore module cards.
  * *Correction to Brief:* The brief specified a 2-column, 5-row grid (10 cards) for navigation. On a 390px mobile screen, 10 dense cards vertically stacked requires excessive scrolling and breaks the "premium, generous space" canon rule. I have reduced the primary navigation hub to 4 essential `SolidCard` tiles and moved secondary routes to an optimized `ListRow` stack, keeping the screen under 1 viewport height before scroll.

# 4. Layout Anatomy
**Regions (Top-to-Bottom):**
1. **TopBar:** Transparent header with screen title and settings glyph.
2. **Profile Anchor:** `GlassCard` (Hero) housing avatar, name, level badge, and XP progress.
3. **Progression Snapshot:** 2x2 `BentoGrid` using `SolidCard` wrappers for legibility.
4. **Life Power Composition:** `SolidCard` containing top 5 domain `ProgressBars` with dynamic copy.
5. **Navigation Hub:** 2x2 `BentoGrid` of primary quick links.
6. **Secondary Nav:** Stacked `ListRow` components for low-priority routes.
7. **Discovery:** Horizontally scrolling `CIAInsightCard` variants.
8. **GlassNavBar:** Global floating pill.

# 5. Components

# 6. Visual Treatment
* **Glass Tier:** `GlassCard` (Hero tier) is reserved for the Profile Anchor to make it the focal point. `SolidCard` is used for all data-dense areas (Stats, Nav, Composition) per canon to preserve legibility and prevent glass-mudding.
* **Glow Color & Meaning:** 
  * **Profile Anchor:** `--glow-you` (#FF5E00). Signifies the user's active identity and effort.
  * **CIA Discovery Card:** `--glow-cia` (#7F24FF). Signifies AI-projected insights.
* **Background Atmosphere:** `--bg-base` with the mandatory warm radial glow top-center and 3-4% soft-light grain. No purple pool here to keep the emphasis on the warm orange user identity.
* **Hero Type Moment:** The user's name inside the Profile Anchor, rendered in Display NM Medium 500, with their *focus* word rendered in Tiempos italic (e.g., "*whole*-life level").

# 9. All States
* **Default:** Fully populated identity hub as spec'd.
* **Cold-start / Day 1:** Profile at Lv.1, 0 XP. Avatar uses first initial. StatBars show ghosted/dashed tracks for unstarted domains. Quick links adapt subtitles ("choose a plan"). Hero ring shows honest 0% (faint full track, no degenerate point).
* **Empty / Partial Sync:** Ghosted/dashed StatBars tracks for un-synced domains (no-data ≠ zero). Missing stats render skeletons; others populate. 
* **Error:** Cached data shown if available; otherwise skeleton. Genuine sync failure triggers `OfflineBanner`. `AvatarBlock` upload failure triggers a brief red flash over the camera overlay.
* **Success:** "Stats refreshed" toast auto-dismisses after 2.5s.
* **Disabled:** Pull-to-refresh is dimmed (40% opacity) and stripped of haptics when offline. Locked modules render `PaywallLock` (blurred glass preview) instead of hiding.

# 10. Motion & Interaction
* **Physical Easing:** Strict draw-first sequence on entrance. Profile fades in (150ms) → Hero Life Power dial ring fills (`0→value`, 250ms) → XP bar draws (`0→value`, 250ms) → Stats count up → StatBars rise vertically (`0→value`, 250ms, 60ms stagger) → Nav and Explore cards fade in.
* **Feedback:** All `QuickLinkTile` and `ListRow` taps execute `scale(0.98)` with light haptic impact in 150ms.
* **Glow Behavior:** The Profile Anchor `glow-you` executes a 4s continuous "breathe" (opacity 55% → 70% → 55%) to signify a living identity.
* **Reduced Motion:** Count-ups and bar drawings are bypassed. Elements appear at final state instantly. Glow breathing is frozen at static 55% opacity.

# 11. Motivation-Tier Adaptation
* **Low Density:** Encouraging CIA copy replaces the Life Power composition ("just checking in today counts"). Explore modules prioritize basic logging tasks.
* **Medium Density (Default):** Base stats and top 5 domains shown as specified.
* **High Density:** "This week" delta trends (▲ / ▼) appear next to stats. Life Power composition expands to show all 10 domains. Explore section unlocks cross-domain analytics and correlation modules directly from the preview.

# 12. Accessibility
* **AA+ Contrast:** Paper-100 (#FEFAF3) on `--surface-2` (#211008) ensures strict >7:1 contrast for all KPI values.
* **44px Targets:** All `ListRow` items maintain 56px min-height. The Settings gear icon in `TopBar` is given an invisible 44x44px padding container to ensure easy tapping.
* **Screen Reader:** The Settings gear is labeled `aria-label="Open settings"`. Avatar upload icon is `aria-label="Change profile photo"`. Domain stats are read as: "Wellbeing score, 40 out of 99."
