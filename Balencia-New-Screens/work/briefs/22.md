# Functional Content Brief: Connected Services

## 1. Purpose
Enables users to manage external data pipelines (health, nutrition, productivity, lifestyle) that feed into Balencia's life-correlation engine. It serves as the central hub making the value of connecting clear while keeping management simple: connect, view sync status, and disconnect.

## 2. Entry and Exit Paths
*   **Entries (Stack Push):** 
    *   Me Main [17] screen via quick link grid.
    *   Settings [21] screen via "connected services" row.
*   **Exits (Stack Pop):**
    *   Back button/swipe returns to the previous screen ([17] or [21]).
    *   External system OAuth flows (system browser or in-app browser for authorization).

## 3. Information Architecture
The screen is a vertical scrolling view containing the following top-to-bottom hierarchy:

*   **Navigation Header:** Back chevron + "Connected services" title.
*   **CIA Coaching Note Card:** Contextual message adapting to the user's connection state.
*   **Wearables & Fitness Section:**
    *   WHOOP, Apple Health, Fitbit, Garmin, Oura Ring, Samsung Health, Strava.
*   **Nutrition Section:**
    *   MyFitnessPal, Nutritionix, Cronometer.
*   **Productivity Section:**
    *   Google Calendar.
*   **Lifestyle Section:**
    *   Spotify.

## 4. Features & Capabilities
*   **Integration Management:** Connect, force sync, or disconnect external services.
*   **Data Pipeline Visualization:** View exactly what data types are syncing (e.g., "Syncing: sleep, HRV, recovery") or what data *will* sync if connected.
*   **Manual Refresh:** Pull-to-refresh the entire screen or tap "Force sync" on individual cards to trigger manual data syncs.
*   **OAuth Trust Previews:** Explicit scope preview modals before authorization, detailing exact data points, storage policies, and disconnect capabilities.
*   **Status Tracking:** View time of last successful sync.
*   **Availability Notifications:** Tap "Notify me when available" for pending integrations to register interest.

## 5. UI Copy (Verbatim Strings)
**CIA Coaching Note Variants:**
*   *Day 1:* "Connecting your services helps CIA see your full picture — sleep, workouts, calendar, and more."
*   *1+ Connected:* "[Service] connected — CIA can now factor in your [specific data, e.g., recovery scores]."
*   *All Connected:* "All your services are syncing. CIA has your full picture now."

**Buttons & Badges:**
*   Primary Action: `Connect`
*   Secondary Actions: `Force sync` / `Disconnect`
*   Status Badges: `Connected` / `Not connected` / `sync pending`
*   Disabled Action: `Notify me when available`

## 6. Data Fields & Metrics
*   **Connection Status:** `[Connected / Not connected / Sync pending / Reconnect required]`
    *   *Source:* Connected services API.
*   **Syncing Data Types:** `e.g., "sleep, HRV, body temp"`
    *   *Source:* Hardcoded per integration scope mapping.
*   **Last Sync Time:** `e.g., "Last sync: 2 minutes ago."`
    *   *Source:* Connected services API sync timestamp.

## 7. Screen States
*   **Cold-Start / Day 1:** All 11 cards display in "Not connected" state, showing the *value* of the data rather than empty status. CIA note is prominently framed as a choice, not a requirement.
*   **Loading (OAuth / Syncing):** Inline spinners replace button text. Scope preview modal slides up. Other cards remain fully interactive.
*   **Empty / Partial Sync:** Cards independently show mixed states. Missing data is represented honestly without dashed lines or "empty" ghost UI.
*   **Error:** Buttons flash error text for 3 seconds. Warm error banners appear below cards with actionable recovery text. Scope changes trigger inline warning cards.
*   **Offline:** Force sync and Connect buttons are disabled (dimmed). Cached "Last sync" times are shown in muted text. Persistent offline banner is pinned below the nav header.
*   **Disabled (Coming Soon):** Cards for unreleased services show a disabled `Notify me when available` button.

## 8. Interactions, Gestures & Motion
*   **Tap:** Triggers Connect (opens OAuth), Force Sync (manual fetch), or Disconnect (opens alert).
*   **Pull-to-refresh:** Global screen refresh; triggers skeleton loading states on sync details.
*   **Swipe right from edge:** Stack pop returns to previous screen.
*   **Motion Intent:** 
    *   *Entrance:* Staggered vertical translation and fade-in for cards as they enter the viewport.
    *   *State Transitions:* Crossfade transitions between unconnected/connected UI states. Morphing animations on buttons indicating success/failure.
    *   *Reduced Motion:* All animations collapse to instant state changes.

## 9. Free vs. Premium Gating
*   **Accessibility:** Connecting and managing basic integrations is functionally available to all users.
*   **Premium Tiering:** (Per Audit Q33) Deep-dive "Life Areas comparison" insights generated *from* these integrations are Plus-gated, requiring enough user history to unlock. General connection management has no friction.

## 10. Cross-Domain Hooks (Correlations & AI Insights)
*   Integration data does not live in silos; it feeds directly into the **CIA (Coach Persona)**. 
*   **Correlations:** Connecting Calendar and WHOOP allows CIA to correlate schedule density with dropping recovery scores.
*   **Contextual Hooks:** Spotify listening data is used as mood/energy signals; Nutrition data contextualizes workout strain. 
*   **Visible Value:** Whenever a user connects a service, the CIA note dynamically updates to explain *exactly* which cross-domain insight is now unlocked (e.g., "CIA can now factor in your recovery scores").
