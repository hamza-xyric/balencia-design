Honesty rules:
- Export truncation (`counts.exported < counts.total`) must surface in the VM (`truncated`), never hidden.
- Account deletion is IMMEDIATE and PERMANENT — no code path or copy may imply an undo/grace period (server has none).
- No consent-history/audit API exists — do NOT fabricate one; P11 renders an honest "not available yet" state.

## Acceptance criteria
- `tsc --noEmit` clean.
- Delete request body contains the EXACT confirmation literal; password included only when provided.
- Privacy mutation is optimistic with rollback on error and invalidates `preferences` on settle.
- `GATED_FEATURES` copy is honest (no "coming soon" promises with dates, no fake data).
