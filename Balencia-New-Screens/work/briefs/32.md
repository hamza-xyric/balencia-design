# FUNCTIONAL CONTENT BRIEF: Career & Work Dashboard

## 1. Purpose
The Career & Work Dashboard is an action-oriented hub where users track professional growth, active career goals, and upcoming deadlines. It translates professional development into actionable daily tasks and visually tracks growth momentum without overwhelming the user with dense data.

## 2. Entry and Exit Paths
*   **Arrives from:**
    *   Explore Section (Screen 18) via standard stack push.
    *   CIA Chat (Screen 09) via deep-link.
*   **Exits to:**
    *   **Primary Exit:** Goal Detail (Screen 14) via tapping a goal card, progress gauge, or deadline tile.
    *   **Secondary Exits:** 
        *   CIA Chat (Screen 09) via tapping the CIA note, "ask CIA →" link, or empty-state prompts.
        *   Create/Edit Goal (Screen 15) via the "add career goal" affordance.
        *   RPG Character Screen (Screen 19) via tapping the Level Badge.

## 3. Information Architecture (Top-to-Bottom)
1.  **Global Navigation:** Status bar, Tab Bar (Today, CIA, Goals, Me), and bottom safe area.
2.  **Domain Header:** Screen title, back button, domain level badge, and XP icon.
3.  **CIA Coaching Note:** Cross-domain AI insight and prompt.
4.  **Active Goals Section:** 
    *   Section eyebrow.
    *   Primary (Hero) Goal Card (contains 96px focal gauge).
    *   Secondary Goal Card(s) (contains 48px compact gauge).
5.  **Career Momentum & Action Header (High Motivation Tier Only):**
    *   Daily Session/XP Momentum Bar.
    *   Action-Type Mix Composition Bar.
6.  **Suggested Actions Section:**
    *   Section eyebrow.
    *   List of AI-suggested semantic action rows.
7.  **Growth Trajectory Section:**
    *   Section eyebrow.
    *   Skill StatBars (Value vs. Target).
    *   Selected Skill Historical Sparkline (High Motivation Tier Only).
    *   CIA Skill Assessment Summary.
    *   Career Momentum Trend Line (Historical vs. AI Projection).
8.  **Upcoming Section:**
    *   Section eyebrow.
    *   Deadline KPI Tiles (Day-counts and proximity signs).
9.  **Consistency Section (High Motivation Tier Only):** Action history calendar heatmap.

## 4. Features and Capabilities
*   **Goal Tracking:** Visualize active career goal progression via progress gauges. Tap to view deep details or specific next actions.
*   **Action Completion:** Inline completion of AI-suggested tasks. Earn immediate XP feedback. Ability to skip, reschedule, or ask the AI for the reasoning behind a suggestion.
*   **Skills Inventory:** View personal skill levels on a 1-10 baseline compared against a target. Tap to view historical trends and improvement recommendations.
*   **Deadline Monitoring:** Visual countdown to professional deadlines. Ability to reschedule past-due items without shame. 
*   **Progress Visualization:** View overall career momentum over a 6-week period, including an AI-projected trajectory. Track daily action consistency via a heatmap.
*   **Cross-Domain AI Coaching:** Receive actionable, cross-life insights from the CIA persona.

## 7. Screen States
*   **Loading:** Depth-preserving skeletons (ring arcs, bar tracks, axes) that morph into drawn data. Copy: *"CIA is preparing your career actions — one moment."*
*   **Cold-start / Day-1:** Ghosted dashed goal gauge outline (no filled 0% disc); ghosted skill bars (no fake zeroed data); flat baseline for momentum line; hidden deadlines section. Includes onboarding CTAs ("Add a career mission").
*   **Established Zero-State (All Done):** Green checkmark illustration. Copy: *"All caught up. CIA will suggest new actions tomorrow."*
*   **Error / Partial Failure:** Per-card skeletons retain cached data. Network banner displayed. Offline banner displayed if disconnected. Checkbox sync failure results in a red ring flash and reverts to unchecked.
*   **Goal Variants:** Active (standard), Near-complete (>80% - green fill), Stalled (Orange fill + "Need help with this?" text label).
*   **Action Variants:** Uncompleted, Completed (strikethrough, XP earned), Skipped (dimmed).
*   **Deadline Variants:** Far (>7d, neutral), Approaching (3-7d, proximity sign + "approaching"), Urgent (<3d, proximity sign + "!" + "soon"), Past-Due (neutral muted, strikethrough, "passed — reschedule?"). 

## 8. Interactions, Gestures, Motion Intents
*   **Taps:** 
    *   Goal Card / Next Action Text -> Goal Detail (Screen 14).
    *   Action Checkbox -> Toggle complete (XP floats up, strikethrough text).
    *   Action Text -> Expand details / CIA explanation.
    *   Skill Pill / StatBar -> Expand history and CIA improvement recommendations.
    *   Deadline Tile -> Goal Detail.
    *   CIA Note -> CIA Chat (Screen 09).
    *   Level Badge -> RPG Character Screen (Screen 19).
*   **Swipes:** 
    *   Swipe Left on Action -> Skip.
    *   Swipe Right from Edge -> iOS back.
    *   Horizontal Scroll on Skills row -> View more skills.
*   **Long-Press:** 
    *   Action Card -> Options menu (reschedule, modify, ask CIA why).
    *   Deadline Row -> Edit/reschedule.
    *   Momentum Trend Line -> Scrub a crosshair across weeks.
*   **System Gestures:** Pull-to-refresh reloads all career data.
*   **Motion Choreography:** Hero gauge draws first (arc fill + count up), followed by secondary gauges, then rising skill bars, count-up deadline numbers, and finally the drawing of the momentum trend line. All charts respect `prefers-reduced-motion` and render in their final static state instantly.

## 9. Free vs. Premium Gating
*   **Global Dashboard Access (Free):** Tracking career goals, completing suggested actions, and viewing the primary skills inventory and upcoming deadlines are baseline features. 
*   **High-Motivation / Premium Tier Features:** Advanced data visualizations are gated behind a "high-motivation tier." This includes the Daily Session Momentum Bar, Action-Type Mix Composition Bar, Selected Skill Sparkline, and the Action Consistency Heatmap. *(Note: The source spec flags these specifically as "high-motivation tier only").*

## 10. Cross-Domain Hooks (Correlations, AI Insights, Links)
*   **Health/Career Intersection:** The CIA explicitly bridges the Health and Career domains via the coaching note: *"Your productivity peaks after morning workouts. Schedule deep work for 10am?"*
*   **RPG / Gamification Ties:** Career goals and actions directly feed the user's global "RPG Character" level (Lv.5 displayed in header, navigates to global RPG profile). 
*   **Global CIA System:** Every career metric (skill levels, action consistency) feeds into the centralized CIA persona, allowing the AI to make assessments (*"Communication is your strongest area"*) and suggest constructive levers across other areas of the user's life. 

---
### ⚠️ Source Contradictions & Audit Flags
*   **Terminology:** The persona is formally renamed **CIA** throughout this brief, replacing all instances of "SIA" found in the source document. 
*   **Competing Focal Heroes:** The source IA prioritized the CIA note as the primary visual focus above goals. The spec's visualization audit later contradicted this, establishing the **96px Lead-Mission GaugeRing** as the sole focal hero. *Resolution: The 96px gauge is the focal point; the CIA note is a visually quieter preamble.*
*   **Line Signature Status:** The career-momentum TrendChart was initially described as the "brand signature." The Design Elevation later redefined it as a "workhorse trend," making the warm-glow chart system the actual brand signature. *Resolution: Followed the workhouse designation; charts use warm-glow styling.*
*   **Stale ASCII Wireframes:** Early ASCII wireframes in the source document showed flat progress rings and red urgent coloring. *Resolution: Explicitly ignored legacy styling in favor of the audited, depth-preserving gauge components and non-shaming, glyph+word status labels.*
