# FUNCTIONAL CONTENT BRIEF: Shopping List

## 1. Purpose
Bridges CIA's AI-generated meal plans and user-saved recipes with real-world grocery execution. Automatically generates, categorizes, and sorts a unified shopping list while allowing manual additions and quick, one-handed in-store check-offs.

## 2. Entry & Exit Paths
*   **Entries (Stack Push):**
    *   Nutrition Dashboard `[28]` → "Shopping list" quick action card.
    *   CIA Chat `[09]` → Deep-link triggered by CIA ("I've added ingredients...").
    *   Recipe Detail Screen → "Add ingredients to list" action.
*   **Exits:**
    *   **Primary:** Nutrition Dashboard `[28]` (via stack pop / back button).
    *   **Secondary:** CIA Chat `[09]` (via empty state CTA or tab switch).
    *   **Secondary:** Recipe Detail (via stack push by tapping recipe source badge).

## 3. Information Architecture
**Scroll Behavior:** Grouped list with sticky section headers.
**Layout Sequence (Top-to-Bottom):**
1.  **Fixed Screen Header:** Back navigation, Screen Title, Domain Accent Rule, Overflow Menu.
2.  **Inline Add Input (Focal Hero):** Persistent text field for quick manual additions.
3.  **List Summary Bar:** Counts (total/purchased) + Hairline progress read + Show/Hide toggle.
4.  **Category Sections (Scrollable):** 9 grouped aisles (Produce, Protein, Dairy, Grains, Snacks, Beverages, Pantry, Frozen, Other). Contains collapsible headers and item rows.
5.  **Purchased Section (Conditional):** Displays completed items when toggled.
6.  **Action Bar:** Bulk list management utilities.
7.  **Floating Action Button (FAB):** Persistent secondary add path.
8.  **Global Tab Bar:** Persistent app navigation.

## 4. Features & Capabilities
*   **Smart Inline Addition:** Text parsing auto-splits item name and quantity (e.g., "2 avocados" → Name: Avocados, Qty: 2).
*   **AI Auto-Categorization:** CIA asynchronously infers store aisles for manual entries.
*   **List Management:** Edit (name, quantity, category, notes), delete, and bulk clear purchased items.
*   **State Toggles:** Collapsible categories; show/hide purchased items.
*   **Delayed Move with Undo:** Checking an item starts a 1.5s delay before moving it to the "Purchased" section, preventing accidental mis-taps.
*   **Offline Mode:** Local caching allows item check-offs, additions, and edits while disconnected; queues for background syncing.
*   **Share/Export:** Generates a plain-text, formatted list to native OS share sheet.
*   **Intelligent Merging:** Deduplicates items (combines manual + AI-generated quantities for the same item).

## 6. Data Fields & Metrics
**API Endpoints:** `GET`, `POST`, `PATCH`, `DELETE /api/shopping-list`
**Data Source:** `shopping_list_items` table
*   `name` (String): Item display name.
*   `quantity` (String): Flexible units (e.g., "200g", "2 cans").
*   `category` (Enum): Aisle grouping.
*   `source` (Enum): `manual`, `diet_plan`, `recipe`.
*   `source_description` (String): URL/link to specific recipe or meal plan day.
*   `is_purchased` (Boolean): Check-off state.
*   `purchased_at` (Timestamp): Purchase time.
*   `priority` (Integer): 0 = normal, 1 = high.
*   `calories` (Integer): Optional macro data for high-motivation views.
*   *Computed Metric:* List Completion % (Purchased Count / Total Count).

## 7. Screen States
*   **Default:** Categories expanded, active and purchased lists separated.
*   **Empty (Cold Start):** No list generated. Prompts manual add or CIA chat.
*   **Loading:** Skeletons preserving row height; CIA generation message.
*   **All Done:** All items purchased; summary progress arrives at 100%.
*   **Error:** Load fails, Add fails, Check-off fails, Sync fails (uses cached data with retry banners).
*   **Offline:** Cached data shown with offline banner; actions queue.
*   **Motivation Variants:**
    *   *Low:* Categories auto-collapsed, minimal metadata, simplified edit.
    *   *Medium:* Default view.
    *   *High:* Macro estimates visible per item/category; maps items to specific week days (e.g., "Mon lunch").

## 8. Interactions & Gestures
*   **Check-off:** Tap checkbox (triggers haptic, strikethrough, 1.5s delayed move).
*   **Swipe Left (Item):** Reveals labeled "Delete" action; full swipe confirms.
*   **Swipe Right (Item):** Reveals labeled "Edit" action; full swipe opens inline editor.
*   **Long Press (Item):** Opens expanded inline editor (Name, Qty, Category, Notes).
*   **Tap (Category Header):** Toggles collapse/expand.
*   **FAB / Input Focus:** Tap "+" scrolls to top and focuses keyboard.
*   **Pull to Refresh:** Forces manual list re-sync.
*   **Accessibility Fallbacks:** Long-press context menus replace swipe gestures for motor-impaired users.

## 9. Free vs. Premium Gating
*   **Free Tier:** Manual list creation, basic item grouping, and category management.
*   **Premium (Plus) Tier:** Auto-generation of lists from active CIA diet plans and saved recipes.

## 10. Cross-Domain Hooks
*   **CIA AI Insights:** Dynamically manages list behind the scenes (merges duplicates, flags "New" vs "No longer needed" based on meal plan shifts).
*   **Nutrition Domain:** Deep bi-directional linking to specific Recipes; high-motivation view exposes underlying caloric/macro data sourced from the nutrition DB.

---
### ⚠️ SOURCE CONTRADICTIONS FLAGGED
1.  **Typography Sizing:** Base spec defines Item Name as `15pt` and Quantity as `15pt`. The "Premium Craft" audit rewrite mandates Item Name as `16pt` and Quantity as `17pt`. 
2.  **Screen Layout Flag:** Base spec ASCII shows the "Inline Add Input" physically at the *top* of the scrollable area. The "Premium Craft" section calls this same input the "focal hero" but notes it stays above the fold. Designers must decide if this input scrolls away with the list or is pinned statically above the list.
3.  **Motivation Adaptation UI:** Spec calls for hiding/showing calories and meal-day mapping based on user motivation, but does not define how a user toggles this state or if it is entirely automatic based on backend profiling.
