# I1 verification matrix

- Tie-breaker: live code/contracts, active I1 specs, current canon, DVF-02 and later accepted decisions; archived audit is evidence only.
- Product gates: exact six-screen ownership, 390×844 containment, 44px controls, 16px fields, five actual 125% root-text proofs plus accepted S80 CSS-zoom evidence under `W-TRUNC-80`, reduced motion, semantic/focus/dialog state, honest local-only capabilities, provider/media/privacy/safety truth, deterministic distinct state proofs.
- Integrity gates: I1 product/API/verifier/production-input fingerprints stable start/end; accepted-through-H1 100-file sentinel union stable; empty isolated storage/cookies; zero console/page/capability/external-request events.
- Repository gates: `npm run check`, root validator `104/104`, accepted sentinels, root and read-only submodule `git diff --check`.
- Manual lenses: CLEAR; design/source; accessibility/privacy/provider/media trust; Sol native-pixel inspection.
- Acceptance: three fresh independent reviews at C0/H0/M0; durable DVF-22 closeout only afterward.
- Stop: source conflict, unsupported real capability, deceptive rating/provider state, unsafe or diagnostic coaching flow, accepted-byte drift, nondeterministic repeated proof, or two equivalent failures.
