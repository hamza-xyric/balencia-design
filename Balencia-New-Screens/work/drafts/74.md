To centralize and organize the user's social and coaching interactions without letting them overshadow the primary AI coaching relationship. The hub acts as a structured command center, connecting community accountability directly to personal growth domains via honest, context-rich signaling.

### 5. Components
- **TopBar:** Transparent over atmosphere, transitions to `.glass-pill` on scroll. Glyph actions: Search, Voice.
- **GlassCard (`hero`):** Container for the CIA pinned anchor.
- **GlassPillInput (`search`):** Native input field for universal search.
- **SegmentedTabs:** Single-select horizontal filters.
- **SolidCard (`interactive`):** Base container for conversation rows.
- **ChipProvenance / `NEW:` ChipKindTag:** Used to demystify message context. *Rationale:* Brief mentions standardizing "Kind" tags (Direct, Group, Room). While Provenance tracks data source, this new chip handles social thread taxonomy at a micro scale. Should be added to the catalog.
- **AvatarStack:** Used inside group/room `SolidCards` to represent members visually.
- **Sheet (`action`):** Launched via long-press or FAB for chat management and creation.
- **`NEW:` FabCompose:** A variant of `FABQuickLog`. *Rationale:* Adjusted icon (compose/pencil) to fit the "Start new chat" brief requirement without violating the native bottom layout rules.
- **GlassNavBar:** Global navigation.

### 9. All states
- **Default:** CIA Hero active, lists populated, search idle.
- **Skeleton:** SolidCard blocks with 1.2s sweep. The CIA Hero skeleton retains its left-border accent and breathing pulse to signify it is loading but present.
- **Empty:** Cold-start preserves the fully rendered CIA Hero. Centered, non-shaming microcopy sits below the "Pinned" section header. Sections gracefully hide if completely empty.
- **Error:** Cached messages remain visible. A glass-pill banner sits below the TopBar with a warning glyph and plain language ("Couldn't refresh chats — pull to refresh").
- **Offline:** Cached messages visible and muted to 50% opacity. "Start new chat" FAB is visually dimmed and disabled with a tooltip/badge explaining the offline state.
- **Success:** Sending/reading a message triggers a subtle 120ms scale-down (0.98) feedback and clears the unread counter instantly.

### 10. Motion & interaction
- **Physical Easing:** `cubic-bezier(0.2, 0.8, 0.2, 1)` for all entrance staggers and sheet deployments.
- **Feedback:** 150ms scale (0.96) on row taps; glows brighten momentarily on press.
- **Glow Breathe:** The CIA Hero `glow-cia` breathes slowly (4s ease-in-out) to signify active intelligence. Sparkle glyphs pulse gently on messages where CIA is assisting.
- **Haptics:** Light impact on long-press for the management sheet; medium impact on receiving a new message while the screen is active.
- **Reduced Motion:** All staggered fades snap instantly to final state. Glow breathing ceases, resolving to a static solid glow. 

### 11. Motivation-tier adaptation
- **Low Density (Recovery/Minimalist):** Avatar stacks are hidden, relying purely on text. "Recent" section is collapsed under a chevron by default to reduce cognitive load. Only direct unread messages trigger the `glow-you`.
- **Medium Density (Default):** As specified in the wireframe. Balanced visual weight, domain tags visible, standard row heights (72px).
- **High Density (Engaged/Power):** Row heights compress to 60px. CIA-assist context expands inline (e.g., showing the specific "Finance" correlation beneath the Run Club room title without needing a tap).

### 12. Accessibility
- **AA+ Contrast:** Paper-50 text (#FEFAF3) on dark surfaces ensures >7:1 contrast ratio. Muted text stays above 4.5:1.
- **Targets:** All interactive elements (filters, row taps, icons) strictly adhere to the 44x44px minimum touch target law, even if visually smaller.
- **Screen Reader:** The "CIA-Assist Sparkles" glyph is read as *"CIA is actively tracking this conversation."* Unread counters are read as *"3 unread items."*
