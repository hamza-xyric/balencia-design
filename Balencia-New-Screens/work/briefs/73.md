# FUNCTIONAL CONTENT BRIEF: Mission Journal

## 1. Purpose
The retrospective companion to the forward-looking Mission Board, allowing users to reflect on past accomplishments. It transforms raw mission data into a personal logbook of growth via narrative summaries, visual progress tracking, and acknowledging pivoted/archived goals without shame.

## 2. Entry and Exit Paths
*   **Entry Paths (Stack Push):**
    *   Mission Board [13] (via header journal icon)
    *   RPG Character [19] (via "View full journal" link)
    *   Me Main [17] (via quick links grid card)
*   **Exit Paths:**
    *   **Back/Previous Screen:** Stack Pop via back button or iOS edge swipe-right.
    *   **Mission Detail [14]:** Stack Push by tapping any journal entry card.
    *   **Image Viewer [67]:** Modal Present by tapping photo thumbnails inside a card.

## 3. Information Architecture (Top-to-Bottom)
1.  **Navigation Bar:** Back button + Screen Title.
2.  **Filter Chips Row:** Primary sorting and filtering mechanisms.
    *   *Sub-filter row:* Animates slide-down when "By domain" or "By type" is tapped.
3.  **Header Summary Module:** All-time metric summary tile.
4.  **Main Content Area (SectionList grouped by Month):**
    *   **Month Section Header:** Sticky temporal grouping label (e.g., "MAY 2026"). *High-motivation variant includes a month-summary module here.*
    *   **Timeline Journey Spine:** Vertical path running through the cards, anchoring the visual hierarchy.
    *   **Completed Mission Card:** Entry node + full mission details, metrics, narrative, and photos.
    *   **Archived/Pivoted Mission Card:** Entry node + mission details, partial metrics, narrative, and user's archive note.

## 4. Features and Capabilities
*   **Timeline Journey Tracking:** Visualizes the chronological history of missions as a continuous drawn path.
*   **Filtering:** Multi-select domain filtering and single-select mission type filtering.
*   **AI Narratives:** Displays grounded, memoir-like summaries for both completed and archived missions.
*   **Photo Memories:** Surfaces progress photos taken during the mission's active timeframe.
*   **Partial Credit Acknowledgment:** Displays partial XP and user-authored context notes for archived/pivoted missions without using deficit framing.
*   **Quantitative Visualizations:** Visual bar representations of XP earned and mission duration normalized against the longest mission in the journal.
*   **Motivation Tiering:** Adds specific data instruments (Donut chart, inline stats) for "High Motivation" users while keeping the default "Medium" view simplified.

## 7. Screen States
*   **Cold-start / Day-1:** Filter chips hidden. Timeline spine omitted (no single degenerate dot). Centered "No entries yet" empty state.
*   **Loading:** Path skeleton draws top-to-bottom. Cards show text shimmers and thumbnail placeholders. Metrics count up on data arrival.
*   **Partial (Cached + Fetching):** Cached entries render solidly. Un-fetched rows appear ghosted. Subtle "Syncing…" indicator.
*   **Error (Fetch Failed):** Network error banner. Defers to cached data if available; otherwise renders the empty state with recovery options.
*   **CIA Summary Failure:** Card renders normally but omits the summary section, replacing it with a "Summary generating..." placeholder.
*   **Photo Load Failure:** Thumbnails show empty placeholder circles; count label remains. Tapping still attempts to open the Image Viewer.
*   **Filtered Empty:** Active filter chips remain visible. Centered "No [filter] entries" messaging.
*   **High Motivation Variant:** Adds a micro-donut chart and inline KPI stats to the month headers.
*   **Reduced Motion:** All staggers, path drawing, and count-ups render instantly at their final settled state. Node pulse is turned off.

## 8. Interactions, Gestures, and Motion Intents
*   **Tap Target (Entry Card):** Pushes Mission Detail [14] to the stack.
*   **Tap Target (Photo Thumbnail):** Opens Image Viewer [67] as a modal.
*   **Tap Target (Filter Chips):** Toggles filter state; reveals secondary filter rows with a slide-down animation.
*   **Screen Gestures:** iOS standard swipe-right-from-edge to pop the stack.
*   **Motion Intent (Draw-First):** On load, the timeline spine stroke-draws top-to-bottom. Nodes scale up and settle as the line reaches them. Cards and internal metric bars fade and rise into position. 

## 9. Free vs. Premium Gating
*   *Note: The source document contains a direct contradiction regarding gating.*
    *   *Spec text:* Implies the screen is accessible as a standard feature.
    *   *Audit Integration:* Notes a decision that "Life Areas comparison is Plus-gated only after enough history exists."
*   **Functional Interpretation:** Access to the base Mission Journal is available to all users. However, advanced aggregate comparisons (like cross-domain life area correlations) require a Premium (Plus) tier subscription and sufficient historical data.

## 10. Cross-Domain Hooks
*   **AI Narrative Engine (CIA):** Generates micro-memoirs by pulling raw data from multiple life domains (e.g., combining session counts with weather context or financial milestones) to contextualize achievements.
*   **Progress Photo System:** Pulls visual data from the broader progress gallery to anchor the specific timeframe of a mission.
*   **Life Areas Correlation:** Premium hook that links mission outcomes in one category (e.g., Fitness) to impacts or parallel activities in another life area.
