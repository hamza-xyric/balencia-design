# Functional Content Brief: Knowledge Graph (Screen 72)

## 1. Purpose
Provides a visual, interactive map of the user's life correlations, rendering CIA’s discovered connections across health domains into an explorable network. It transforms abstract data into a tangible, personal intelligence layer, allowing users to explore how behaviors (like sleep) impact outcomes (like workout performance).

## 2. Entry and Exit Paths
*   **Entry Paths:**
    *   Intelligence Dashboard [48] via the "Explore your health knowledge graph" link card.
*   **Exit Paths:**
    *   Intelligence Dashboard [48] (via Back button stack pop).
    *   CIA Chat [09] (via "ask CIA" button, carries node context).
    *   Domain Dashboards [26-36] (via "go to [domain]" button).
    *   Help Bottom Sheet (modal presentation).

## 3. Information Architecture
**Layout Strategy:** The graph canvas is the sole full-viewport hero. The Node Detail Panel is hidden on first paint and slides up only upon interaction. 

**Top-to-Bottom Module Stack:**
1.  **Navigation Header:** Back chevron, "Knowledge Graph" title, Help icon. A 3pt accent line sits directly beneath the header to signify the AI-Mode register.
2.  **Graph Canvas (Hero):** A floating, full-viewport interactive network. No card or background container; it floats directly on the base canvas for maximum visual impact.
3.  **Floating UI Layer:**
    *   **Legend Pill:** Bottom-left floating affordance (expandable into a full card).
    *   **Graph Controls:** Bottom-right floating button stack (Zoom in, Zoom out, Reset).
4.  **Node Detail Panel:** A bottom sheet (~45% screen height) that slides up over the graph canvas when a node is tapped.
5.  **Global Tab Bar:** Standard app navigation (Today, CIA, Goals, Me).

## 4. Features & Capabilities
*   **Settled Network Visualization:** Interactive node-link network that is precomputed server-side to ensure identical, jitter-free geometry on every visit without live physics simulation.
*   **Node Topology Encoding:** 
    *   Node radius dynamically represents connection degree (24pt for 1–2 edges up to 56pt for 8+ edges).
    *   High-degree "hub" nodes feature a subtle, calibrated glow to serve as visual anchors.
*   **Correlation Edge Encoding:** 
    *   Edge thickness and opacity scale proportionally to correlation strength. 
    *   Edges weaker than 25% strength are hidden by default (doubles as a performance and contrast floor).
*   **CIA Confidence Signature (Inferred vs. Confirmed):** 
    *   Data-confirmed correlations render as solid lines.
    *   CIA-hypothesized (unconfirmed) correlations render as dashed lines, communicating CIA's confidence level visually without relying on color.
*   **Interactive Exploration:** Pan (single-finger drag), zoom (pinch 0.3×–3.0×, double-tap, or button controls), tap to select/deselect nodes.
*   **Focus by Subtraction:** Selecting a node scales it up, intensifies its glow, and pulses its connected edges, while dimming all unrelated nodes (to 30%) and edges (to 5%).
*   **Ego-Graph Detail View:** Tapping a node renders a zoom-locked excerpt of the hero graph in the detail panel, showing the tapped node centered with its immediate neighbors as mini-nodes.
*   **StrengthBar Details:** A scrollable list of the selected node's connections, sorted by strength, featuring graded fill bars and visible percentages.
*   **CIA Insights:** Contextual, per-node observations framed as non-shaming coaching prompts.
*   **Alternative Text View:** When a screen reader (VoiceOver) is active, the visual graph dynamically renders as a flat, expandable list of nodes sorted by connection count.
*   **Motivation Adaptation:** 
    *   *Low Motivation:* Defaults to a simplified 2D list view to prevent cognitive overload.
    *   *High Motivation:* Reveals advanced metadata like edge correlation type labels and data-point count scaling.

## 6. Data Fields & Metrics
*   **Node Identity:** 
    *   *Metrics:* Node name, Domain classification, Degree (connection count).
    *   *Source:* `GET /api/v1/intelligence/knowledge-graph` (filtered to max 60 most relevant nodes).
*   **Node Visual Variables:** 
    *   *Metrics:* Radius (derived from degree), Fill (domain color identity), Hub Status (boolean if 3+ edges ≥70% strength).
*   **Edge/Correlation Data:** 
    *   *Metrics:* Connected node IDs, Strength (percentage 25%–100%), Inferred status (boolean).
    *   *Source:* `GET /api/v1/intelligence/knowledge-graph` (filtered to max 120 edges, dropping <25% strength).
*   **Geometry Coordinates:** 
    *   *Metrics:* Normalized `(x,y)` positions ∈ [0,1].
    *   *Source:* Precomputed server-side; stored in `knowledgeGraph` mock/data (`src/data/mock.ts`).
*   **Per-Node Insights:** 
    *   *Metrics:* Unique qualitative observation string per node.
    *   *Source:* Replaces single shared blob; must be a node-keyed map in `knowledgeGraph`.

*   **⚠️ CONTRADICTION FLAG (Data Shape):** The existing build prototype features a data bug where a single shared `connections` + `insight` blob is read by every node, resulting in the same 4 connections showing regardless of the node tapped. The spec demands this be fixed to a node-keyed map before launch (Critical Finding B10-F03 / S72-V03). Additionally, the `inferred: boolean` flag on edges is completely absent in the current build and must be minted.

## 7. Screen States
*   **Default (Rich Data):** Full interactive graph (20–50+ nodes, many edges).
*   **Cold-Start (Day 1):** Never an empty canvas. Shows 3–5 ghosted domain placeholder nodes (at 20% opacity, no edges), centred growing text, and a calm 3-dot purple pulse.
*   **Early Data (1–2 weeks):** Sparse but interactive real graph (5–15 nodes) with a bottom motivational nudge.
*   **Partial Sync:** Available nodes render; un-synced domains are entirely absent (distinct from an error state, as no "complete" reference exists for the user).
*   **Loading:** 3 staggered purple dots pulsing. Transitions to Error state after 10 seconds.
*   **Error (Network/Timeout):** Centred glyph, error copy, and an orange retry link. Header and controls persist; controls dimmed to 40%.
*   **Layout Reveal Error:** Server positions still load, but the "draw-in" animation is skipped; the graph appears instantly in its settled state (silent error).
*   **Offline:** Sticky banner below the header; graph populates from last cache; "ask CIA" button disabled.
*   **Detail Panel Load Failure:** Node name and domain pill render from cache, but connection list and insight show skeleton shimmers for 5 seconds before falling back to error copy.
*   **Node Selected:** Selected node scales to 1.2× with a white border and intensified glow. Connected edges brighten and pulse. All unrelated nodes dim to 30% opacity.

## 8. Interactions & Gestures
*   **Canvas Pan:** Single-finger drag.
*   **Canvas Zoom:** Pinch (0.3× to 3.0×).
*   **Canvas Reset/Zoom:** Double-tap (zooms to 1.5× or resets).
*   **Node Selection:** Tap node (scales up, triggers detail panel, highlights local network). Haptic: Medium impact.
*   **Node Pressed (Pre-selection):** Scales to 1.1, brightens slightly. Haptic: Light impact.
*   **Deselection:** Tap empty canvas area, tap close `[×]`, or drag down on the detail panel.
*   **Connection Row Tap (in Panel):** Re-centers the hero graph on the newly selected node and updates the panel content. Haptic: Light impact.
*   **Accessibility/Keyboard:** Focus rings (2pt orange) on all interactive targets. Minimum 44×44pt hit areas applied to all nodes (via an invisible hit-box) and floating controls.

*   **Motion Intents:**
    *   **Entrance Choreography:** Nodes fade in staggered (20ms/node). Once settled, edges "draw" themselves outward via stroke-dashoffset. Legend and controls fade in last. 
    *   **Continuous Motion:** Selected edges feature an opacity pulse loop (oscillating 60→80→60% over 2s).
    *   **Reduced Motion (`prefers-reduced-motion`):** The graph renders instantly at its final settled frame. The entrance draw-in and continuous pulse loops are disabled. No information is lost.

## 9. Free vs. Premium Gating
*   **Standard Access:** The base visualization (graph exploration, CIA insights, domain navigation, and the AT alternative text list) is available to all users.
*   **Premium Gating (Implied/Variants):** The "High Motivation" adaptive variant exposes premium-level analytics (e.g., cluster density indicators, data-point count scaling, and "Deep dive" context routing to CIA Chat). 

## 10. Cross-Domain Hooks
*   **Life Correlation System:** This screen *is* the visible hook for the entire Life Correlation system. It explicitly bridges the 9 life domains (Fitness, Sleep, Nutrition, Wellbeing, Productivity, Finances, etc.) by clustering same-domain nodes and drawing cross-domain edges to represent AI-discovered correlations.
*   **Intelligence Routing:** Tapping "ask CIA" links the static graph view into the dynamic CIA Chat [09], passing node context to enable conversational deep-dives.
*   **Domain Deep-Linking:** The "go to [domain]" action bridges the user from an abstract system overview directly into the specific, single-domain Dashboard [26-36] for tactical data review.
