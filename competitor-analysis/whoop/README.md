# WHOOP — UI Reference

Wearable-band recovery/strain/sleep coach. Dark, data-dense, ring-led. **24 screenshots** (`app-store/` 10 · `google-play/` 8 · `community/` 6). Sources: `sources.md`, `community-sources.md`.

## Screens captured & features shown

| Screen | Key UI / features visible |
|--------|---------------------------|
| **Home / Overview** | Stacked Sleep · Recovery · Strain rings, "Optimal Health" card, daily summary |
| **Recovery** | Large % recovery ring (green/yellow/red), HRV, Resting HR, Respiratory Rate, Sleep Performance; AI insight card → *"Break down my recovery"* |
| **Sleep** | Sleep performance %, stages, sleep need vs. got, consistency |
| **Strain** | Cardiovascular strain (0–21 scale), strain target/coaching, activity strain |
| **Healthspan / WHOOP Age** | Physiological age vs. real age, pace-of-aging, contributing factors |
| **WHOOP Coach (AI)** | Conversational AI grounded in the user's own data; natural-language Q&A |
| **Journal** | Behavior tracking (alcohol, caffeine, etc.) correlated to recovery |
| **Stress** | Real-time stress monitor / day stress timeline |
| **Weekly / Monthly report** | Trend roll-ups, performance assessment |

## Patterns relevant to Balencia
- **Single hero metric per screen** (one giant ring) — extreme focus vs. Balencia's multi-stat dashboards.
- **AI coach grounded in personal data** (WHOOP Coach) — direct analog to SIA; note the "explain this score" CTA pattern.
- **Behavior→outcome correlation** (Journal) — conceptually similar to Balencia's Life Correlation Matrix, but single-domain (physiology only).
- **"WHOOP Age" / Healthspan** — gamified longevity framing; a Balencia "Life Power" cousin.
- Relentlessly **dark, monochrome + one accent**; numbers do the talking.
