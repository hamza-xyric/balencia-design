# FUNCTIONAL CONTENT BRIEF: Reports Center

## 1. Purpose
Reports Center translates Balencia data into structured, shareable summaries (weekly life, doctor, mission progress) without exposing private notes by default. It serves as a calm, editorial review and export surface, leveraging CIA to provide plain-language context rather than functioning as a raw data dump.

## 2. Entry and Exit Paths
*   **Entry Paths:** Stack push from Me Main [17], Intelligence Dashboard [48], Data Sources [84], Help Center [25], or via CIA deep-link.
*   **Primary Exits:** Tap "Screenshot guide" or "Share" bottom actions.
*   **Secondary Exits:** Tap a report card to open the Report Preview/Detail. System back returns to the origin screen.

## 3. Complete Information Architecture
The screen is a vertical scroll view with a fixed header, fixed bottom actions, and a visible tab bar.

*   **Region 1: Global Header** (Sticky)
    *   Back navigation, Screen Title ("Reports").
*   **Region 2: Report Builder Hero** (Focal Anchor)
    *   Eyebrow text, Title, Description.
    *   Feature signal pills.
*   **Region 3: Recent Reports** (Index List)
    *   Section Header.
    *   Report Cards (Weekly life report, Doctor summary, Mission progress). *Note: Flat text rows are functionally upgraded to status-dot metric cards with mini coverage rings.*
*   **Region 4: This Week Summary** (Index Glance)
    *   Section Header.
    *   Headline KPI Metric Tiles. *Note: Flat label/value rows are functionally upgraded to metric cards with embedded sparklines.*
    *   CIA Insight contextual read.
*   **Region 5: Global Bottom Actions** (Sticky)
    *   Share, Screenshot guide.
*   **Region 6: Report Preview Modal/Expansion** (Rendered on tap)
    *   Preview Header (Title, Share).
    *   Data Review & Privacy block (Included domains, excluded notes).
    *   Headline KPI Strip.
    *   Period-over-Period Comparison.
    *   Headline Trend (Living Line).
    *   Report Coverage (Category Split).
    *   Cross-Domain Summary (Correlation Matrix + Ranked Rows).

## 4. Features and Capabilities
*   **Report Generation & Review:** Build, resume, and review structured life reports.
*   **Privacy Controls:** Automatic exclusion of private notes. Explicit in-app review step detailing included domains and excluded data before sharing.
*   **In-App Preview:** Deep-dive view rendering five data visualizations (KPI strip, comparison bars, trend line, coverage donut, correlation matrix).
*   **Data Confidence Indicators:** Sparsely synced data displays visible confidence signals (ghosting, chips) ensuring missing data is never misrepresented as a real zero.
*   **Screenshot Export & Sharing:** V1 sharing is restricted to in-app screenshot guidance rather than raw data/PDF exports. Native share sheet integration.

## 6. Data Fields and Metrics
*   **Report Meta-data:** Title, Included Domains (e.g., Fitness, Sleep, Nutrition), Status (Ready/Draft). *Source: Local user generation state.*
*   **Headline KPIs:** Sleep consistency %, Workout adherence %, Stress load %. *Source: Synced device/health data.*
*   **KPI Deltas:** Value vs prior period (e.g., +18%, -11%), Synced day count (e.g., 6 of 7 days). *Source: Computed from historical synced data.*
*   **Time-Series Trend:** Daily metric values over report window, CIA next-period projection. *Source: Synced health metrics + CIA projection model.*
*   **Report Coverage/Composition:** Domain share percentages (e.g., Fitness 45%). *Source: Tracked time/contribution per domain.*
*   **Cross-Domain Correlations:** Matrix strength, direction (reinforcing/competing), computed status. *Source: CIA analytical engine computing N×N metric relationships.*

## 7. Screen States
*   **Cold-Start / First Report:** Hero visible. Empty card shown in Recent Reports. "This Week" section hidden. Preview visuals do not render.
*   **Loading (List & Preview):** Depth-preserving skeletons morph into drawn data. Axes, tracks, and outlines remain visible. Bottom actions disabled.
*   **Partial Sync:** Visuals retain shape but display confidence chips (e.g., "6 of 7 days"). Un-synced periods appear ghosted/dashed.
*   **Error (Sync/Load):** Specific chart failure messages with visible "retry" actions. Report cards display warning icons/borders.
*   **Offline:** Cached data displayed. Actions dimmed (50% opacity). Pull-to-refresh dimmed.
*   **Report Preview, Insufficient Data:** Trend shows baseline axes with "Calibrating". Projection hidden. Correlation matrix shows ghosted empty cells.
*   **Export Failed:** Inline toast: "PDF export failed. Try again."
*   **Share Unavailable:** Fallbacks to file export.
*   **Export Success:** Button label changes to "Exported" with a check icon for 900ms.

## 8. Interactions, Gestures, and Motion Intents
*   **Tap Report Card:** Opens detailed Report Preview (rendering the 5 below-fold visualizations).
*   **Tap KPI Tile:** Scrolls or links directly to that metric's expanded trend visualization.
*   **Long-Press Trend Chart:** Engages scrubbing crosshair for specific window value read-outs.
*   **Tap Matrix Cell/Tooltip:** Reveals readable correlation pill.
*   **Selector Pills (W/M/Y):** Toggles temporal windows (Week/Month/Year) for charts.
*   **Button Press States:** Scale(0.98), ghost background highlights, progress spinners replacing icons.
*   **Motion Intent (Draw-First):** Hero fades up -> KPI strip counts up -> Bars rise -> Living Line draws itself left-to-right -> Donut arcs draw clockwise -> Matrix cells scale in row-by-row. Strictly enforces `prefers-reduced-motion` (instant final state with static signatures preserved).
