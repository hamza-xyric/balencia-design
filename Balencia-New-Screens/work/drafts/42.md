### 2. Purpose
To provide an honest, cinematic, and emotionally resonant payoff for user consistency, milestone achievements, and streaks. Reinforces the XP loop without toxic gamification, scaling dynamically from full-screen cinematic moments for major milestones to lightweight toasts for everyday actions.

### 3. Entry & exit
**Entry paths (System-triggered):**
*   Mission completion (Screen 14)
*   Workout finish (Screen 27)
*   Habit streak achieved (Screen 38)
*   Action completion on Home (Screen 12)
*   Overall or Domain level-up threshold crossed

**Exit paths:**
*   **Primary:** Tap anywhere on the backdrop scrim (or VoiceOver escape action) → Dismisses overlay, returns to underlying trigger screen.
*   **Secondary:** Tap "Share" (`BtnSecondary`) → Triggers native share sheet.
*   **Tertiary (Toasts):** Auto-dismiss after 3 seconds (extends to 5s if VoiceOver is active) or swipe up to dismiss early.
*   *Correction:* The 10-second auto-dismiss failsafe in the brief is replaced by a strictly enforced 1.2-second input lockout during entrance animation, after which standard tap-to-dismiss is immediately active. Infinite lingering violates the premium "moment in time" aesthetic.

### 4. Layout anatomy
**Regions (Top-to-Bottom):**
1.  **Scrim & Atmosphere Layer:** Darkened blur capturing global tap-to-dismiss.

4.  **Continuous Stroke Divider:** SVG line motif drawing across.
5.  **CIA Message:** Dynamic insight text with attribution.
6.  **Action Row:** Share CTA and Dismiss hint.

### 5. Components
*   **ModalOverlay** — Base structural container with `.glass-frost` and scrim.
*   **FrostCard** — The hero container holding the achievement data (`variant: summary`).
*   **ProgressRing** — Embeds the achievement badge (`variant: ring`), blooming behind the badge.
*   **GlassStatCard** — Underlying metric display for the +XP value (`variant: metric`). 
*   **ProgressBar** — Linear tracking of XP to the next level (`variant: segmented`).
*   **BtnSecondary** — "Share" action.
*   **NEW: ContinuousStrokeDivider** — *Rationale: Canon §6 explicitly mandates "continuous-stroke line motif for hero/celebration only", requiring a dedicated decorative SVG component to execute the signature draw-on animation safely without violating shape rules.*
*   **NEW: XPToast** — *Rationale: Canon §9 lists XPToast in the catalog but lacks structural specifics. Promoted here as a top-aligned, non-blocking glass-pill that auto-dismisses, obeying selective glass rules.*

### 6. Visual treatment
*   **Glass tier:** 
    *   Scrim: `rgba(10,10,15,.6)` blur 48px.
    *   Hero Card: `.glass-frost` (`rgba(255,255,255,.10)`, blur 48px, sat 130%, radius 40).
    *   Action Buttons: `.glass-pill`.
*   **Glow color & meaning:** 
    *   `--glow-you: #FF5E00` — Applied to the ProgressRing. Represents the *effort* and *active momentum* the user just generated.
    *   `--glow-done: #34A853` — Applied to the bottom edge of the FrostCard and the particle burst. Represents *completion* and the *milestone reached*.
*   **Background atmosphere:** `--bg-base` with the mandatory warm radial glow top-center.
*   **Hero type moment:** The "+ 120 XP" counter rendered in **Display (NM Medium 500, 52px)** using tabular-nums.

### 8. Data & honesty states
**Metric:** XP Earned & Count-up Value
*   **Real:** Displays "+ 120 XP" (NM Medium, tabular-nums). Provenance chip: `via Balencia RPG`.
*   **Low-confidence:** N/A (XP is an exact system calculation, never estimated). 
*   **Honest-null:** If XP data is missing, the XP block is gracefully hidden. The overlay relies purely on the badge and CIA text without inventing an arbitrary "+50 XP" filler number.

**Metric:** Progress to Next Level 
*   **Real:** ProgressRing sweeps to `82%`. Provenance chip: `level 8 → 9`.
*   **Low-confidence:** N/A.
*   **Honest-null:** If this is a pure streak without level progression, the ring and bar are entirely omitted from the layout.

### 9. All states
*   **Default:** Full-screen cinematic moment with choreographed entrance.
*   **Skeleton:** If achievement data is delayed, renders the FrostCard with a subtle shimmering `--surface-3` block for the badge, a `0 XP` placeholder, and `CIA is thinking...` text. 
*   **Empty (CIA Failure):** If the CIA message API fails, the ContinuousStrokeDivider and CIA text block are hidden entirely. The FrostCard margin is dynamically centered to prevent awkward negative space.
*   **Error (Share Failure):** `BtnSecondary` "Share" gets a temporary 1.5px `#ef4444` border, label switches to `sharing failed` for 2.5s, then reverts.
*   **Success:** State resolves instantly to the final visual (bypassing count-ups) if the user taps to dismiss early.
*   **Disabled:** N/A. The overlay is either present or dismissed. 

### 10. Motion & interaction
*   **Physical easing:** Entrance uses spring physics (`stiffness: 150, damping: 15`) for the badge scale. All opacity fades use standard 150-250ms ease-out.
*   **Glow behavior:** The `--glow-you` ProgressRing "breathes" (opacity 60% → 100% over 3s) to make the achievement feel alive.
*   **Haptics:** `Core Haptics` transient impact (medium weight) synced precisely with the final snap of the badge scale-in.
*   **Reduced-motion path:** All confetti/particles are removed. Badge, XP, and stroke divider render instantly at their final state. CIA text is immediately visible. Dismissal lockout is bypassed completely for immediate escape.

### 11. Motivation-tier adaptation
*   **Low motivation:** Lower threshold triggers (e.g., 3-day streaks yield full-screen). The copy is heavily encouraging: `Everyone starts here. You just did the *hardest* part — starting.`
*   **Medium motivation:** Standard behavior. Domain level-ups trigger toasts; overall level-ups trigger the overlay.
*   **High motivation:** Suppressed everyday toasts; actions yield minimal inline pulses on the trigger screen. Confetti is replaced by clean, data-rich `SolidCard` summaries appended to the overlay, prioritizing data over visual fanfare.

### 12. Accessibility
*   **Contrast pairs:** Paper-100 `#FEFAF3` on `rgba(10,10,15,.6)` scrim (passes AA+). Burnt Orange `#FF5E00` over base dark `#0A0A0F` (passes AA+).
*   **Targets:** The "Share" button meets the 44px minimum height target. The entire background scrim acts as a massive tap target for the "tap anywhere to close" affordance.
*   **Screen-reader labels:** `AccessibilityElement` trait set to `.button` on the backdrop with label `"Dismiss celebration"`. Badge glyph hidden from VoiceOver; the API injects a direct text node ("Level 9 badge") instead.
