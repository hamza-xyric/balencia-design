# Functional Content Brief: Nutrition & Diet Dashboard

## 1. Purpose
The Nutrition & Diet Dashboard is the user's daily hub for nutrition management, surfacing CIA's AI-suggested meal plans, tracking macro intake against targets, and logging food/water consumption. It establishes the domain dashboard template for continuous health tracking data.

## 2. Entry and Exit Paths
*   **Entry Paths (Navigates From):**
    *   Explore Section [18] via stack push
    *   CIA Chat [09] via deep-link stack push
    *   Home Screen [12] via action card stack push
    *   Life Areas Overview [16] via domain tap stack push
*   **Exit Paths (Navigates To):**
    *   Meal Detail / Food Logger [29] via stack push (triggered by FAB or meal row tap)
    *   Goals List [13] via stack push (filtered to nutrition)
    *   Goal Detail [14] via stack push
    *   RPG Character [19] via stack push (tapping RPG badge)
    *   CIA Chat [09] via tab switch (tapping CIA note card)

## 3. Complete Information Architecture
**Scroll Behavior:** Vertical ScrollView (content exceeds viewport). 
**Layout Structure (Top-to-Bottom):**
1.  **Sticky Header:** Back button, domain title ("Nutrition & diet"), RPG level badge.
2.  **CIA Coaching Note:** Emotional anchor, dynamic message based on recent nutrition data.
3.  **Headline KPI Strip:** 3 tiles (Calories left, Protein, Adherence).
4.  **Daily Macros Card:** 
    *   *Macro Donut Hero*: Part-of-whole composition.
    *   *MacroBars Group*: 4 horizontal progress bars vs target.
    *   *CalendarHeatmap*: 7-day intake consistency grid.
5.  **Water Intake Card:** Circular gauge ring with add/remove controls.
6.  **Quick Actions Bar:** 3 utility cards (Shopping list, Recipes, Trends).
7.  **Today's Meals Timeline:** 4 AI-suggested/logged meals with micro-donuts and weight bars.
8.  **Active Goals Section:** Progress bar for domain-specific goals.
9.  **Recent Food Log:** List of recently logged foods with weight bars.
10. **Floating Action Button (FAB):** "Log food" shortcut.
11. **Bottom Tab Bar:** Global navigation (Me tab active).

## 4. Every Feature and Capability 
*   **Food Logging:** Quick-access via FAB (auto-selects meal by time of day) or by tapping a specific meal row.
*   **Macro Tracking:** Visualizing daily intake (Calories, Protein, Carbs, Fat) against configured targets.
*   **Macro Composition Analysis:** Viewing exact percentage split of logged calories across macros.
*   **Hydration Tracking:** Incrementing/decrementing water glasses with goal-arrival feedback (+25 XP).
*   **AI Meal Planning:** Surfacing breakfast, lunch, dinner, and snack suggestions.
*   **Trend Analysis:** Deep-linking to weekly/monthly nutrition trends and adherence patterns.
*   **Goal Tracking:** Viewing progress on active nutrition goals (e.g., "Lose 5kg").
*   **Adaptability:** Screen complexity and detail adapt to user motivation state (Low/Medium/High).
*   **Progressive Disclosure:** Expanding the Macro Donut hub to view fiber/sugar/sodium metrics (high motivation).
*   **Offline Resilience:** Logging food/water offline with cached data retention and background syncing.

## 6. Data Fields and Metrics
*   **Macros (Calories, Protein, Carbs, Fat):** *Source: Aggregated food log data vs calculated targets.* Displayed as current value, target value, and percentage of target.
*   **Calorie Share Split:** *Source: Derived from macros using constants (Protein 4cal/g, Carbs 4cal/g, Fat 9cal/g).* Displayed in the Macro Donut.
*   **Water Intake:** *Source: User input.* Displayed as glasses completed vs target (e.g., 5/8) and ml volume.
*   **Meal Composition (Cal, P, C, F):** *Source: AI meal planning engine and user food log.* Displayed per meal row.
*   **Protein Delta:** *Source: Fixed, disclosed 7-day average.* Displayed in KPI strip (e.g., "▲ vs 7-day avg").
*   **7-Day Adherence:** *Source: Food log history.* Displayed as "5/7 days on target" and visually in the CalendarHeatmap.
*   **RPG Level:** *Source: RPG system.* Displayed as skill level (e.g., "Lv.8").
*   **Goal Progress:** *Source: User goals filtered to Nutrition domain.* Displayed as percentage (e.g., 70%).
*   **Nutrition Score / Micro-nutrients (Fiber, Sugar, Sodium):** *Source: AI food log analysis.* Displayed only in high motivation state.

## 7. Screen States
*   **Cold-start / Day-1:** Macro Donut is a ghosted ring with "Log a meal to see your split". KPI tiles show honest zeros ("2200 CAL LEFT", "0g PROTEIN", "0/7 ON TARGET"). Heatmap is entirely ghosted. CIA provides a starter plan invite.
*   **Established User (Morning/Empty):** CIA references yesterday's data. Macros at 0%. Heatmap retains history. "No food logged today."
*   **Loading:** Depth-preserving skeletons across all cards. Macro donut shows a radial shimmer. Copy: "CIA is reading your nutrition — one moment."
*   **Partial:** 1 macro logged → Macro Donut shows the logged slice + ghosted remainder arc.
*   **Error / Offline:** Network banner below header. Cached data is shown. `[+]` actions are visibly dimmed (0.5 opacity). "Couldn't refresh — pull again."
*   **Variants (Motivation):** 
    *   *Low:* Hides macro badges, recent food log, and excess details; simpler CIA text.
    *   *Medium:* Default experience.
    *   *High:* Adds micro-nutrients, optimal eating windows, and weekly sparklines.
*   **Disabled:** Water `[+]` button dims (0.4 opacity) when 8/8 glasses are reached.

## 8. Interactions, Gestures, Motion Intents
*   **Gestures:** 
    *   Pull down: Refresh dashboard.
    *   Swipe right edge: Back navigation.
    *   Tap: Select cards, meals, glasses, quick actions.
    *   Long-press: Remove filled water glass (triggers undo affordance).
*   **Motion Choreography (Sequential Entrance):** 
    1. Macro Donut arcs draw clockwise (largest to smallest). 
    2. Hub numbers count up. 
    3. KPI numbers count up + MacroBars rise. 
    4. Water ring fills. 
    5. Below-fold elements (meal weight bars, micro-donuts, heatmap) draw on scroll-into-view.
*   **Micro-interactions:** 
    *   FAB fades out on scroll down, returns on scroll up.
    *   Tapping a Donut slice pulses its corresponding MacroBar + tooltip.
    *   Tapping the Donut hub expands to show fiber/sugar/sodium.
    *   Adding water triggers a brief green glow on the glass.
    *   Completing 8 glasses triggers a synchronized pulse on all glasses.

## 9. Free vs Premium Gating
*   **Free Tier:** Standard food/water logging, basic AI meal plan, default macro tracking (Medium Motivation default).
*   **Premium Tier (Opt-in):** AI analysis of progress photos (encrypted, user-deletable), high-motivation micro-nutrient tracking (fiber, sugar, sodium), and advanced AI insights.

## 10. Cross-Domain Hooks
*   **CIA (AI) Insights:** Deep two-way integration. CIA reads macro gaps to proactively suggest meals ("Chicken or lentils for dinner?"). Tapping the CIA card deep-links to CIA Chat with full nutrition context.
*   **RPG / Gamification:** Hitting target macros or completing 8 glasses of water triggers life-power/XP gains ("+25 XP"). RPG level is prominently displayed in the header.
*   **Goals Correlation:** Nutrition goals (e.g., "Lose 5kg") sync bidirectionally with the global Goals domain.
