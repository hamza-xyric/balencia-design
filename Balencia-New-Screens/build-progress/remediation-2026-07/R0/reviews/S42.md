## Dimension notes
1. Spec conformance — issue: the spec's Components section names a distinct `Badge emblem` inside the `ProgressRing` and states the ring is deliberately a non-numeric "ambient progress frame ... so the badge glyph isn't fighting a number for the same space." The build drops the badge glyph entirely and instead passes `value="13" label="Level"` into `ProgressRing`, rendering exactly the numeral-readout pattern the spec rejects (grep confirms "badge" appears nowhere in the JSX, only in a code comment). The spec's `FrostCard` (`--r-2xl`/40px, `.glass-frost` immersive tier) is also not used — the build substitutes the standard `GlassCard`/`.glass-card` (28px radius, standard blur tier, confirmed in globals.css).
2. Canon fidelity — issue: the hero card stacks two glow mechanisms — `GlassCard tone="done"`'s canonical `glow-inner-done` pool plus an extra inline `shadow-[var(--glow-green-md)]` box-shadow — against canon §3's "one glow per card, meaning-driven" rule. The wrong glass tier/radius from #1 is also a canon-fidelity issue (glass-tier selection), not just a naming nit.
3. Data honesty — ok: XP (`+120`, `you earned it`) and level progress (`82%`, `level 12 → 13`) are both real, deterministic, correctly-provenanced values; no fabricated numbers, consistent with spec §Data Honesty.
4. Cross-cutting — issue: the `CIAInsightCard`'s cross-pillar evidence row (`Fitness`, `Finance`) is spec'd as a `ChipDomainTag` pair in domain colors (Fitness `#ef4444`, Finance `#10b981`, canon §4) but is passed through the generic `provenance` prop → `Provenance` → `Chip`, whose `Tone` union (`you|done|cia|muted`) has no domain-color option — confirmed visually, both chips render as plain neutral/purple-tinted pills with no domain color at all. Crisis-layer/consent-rail requirements are not applicable here (no health data, no synced third-party source on this screen; XP is first-party/system-computed).
5. Composition craft — issue (High): the full-screen overlay's content (`FrostCard` + divider + `CIAInsightCard` + action row) overflows the 844px phone frame with no scroll affordance on the `fixed inset-0` container. `BtnSecondary` ("Share") is visibly clipped and collides with the home-indicator bar at the very bottom edge in the baseline screenshot — confirmed by pixel-cropping the bottom 64px of `42.png`, where the pill's lower half/rounded bottom edge is cut by the frame boundary and the home-indicator bar overlaps its label.
6. Copy voice — ok apart from known CIA casing (A24-008, see below); sentence case, second person, no exclamations, one Tiempos-italic emphasis word (`consistency`), coach-leads-with-meaning phrasing.
