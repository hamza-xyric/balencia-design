# Functional Content Brief: Breathing Exercises

## 1. Purpose
The user's guided breathing practice space, serving as both a technique library and an immersive, full-screen active session view. It answers "how do I calm down right now?" while tracking session frequency to correlate with broader wellbeing metrics (like sleep and stress).

## 2. Entry and Exit Paths
*   **Entry Paths:**
    *   Stress Dashboard [52] via "breathing" card (stack push).
    *   Explore [18] via Wellbeing module card (stack push).
    *   CIA Chat [09] via deep-link (e.g., "try a breathing exercise").
    *   Home Screen [12] via stress-related action card.
*   **Exit Paths:**
    *   Back button / edge swipe (stack pop) to previous screen.
    *   Tab switch to CIA Chat [09] via "ask CIA" link.
    *   Forward to Celebration Overlay [42] (on milestone achievements, e.g., 10th session or 7-day streak).
    *   RPG Character Screen [19] via RPG skill badge tap.

## 3. Complete Information Architecture
The screen operates in three distinct functional modes: **Library View**, **Active Session**, and **Post-Session Rating**.

**Library View (Scrollable)**
1.  **Domain Header:** Sticky navigation, screen title, and RPG level badge.
2.  **Stats Card (Secondary Focal):** Expandable card displaying practice metrics.
    *   *Collapsed:* 2x2 metric grid (Sessions, Minutes, Streak, Most-used).
    *   *Expanded:* Consistency heatmap, weekly trend sparkline, and honest metric deltas.
3.  **"When to Use" Filter Tags:** Horizontally scrolling contextual filters.
4.  **Exercise List:** Vertical scroll list of breathing technique cards.
5.  **Bottom Padding:** Clears the global tab bar.

**Active Session (Full-Screen Immersive)**
*Tab bar hidden.*
1.  **Session Header:** Close control and current exercise identification.
2.  **Breathing Circle (Primary Focal Hero):** Center-screen animated guide with phase labels and countdown.
3.  **Timer Display:** Overall session countdown.
4.  **Guidance Text:** Phase-specific verbal cues.
5.  **Timer Controls:** Play/pause toggle and duration selector.

**Post-Session Rating (Bottom Sheet Modal)**
1.  **Drag Handle & Title:** Sheet frame and prompt.
2.  **Session Summary:** Completed exercise name and duration.
3.  **Effectiveness Rating:** Interactive 5-star scale.
4.  **Optional Note Input:** Text field for observations.
5.  **Actions:** Save CTA and demoted Skip link.

## 4. Every Feature and Capability
*   **Technique Library:** Browsing 5 core breathing techniques (Box, 4-7-8, Deep Belly, Wim Hof, Coherence).
*   **Contextual Filtering:** Single-select filtering of techniques by situation (e.g., "before sleep", "focus").
*   **Guided Breathing:** Audio-haptic-visual guided sessions with precise phase durations (inhale, hold, exhale).
*   **Adaptive Durations:** Selectable session lengths (1, 3, 5, or 10 minutes).
*   **Immersive Mode:** Full-screen, distraction-free practice environment.
*   **Eyes-Free Guidance:** Haptic feedback on phase transitions for meditating without looking at the screen.
*   **Progress Tracking:** Real-time logging of session frequency, duration, and consecutive day streaks.
*   **Data Visualization (Expanded Stats):** GitHub-style consistency grid (CalendarHeatmap) and weekly trend line (Sparkline).
*   **Effectiveness Feedback:** 5-star rating and qualitative note capture to train the AI.
*   **Event Triggers:** Milestone celebrations (e.g., streaks, total sessions) routed to the overlay system.
*   **Motivation Adaptation:** UI adapts based on user's motivation level (e.g., hiding stats for low motivation, adding advanced techniques for high motivation).

## 6. Data Fields and Metrics
*   **RPG Skill Level:** Numeric (N). Source: User Profile API.
*   **Total Sessions:** Numeric (e.g., 42). Source: `breathing_tests` + `mindfulness_practices` (category = 'breathing').
*   **Total Minutes:** Numeric (e.g., 210). Source: `mindfulness_practices.actual_duration_minutes`.
*   **Current Streak:** Numeric (e.g., 8). Source: Aggregated from `completed_at` dates.
*   **Most Used Technique:** String (e.g., "box br."). Source: Aggregated from `mindfulness_practices`.
*   **Delta vs Prior Window:** Numeric (e.g., +6). Source: Derived from 30-day prior window query.
*   **Consistency Grid:** Daily counts (last 5-6 weeks). Source: `mindfulness_practices.completed_at`.
*   **Weekly Trend:** Weekly bucket counts (last 7 weeks). Source: `mindfulness_practices` ISO week aggregation.
*   **Active Session Timer:** Duration (M:SS). Source: Local timer state.
*   **Breath Phase Countdown:** Duration (S.ms). Source: Local timer state.
*   **Effectiveness Rating:** Numeric (1-5). Source: User input -> `mindfulness_practices.effectiveness_rating`.
*   **Session Notes:** String (max 500 chars). Source: User input.

## 7. Screen States
*   **Library - Cold-start / Day 1:** Zeroed stats framed aspirationally ("0 sessions · building foundation", "-- · choose a technique"); full exercise list visible with CIA "recommended" badge on Box Breathing.
*   **Library - Loading:** Depth-preserving skeleton shimmers; sparkline shows flat line drawing into shape.
*   **Library - Filtered Empty:** "None of our techniques fit..."
*   **Library - Error:** Stats show "--" but card remains visible; pull-to-refresh banner displayed.
*   **Library - Low Motivation Variant:** Stats and filters hidden; only 2 simplest exercises shown; post-session rating simplified to thumbs up/down.
*   **Session - Starting:** 3-2-1 countdown in center of resting circle.
*   **Session - Paused:** Circle frozen at current size; glow dimmed; "paused" label overlay.
*   **Session - Complete:** Circle pulses 3x in green; timer shows 0:00.
*   **Rating - Default:** Empty stars.
*   **Rating - Saving:** Save button shows spinner.
*   **Rating - Error:** "couldn't save rating. try again."
*   **Accessibility (Reduced Motion):** Circle rests at final size; phase labels legible; KPI numbers static at final value; sparkline fully drawn.
*   **Accessibility (VoiceOver):** Timer announces every 30 seconds; phase changes announced.

## 8. Interactions, Gestures, Motion Intents
*   **Library Gestures:** Tap stats card to expand/collapse; tap filter chips; tap exercise card to push Active Session; swipe edge to go back; pull-to-refresh.
*   **Session Gestures:** Tap breathing circle to toggle play/pause; tap duration selector to open inline picker; tap X to close (prompts confirmation if in-progress); long-press play/pause to toggle haptics.
*   **Rating Gestures:** Tap stars sequentially; drag down sheet handle to dismiss (auto-saves if rated).
*   **Motion Choreography:**
    *   *Library:* KPI numbers count up on mount; tags and cards rise with a staggered fade.
    *   *Expanded Stats:* Heatmap cells fade in row-by-row; sparkline draws stroke on scroll-into-view.
    *   *Session Transitions:* List crossfades out; session UI fades in; tab bar slides down/fades out.
    *   *Active Session:* The breathing circle is the *only* motion hero. It scales from 160pt to 240pt with a custom symmetric ease-in-out curve mimicking a natural breath arc. Phase text crossfades. Timer digits slide up/down. Session complete triggers a green pulse sequence.

## 9. Free vs. Premium Gating
*   **Free Tier:** Includes all 5 core breathing techniques, the session timer, standard durations (1/3/5 min), and standard progress tracking.
*   **Plus (Premium) Tier:** Unlocks CIA personalized coaching notes (e.g., stress-dip correlations), advanced technique recommendations, the 10-minute duration option, and deeper session analytics (e.g., average breath rate, phase adherence). Premium states are shown via non-aggressive blur overlays with calm copy ("10 min available in Plus").

## 10. Cross-Domain Hooks
*   **Wellbeing Correlation Engine:** Breathing data directly feeds the overarching stress correlation system, linking practice days to sleep quality and mood trends.
*   **CIA AI Integration:** Session ratings train the CIA model to refine future recommendations. CIA can deep-link into specific exercises from chat.
*   **RPG System:** Practice frequency accrues XP/levels for the Wellbeing Domain RPG character.
*   **Stress Module:** Direct bidirectional linking with the Stress Dashboard [52] (pre-filters the library to "during stress" if arriving from a high-stress alert).
*   **Social / Gamification:** Milestone triggers push to the Celebration Overlay [42]; future capabilities allow private challenges (Plus gated).
