# 2. Purpose
A capture-first, low-friction layer for rapidly recording raw health observations, mood shifts, and reactions before the thought disappears. It automatically ingests and tags notes to transform fleeting moments into actionable *CIA* coaching conversations.

# 3. Entry & exit
- **Entries:**
  - Global FAB long-press or tab bar overflow (opens `Sheet` half variant).
  - Deep-link from CIA Chat `[09]` or Me Main `[17]` (opens full-screen push).
- **Exits:**
  - `Sheet`: Drag down, tap backdrop, or tap "done" to dismiss to underlying screen.
  - **Full-Screen:** Standard back navigation to Me Main `[17]`.
  - **Secondary:** Tap "ask CIA" to route to CIA Chat `[09]` with context, or expand to Journal `[37]`.

# 4. Layout anatomy
**Regions (Full-Screen variant, top-to-bottom):**
1. **TopBar**: Transparent screen header, back chevron, title.
2. **Atmosphere**: Warm radial glow at top-center.
3. **Archive Summary Region**: `SolidCard` containing sparkline trend and ambient capture copy.
4. **Filter Region**: Horizontally scrolling domain tag chips.
5. **Notes Feed**: Reverse-chronological list of `NoteCard`s, separated by date headers.
6. **Quick Add Bar**: Pinned glass pill input + send button.
7. **GlassNavBar**: Floating pill bottom navigation.

# 8. Data & honesty states
*Every metric ships 3 states. Never a fabricated number.*

**Metric 1: Note Word Count (High Motivation)**
- **Real**: "45 words" (`ChipProvenance`: `you logged`)
- **Low-confidence**: `N/A` (Cannot be low confidence, exact text parsing)
- **Honest-null**: hidden (metadata hidden until > 0 notes)

**Metric 2: Weekly Note Frequency (Sparkline)**
- **Real**: Solid orange line (`TrendChart`). Tooltip: `12 notes this week`. (`ChipProvenance`: `derived locally`)
- **Low-confidence**: Trailing week line segment switches to dashed purple.
- **Honest-null**: Quiet plain text Caption: `your capture activity will appear here`. Sparkline axis hidden.

**Metric 3: Tag Share Distribution (Filter Counts)**
- **Real**: `4 health` text under `ChipDomainTag`. (`ChipProvenance`: `you logged`)
- **Low-confidence**: `~4 health` (number muted to 64%). Label: `estimated · low confidence`.
- **Honest-null**: Count hidden. Tag chip shows `0 health` and is disabled (40% opacity).

# 9. All states
- **Default**: Archive list presented with pinned composer. Warm atmosphere visible.
- **Skeleton**: Depth-preserving `SkeletonState` for `NoteCard`s. `TrendChart` shows axis + ghost orange line.
- **Empty (Cold-start)**: Input auto-focused, tag row hidden. Centered Notepad glyph. Body-light text: `capture a thought, observation, or reminder. CIA will help you connect the dots.`
- **Error (Save)**: ChatComposer border flashes red, preserves input text. Toast appears: `couldn't save. pull to refresh.`
- **Error (Offline)**: Glass-pill banner at top: `you're offline — cached notes shown`. Unsynced `NoteCard`s display small orange cloud glyph.
- **Success**: Capture success animates card sliding in from top. `XPToast` drops (+5 XP · Mindfulness). Tags show `SkeletonState` micro-shimmer before resolving.
- **Disabled**: Send button inside `ChatComposer` remains 40% opacity until text is entered.

# 10. Motion & interaction
- **Physical Easing**: `cubic-bezier(0.32, 0.72, 0, 1)` for sheet entry and card slide-ins. 
- **Feedback (150-250ms)**: 
  - Send button tap: Scale `.98`, hold 150ms, spinner spin.
  - Swipe Left (>60%): Full commit deletes card, triggers undo `Sheet` slide-up (250ms).
- **Glow Behavior**: `NoteCard` (User) `glow-you` brightens to 75% opacity on press. `NoteCard` (CIA) features a continuous, slow 4s breathing pulse on the `glow-cia` element.
- **Haptics**: Light impact haptic on successful note save. Medium impact on swipe-to-delete commit.
- **Reduced-motion path**: Card slide-ins compress to instant opacity fades. `TrendChart` line draws instantly. CIA breathing glow static.

# 11. Motivation-tier adaptation
- **Low**: Pinned `ChatComposer` shows NM Light placeholder: `even one word counts.` Tag chips and Sparkline hidden to reduce cognitive load.
- **Medium (Default)**: Full `TrendChart` visible. Tag filter row visible. Cards truncate to 3 lines requiring tap-to-expand.
- **High**: Word count metadata appended to `NoteCard` captions (e.g., `• 45 words`). `BtnGhost` "Export archive" appears under `TrendChart`. CIA cross-reference footnotes added to relevant cards (e.g., `↗ referenced in Sleep Chat`).

# 12. Accessibility
- **AA+ Contrast**: Body text uses `#FEFAF3` (paper-100) on `#140A05` (surface-1). CIA tag text uses paper-100 on purple-tinted glass.
- **44px Targets**: All `ChipDomainTag`s meet 44px height. `BtnPrimary` send button is 44px. NoteCards maintain 56px min touch height.
- **Screen-reader labels**: 
  - Glyph-only Send button: `aria-label="Save note"`.
  - `VoiceMicGlow`: `aria-label="Record voice note"`.
  - `TrendChart`: `aria-label="Captured 12 notes this week. Trending upwards."`
  - Swipe actions announced via custom rotor: `actions: delete, assign tags`.
