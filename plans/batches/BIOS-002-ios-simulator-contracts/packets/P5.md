## Contracts (implement exactly)

**provenance.ts** — import `Provenance` from `@/components/balencia/states` (single source of truth) and build:
```ts
export type Metric<T = number> = { value: T | null; display: string; provenance: Provenance };
export function realMetric<T>(value: T, opts: { source: Provenance & {kind:'real'} extends never ? never : ('whoop'|'self_report'|'computed'|'server'); label?: string; format?: (v: T) => string }): Metric<T>;
export function nullMetric<T = number>(label?: string): Metric<T>;   // value:null, display:'—', provenance {kind:'null', label: label ?? 'Not enough data yet'}
export function lowMetric<T>(value: T, label: string, format?: (v:T)=>string): Metric<T>;
export function fromNullable<T>(value: T | null | undefined, opts: { source: 'whoop'|'self_report'|'computed'|'server'; label?: string; nullLabel?: string; format?: (v:T)=>string }): Metric<T>; // null/undefined → nullMetric
```
Default `format` = `String(v)`; `display` for null is ALWAYS `'—'`.

**View models** (`src/viewmodels/index.ts`) + adapters:

`toTodayView(dto: OverviewDashboardResponse): TodayVM`
```ts
export type TodayVM = {
  lifePower: Metric<number>;                       // dto.lifeScore.totalScore — null stays null (fresh account!)
  pulse: { score: Metric<number>; metrics: Array<{ key: 'energy'|'recovery'|'stress'; metric: Metric<number>; caption: string | null; qualityLabel: string | null }>; tip: string | null; hasWearable: boolean };
  dailyBrief: { headline: string | null; opportunity: string | null; risk: string | null; focusAreas: string[] };
  priorities: Array<{ id: string; action: string; pillar: string; priority: 'high'|'medium'|'low' }>;
  momentum: { streak: Metric<number>; xp: Metric<number>; level: Metric<number>; levelName: string | null };
  domains: Array<{ key: string; label: string; score: Metric<number>; status: 'strong'|'steady'|'attention'|'no_data' }>;
  coachPrompts: string[];
  meta: { generatedAt: string; hasLifeAreas: boolean; hasGoals: boolean };
};
```
Provenance rules: pulse metric `source` field maps 1:1 (`whoop`→'whoop' label "via WHOOP"; `self_report`→label "you logged"; `computed`→label "computed"); `hasWearable:false` → recovery & stress FORCED to `nullMetric('Connect a wearable')` even if a number sneaks in; `lifeScore.totalScore` null → `nullMetric()`; `momentum.streak/xp/level` are server-computed → source 'server', but null/undefined → nullMetric. NEVER coalesce null to 0.

`toMissionsView(dto: UnifiedGoalsResponseDto): MissionsVM`
```ts
export type MissionTier = 'life'|'main'|'side';   // daily/weekly/group need backend periodicity — NOT derivable yet (documented simplification)
export type MissionVM = { id: string; title: string; description: string | null; tier: MissionTier; status: 'active'|'blocked'|'complete'; progress: number; domain: string; source: GoalSource; isPrimary: boolean; dueDate: string | null; target: { current: number; target: number; unit: string } | null };
export type MissionsVM = { missions: MissionVM[]; summary: { total: number; active: number; completed: number; avgProgress: number } };
```
Tier rule (EXACT, deterministic — `cadence` is a measurement unit, NOT a schedule; do not use it for tiers):
`isPrimary && source === 'life'` → `'life'`; else `isPrimary` → `'main'`; else → `'side'`.
Status map: `active`/`in_progress` → `'active'`; `paused` → `'blocked'`; `completed` → `'complete'`.

`toLifeAreasView(dto: LifeAreasSummaryResponseDto): LifeAreasVM`
```ts
export type LifeAreaVM = { id: string; name: string; domainType: string; score: Metric<number>; checkinStreak: number; lastCheckinDate: string | null; linkCount: number };
export type LifeAreasVM = { activeAreaCount: number; averageMomentum: Metric<number>; areas: LifeAreaVM[] };
```
snake_case→camelCase here and ONLY here (`display_name`→name, `momentum`→score via `fromNullable(..., {source:'self_report', label:'you logged', nullLabel:'No check-ins yet'})`). There is NO server `trend`/`drivers` — do NOT emit such fields at all.

`toFitnessView(dto: WorkoutPlansResponseDto): FitnessVM`
```ts
export type FitnessVM = {
  planCount: number;                                // real: dto.plans.length
  activePlan: { id: string; name: string; currentWeek: number; durationWeeks: number; workoutsPerWeek: number; completionRate: Metric<number>; totalWorkoutsCompleted: number } | null; // first plan with status 'active', else null
```

`completionRate` = `fromNullable(plan.overallCompletionRate, {source:'server', label:'from your plan'})`. The three null metrics are the anti-fabrication core: no derivation, no plans.length math.
