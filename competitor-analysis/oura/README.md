# Oura — UI Reference

Smart-ring sleep/readiness tracker. Soft, calm, light-mode, score-led. **22 screenshots** (`app-store/` 9 · `google-play/` 7 · `community/` 6). Sources: `sources.md`, `community-sources.md`.

## Screens captured & features shown

| Screen | Key UI / features visible |
|--------|---------------------------|
| **Today / Home (Morning)** | Readiness · Sleep · Activity score cards, Cycle day, daily message, timeline |
| **Vitals — Activity** | Activity detail card, goal progress, movement breakdown |
| **My Health** | Long-term trend dashboard across metrics (the "trends" hub) |
| **Sleep details** | Sleep stages (deep/REM/light), efficiency, timing, contributors |
| **Heart Health** | Cardiovascular age, daytime/night HR, vascular metrics |
| **Cycle Insights** | Menstrual cycle prediction & phase insights |
| **Daytime Stress** | Stress vs. restorative-time balance through the day |
| **Today (AAD)** | Automatic Activity Detection prompt / confirmation |
| **Advisor (AI)** | Conversational AI health advisor grounded in ring data |

## Patterns relevant to Balencia
- **Three balanced scores** (Readiness/Sleep/Activity) rather than one — closer to Balencia's domain-stat model.
- **Advisor** = AI coach analog to SIA, with a warmer, calmer tone than WHOOP.
- **Light, low-saturation "wellness" aesthetic** — useful counterpoint to Balencia's dark warm-ink direction.
- Strong **trends/longitudinal view** ("My Health") — a pattern Balencia's domain dashboards should match.
- **Cycle Insights** — a health vertical Balencia doesn't currently spec.
