# 2. Purpose
A dual-purpose detail screen rendering either a single transaction or a budget category drill-down. It contextualizes flat financial numbers with behavioral intelligence, enabling users to review, edit, and understand their financial records without gamification or shame.

# 3. Entry & exit
- **Entry:** Stack push from Finance Dashboard (Screen 30) by tapping a transaction row or budget category. 
- **Internal Navigation:** In Budget View, tapping a transaction in the filtered list pushes Transaction View onto the stack.
- **Exit:** Swipe-right edge gesture or back chevron returns to Dashboard. Tapping the CIA Context Card routes to CIA Chat (Screen 09). Edit, delete, and recategorize actions present as bottom Sheet modals.

# 4. Layout anatomy
Regions top-to-bottom:
1. **TopBar:** Transparent header with back chevron, contextual title, and edit/delete glyphs.
2. **Hero/Data Region:** 
   - *Transaction View:* Hero amount, domain tag, and metadata SolidCard.
   - *Budget View:* SolidCard containing ProgressRing (hero) and MacroBar (secondary progress/pace).
3. **CIA Insight Region:** CIAInsightCard correlating data to life events.
4. **History/List Region:** 
   - *Transaction View:* Receipt attachment (if any).
   - *Budget View:* SectionHeader and filtered transaction ListRow(s).
5. **Action Target:** Primary CTA anchored above the floating nav.
6. **Navigation:** Floating GlassNavBar.

# 5. Components
- **TopBar:** Transparent header, transitions to `.glass-pill` on scroll.
- **SolidCard:** Used for all dense financial data blocks (Transaction details, Budget Overview, ListRows).
- **GlassStatCard / ProgressRing:** Used for the Hero budget visualization. 
- **CIAInsightCard:** Purple-tinted glass card for behavioral analysis.
- **ListRow:** Dense transaction history scroll.
- **BtnPrimary:** CTA for editing/recategorizing.
- **SegmentedTabs:** NEW: Context Toggle. *Rationale: Needed at the top of the screen to switch cleanly between Transaction view and Budget view if accessed from a hybrid deep-link, preventing dual-scroll clutter.*
- **Sheet:** `.glass-frost` modal for delete confirmation and category pickers.

# 6. Visual treatment
- **Glass Tiers:** `.glass-card` is reserved for the CIAInsightCard to make it float above the dense data. Dense metadata and lists use `--surface-2` SolidCard for maximum legibility.
- **Inner-Glow & Meaning:** 
  - **CIAInsightCard:** `--glow-cia` (Royal Purple) — represents AI synthesis and cross-pillar projection.
  - **Budget Hero Ring:** `--glow-you` (Burnt Orange) — represents active personal effort and capacity.
- **Background Atmosphere:** True base `--bg-base` with the mandatory soft warm radial glow top-center. 
- **The Hero Type Moment:** The transaction amount or budget allocation value rendered in **Display NM Medium 500 (48px)**, using `tabular-nums` to anchor the screen visually.

# 8. Data & honesty states
*Every metric ships with three states. No fabricated numbers.*
- **Amount ($480 / $620):**
  - *Real:* $480.00 · `via Plaid`
  - *Low-confidence:* $480.00 (muted) · `estimated · low confidence`
  - *Honest-null:* "Not enough data yet — 3 more days"
- **Days Remaining (12 days left):**
  - *Real:* 12 days left · `via Finance API`
  - *Low-confidence:* ~12 days left · `estimated`
  - *Honest-null:* "Cycle dates unknown"
- **Category Breakdown (List):**
  - *Real:* "Joe's Pizza · -$24.00 · `via Plaid`"
  - *Low-confidence:* "Merchant pending · -$24.00"
  - *Honest-null:* "No spending in Dining yet. Budget fully available."
- **SIA / AI Suggestion ($480):** *(Note: SIA updated to CIA globally)*
  - *Real:* "$480 realistic limit · `based on 3-mo average`"
  - *Low-confidence:* N/A (AI projections are always labeled estimated)
  - *Honest-null:* "2 of 3 merchants synced — check back soon."

# 9. All states
- **Default:** Renders Transaction or Budget view based on route payload.
- **Skeleton:** Shimmer blocks (`--surface-3` base, 1.2s sweep) for the hero amount, cards, and list rows. Charts render as axis + ghost line.
- **Empty (Honest Null):** Ghosted full-ring outline. "No spending in Dining yet. Budget fully available." (Explicitly *avoids* the 100% green bar from the legacy wireframe).
- **Error (Cached):** "Couldn't load budget — pull to refresh." Displays cached or muted data underneath.
- **Success:** "Budget updated" toast (XPToast component, auto-dismiss).
- **Disabled:** Delete button hidden if transaction is still pending bank clearance.

# 10. Motion & interaction
- **Budget Hero Draw-First:** ProgressRing arcs sweep clockwise from 12 o'clock (250ms). MacroBar fills left-to-right immediately after. Count-up animation on KPI numbers.
- **Filtering:** Tapping a category slice in the Donut filters the transaction list below with a 150ms fade.
- **Physical Easing:** `cubic-bezier(0.32, 0.72, 0, 1)`. All sheet overlays spring in 250ms.
- **Glow behavior:** The `--glow-you` on the budget ring breathes subtly (4s ease) if the user is "on pace".
- **Haptics:** Light success impact on data sync completion.
- **Reduced-Motion:** Count-ups snap to final value; donut sweeps are instant; CIA glow breathing is paused (static opacity).

# 11. Motivation-tier adaptation
- **Low:** Core data only. ProgressRing is present but CIAInsightCard and trend charts are hidden. List is collapsed to the last 3 transactions.
- **Medium:** Default layout. CIAInsightCard visible. Full transaction list.
- **High:** Unlocks the 4-week `TrendChart` (Solid Orange line, dashed purple projection) and the monthly spend summary text.

# 12. Accessibility
- **AA+ Contrast:** Paper-100 (#FEFAF3) on `--surface-2` (#211008) ensures high legibility for tabular numbers. Paper-64% used strictly for metadata.
- **Targets:** All list rows, edit glyphs, and CTAs meet the 44px minimum touch target.
- **Screen-reader:** The hero ProgressRing is grouped with an `aria-label` ("Budget 78 percent full. Over by 40 dollars. 12 days left."). Delete glyph explicitly labeled "Delete transaction".

# 13. Premium checklist
1. **Connects:** Cross-domain hook mapped (Finance + Wellbeing/Mental) in the CIAInsightCard.
2. **Honest:** Visual cap implemented. Progress ring never turns alarm-red; stops at 100% and displays neutral "Over by $40" text.
3. **Premium:** Warm radial atmosphere, selective `.glass-card` usage, and Tiempos italic emphasis applied.
4. **Vibe:** No flat black; warm dark surfaces (#211008) used.
5. **Type:** Display NM Medium for the hero metric. Tiempos italic reserved for CIA insights.
6. **Spacing:** 8pt grid respected with 32px section rhythm.
7. **Glow logic:** `--glow-cia` and `--glow-you` map perfectly to AI synthesis and active user effort.
8. **60/30/10:** Orange user lines, purple AI accents, and warm dark base.
9. **Data density:** SolidCard used instead of glass over dense transaction lists to prevent cognitive load.
10. **Tone:** Exclamation marks removed from budget warnings. "SIA" renamed to "CIA".
11. **Visual elevation:** Flat progress bars replaced by warm-glow Donut hero composition.
12. **No red/green moralizing:** Success/completion uses green; over-budget uses muted text, preserving user dignity.
13. **A11y:** Focus traps on edit sheets, VoiceOver labels on visualizations.
14. **Empty state:** Inverted green bar removed in favor of a designed ghost-ring honest null state.
