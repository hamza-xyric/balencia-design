# Functional Content Brief: Stress Management

## 1. Purpose
The Stress Management screen serves as the user's centralized stress command center. It surfaces a composite stress score (derived from biometric, sentiment, and behavioral signals), enables fast manual logging, identifies recurring triggers, and provides immediate access to relief tools, directly answering: *"How stressed am I, what's causing it, and what can I do about it right now?"*

## 2. Entry & Exit Paths
*   **Entry Paths:**
    *   Explore Domain Card (Stack push)
    *   Home Screen Wellbeing Quick-Action (Stack push)
    *   CIA Chat Deep-Link (via conversational triggers like "let's look at your stress")
    *   Wellbeing Dashboard Push
*   **Exit Paths:**
    *   Back to Explore / Wellbeing Dashboard (Stack pop)
    *   Breathing Exercises (Stack push)
    *   Meditation (Stack push)
    *   Yoga (Stack push)
    *   CIA Chat (Tab switch with stress context pre-loaded)
    *   Goal Detail (Stack push via stress-related goals)
    *   Connected Services (Stack push via Biometric card)

## 3. Complete Information Architecture (Top-to-Bottom)
1.  **Sticky Domain Header:** Back button, "Stress management" title, RPG skill level badge.
2.  **Current Stress Level Card (Hero):** Composite stress score dial, severity label, mental capacity meter, 3 sub-score mini-rings (biometric, sentiment, behavioral), CIA high-stress lever.
3.  **Quick Log Card:** Stress rating slider, trigger multi-select chips, optional note field, "Log stress" CTA.
4.  **CIA Coaching Note Card:** AI-generated insight, pattern identification, and actionable recommendation.
5.  **Trigger Analysis Card:** Donut chart aggregating log frequency by trigger, legend, and log count.
6.  **Stress Trend Card:** Time-range selector (7d/14d/30d), line chart of historical composite scores, dashed CIA projection line, calm-zone band, time-of-day scatter plot, trend summary metrics.
7.  **Mental Recovery Card:** Recovery score ring, trend direction, component bars (emotion, sleep, activity, social), previous period comparison.
8.  **Relief Tools Section:** Horizontally scrolling cards for Breathing, Meditation, and Yoga.
9.  **Biometric Stress Card (Conditional):** WHOOP HRV data, physiological stress state, and trend.
10. **Floating Action Button (FAB):** Persistent quick-log shortcut.
11. **Bottom Tab Bar:** Global navigation.

## 4. Features & Capabilities
*   **Composite Stress Scoring:** Automated aggregation of user inputs, sentiment analysis, and physical metrics into a single 1-10 score.
*   **Manual Check-Ins:** Frictionless logging of subjective stress levels (1-10) and multi-select triggers.
*   **Free-Text Tagging:** Ability to add custom notes or specify "Other" triggers during logging.
*   **AI Pattern Recognition (CIA):** Automated identification of recurring stress drivers and contextual recommendations (e.g., "Work stress peaks after lunch").
*   **Temporal Correlation:** Scatter plot mapping exactly *when* during the day stress events occur.
*   **Mental Capacity Tracking:** Dynamic visualization of daily psychological headroom depleting as stress/load accumulates.
*   **Mental Recovery Tracking:** Assessment of resilience bouncing back via sleep, social, emotional, and physical factors.
*   **Device Integration:** Automated ingestion of physiological stress markers (Heart Rate Variability) via WHOOP.
*   **Prescriptive Relief Routing:** Context-aware shortcuts to immediate interventions (Breathing, Meditation, Yoga).

## 6. Data Fields & Metrics
| Field / Metric | Data Source | Description |
| :--- | :--- | :--- |
| `stress_rating` | User Input (`POST /log`) | Integer 1-10 indicating subjective stress level. |
| `triggers` | User Input (`POST /log`) | Array of selected standard triggers (e.g., Work, Health). |
| `other_trigger` | User Input (`POST /log`) | Free-text string for custom triggers. |
| `note` | User Input (`POST /log`) | Free-text string for contextual journal logging. |
| `final_stress_score` | API (`GET /logs`) | Weighted composite decimal (1-10) of biometric, sentiment, and behavioral signals. |
| `biometric_stress_score` | WHOOP API → `stress_logs` | Decimal (1-10) derived from Heart Rate Variability (HRV). |
| `sentiment_stress_score` | CIA Text Analysis → `stress_logs` | Decimal (1-10) derived from journal/conversation sentiment analysis. |
| `behavioral_stress_score` | OS Activity/Sleep APIs → `stress_logs` | Decimal (1-10) derived from activity patterns, screen time, and sleep. |
| `recovery_score` | API (`mental_recovery_scores`) | Integer (0-100) measuring bounce-back resilience. |
| `components` (recovery) | API (`mental_recovery_scores`) | JSON sub-scores for `emotion`, `sleep`, `activity`, `social`. |
| `HRV` (value & trend) | WHOOP API via Connected Services | Integer (milliseconds) + directional delta vs previous period. |
| `triggers` (frequency) | API (`GET /triggers`) | Aggregated percentage breakdown of triggers over 30 days. |

## 7. Screen States & Variants
*   **Day 1 / Cold Start:** Gauge is ghosted on the 0-foot with center "—". Sub-scores and trend charts hidden. Quick Log card promoted as primary action. Trigger Analysis omitted entirely. Recovery ring ghosted.
*   **Empty / No Data (Partial):** Charts display empty axes or ghosted rings. "No data ≠ zero" (e.g., no WHOOP connection renders a "—" sub-score, not a 0).
*   **Low Motivation Variant:** Screen is aggressively minimized to fit one viewport: Stress Gauge, Quick Log (no chips), 1-line CIA Note, and only the top CIA-recommended Relief Tool.
*   **High Motivation Variant:** Unlocks secondary analytics below the Recovery Card: Weekly stress calendar heatmap, CIA trigger correlation matrix (time/day patterns), and expanded component factor breakdowns.
*   **Loading:** True-depth skeletons that morph into drawn data (e.g., ArcGauge shimmer sweeps into orange fill). Trend chart axis draws flat line that morphs into the curve.
*   **Error / Failure:** Localized per-card. E.g., "Could not load WHOOP data + retry". Logs failing to submit triggers red border flash on CTA + toast error.
*   **Offline:** API sections show last cached data with an "offline" banner. Quick Log remains fully functional and queues logs locally to sync later.
*   **Success:** CTA flashes green glow (600ms). Card content crossfades and resets. Gauge re-sweeps to the new score.

## 8. Interactions & Motion
*   **Gestures:** Pull-to-refresh (global), Drag (Slider), Tap/Toggle (Trigger Chips, CTAs, Cards, Charts), Horizontal swipe (Relief Tools carousel), Touch-drag (Trend chart scrubbing to reveal tooltips).
*   **Motion Intent (Draw-First Choreography):**
    *   On load, the ArcGauge hero sweeps from 0 to the score value (520ms).
    *   Quick Log and CIA note rise sequentially (staggered fade).
    *   Trend line draws itself left-to-right (1200ms). The dashed CIA projection draws *after* the actual line completes.
    *   Sub-score numbers count up from 0.
*   **Slider Haptics:** Light impact on first touch; light impact when snapping to an integer; medium impact on trigger chip selection.
*   **FAB Behavior:** Fades out and translates down (+20pt) when scrolling down; fades back in on scroll up. Tapping FAB smooth-scrolls to the Quick Log card and pulses its border.

## 9. Free vs. Premium Gating
*   **Free Tier:** Manual stress logging, trigger browsing, standard relief tool navigation, and basic composite score viewing.
*   **Premium Tier:** Unlocks all CIA-powered layers (trend analysis projections, AI-generated coaching notes, trigger correlations, and time-of-day scatter plots).

## 10. Cross-Domain Hooks
*   **CIA Chat Integration:** Tapping the coaching note passes deep context to the CIA Chat interface to continue the stress-management conversation.
*   **Biometric / Hardware:** Real-time HRV ingestion from third-party wearables (WHOOP).
*   **Mindfulness Routing:** Prescriptive deep-links to specific interventions (Breathing, Meditation, Yoga).
*   **Goal Linking:** Bidirectional hooks to Goal Detail screens for users working on active stress-reduction or sleep-improvement goals.
