# Functional Content Brief: Recipes Screen (Mobile)

## 1. Purpose
The Recipes screen serves as the user's personal nutrition library and discovery hub, allowing them to browse CIA-suggested meals, manage favorites, and create custom recipes. It bridges meal planning and food logging by pushing recipes directly into diet plans, shopping lists, and daily macro tracking. 

## 2. Entry and Exit Paths
*   **Entry Paths:** 
    *   Nutrition Dashboard [28] via "Recipes" quick action card.
    *   CIA Chat [09] via deep-link (e.g., "here are some high-protein recipes").
    *   Home Screen [12] via nutrition action card.
*   **Exit Paths:**
    *   **Back:** Returns to Nutrition Dashboard [28].
    *   **Forward:** Recipe Detail (stack push), Meal Detail / Food Logger [29] (stack push via "Log as Meal"), Create Recipe (modal bottom sheet), CIA Chat [09] (tab switch via CIA insight tap).
    *   **System Links:** RPG Character [19] (via Lv.8 badge tap), Image Viewer [67] (via hero image tap), Report/Block [64] (via overflow menu for community recipes).

## 3. Complete Information Architecture

### A. Recipes Browse View (Top-to-Bottom)
1.  **Sticky Header:** Back button, "Recipes" title, RPG Skill Level Badge.
2.  **Search Bar:** Text input field and advanced filter toggle.
3.  **Filter Chips Rows:** Two horizontally scrollable rows for category and attribute refinement.
4.  **CIA Suggestions Section:** CIA coaching note followed by a horizontal scroll of AI-curated recipe cards.
5.  **Favorites Section:** Horizontal scroll of user-favorited recipes (hidden if empty).
6.  **Diet Plan Recipes Section:** List of recipes tied to the user's active diet plan (hidden if empty).
7.  **All Recipes Grid:** Main browsable 2-column masonry library with infinite scroll.
8.  **Floating Action Button (FAB):** Persistent "+ Create recipe" button.
9.  **Tab Bar:** Global navigation (Me tab active).

### B. Recipe Detail View (Stack Push)
1.  **Sticky Header:** Back button, dynamic title, Overflow menu (Edit/Share/Delete/Report).
2.  **Hero Image:** Full-bleed recipe photo with favorite toggle.
3.  **Recipe Info Row:** Name, metadata (category, time, difficulty), cuisine tag, source link.
4.  **Macros Per Serving Card:** Nutritional breakdown visualization and data.
5.  **Ingredients List Card:** Interactive checkboxes with serving adjuster.
6.  **Instructions Card:** Numbered, tappable step-by-step guide.
7.  **Rating and History Row:** Interactive 5-star rating and times-made counter.
8.  **Primary CTA:** "Add to Shopping List".
9.  **Secondary CTA:** "Log as Meal".
10. **CIA Insight Card:** Contextual AI nutritional coaching note.

### C. Create Recipe Modal (Bottom Sheet)
*   **Header:** Cancel / Create recipe / Save.
*   **Photo Picker:** Circular camera/gallery entry point.
*   **Details Inputs:** Name, Description, Category (pills), Cuisine, Servings stepper.
*   **Macros & Time Inputs:** Calories, Protein, Carbs, Fat, Fiber, Prep/Cook time.
*   **Content Builders:** Dynamic Ingredients list, Dynamic Instructions list.
*   **Tagging:** Dietary flags (multi-select), Tags input.

## 4. Features and Capabilities
*   **Text Search:** Debounced (300ms) search across names, ingredients, and cuisines with clear-input functionality.
*   **Faceted Filtering:** Single-select categories (Breakfast, Lunch, etc.) and multi-select attributes (Vegan, Keto, Easy, etc.). Overflow "Cuisine" filter available when a category is active.
*   **AI Recipe Recommendations:** Dynamic carousel of recipes tailored to the user's macro gaps, goals, and dietary preferences.
*   **Favorites Management:** Quick-toggle heart icon on cards to save/unsave recipes.
*   **Diet Plan Integration:** Surfaces active diet plan recipes with distinct visual identifiers.
*   **Custom Recipe Creation:** Full form for user-generated recipes with proportional serving scaling and client-side validation.
*   **Interactive Meal Prep:** Tappable ingredient checkboxes (to mark as "in hand") and tappable instruction steps (to mark as complete).
*   **Serving Adjuster:** Inline stepper that dynamically rescales ingredient quantities.
*   **Shopping List Integration:** Automatically adds all "unchecked" ingredients to the user's shopping list.
*   **Food Logging:** Pushes recipe macros to the daily food log via a meal-type selector.
*   **Feedback Mechanisms:** 5-star rating system and automatic "times made" tracking.

## 6. Data Fields and Metrics
*   **Recipe Identifiers:** `name`, `description`, `image_url`, `source`, `source_url` (Source: User input / Community DB).
*   **Categorization:** `category`, `cuisine`, `dietary_flags`, `tags`, `difficulty` (Source: User input / Recipe DB).
*   **Timing Metrics:** `prep_time_minutes`, `cook_time_minutes`, `total_time_minutes` (Source: User input / Recipe DB).
*   **Nutritional Metrics (Per Serving):** `calories_per_serving`, `protein_grams`, `carbs_grams`, `fat_grams`, `fiber_grams`, `servings` (Source: User input / Recipe DB).
*   **Relational/State Data:** `ingredients` (JSONB array), `instructions` (JSONB array), `is_favorite` (Boolean), `rating` (0-5 float), `times_made` (Integer).
*   **System Metrics:** RPG Skill Level (e.g., "Lv.8") (Source: Global RPG system).

## 7. Screen States
*   **Cold-start / Day 1:** Search and filters active; CIA suggestions populated with starter recipes; Favorites and Diet Plan hidden; Grid shows "No recipes yet" prompt.
*   **Loading:** Depth-preserving skeleton shimmer for cards/text; Donut chart visualizations render as ring outlines that morph into drawn arcs.
*   **Empty (No Search Match):** Replaces grid with a message card offering to clear filters or create a recipe. AI Suggestions and Favorites are hidden during search.
*   **Error:** Red border flash on failed search; "Could not load" toasts with auto-retry on action failures; images degrade gracefully to gradient placeholders.
*   **Offline:** Browse shows cached data; Search and FAB disabled with explanatory tooltips.
*   **Partial Data:** Donut charts display present macro slices and a ghosted remainder arc if data is missing. If all macros are missing, displays a ghosted full-ring outline.
*   **Motivation Variants:** 
    *   *Low:* Simplified UI, fewer cards, suppressed macro breakdowns (calories only).
    *   *Medium:* Default experience.
    *   *High:* Expands data to show fiber/sodium, nutrition scores, and meal prep batch suggestions.

## 8. Interactions, Gestures, and Motion
*   **Gestures:** Tap (links, toggles, CTAs), Horizontal scroll (filter chips, carousels), Pull-to-refresh (reload data), Swipe left-to-delete (Create Recipe form rows), Drag down (dismiss Create Recipe modal).
*   **Haptics:** Light impact (taps, focus, deactivations), Medium impact (activations, primary CTA presses), Success notification (saving, favoriting, logging meals).
*   **Motion / Animation:** 
    *   Staggered fade-in and rise for all cards and sections on mount.
    *   Favoriting: Scale bounce (0.8 to 1.2 to 1.0).
    *   FAB: Translates out of view on scroll down, returns on scroll up.
    *   Macro Visuals: Donut arcs draw clockwise from 12 o'clock (1200ms, largest to smallest slice). Center hubs count up.
    *   Instruction completion: Number circle cross-fades color, checkmark draws in.

## 9. Free vs. Premium Gating
*   **Free Tier:** Access to recipe browsing, standard search, favorites, and viewing the recipe grid.
*   **Premium (Plus) Tier:** Unlocks CIA personalized suggestions and AI nutritional analysis/insights.

## 10. Cross-Domain Hooks
*   **CIA AI Ecosystem:** Deeply integrated via the CIA Chat [09]. The AI analyzes daily macro tracking, food history, and active goals (Nutrition Mode) to populate the "CIA Suggestions" carousel and provide post-workout/coaching insights on the Recipe Detail screen.
*   **RPG / Avatar System:** The header explicitly displays the user's global RPG Skill Level ("Lv.8"), linking recipe browsing to overarching gamification and avatar progression.
*   **Supply Chain / Tasks:** "Add to Shopping List" bridges nutrition directly to the user's errands or shopping supply chain module.
*   **Daily Logging / Health:** "Log as Meal" directly mutates the user's daily nutritional targets and food logger.
*   **Meal Planning:** Automatically synchronizes with active Diet Plans, tagging relevant recipes to keep the user aligned with their structured regimens.

### ⚠️ Source Contradictions Flagged
1. **UI Copy Strings:** The source dictates renaming "SIA" to "CIA". However, verbatim UI copy examples in the source explicitly include the string "SIA pick" (badge) and "SIA is gathering recipes" (loading text). These strings must be globally updated to "CIA pick" and "CIA is gathering recipes" during implementation.
2. **Filter Chips Logic:** The wireframe ASCII marks Category chips as "r-sm" (small radius), while the component spec defines chips with "r-pill (999pt)". Pill styling should override the wireframe's ASCII shorthand.
3. **Competing Focal Hierarchy:** The spec contains a resolved contradiction regarding the screen's hero element. Visualization rules named the 96px Macro Donut as the focal instrument, while Premium Craft rules named the All Recipes grid. The source resolution (carried into this brief) dictates: The **Browse View** focal point is the grid (no single glowing heroes, cards have no glow at rest). The **Detail View** focal point is the Hero Image (carries the 32px glow), while the Donut is the focal *data* instrument (carries a smaller 12px glow).
