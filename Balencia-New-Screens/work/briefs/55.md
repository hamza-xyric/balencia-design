# Functional Content Brief: Yoga Sessions Screen

## 1. Purpose
Provides a gateway to guided yoga practice, surfacing streaks, filterable sessions, and instructional poses. Manages the full session lifecycle from browsing to active practice and post-session summary.

## 2. Entry and Exit Paths
*   **Entry Paths:** Stack push from Explore [18], Fitness [26], CIA Chat [09] (deep-link), or Home Screen [12].
*   **Primary Exit:** Forward to Active Session mode (in-screen transition).
*   **Secondary Exits:** Pose Detail (modal), CIA Chat [09], RPG Character [19], or stack pop back to origin.

## 3. Information Architecture (Top-to-Bottom)
### Mode 1: Browse
1.  **Header:** Fixed navigation, "Yoga sessions" title, RPG level badge.
2.  **Streak Banner:** Hero visualization (CalendarHeatmap), flame icon, current/longest streak.
3.  **CIA Coaching Note:** Contextual AI recommendation card.
4.  **Difficulty Filter Chips:** Row of selectable tags (All, Beginner, Intermediate, Advanced).
5.  **Guided Sessions:** Vertical stack of browsable Session Cards.
6.  **Pose Library:** Heading with "see all" link, plus a 2x3 grid of Pose Cards.
7.  **Stats Section:** 
    *   Poses Mastered GaugeRing (hero metric).
    *   MetricCards for total sessions and hours.
    *   Weekly practice Sparkline.
    *   Library Mix Donut (difficulty breakdown).

### Mode 2: Active Session (Full-screen takeover, tab bar hidden)
1.  **Header:** Close button, elapsed time, current pose tracker ("pose N of M").
2.  **Current Pose Display:** Large media area, pose name, hold duration.
3.  **Pose Timer Ring:** Circular countdown timer.
4.  **Instructions Card:** Step-by-step text for the current pose.
5.  **Next Pose Preview:** Card showing the upcoming pose thumbnail and duration.
6.  **Control Row:** "Skip pose" and "Pause/Resume" buttons.
7.  **CIA Real-Time Note:** Rotating, single-line motivational cues.

### Mode 3: Post-Session Summary
1.  **Header:** "Session complete" title.
2.  **Summary Card:** 2x2 grid showing Duration, Poses completed, Difficulty, and XP earned.
3.  **Difficulty Rating:** 1-5 selection circles with extremity labels.
4.  **Notes Input:** Text area for optional session notes.
5.  **Streak Update:** Updated streak count and personal best indicator.
6.  **Done CTA:** Button to save and return to Browse Mode.

### Modal: Pose Detail
*   **Container:** ~85% screen height bottom sheet.
*   **Content:** Pose image, name, difficulty badge, written instructions, and embedded YouTube video tutorial.

## 4. Features & Capabilities
*   **Practice Tracking:** Visualizes daily practice consistency and current/longest streaks.
*   **AI Coaching:** Generates contextual pre-session notes and rotating in-session cues.
*   **Content Filtering:** Single-select filtering of guided sessions by difficulty level.
*   **Guided Sessions:** Lifecycle management (browse, active timer, recap) with automated pose transitions.
*   **Media Integration:** Embedded instructional YouTube videos per pose.
*   **Post-Session Feedback:** Mandatory difficulty rating (1-5) and optional text notes.
*   **Gamification:** Awards XP upon session completion and tracks RPG level.
*   **Motivation Adaptation:** Dynamically alters UI density based on inferred user motivation (low motivation hides stats/poses to reduce cognitive load; high motivation expands visible content).

## 6. Data Fields & Metrics
*   **RPG Level:** *Source: User RPG System.* (e.g., "Lv.8")
*   **Practice History & Streaks:** *Source: `yoga_streaks` / `yoga_session_logs`.* Current streak, longest streak, daily practice minutes over trailing weeks.
*   **CIA Context:** *Source: AI generation based on workout history, recovery, frequency, time of day.*
*   **Session Data:** *Source: `yoga_sessions`.* Session name, difficulty, duration (minutes), pose count, thumbnail, associated poses (JSONB).
*   **Pose Data:** *Source: `yoga_poses`.* Pose name, difficulty, image URL, text instructions.
*   **Video Media:** *Source: `/api/youtube`.* Queried via "[pose name] yoga tutorial".
*   **Aggregate Stats:** *Source: DB Aggregation.* Total sessions, total hours, poses mastered (vs next milestone, e.g., 42/50), weekly practice minutes, library difficulty breakdown.

## 7. Screen States
*   **Day-1 / Cold-Start:** "Beginner" pre-selected. Pre-populated with 3 default beginner sessions and 6 foundational poses. Stats display a true "0". CIA note encourages starting. Gauge is empty/ghosted.
*   **Established (All sessions done today):** Session cards display "completed" badges. CIA note acknowledges prior practice (e.g., "You already practiced today. Rest is part of the process.").
*   **Loading:** Depth-preserving skeletons. Heatmap cells, gauge arcs, and card lines shimmer in place without losing structural layout.
*   **Network Error:** Graceful per-section degradation. Cached data shown where possible. Specific copy: "Could not load sessions", "streak data unavailable". Active session continues on local timer if network drops mid-workout.
*   **Active Session (Paused):** Timer freezes, background dims to 40% opacity, "Pause" button toggles to "Resume".
*   **Active Session (Transitioning):** Current pose crossfades into the next pose; timer ring flashes green briefly before resetting.
*   **Disabled (Done Button):** "Done" CTA remains at 0.4 opacity until a difficulty rating is selected.

## 8. Interactions, Gestures & Motion
*   **Tap:** Trigger CTAs, open Pose Detail modal, select rating circles, select filters.
*   **Pull Down:** Refresh all session, pose, and streak data.
*   **Swipe Right (Edge):** Native iOS back navigation.
*   **Drag Down:** Dismiss Pose Detail modal via top handle.
*   **Tap (Outside):** Dismiss Pose Detail modal by tapping backdrop.
*   **Motion Intent (Browse):** Elements stagger entry (fade-in + 12pt slide-up). Heatmap cells populate sequentially. Line charts draw left-to-right.
*   **Motion Intent (Session):** Pose timer sweeps counterclockwise. Pose transitions use a 280ms crossfade. CIA notes cycle every 30 seconds. 
*   **Motion Intent (Summary):** XP badge scales up and pulses with a green glow. Stat numbers count up from 0 to final value.

## 9. Free vs. Premium Gating
*   **Free Tier:** Full access to the guided session library, pose library, and active session timer.
*   **Premium (Plus) Tier:** Unlocks contextual CIA coaching notes and personalized difficulty recommendations.

## 10. Cross-Domain Hooks
*   **CIA Chat [09]:** Tapping the CIA Coaching Note routes the user to the CIA chat interface with the yoga/wellbeing context pre-loaded.
*   **Fitness & Workouts [26]:** CIA notes pull data from yesterday's workouts to inform today's yoga stretch recommendations.
*   **RPG Character [19]:** Completing sessions updates the user's Wellbeing skill level, accessible via the header badge.

---
### ⚠️ Source Contradictions Flagged
1.  **User Motivation Variants vs. Fixed UI Constraints:** The spec explicitly limits the Pose Library preview to "6 poses (2 rows x 3 columns)". However, the "High motivation" variant states the library expands to "9 poses (3x3 grid)". The UI must be flexible to render 6 or 9 cards dynamically based on the inferred motivation state.
2.  **Color Identity for Timer Fill:** The older component spec describes the Active Session timer fill as *wellbeing-teal* "to distinguish yoga from fitness." The newer visualization overrides state this fill is *burnt-orange* to adhere strictly to the 60/30/10 color law (orange = progress data ink everywhere). **Resolution:** Use *burnt-orange* for the timer fill, as per the updated visualization mandate.
