### 1. Purpose
To act as the universal command line for Balencia, collapsing 9 life domains and 73 screens into a single, high-speed text field that instantly deep-links users to their target content. CIA powers the ranking engine, injecting predictive, behavioral intelligence directly into the search flow.

### 2. Entry and exit paths
**Entry Paths (Modal Slide-up):**
*   Home Screen [12] via search icon tap.
*   Any Today tab screen via pull-down gesture.
*   Settings [21] via search bar tap.
*   CIA Chat [09] via "search for that" deep-link.

**Exit Paths (Slide-down):**
*   **Primary:** Tap any result row (dismisses overlay and stack-pushes to destination).
*   **Secondary:** Tap "Cancel" button, swipe-down from top, or hardware back (Android).

**Deep-link Targets:** Goal Detail [14], Habits [38], Recipe Detail [56], Quick Notes [62], Journal [37], Settings [21], CIA Chat [09], any feature screen [01-73], Community Room Detail [40].

### 3. Information Architecture (Top-to-Bottom)
1.  **Search Header:** Auto-focused text input field, inline clear (x) button, and "Cancel" escape hatch. Pinned at top.
2.  **Category Filter Chips:** Horizontal scroll row (All, Goals, Habits, Recipes, Notes, Journal, Settings, Screens, Community). Pinned below header.
3.  **CIA Suggestion Row:** AI prediction card. Appears dynamically after 2+ typed characters.
4.  **Recent Searches:** Scrollable list of up to 10 previous queries (only visible when input is empty and history exists).
5.  **Result Sections:** Grouped by content category (CIA-ranked relevance). Features a section eyebrow with result count badge.
6.  **Result Row Variants (8 total):** Flat rows nested within section cards, tailored to the content type (Goal, Habit, Recipe, Note, Journal, Setting, Screen, Community).
7.  **Empty/Error State:** Centered fallback block or inline banners based on query results and network status.

### 4. Features and capabilities
*   **Universal Deep-Linking:** Every row acts as a direct router to specific items, pre-focusing the target item on the destination screen.
*   **Live Search:** 300ms debounce triggers an instant, cross-domain query.
*   **CIA Intent Prediction:** AI analyzes partial queries, recent behavior, and time-of-day to surface a high-confidence "I'm feeling lucky" top row.
*   **Scoped Filtering:** Radio-button style chips narrow results to a single category without altering the text query.
*   **Local-First Architecture:** Goals, Habits, Notes, Journal, Settings, and Screens are indexed locally for offline search and <200ms latency.
*   **History Management:** Local storage of last 10 queries with swipe/tap to delete or "Clear all".
*   **Fuzzy Matching:** "Did you mean?" logic for misspelled queries.
*   **Visual Query Highlighting:** Matched characters are visually distinct (bolded/orange) within the result text.

### 7. Screen states
*   **Cold-start / Day-1:** No history. Hides recent searches, shows warm prompt ("Search across everything...").
*   **Empty-Query (History):** Shows up to 10 recent searches in a list.
*   **Loading:** Shows inline text ("Searching for...") and 4 skeleton shimmer rows matching card depth.
*   **Typing / Live Suggestions:** Displays CIA card at top, followed by dynamically filtering result sections.
*   **No Results:** Centers a block with a search icon and constructive text. Category chips are pushed to 40% opacity (disabled).
*   **Partial Results:** Hides empty categories entirely. Tapping a 0-result chip yields a brief inline message.
*   **Error (API Failure):** Shows an inline banner with an error-red border and glyph. Local categories remain visible; server categories degrade.
*   **Offline:** Informational banner (no error color). Hides Community Rooms; limits Recipes to cached data only.

### 8. Interactions, gestures, motion intents
*   **Gestures:** Pull-down to open (from Today tab). Swipe-down to dismiss. Swipe-left on recent searches to reveal delete zone (release past 30% to commit). Tap to select deep-links.
*   **Scrolling:** Vertical scroll for results (keyboard auto-dismisses on first scroll). Horizontal scroll for category chips.
*   **Motion Intents:** Overlay slides up/down (280ms ease-out-soft). Staggered fade-ins for result sections and rows (60ms/40ms offsets). GaugeRing on Goal rows scales in. Category filtering crossfades list (280ms).
*   **Accessibility Motion:** If OS "Reduce Motion" is active, all slide/stagger animations collapse to 0ms instant renders or basic fades.

### 9. Free vs premium gating
*   *Contradiction Flag:* The original source spec states "Universal Search is a pure utility screen. It does not adapt based on motivation tier... No gamification, no XP." However, later documentation references "Premium Craft" and "tier-influenced content." 
*   **Functional Resolution:** There is no hard paywall blocking the search utility itself for free users. The **behavioral ranking** and **CIA suggestions** dynamically adapt to the user's status (e.g., a low-motivation user gets gentle suggestions, high-motivation gets intense routines), but no explicit premium feature gates are documented on this specific screen.

### 10. Cross-domain hooks (correlations, AI insights, links to other life areas)
*   **The CIA Intent Engine:** Acts as the ultimate cross-domain hook. It fuses text matching with behavioral data, tracking engagement recency, frequency, and time-of-day across *all 9 domains* to rank results.
*   **Cross-Domain Tagging:** Quick Notes and Goals utilize shared domain tags (e.g., [nutrition], [fitness]) allowing users to search a concept and see how it manifests across their habits, goals, and journal entries simultaneously.
*   **Screen Router:** Functions as a map for the entire app ecosystem, directly linking surface-level intent to deeply nested settings or specific community rooms.
