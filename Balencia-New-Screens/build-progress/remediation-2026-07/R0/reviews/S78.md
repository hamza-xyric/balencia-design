## Dimension notes
1. Spec conformance: issue — "2 drafts" meta is inaccurate and the spec's "New"/create-report affordance is absent (#3); an unspecified "Data Sources" error row is invented (#4); consent/safety module required by spec is missing entirely (#1).
2. Canon fidelity: issue (Low, #5) — Recent Reports cards use `.glass-card` for data-dense content (sync %, ring, status) while the equally data-dense This Week tiles correctly use `SolidCard`; spec's NEW-ReportCard rationale explicitly directs GlassCard here, so this is a spec/canon tension to classify, not a clear-cut violation.
3. Data honesty: mostly ok — real+provenance (sleep `via wearable`, work `you logged`) and low-confidence (Doctor Summary Draft 3/7, CIA insight `estimated · low confidence`) are correctly modeled; but the "2 drafts" section-meta count is itself a fabricated/wrong number (#3), and the CIA insight states a confident claim while flagged low-confidence (soft mismatch, not separately filed).
4. Cross-cutting: issue (High, #1) — canon §8 mandates a revoke/delete entry point on any screen touching health/synced data (wearable sleep, fitness sync); none exists. Header `ShieldCheck` icon is decorative-only (no button, no onClick, no aria-label) so it cannot serve as that entry point. Crisis layer n/a (no mood/check-in surface); quick-log FAB correctly absent (activeTab="me", not Today).
5. Composition craft: issue (#2) — invalid Tailwind arbitrary-value class `text-20px` (missing brackets) on the Sleep/Work stat numbers silently drops the intended 20px semibold stat treatment. Otherwise clean above the fold: hero, chips, report cards, KPI tiles all align with no truncation/overlap in the captured viewport.
6. Copy voice: issue, known — Title Case chip copy (`CIA Summary`, `Private By Default`, `6 Of 7 Days Synced`, `Screenshot Guide`) vs. canon sentence case (S-04); "CIA" all-caps in visible copy throughout (A24-008). No new filing.
