# Bevel (AI Health Coach) — UI Reference

All-in-one AI health coach (sleep/recovery/fitness/nutrition/stress) on Apple Watch data. Closest **design + positioning comp to Balencia**. iOS-only (no Google Play). **15 screenshots** (`app-store/` 10 · `community/` 5). Sources: `sources.md`, `community-sources.md`.

## Screens captured & features shown

| Screen | Key UI / features visible |
|--------|---------------------------|
| **Home dashboard** | Today's **Strain / Recovery / Sleep** tri-ring, "Good morning, {name}" AI insight, **Stress & Energy** (high/lowest/avg), Nutrition, persistent **"Ask Bevel"** bar |
| **Fitness** | Cardio Load, Cardio Focus, Heart-Rate Recovery (HRR) |
| **Sleep detail** | Sleep-stage **hypnogram** + stage breakdown |
| **Recovery** | % recovered ring, Resting HRV / HR, recovery-insight timeline |
| **AI chat ("Ask Bevel anything")** | Conversational coach answering recovery/health questions **from the user's own data** |
| (others) | Nutrition logging, Apple Watch companion views |

## Patterns relevant to Balencia
- **Strongest direct analog**: AI coach + unified daily dashboard + warm, rounded, Apple-esque premium feel (recently adopted Liquid Glass). Already profiled in `app_design 3/competitor-analysis.md`.
- **Persistent "Ask {AI}" entry point** docked on the dashboard — pattern Balencia's SIA should consider.
- **Personalized morning narrative** ("Good morning, John… aim for 50–60% strain today") — exactly the SIA daily-briefing tone.
- Health-only scope — **no Finance/Career/Relationships/Learning/Creativity**; this is the white space Balencia owns.
- Tri-ring + insight-card layout is a clean, premium reference for Balencia's domain dashboards.
