## Dimension notes
1. Spec conformance — issue: Consent-and-Safety module (revoke/export/delete entry) is entirely unbuilt; Data Honesty's honest-null rule for zero-count chips is violated; the sparkline's "Real" state is missing its required provenance chip. See defects #2, #3, #7.
2. Canon fidelity — issue: dense notification rows use the glass tier instead of solid `--surface-2` (§2); domain tag colors are misapplied ("Sleep" tagged with the fitness token) or reference an undefined token entirely ("Social") against §4's domain palette. See defects #4, #5, #6.
3. Data honesty — issue: `Check-ins 0` chip is shown instead of omitted per the spec's own honest-null rule; the 7-day frequency-pulse ships in its "Real" state with no `via Notifications API` provenance chip. See defects #3, #7.
4. Cross-cutting — issue: no revoke/delete/export consent entry point exists anywhere on the screen despite canon §8 and this screen's own "Consent and Safety" spec section (defect #2). Chrome-semantics/purple-classification/touch-target patterns visible here are already covered by A24-002/A24-003/A24-010 (see Known-finding sightings).
5. Composition craft — issue: a literal HTML/JSX markup string prints as visible garbled text above the summary chip row, defeating the spec-required Tiempos-italic emphasis word (defect #1).
6. Copy voice — ok apart from "CIA Insight." mid-sentence capitalization (known S-04 Title-Case drift) and all-caps "CIA" (known A24-008 casing sweep) — neither refiled here.
