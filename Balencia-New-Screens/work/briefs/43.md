# Functional Content Brief: Paywall / Upgrade Prompt

## 1. Purpose (2 lines)
Converts free users to subscribers contextually at the exact moment they trigger a premium feature, using a blurred preview and honest feature matrix. Employs a strict non-coercive design philosophy, ensuring easy-out paths are equally weighted and free of dark patterns.

## 2. Entry and Exit Paths
**Entry Paths (System-Triggered Modal or Inline Chat Card):**
*   **CIA Chat limit reached:** User hits free tier message cap.
*   **Domain Dashboards:** Tapping premium analytics sections.
*   **Cross-Domain Insights:** Tapping correlation drill-downs.
*   **Goals/Habits:** Triggering advanced goal decomposition or AI habit suggestions.
*   **Voice Mode:** Hitting voice usage limits.
*   **Journal:** Triggering AI reflection analysis.

**Exit Paths:**
*   **Conversion Success:** Tap primary CTA → native IAP flow → modal auto-dismisses after success state.
*   **Dismissal:** Tap "maybe later", tap backdrop, drag down modal, or swipe left (chat variant) → returns to underlying screen.
*   **Comparison:** Tap "Compare all plans" → dismisses modal and pushes Subscription & Billing screen onto stack.

## 3. Complete Information Architecture

**Variant A: System Modal (z-50 overlay, ~75% screen height)**
1.  **Backdrop Layer:** Full-screen dimming layer.
2.  **Drag Handle:** Affordance at the top edge of the modal.
3.  **Contextual Headline:** Dynamic text adapting to the locked feature.
4.  **Blurred Preview:** Render of the locked premium content.
5.  **Feature Comparison Matrix (Hero Element):** Grid mapping features (rows) against tiers (columns).
6.  **Price Tiles:** Stat tiles displaying the cost per tier.
7.  **Trial Terms:** Honest text clarifying the offer.
8.  **Primary CTA:** Full-width conversion button.
9.  **Easy-Out Link:** Text link to dismiss.
10. **See All Plans Link:** Text link to navigate away.

**Variant B: CIA Chat Inline Card (z-10, within Chat Screen 09)**
1.  **CIA Contextual Message:** Chat bubble introducing the premium link naturally.
2.  **Inline Upgrade Card:** Embedded rich card within the chat flow.

## 4. Every Feature and Capability
*   **Contextual Dynamic Copy:** Headlines, preview renders, and tier emphasis automatically adapt to the exact feature the user attempted to access.
*   **Gaussian Blurred Preview:** Teases the locked UI to create desire without revealing usable data.
*   **Honest Comparison Matrix:** Visualizes exactly what is included (Check), missing (Minus), already owned (Green Check), and unlockable (Orange Check) across tiers.
*   **In-place Feature Expansion:** Tapping a feature row in the matrix expands a plain-language explanation of what it does.
*   **Price Count-up:** Tiles animate from 0 to final price on appearance.
*   **Native IAP Integration:** Connects directly to OS-level payment processing.
*   **CIA Chat Integration:** Seamlessly injects upgrade prompts into the conversational flow without breaking context.
*   **Multi-Path Dismissal:** Provides escape routes via links, gestures (drag/swipe), and backdrop taps.
*   **State Fallbacks:** Gracefully degrades from matrix view to text lists if data fails to load.
*   **Usage Frequency Throttling:** System limits paywall triggers based on user motivation tiers to prevent fatigue.

## 6. Data Fields and Metrics
| Data Field | Source | Purpose |
| :--- | :--- | :--- |
| **Trigger Context** | Passed from calling screen | Dictates headline copy, blurred preview render, and specific matrix features. |
| **Current User Plan** | User API | Determines baseline features (green "owned" checkmarks in matrix). |
| **Available Tiers & Features** | API / `_tier-matrix.md` | Populates the rows and columns of the comparison grid. |
| **Pricing ($20/mo, etc.)** | API Tier Pricing | Drives the numerical count-up in the price tiles. |
| **Trial Eligibility** | API (User History) | Determines CTA copy ("Start 7-day free trial" vs "Upgrade to Plus"). |
| **Motivation Tier** | System metric | Throttles paywall presentation frequency per session. |

## 7. Screen States
*   **Cold-Start / Day-1:** Matrix renders immediately. System prefers the softer CIA Chat Inline variant over the modal for first-time triggers.
*   **Loading:** Grid layout is preserved with skeleton pills. Prices count up. Delay >1.5s shows "Loading your plans…".
*   **Partial Data:** Known features render glyphs; pending features show ghosted dashes.
*   **Error (Matrix Failure):** Collapses to text fallback list ("Couldn't load the full comparison...").
*   **Error (IAP Failure):** CTA reverts from spinner; red error text appears below CTA.
*   **Offline:** Displays cached matrix behind a "Showing saved plans" banner; CTA dimmed.
*   **IAP Processing:** CTA text replaced by white spinner; modal dims slightly.
*   **IAP Success:** CTA turns green with checkmark; holds 1.5s, then auto-dismisses. No confetti.
*   **Trial Ineligible:** CTA text swaps from trial offer to direct upgrade.
*   **Blurred Preview Failure:** Replaces render with solid background, lock icon, and text caption.

## 8. Interactions, Gestures, Motion Intents
**Gestures:**
*   **Drag Down:** Dismiss modal (velocity-based: fast flick dismisses, slow drag springs back).
*   **Tap Backdrop:** Dismiss modal.
*   **Swipe Left:** Dismiss chat inline card.
*   **Tap Feature Row:** Expand "what this does" caption.

**Motion Intents:**
*   **Entrance Sequence:** Structure (grid headers/labels fade in) → Focal (cells settle, recommended column glow blooms once and rests) → Support (prices count up, CTA fades in). Total: ~2.5-2.8s. *Intent: Calm, structural reveal, strictly no looping or urgency pulses.*
*   **Dismissal:** Modal slides down proportionally to drag, or snaps out on tap. *Intent: Frictionless escape.*
*   **Success:** CTA fills green, rests for 1.5s, slides away. *Intent: Calm affirmation, preventing the user from feeling ambushed.*

## 9. Free vs. Premium Gating
This screen *is* the functional mechanism for gating. 
*   **Free Tier Limits Enforced:** CIA message caps, standard analytics, manual goal tracking.
*   **Plus ($20/mo) Unlocks:** Unlimited CIA messages, voice coaching, cross-domain insights, RPG gamification, all 9 life areas.
*   **Pro ($60/mo) Unlocks:** Advanced analytics, trend projections, deep domain comparisons.
*   **Ethical Gate:** Gating is never hidden. If a user cannot access a feature, the matrix explicitly shows the glyph mapping (owned vs. unlockable) so the user knows *exactly* what they are paying for. No auto-renewals are buried; terms are stated plainly ("7-day free trial, then $20/mo · cancel anytime").

## 10. Cross-Domain Hooks
*   **CIA Chat (09):** The inline card variant is fundamentally hooked into the chat UI. CIA autonomously recognizes when a user's query (e.g., asking about sleep and spending) brushes against a premium analytics gate, triggering the card contextually without leaving the chat keyboard.
*   **All Life Areas / Domains (16-36):** Headlines and previews dynamically pull data context from whichever domain the user triggered the paywall from (e.g., "get the complete Fitness experience"). 
*   **Settings / Subscription Management (23):** The "Compare all plans" hook routes users out of the contextual modal to perform deeper cross-tier analysis.
