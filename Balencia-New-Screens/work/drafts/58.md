# 2. Purpose
Provides a comprehensive command center for sleep analysis, answering "how well am I sleeping and what can I do better?" It surfaces last night's data and long-term patterns to deliver AI-driven, cross-domain coaching without overwhelming the user.

# 3. Entry & exit
*   **Entry points:**
    *   Explore grid card.
    *   Home Screen sleep action/insight card.
    *   CIA Chat deep-link ("let's look at your sleep").
    *   Wellbeing Dashboard.
*   **Exit points:**
    *   Back button (stack pop to previous screen).
    *   CIA Chat (stack push via tapping CIA insight card).
    *   RPG Character profile (stack push via RPG skill badge in TopBar).
    *   Connected Services (stack push via wearable connect prompt).
    *   Manual Sleep Log (`Sheet` modal invoked via `FABQuickLog`).

# 9. All states
*   **Default:** WHOOP connected, 7d trend view, hero score visible.
*   **Skeleton:** Depth-preserving. Axis labels/grids visible, chart elements and hero score shimmer (`--surface-3` base, 1.2s sweep). No spinning indicators.
*   **Empty (Cold-start / Day 1):** Hero ring shows faint empty track. Charts show faint grids with target lines and warm, aspirational copy ("Log a few more nights...").
*   **Error (Partial Sync / Offline):** Cached data displayed. Un-synced nights rendered as ghosted cells or dashed gaps (never interpolated as zero). `OfflineBanner` glass-pill visible. FAB disabled (50% opacity) with aria-label: "Offline — logging will sync when you reconnect."
*   **Success:** Manual log saved. `XPToast` appears: `+40 XP · Wellbeing`. Auto-dismisses.
*   **Disabled:** FAB Quick-log is disabled during offline mode.

# 10. Motion & interaction
*   **Physical easing:** Custom cubic-bezier curves (standard out: `cubic-bezier(0.2, 0, 0, 1)`). 150–250ms feedback for taps.
*   **On Mount:** Hero `ProgressRing` fills first (520ms), numbers count up. `SolidCard`s rise in a staggered sequence (80ms apart).
*   **Scroll-into-view:** "Living Lines" in charts draw themselves left-to-right (1200ms). Heatmap cells fade in row-by-row. Green milestone dots "pop" (scale 0 to 1) after lines draw.
*   **Glow behavior:** CIA Coaching Note card features a slow "breathe" (4s ease) on its purple inner-glow to signify active intelligence.
*   **Haptics:** Light impact haptic on toggling SegmentedTabs, successful sync, and saving manual log.
*   **Reduced-motion path:** Honors `prefers-reduced-motion`. Instantly renders final states. No ring fills, no line draws, no glows breathing.

# 11. Motivation-tier adaptation
*   **Low density:** Stages and Consistency BentoGrid hidden. Heatmap hidden. User sees only CIA Insight, Hero Score, and 7-day trend.
*   **Medium density:** (Default) All elements present. 7-day trend view standard.
*   **High density:** Cards use tighter 12px padding. Trend chart defaults to 14-day view. ConsistencyCloud numerical variance (`σ`) displayed next to the graph.

# 12. Accessibility
*   **Contrast:** AA+ maintained. Primary text `#FEFAF3` on `--bg-base` / `--surface-2`. Orange `#FF5E00` reserved strictly for non-text UI elements (glows, chart lines, active states) to avoid contrast violations.
*   **Targets:** All interactive elements (Back chevron, SegmentedTabs, RPG badge, FAB) strictly maintain 44px minimum hit targets.
*   **Screen-reader labels:** Glyph-only buttons possess strict aria-labels (e.g., Back button = "Back to previous screen", FAB = "Log sleep manually").
