## Contracts (implement exactly)
```ts
// Provenance type — duplicate locally in states.tsx and export it (adapters will import it from here or re-declare; keep the shape EXACT):
export type Provenance =
  | { kind: 'real'; source: 'whoop' | 'self_report' | 'computed' | 'server'; label: string }   // e.g. "via WHOOP", "you logged"
  | { kind: 'low'; label: string }                                                              // "estimated · low confidence"
  | { kind: 'null'; label: string };                                                            // "Not enough data yet"

export function SkeletonState(props: { lines?: number; variant?: 'card' | 'hero' | 'list' }): JSX element
export function ErrorState(props: { message: string; onRetry?: () => void }): existing signature EXTENDED with optional onRetry
export function HonestNullState(props: { title: string; detail?: string }): JSX element
export function ProvenanceChip(props: { provenance: Provenance }): JSX element
export function OfflineBanner(props: { lastSyncLabel?: string; onRetry?: () => void }): JSX element
export function LockedFeatureState(props: { title: string; detail?: string; onUnlock?: () => void; unlockLabel?: string }): JSX element
export const LoadingState: alias of SkeletonState accepting { label?: string } for back-compat (keep existing call sites compiling)
export function EmptyState(props: { title: string; detail: string }): keep existing
```

Behavior/visual requirements:
1. **SkeletonState**: shimmer blocks on `#2A1A10`-ish surface (derive from theme tokens; base block color from existing card surfaces), 1.2s opacity pulse via `Animated` from `react-native` (opacity loop 0.4→0.8) — transform/opacity only. `variant:'hero'` = one tall block; `'card'` = title line + 2 body lines; `'list'` = N rows (default `lines ?? 3`).
2. **ErrorState**: quiet failure — glyph/text + plain-language message, never blames the user; optional retry as a bordered 44px-height pressable labeled "Try again".
3. **HonestNullState**: designed empty per canon §7 — muted title (e.g. "Not enough data yet"), optional detail line; NO fake numbers, NO progress visuals.
4. **ProvenanceChip**: 24px-high micro pill; `real` → green-tinted border/text; `low` → muted amber/paper tone; `null` → dim paper. Text = `provenance.label`.
5. **OfflineBanner**: full-width pill banner, honest staleness copy: `Offline — showing last sync ${lastSyncLabel ?? 'unknown'}`; optional retry.
6. **LockedFeatureState**: gated preview per canon §8 — dimmed card w/ lock glyph (use a simple "🔒" text glyph or a drawn view — no new icon deps), one-line value `detail`, single primary CTA (orange) `unlockLabel ?? 'Unlock'` calling `onUnlock`; when `onUnlock` absent render the CTA disabled. Never a dead end: always show title+detail even when disabled.
7. Reduced-motion: guard animations with `AccessibilityInfo.isReduceMotionEnabled()` (state + effect; fall back to static blocks). All pressables ≥44px, `accessibilityRole`/`accessibilityLabel` set.
