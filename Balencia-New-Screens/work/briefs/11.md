### 1. Purpose
Provides a distraction-free, immersive conversational voice interface where the user and the CIA (coach) interact naturally. Serves as Balencia's most intimate interaction, utilizing a state-reactive 3D avatar and real-time feedback to simulate a premium, face-to-face coaching experience.

### 2. Entry and Exit Paths
*   **Entry Paths:** Arrives from CIA Chat [09] via the immersive voice button or a long-press on the mic button.
*   **Exit Paths:** Returns to CIA Chat [09] via the close (✕) button or a full-screen swipe-down gesture (>120pt). The entire voice exchange is transcribed and appended to the chat history. 

### 3. Information Architecture
Fixed, single-viewport layout (no scrolling). Top-to-bottom structure:
1.  **Status Bar Zone:** Time and system indicators (unobtrusive).
2.  **Close Button:** Escape hatch (top-right).
3.  **Upper Ambient Zone:** Atmospheric negative space.
4.  **CIA Avatar Container (Hero):** The sole visual focal point (200pt diameter).
5.  **Avatar Glow Zone:** Radial depth behind the avatar, reacting to conversation state.
6.  **Mid Spacer:** Visual breathing room.
7.  **Transcription Area:** Real-time text feedback (max 3 lines, 280pt width).
8.  **Waveform Visualization:** Audio amplitude bars (280pt wide).
9.  **Mute Button:** Mic control toggle.
10. **Bottom Safe Area:** Home indicator.

### 4. Features and Capabilities
*   **State-Reactive CIA Avatar:** 3D model (or 2D animated fallback) that shifts between Idle, Listening, Processing, and Speaking behavioral poses. Features ambient breathing, eye contact, and lip-sync/expression capabilities.
*   **Real-Time Transcription:** Live, word-by-word text streaming of the conversation.
*   **Dual-Color Audio Waveform:** Visualizes audio amplitude to provide non-text attribution (User vs. CIA).
*   **Ambient Particle System:** Background depth elements that react to CIA's state (drifting inward, outward, or orbiting).
*   **Persistent Voice Controls:** Mute toggle and dismiss/close functionality available across all non-blocking states.
*   **State Machine Error Recovery:** Automated background retries for network drops, warm fallbacks for API timeouts, and text-failovers for audio output errors.

### 6. Data Fields and Metrics
*   **Transcription Text Data:** 
    *   *Source:* User speech (via native OS speech-to-text recognition).
    *   *Source:* CIA speech (via LLM text generation tied to voice output).
*   **Waveform Amplitude:** 
    *   *Source:* Device microphone input (User state) and system audio output buffer (CIA state).
*   **Conversation History Payload:**
    *   *Source:* Native app local storage; synced to CIA Chat [09] database upon screen dismissal.

### 7. Screen States
*   **Cold-Start / First Use:** SIA speaks first to break the silence; flat waveform transitions to listening.
*   **Idle (>10s silence):** Calm breathing avatar, minimal ambient particles, soft prompt from CIA.
*   **Listening:** Attentive avatar posture, active waveform.
*   **Processing (Thinking):** Contemplative avatar posture, orbital particles, pulsing glow, processing dots.
*   **Speaking:** Animated avatar (lip-sync/gestures), elevated glow intensity, outward-projecting particles.
*   **Loading (Audio Init):** Idle pulse animation (<500ms).
*   **Microphone Permission Denied:** Static UI, links to settings, no audio waveform.
*   **Network Error:** Frozen avatar, dimmed glow, manual retry option + background auto-retry.
*   **Speech Recognition Failure:** No visual error; CIA re-enters listening state with a soft prompt.
*   **Audio Output Failure:** Avatar speaks but no audio; automatic fallback to text-only mode.
*   **API Timeout (>8s):** Drops processing dots and triggers specific conversational recovery copy.
*   **Muted (Control State):** Visual/haptic shift on the mic button to indicate operational status.

### 8. Interactions, Gestures, and Motion Intents
*   **Tap (Close ✕):** Dismisses overlay.
*   **Swipe Down (>120pt):** Dismisses overlay (alternative to close).
*   **Tap (Mute Button):** Toggles mic on/off.
*   **Speak (Microphone):** Primary input mechanism.
*   **Motion Intent - "Draw, Don't Fade":** Screen slides up; CIA avatar scales up and glow expands radically as a signature entrance. Transcription words fade-in sequentially (160ms) rather than swapping full lines.
*   **Motion Intent - "Breathing Presence":** Avatar maintains a 4000ms sinusoidal scale/y-offset pulse during idle to avoid feeling static.
*   **Motion Intent - "Color Crossfade":** Waveform and avatar glow transition smoothly (280ms ease-out-soft) between speaker turns.
