# 2. Purpose
Establish the foundational "it gets me" emotional moment within the first 60 seconds of app installation. By replacing traditional baseline forms with a collaborative, systemic AI brainstorm, Balencia visualizes the user's inputs as an interconnected graph, gathering baseline health, domain focus, structured goals, and coach preferences without friction.

# 5. Components
*   **CIAPresenceOrb:** Idle breathing state. 
*   **CIAChatBubble:** User (orange fill, right-aligned), CIA (purple-tinted glass, left-aligned).
*   **ProgressRing:** Radial stroke wrapping the orb. 
*   **ChatComposer:** `GlassPillInput` + `BtnPrimary` (send). 
*   **BtnSecondary:** Pill format used for horizontally scrolling suggestion chips.
*   **NEW: BrainstormCanvasObject** — Rationale: Required to render floating domain tags/goal cards that drift with physics and morph into chat bubbles; native canvas element handles complex coordinate mapping unavailable in standard cards.
*   **NEW: ContinuousStrokeMotif** — Rationale: The 1200ms core-brand signature draw (`pathLength` animation) that connects the floating bubbles into a literal visual graph.

# 6. Visual treatment
*   **Glass Tier:** `ChatComposer` and `CIAChatBubble` (CIA side) use `.glass-pill` and `.glass-card` respectively. The top Brainstorming Area uses NO glass—it relies on solid tags and a bright SVG stroke to maintain crispness over the atmosphere.
*   **Glow & Meaning:** The `CIAPresenceOrb` projects `--glow-cia` (#7F24FF) outward, signifying premium AI thinking. As users tap domain tags, those tags illuminate with `--glow-you` (#FF5E00), reflecting their personal effort and active selection. 
*   **Background Atmosphere:** True to Canon §1, `--bg-base` (#0A0A0F) overlaid with the mandatory top-center warm radial glow AND a dedicated purple pool (`rgba(127, 36, 255, 0.15)`) to center focus on the CIA orb.
*   **Hero Type Moment:** The initial CIA message contains the hero type moment: the word *whole* in Tiempos italic.

# 9. All states
*   **Default (Day 1 / Cold Start):** Canvas displays fully drawn stroke; domain bubbles float ready. CIA proactively initiates conversation. 
*   **Loading (CIA Thinking):** Chat bubble contains 3 pulsing dots. `ChatComposer` dims to 60% opacity, blocks typing, displays "CIA is thinking...".
*   **Partial Selection:** Selected domain bubbles glow brightly (`--glow-you`) and drift toward the center; unselected fade to 50% opacity and recede to edges. Goal cards appear.
*   **Error (Generation Fails):** Soft-error copy replaces generic system alerts. Chat bubble reads "I hit a snag — let me try that again." Accompanied by a `BtnSecondary` "retry" chip. Uses calm orange (`#FF5E00` @ 40% opacity border), never alarming red.
*   **Offline:** Cached messages remain interactive. `OfflineBanner` appears as a glass-pill above the composer: "You're offline. Your responses have been saved locally..."
*   **Success (Transition):** Visual elements converge into the center, morph into a pulse ring, and crossfade to `08`.
*   **Disabled (OAuth in Progress):** Triggered by integration tap. Input field dims, typing blocks, placeholder reads "Connecting to [provider]...".

# 10. Motion & interaction
*   **Physical Easing:** Elements use iOS-standard physical springs (`easeInOut`). No linear motion.
*   **Timing:** Feedback interactions (taps, chip selects) resolve in 150-250ms. 
*   **Glow Behavior:** The `CIAPresenceOrb` breathes on a 4s `ease-in-out` loop. 
*   **Tap-to-Morph Intent:** Tapping a floating domain bubble fires a physics-based fly-and-morph animation where the bubble content travels to the `ChatComposer`, drops the text, and transforms into a right-aligned user message bubble.
*   **Haptics:** Light selection haptic (iOS `UIImpactFeedbackGenerator.light`) on domain bubble tap. Medium haptic (`medium`) on successful message send. 
*   **Reduced-Motion Path:** Halts all ambient canvas drift, bubble floating, and orb breathing. Elements appear static and fully settled. The transition to screen `08` skips the convergence morph; uses a simple 200ms opacity crossfade.

# 11. Motivation-tier adaptation
*   **Low Density (Minimalist):** Canvas displays a maximum of 3 large domain bubbles at a time. The "something else" chip is hidden to reduce cognitive load.
*   **Medium Density (Default):** Canvas displays up to 6 floating bubbles. Suggestion chips row auto-suggests 4 items based on semantic parsing of the user's baseline input.
*   **High Density (Comprehensive):** Canvas displays all 10 life domains simultaneously as a tight constellation. Suggestion chip row is fully populated, and goal example cards drop automatically based on domain selections.

# 12. Accessibility
*   **Contrast:** Paper-100 (#FEFAF3) text on `--surface-2` data backgrounds and `--bg-base` passes AAA. Paper-50 on `.glass-pill` inputs passes AA.
*   **Targets:** All floating `BrainstormCanvasObject`s map to a minimum 44x44px invisible bounding box for tapping, regardless of visual size. The `ChatComposer` send button is exactly 44x44px.
*   **Screen Reader:** The `CIAPresenceOrb` visual is grouped and read as `accessibilityLabel="CIA coach visual"`. The radial `ProgressRing` hides from VoiceOver and is replaced by a hidden text node: `accessibilityLabel="Onboarding step 2 of 7"`.
