# FUNCTIONAL CONTENT BRIEF: Personal Wiki / CIA Memory

## 1. Purpose
A browsable, editable knowledge base ("book of life") that makes the CIA's memory of the user transparent and controlled. It stores compiled chapters of personal details, behavioral patterns, cross-domain correlations, and life events, growing into a comprehensive life record over time. 

## 2. Entry and Exit Paths
*   **Entry Paths:** Pushed via the "book of life" quick link on the Me Main root screen (Stack depth 1).
*   **Primary Exit:** Back button / edge swipe → returns to Me Main.
*   **Secondary Exit:** Tapping a correlation entry → switches to CIA Chat with "explain this correlation" context provided.
*   **In-screen Transitions:** Entering inline edit mode; confirming/deleting an entry via bottom sheets.

## 3. Information Architecture
**Vertical Hierarchy (Top-to-Bottom):**
1.  **Navigation Header:** Back button + Screen Title.
2.  **Search Bar:** Real input field for filtering memories across all chapters.
3.  **Chapter Tabs:** Horizontally scrolling pills. Represents the core taxonomy of the user's life domains.
4.  **Chapter Meta:** Composition metrics (total entries, last update, memory density).
5.  **Entry Cards (FlatList):** Variable-height scrollable list of memory items for the selected chapter.

**Chapter Taxonomy (Wiki Domains):**
*   `about you` (Name, age, personal details)
*   `preferences` (Communication, diet, schedule preferences)
*   `patterns` (Discovered routines, i.e., "skipping workouts on Mondays")
*   `correlations` (The hero domain; cross-domain connections, i.e., "sleep ↔ spending")
*   `goals history` (Archived goals and lessons learned)
*   `life events` (Significant milestones and timeline events)

## 4. Features and Capabilities
*   **Cross-Chapter Memory Search:** Client-side keyword search spanning all titles and contents. Overrides chapter view when active, displaying flat results with chapter badges. Returns "no results" state gracefully.
*   **Inline Memory Editing:** Users can directly edit the title and content of any memory card in place.
*   **Fact-Flagging ("This is wrong"):** A calm, non-destructive review flow to flag CIA's incorrect inferences, prompting a background correction.
*   **Data Deletion:** A genuinely irreversible flow (requires explicit confirmation) to delete a memory.
*   **Correlation Network Visualization:** A dynamic mini-graph mapping inferred cross-domain connections. Nodes are tappable to surface explanations, and edges visually distinguish between confirmed and inferred data.
*   **Honest Confidence Strength:** Displays the magnitude of CIA's confidence in an inference (High, Medium, Low) as a visible percentage/bar alongside the text, rather than relying on color alone.
*   **Motivation-Based Content Pivoting:** 
    *   *Low motivation:* Truncated text (title + 1 line), simplified correlations, source indicators hidden.
    *   *High motivation:* Full content expanded, highly detailed correlation data points (e.g., specific percentages, sample sizes).

## 7. Screen States
*   **Default (Established):** Fully populated lists across active chapters.
*   **Cold-start / Day-1:** Most chapters show a "0" hollow ghost dot. Displays warm, growth-oriented copy instead of blank canvases. The Correlation graph shows a placeholder skeleton with 3-5 ghosted nodes.
*   **Search Active:** Tabs dim and become inactive. Results aggregate into a flat list. Each card gains a chapter badge. Typing an X clears the query.
*   **Loading:** Tabs and meta shimmer. Correlation graph shows 3 purple pulsing dots. Entry cards show skeleton shimmers while preserving card depth and borders.
*   **Edit Mode:** Card transforms; title and content become bordered text inputs. Action row swaps to save/cancel/delete.
*   **Success / Failure:** Brief green glow border on save success; brief red flash and haptic on failure. Entry slides left and collapses on successful deletion.
*   **Offline:** Pull-to-refresh disabled. Cached entries visible. Search disabled with an explanatory banner.

## 8. Interactions, Gestures, and Motion
*   **Standard Gestures:** Tap (buttons, tabs, nodes), Horizontal Scroll (chapter tabs), Vertical Scroll (entry lists), Pull-to-refresh (fetch latest API).
*   **iOS Native:** Swipe right from left edge to pop stack back to Me Main. Swipe down to dismiss bottom sheets.
*   **Motion Intent (Draw-First):** 
    *   On entering the Correlations chapter, the NetworkGraph *draws first*: nodes fade in staggered (20ms/node), then edges stroke-draw outward (520ms), then the central hub blooms last. 
    *   Confidence bars rise from 0 to their level (520ms).
    *   Chapter transitions use a 160ms fade-out / 280ms fade-in crossfade. 
    *   Bottom sheets slide up (280ms) with a 60% backdrop fade.
    *   *Accessibility Note:* All staggered animations and graph drawing collapse to instant, settled final frames under `prefers-reduced-motion`.

## 9. Free vs Premium Gating
*   *General Access:* Not explicitly detailed in the base spec (assumes baseline access to personal data).
*   *Premium Gating (Audit Conflict Resolution Q33):* Life Areas comparison features and advanced cross-domain correlation exploration are strictly PLUS-gated, requiring the user to build up enough history to unlock.

## 10. Cross-Domain Hooks (AI Insights)
*   **The Secret Sauce:** The `correlations` chapter serves as the ultimate cross-domain hook, making hidden life connections browsable (e.g., linking sleep habits to next-day spending, or workout adherence to overall mood).
*   **CIA Chat Integration:** Tapping a correlation node or card triggers a context-aware jump to CIA Chat, allowing the user to verbally explore or question the inferred connection.
*   **Knowledge Graph Reuse:** The visualization primitive established on the global Knowledge Graph screen is intentionally reused here to visually anchor the user's localized memory web.

## 11. Source Contradictions & Resolutions
*   **CONTRADICTION (Color Styling):** The legacy typography/color spec demanded destructive, alarm-red (`#f44336`) colors for the "this is wrong" and inline "delete" buttons. The audit (S20-V04) explicitly flags this as a brand violation, noting that editing one's own AI memory should be a calm, non-shaming action. **Resolution:** Routine memory controls are neutral muted; alarm-red is strictly reserved for the final, irreversible delete confirmation CTA. *(Visual styling excluded from final build per prompt parameters).*
*   **CONTRADICTION (Visual Rendering):** The reused NetworkGraph primitive originally utilized `preserveAspectRatio="none"`, which distorted circular nodes into ellipses. The spec flags this as a data-honesty defect (S20-V03). **Resolution:** The graph must render on a square logical canvas with aspect ratio preserved.
*   **CONTRADICTION (Screen Register):** The spec initially claimed the color "purple is absent" from this screen, despite purple being the designated CIA-authored AI register. The audit corrects this: **Resolution:** User-control chrome remains orange/dominant, but the CIA-inferred correlation graph and confidence bars are locally scoped to purple.
*   **Mandatory UX Fix (B08-F04/F05/F06):** The prototype route featured "clickable divs" instead of real search inputs and lacked proper accessibility touch targets. **Resolution:** The build *must* implement real search semantics, 44px minimum touch targets on all tabs/actions, and strict 3:1 contrast minimums for graph nodes/edges.
