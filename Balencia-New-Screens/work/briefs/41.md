# Functional Content Brief: Schedule / Calendar (Screen 41)

## 1. Purpose
The Schedule / Calendar is the user's time-based planning view. It bridges synced external calendar events with the CIA’s AI-generated action suggestions to answer: "What does my day look like, and what should I do when?"

## 2. Entry & Exit Paths
**Entry Paths (Stack push):**
*   **Home Screen (12):** Schedule preview tap (lands on Today tab).
*   **Explore Section (18):** Calendar module card (lands on Me tab).
*   **CIA Chat (09):** Deep-link card (lands on Today tab).
*   **Domain Dashboards / Reminders & Tasks:** "View in calendar" links.

**Exit Paths:**
*   **Primary:** Tap event → Event Detail or relevant Domain Dashboard (e.g., Fitness, Nutrition, Career).
*   **Secondary:** Back arrow/swipe (Stack pop); Connected Services (22) via "Connect calendar" CTA or Sync Status tap; CIA Chat (09) via CIA suggestion context tap.

## 3. Complete Information Architecture (Top-to-Bottom)
The layout varies slightly by view (Day, Week, Month), but maintains a consistent structural hierarchy. *Note: Visual styling (colors, gradients, specific typography) is excluded per brief parameters.*

1.  **Navigation Header:** Title ("Schedule"), Sync Status Indicator, Back button, and Add (`+`) button.
2.  **View Switcher:** Segmented control for Day / Week / Month.
3.  **Date Navigator:** Current date or range, with Previous/Next arrows.
4.  **Day-at-a-Glance Strip (Secondary visual summary):** Domain time split (Donut) and Day Fullness (MomentumBar).
5.  **Unscheduled Tasks Area:** Collapsible list of actions not yet assigned a time slot.
6.  **Schedule Templates (Contextual):** Appears if the day is mostly empty.
7.  **Time-Slot Grid & Reading Layer:** The primary interactive surface.
    *   *Day View:* Vertical scrollable timeline (hour-by-hour) with absolute-positioned event cards and a drawn path agenda timeline over the grid.
    *   *Week View:* Horizontal 7-day selector (with density indicators) and a vertical agenda list for the selected day.
    *   *Month View:* Standard calendar grid with event density indicators, plus a selected day's event list preview.
8.  **Floating Add Button (FAB):** Persistent quick-action.
9.  **Tab Bar:** Global app navigation (Today, CIA, Goals, Me).

## 4. Features & Capabilities
*   **View Switching:** Toggle between Day, Week, and Month views. *(Contradiction Flag: The Motivation Adaptation section suggests hiding Week/Month views for low-motivation users, but standard interaction states imply all views are accessible. Flagged for UX clarification).*
*   **Time Navigation:** Step forward/backward by day, week, or month. Swipe gestures supported.
*   **CIA Suggested Actions:** Unique visual treatment for AI-recommended events (dashed outline cards; purple nodes in reading layer) distinct from synced/manual events.
*   **Drag-and-Drop Scheduling:** Long-press an unscheduled task to drag it into a specific empty time slot.
*   **Quick Event Creation:** Tap the FAB or tap/long-press an empty time slot to create a new event (time pre-filled if tapping a slot).
*   **Schedule Templates:** Apply pre-built routines (e.g., "morning routine") to an empty day.
*   **External Calendar Sync:** OAuth integration to pull in and display Google Calendar events.
*   **Motivation-Adaptive UI:** The UI scales feature complexity based on user motivation state (e.g., limiting task visibility in low-motivation mode).
*   **Density Visualization:** Real-time calculation of event density to show "day fullness" and "which life areas fill time."

## 7. Screen States
*   **Cold-Start / Day 1 (No Calendar):** Connect Calendar Card is primary. CIA starter tasks appear in Unscheduled. Donut shows ghosted ring. Time grid is empty but manually interactive.
*   **Loading:** Depth-preserving skeletons (shimmer) on the agenda path, donut rings, and full event cards. Copy: "CIA is reading your week..."
*   **Empty Day:** Aspirational empty states. No red/guilt cells. Heatmaps show lightest shade. Prompt to ask CIA for suggestions.
*   **Error (Sync/Load):** Cached reached nodes preserved. Red left border on failed event card. "Couldn't load..." toasts with explicit retry actions.
*   **Offline:** Cached schedule viewable. Top banner visible. FAB and pull-to-refresh disabled with explicit reasons given.
*   **Low Motivation Variant:** Week/month hidden. Only 1-2 unscheduled tasks shown. Softer CIA copy.
*   **High Motivation Variant:** Detailed event metadata (XP, effort). Week density indicators. Detailed analytics link visible.

## 8. Interactions & Gestures
*   **Tap:** Event card (view detail), CIA suggestion (accept), Time slot (create event), Checkbox (complete task).
*   **Swipe Left/Right:** On time grid = navigate days/weeks/months. On CIA Suggestion = dismiss (left) or accept (right).
*   **Long-Press:** Unscheduled task (lift to drag-and-drop into grid), Event card (quick actions: edit, delete, reschedule), Empty time slot (create event).
*   **Pull-to-Refresh:** Sync latest calendar data.
*   **Motion & Choreography:** 
    *   "Draw-first" UI philosophy. Agenda timelines draw top-to-bottom; Donut arcs sweep clockwise largest-to-smallest.
    *   *Non-shaming principle:* Animations and UI never turn red, break, or use loss-aversion framing. Missed events are neutral glyphs; empty days are "open time."

## 10. Cross-Domain Hooks & AI Insights
*   **CIA Integration:** Deep hooks with CIA for daily planning, accepting/rejecting schedule suggestions, and conversational context ("Ask CIA why").
*   **Domain Routing:** Events tagged with specific life areas (Fitness, Career, Nutrition, etc.) act as deep links into their respective domain dashboards (Screens 26, 28, 32).
*   **Visual Domain Splitting:** The "Day-at-a-Glance" strip explicitly answers the cross-domain question: "Which life areas fill my time?" by mapping scheduled minutes to identity colors.
*   **Goal & Habit Linkages:** Events can link back to specific Goals (Screen 14) or Habits (Screen 38).
