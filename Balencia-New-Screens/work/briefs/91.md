# Functional Content Brief: 91-Social Feed (/feed)

## 1. Purpose
A centralized, vertical scrolling social timeline where members discover, share, and engage with community updates, milestones, and cross-domain life activities. It serves as the daily social anchor for the Balencia community.

## 2. Entry and Exit Paths
*   **Entry Paths:** 
    *   Primary: Bottom tab navigation (`Social` / `feed`).
    *   Secondary: Deep-link from CIA Coach ("Check out what your Pod is saying in the Feed").
    *   Push Notification: Tapping a "New Kudos" or "Comment" alert routes directly to the specific post.
*   **Exit Paths:** 
    *   Tapping a user's avatar/name -> User Profile (`/profile/[id]`).
    *   Tapping a goal/workout/nutrition card within a post -> Respective Domain Detail screens (e.g., `/workouts`, `/goals`).
    *   Tapping a Community/Pod tag -> Community/Pod Detail (`/community/[slug]`, `/groups`).

## 3. Complete Information Architecture (Mobile-Inferred)
*Note: Mobile layout is inferred from the web's social feed obligations, collapsing sidebars into a top bar or bottom sheet.*

*   **Region 1: Feed Header**
    *   Title / Context Selector (e.g., "All", "My Pods", "Following").
    *   "New Post" Composer Entry Point.
*   **Region 2: AI/CIA Contextual Strip (Inferred)**
    *   Dynamic CIA prompt strip surfacing relevant community context ("Your Pod just finished a challenge...").
*   **Region 3: Activity Feed (Scrollable List)**
    *   *Post Card Module:* Avatar, Name, Timestamp, Post Type Tag, Post Body, Shared Life-Domain Card (e.g., Goal/Workout), Engagement Metrics (Kudos, Comments, Views).
    *   *Rich Content Module:* Image attachments, external links, or AI-generated insights.
*   **Region 4: Floating Action Button (FAB) / Quick Capture**
    *   Dedicated mobile affordance to create a new discussion, question, or log a win.
*   **Region 5: Empty / Error State Container**
    *   Fallback messaging and illustration area.

## 4. Every Feature and Capability
*   **Post Creation:** Ability to create posts across multiple formats: Discussion, Question, Tip, Success Story, Challenge, Announcement.
*   **Post Engagement:** Giving "Kudos" (like/upvote) and viewing participant lists.
*   **Commenting & Replies:** Threaded discussions and replies on post details.
*   **Cross-Domain Sharing:** Automatic or manual rich-card sharing of fitness logs, nutrition milestones, goal progress, and financial wins into the feed.
*   **Content Discovery:** Scrolling chronologically or algorithmically through community activity.
*   **Reporting & Moderation:** In-line ability to flag posts or comments for admin moderation/trust review.
*   **Pod/Community Scoping:** Filtering the feed to only show content from specific Pods, Circles, or Communities.

## 6. Data Fields and Metrics
*   **Post Content Body:** Text, Media (Images/Video) (*Source: User Input*).
*   **Author Data:** Avatar, Display Name, User ID (*Source: User Profile Database*).
*   **Timestamp:** Created At, Edited At (*Source: System Clock*).
*   **Engagement Metrics:** Kudos Count, Comment Count (*Source: Social Graph Database*).
*   **Cross-Domain Metadata:** Goal title, Workout type, PR (Personal Record) achievement (*Source: Fitness/Goals BFF*).

## 7. All Screen States
*   **Loading/Skeleton:** Shimmer blocks for feed cards while fetching.
*   **Empty State:** "No posts yet. Be the first to share a tip or success story!"
*   **Error State:** "Something went wrong. Pull to refresh."
*   **Success State:** Toast confirmation ("Posted successfully", "Comment added").
*   **Disabled/Offline:** Local only rendering ("You are offline. Showing cached posts").

## 8. Interactions, Gestures, Motion Intents
*   **Scroll:** Vertical pan to navigate the feed.
*   **Pull-to-Refresh:** Standard mobile gesture to fetch latest posts.
*   **Tap:** Tap post card to expand to full detail view; Tap heart icon for Kudos.
*   **Long-Press:** Reveal context menu to "Save", "Report", or "Copy Link".
*   **Motion:** Subtle bounce animation on the Kudos icon when tapped; smooth slide-in transitions for new comments.

## 9. Free vs Premium Gating
*   **Free Tier:** Full read access to the main community feed; ability to give Kudos and post basic text updates.
*   **Premium Gating (Inferred Strategy):** Posting rich "Success Story" templates, cross-domain automated sharing (e.g., auto-publishing an AI-generated weighted PR card), or joining exclusive "Premium Circles" may require an active subscription/upgrade.

## 10. Cross-Domain Hooks
*   **CIA Insights (AI):** CIA scans feed interactions (e.g., if a user posts about feeling demotivated, CIA surfaces a feed post to prompt encouragement or suggest a habit). 
*   **Domain Correlations:** Posts can serve as accountability anchors. A user sharing a "Finance" win (Money Map) can be linked to their "Goals" progress. 
*   **Pod/Group Integration:** Deep ties to the `Pods` and `Community` modules—activities posted in sub-groups naturally bubble up to the main feed based on algorithmic relevance.
