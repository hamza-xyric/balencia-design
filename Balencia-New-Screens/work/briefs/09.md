# FUNCTIONAL CONTENT BRIEF: CIA Chat

## 1. Purpose
The core product of Balencia—a unified AI conversation interface. CIA proactively initiates dialogue, embeds rich app intelligence (charts, metrics, summaries), and surfaces cross-domain insights, acting as the central hub where users spend most of their time.

## 2. Entry and Exit Paths
*   **Arrives from**: Bottom tab bar (CIA tab root, stack depth 0), CIA greeting card on Home Screen, or any "Ask CIA" shortcut throughout the app.
*   **Primary exit**: Feature/domain screens via rich inline card taps (stack push).
*   **Secondary exits**: Other tabs via bottom tab bar; Full-screen voice mode via long-press mic or top-bar voice icon (modal).
*   **Mode switch**: In-chat voice mode via mic tap (UI state change).

## 3. Complete Information Architecture
**Visual Priority & Layout (Top-to-Bottom)**
1.  **Status Bar Zone**: System status (44pt).
2.  **Top Bar**: Screen identity + actions (48pt). Contains "CIA." title (left). Search icon + Voice icon (right). Gains backdrop blur on scroll.
3.  **Chat Message Area (FlatList, inverted)**: The core conversation zone. Renders from oldest to newest. Contains:
    *   *Day Separators*: Date dividers (e.g., "today").
    *   *CIA Message Bubbles*: Left-aligned. Contains text and inline domain tags. Avatar only shows on the first bubble of a consecutive group.
    *   *Rich Inline Cards*: Left-aligned, embedded in CIA messages. Contains charts, progress rings, meal plans, financial summaries, workout previews, and connection spotted modules.
    *   *User Message Bubbles*: Right-aligned.
    *   *Suggestion Chip Row*: Horizontally scrolling quick-response options positioned below the latest CIA message.
    *   *Thinking Indicator*: Left-aligned bubble with pulsing dots.
4.  **Chat Input Bar**: Text entry field with a dynamic Mic/Send button (52pt).
5.  **Bottom Tab Bar**: App navigation; Today | **CIA** (active) | Goals | Me (56pt).
6.  **Home Indicator Zone**: System gesture area (34pt).

## 4. Every Feature and Capability
*   **Conversational AI Chat**: Send/receive text messages with an AI coach.
*   **Proactive Greetings**: CIA initiates conversations on screen open, return, or day-1.
*   **Rich Inline Cards**: Interactive, tappable modules embedded in chat bubbles:
    *   *Chart Card*: Mini line chart showing past trend and AI projection.
    *   *Goal Progress Card*: Mission completion ring and next action.
    *   *Meal Plan Card*: Meal macros (pills + optional donut).
    *   *Financial Summary Card*: Income, expenses, and net financial layout.
    *   *Workout Preview Card*: Exercise metadata and direct start CTA.
    *   *Connection Spotted Card*: Cross-domain correlation data.
    *   *Conversational Log Confirmation*: Acknowledgment of user-logged data with trend.
*   **Conversational Logging**: Natural language logging ("I did 30 min yoga", "I spent $45").
*   **Contextual Suggestion Chips**: Quick replies adapted to user motivation tier.
*   **Chat Search**: Slide-down overlay to find exact message strings.
*   **In-Chat Voice Mode**: UI state change to voice input.
*   **Full-Screen Voice Mode**: Immersive voice conversation modal.
*   **Pull-to-Load History**: Fetch older messages by pulling down at the top.
*   **Message Actions**: Long-press to copy text.

## 6. Data Fields and Metrics
*   **CIA Series Data (Actual & Projected)**: *Source: AI/Backend chartCard.series.* Drives the TrendChart actual line and projected dashed line.
*   **Mission Progress Data**: *Source: mission.progress, mission.name, mission.nextAction.* Drives GaugeRing fill and copy.
*   **Cross-Domain Correlation Pairs**: *Source: connectionCard.pairs[]. Drives correlation strength bars, +/- glyphs, direction words.
*   **Conversational Log Metrics**: *Source: Logged domain's trailing 7 points.* Drives optional Sparkline trend line.
*   **Macro Splits**: *Source: meal.protein, meal.carbs, meal.fat, meal.calories.* Drives Donut chart and pill data.
*   **Financial Scalars**: *Source: Finance API.* Drives text rows for income, expenses, net.

## 7. Screen States
*   **Cold-start / Day-1**: Proactive greeting card (focal), 1-2 chips, no message history above, no rich viz (prevents empty charts).
*   **Loading (CIA Response)**: 3 pulsing dots in a CIA bubble. >2s shows "thinking" text; >5s shows "deeper" text.
*   **Rich Card Loading**: Card skeleton morphs into drawn data (mid-draw visibility).
*   **Empty / Partial**: If rich-card fetch fails, card shows error + retry; non-failed message text remains visible. Empty/Day-1 activity feed shows anticipatory copy.
*   **Error (Message Send Fails)**: User bubble shows error icon + "not sent" text + tap menu for retry/delete.
*   **Error (Logging Fails)**: CIA message says it couldn't log, offers "retry" and "skip" chips.
*   **Offline**: Centered banner below top bar. Input bar disabled. Existing history cached.
*   **Pull-to-Load Fail**: Inline text "Could not load messages."
*   **Motivation Variants**: *Low* (shorter copy, fewer chips, simple data), *Medium* (default experience), *High* (data-heavy copy, advanced chips).

## 8. Interactions, Gestures, Motion
*   **Gestures**:
    *   *Tap*: Suggestion chip (send), Input field (focus), Send button (submit), Voice/Search icons, Rich inline cards (deep-link).
    *   *Tap (quick)*: Mic button -> in-chat voice mode.
    *   *Long-press (500ms+)*: Mic button -> full-screen voice modal. Message bubble -> copy text menu.
    *   *Swipe/Pull*: Pull down past first message -> load older history.
*   **Motion Choreography**:
    *   *Message Entrance*: Fade in + translateY(8→0), 280ms.
    *   *User Send*: Text slides from input to bubble, input clears.
    *   *Inline Viz Draw*: After bubble lands (120ms stagger), charts animate via progressive stroke draw or arc fill (520ms) rather than opacity fades.
    *   *Proactive Entry*: Slides up from bottom with bounce (520ms).
    *   *Chip Selection*: Fills orange, flies up to user bubble position.
    *   *Send/Mic Crossfade*: 160ms transition based on text presence.
    *   *Reduced Motion*: All proactive bounces and auto-scrolls disabled; charts render instantly at final state; thinking dots become static.

## 10. Cross-Domain Hooks (AI Insights & Correlations)
*   **Connection Spotted Variant**: The signature AI capability of this screen. Surfaces correlations between disparate life domains (e.g., "Sleep follows Fitness" or "Career follows Fitness").
*   **Inline Domain Tags**: CIA can contextually link life areas (e.g., "your [fitness] and [nutrition] goals are connected") using tag chips directly inside message text.
*   **Conversational Cross-Domain Logging**: Users can log data for any domain natively in chat (Fitness, Finance, Spirituality, Nutrition) without navigating to specific dashboards.
