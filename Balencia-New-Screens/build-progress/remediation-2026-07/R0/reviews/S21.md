## Dimension notes
1. Spec conformance — issue: `Toggle` (listed in spec Components) and every biometric/notification row implied by spec text (States → Default: "Face ID off"; Motion's toggle-thumb slide; a11y example `Toggle background sync`) are entirely absent from the build; screen has zero switches, only chevron-nav rows.
2. Canon fidelity — issue: CIA note italicizes a full sentence with plain Tailwind `italic` on the default font instead of the one-word `.text-emphasis` (Tiempos/Newsreader) treatment (§5 "one spotlight word max"). Otherwise SolidCard usage, radii/spacing, and glow discipline are clean.
3. Data honesty — issue: none of the CIA Preferences values (Coaching style, Formality, Check-in times) ship any of the three canon §7 honesty states, contradicting the spec's own worked "Data Honesty" examples for this exact screen.
4. Cross-cutting — issue: Privacy & data card uses the read-only `Provenance` component for Revoke/Delete instead of the purpose-built interactive `ConsentRail`, leaving those consent actions inert; `SafetyCard` ("Crisis resources") has no button/link/chevron anywhere, so the Emergency module has no actual reachable entry point.
5. Composition craft — minor issue: Account section opens with two adjacent identity rows where the spec's Final Composition shows one; the second row has no leading icon (inconsistent with siblings) and a stray `tabular-nums` class on non-numeric text.
6. Copy voice — ok apart from the italic-scope issue in #2 and known CIA casing (A24-008, see below); sentence case, no exclamations, second-person throughout.
