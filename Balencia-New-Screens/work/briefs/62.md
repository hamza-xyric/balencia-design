# Functional Content Brief: Quick Notes

## 1. Purpose (2 lines)
A capture-first, low-friction layer for rapidly recording raw health observations, mood shifts, and reactions before the thought disappears. Ingests and auto-tags notes to transform fleeting moments into actionable CIA coaching conversations and cross-domain insights.

## 2. Entry and Exit Paths
**Entries:**
*   **Bottom Sheet Overlay (Primary):** Global FAB long-press from any screen, edge swipe-up (bottom-right corner), or tab bar "+" overflow.
*   **Full-Screen Archive:** Pushed from Me Main `[17]` via quick link grid, or deep-linked from CIA Chat `[09]`.

**Exits:**
*   **Bottom Sheet:** Drag down, tap backdrop, or tap "done" to dismiss to underlying screen.
*   **Full-Screen:** Standard back navigation to Me Main `[17]`.
*   **Secondary Exits:** Tap "ask CIA" to route to CIA Chat `[09]` (tab switch with context). Expand to Journal `[37]` (stack push with text pre-populated).

## 3. Information Architecture
**Bottom Sheet (Top-to-Bottom):**
1.  **Drag Handle & Backdrop:** Z-40 overlay container.
2.  **Quick Add Bar:** Text input + circular send button.
3.  **Tag Filter Row:** Horizontal scroll of category chips.
4.  **Notes List:** Virtualized reverse-chronological feed of Note Cards.

**Full-Screen Archive (Top-to-Bottom):**
1.  **Screen Header:** Back navigation + title.
2.  **Search Bar:** Text input for full-text search.
3.  **Archive Activity:** Sparkline visualization + caption.
4.  **Tag Filter Row:** Horizontal scroll of category chips (expands to reveal tag share donut).
5.  **Notes List:** Grouped by Date Section Headers (Today, Yesterday, etc.) containing Note Cards.
6.  **Quick Add Bar (Pinned):** Text input + circular send button.

## 4. Features and Capabilities
*   **Rapid Text Capture:** Single/multi-line text input (max 3 lines) with auto-focus on entry.
*   **Send & Save:** Submit note via send button tap or keyboard "return".
*   **CIA Auto-Tagging:** Background AI process assigns 1-2 category tags on save.
*   **Manual Tagging:** Multi-select tag assignment via swipe gesture.
*   **Inline Edit Mode:** Long-press to edit existing note text.
*   **Tap-to-Expand:** Tap a note card to toggle between 3-line truncated preview and full text view.
*   **Swipe-to-Delete:** Swipe left to delete (includes 5-second undo window).
*   **Stateful Filtering:** Radio-select tag chips to filter the notes list.
*   **Full-Text Search:** Live debounced search through the note archive.
*   **Offline Capture:** Local saving with cloud-sync indicator upon reconnection.
*   **Data Export:** High-motivation users can export archive to CSV/text.
*   **CIA Note Injection:** CIA can proactively add notes on the user's behalf following a coaching chat.
*   **Ambient Visualization:** 7-week capture activity trend and tag-share distribution (archive mode only).

## 6. Data Fields and Metrics
*   **Note Text:** User input or CIA injected text. *Source: User / CIA Chat [09]*
*   **Tags:** Array of canonical IDs (`health`, `workout`, `nutrition`, `mood`, `idea`, `reminder`). *Source: CIA Auto-Tagging AI / User Manual Selection*
*   **Timestamp:** Note creation time. Displayed as relative (e.g., "2 min ago") or absolute ("May 19"). *Source: System `createdAt`*
*   **Offline Sync State:** Boolean indicating local-only data pending API sync. *Source: Local network state*
*   **Filter Counts:** Number of notes per tag. *Source: API `GET /api/quick-notes` metadata*
*   **Weekly Note Frequency:** Count of notes captured per week over trailing 7 weeks. *Source: Derived client-side from API archive payload*
*   **Highest Week Boolean:** Flag for latest week being highest capture rate. *Source: Derived from Weekly Note Frequency*
*   **Tag Share Percentage:** Distribution of notes across tag categories. *Source: Derived from API metadata*
*   **Word Count / Reference Count:** High-motivation metadata. *Source: API text analysis / CIA Chat logs*

## 7. Screen States
*   **Empty/Cold-start (Day 1):** Input auto-focused, tag row hidden, list shows notepad icon and welcoming copy. Sparkline omitted entirely.
*   **Active (Capture):** Text entered, send button transitions from disabled to active.
*   **Loading (Save):** Input clears, spinner appears on button, new card slides in, tags show shimmer.
*   **Loading (List):** Depth-preserving skeleton baseline for Sparkline.
*   **Empty (Filtered/Search):** Replaced by centered specific copy.
*   **Error (Save/Delete):** Red flash on UI element, preserves input, toast appears.
*   **Error (Fetch Sparkline):** Fails invisibly; falls back to plain text count.
*   **Offline:** Cloud icon appears on unsynced notes.
*   **Note Expanded:** Card grows to fit full text.
*   **Partial Sync:** Sparkline trailing week appears as dashed segment.
*   **Reduced Motion:** All slide/draw animations compress to instant static renders.

## 8. Interactions, Gestures, and Motion
*   **Entry/Exit Motion:** Bottom sheet slides up (y: screen height to 70%), expanding to 90% upon keyboard rise. Backdrop fades in.
*   **Tap:** Expand/collapse card, trigger send, toggle filters.
*   **Swipe Left:** Reveals red delete zone. Full swipe (>60%) deletes card and triggers undo toast.
*   **Swipe Right:** Reveals orange tag zone. Release opens tag selector dropdown (scaleY 0->1).
*   **Long-Press:** Enter inline edit mode (text becomes editable).
*   **Drag/Pull:** Drag down on handle to dismiss sheet. Pull down on list to refresh.
*   **Motion Choreography:** Capture success animates the card sliding in from top. Tag shimmers morph into chips. Sparkline draws left-to-right on scroll-into-view. Green milestone dot scales in after draw completes.

## 9. Free vs. Premium Gating
*   **Free Tier:** Basic text capture, manual tagging, offline mode, and standard list viewing.
*   **Premium Tier:** Access to "ask CIA" contextual chat routing, background CIA Auto-Tagging, proactive CIA pattern surfacing, and CIA note injection. *(Note: spec text contains a minor contradiction regarding whether basic capture is entirely free or if certain text limits apply; standard gating places capture limits behind free tier while keeping auto-tagging premium).*

## 10. Cross-Domain Hooks
*   **CIA Chat [09]:** "ask CIA" deep-links with context. CIA can ingest notes to find patterns (e.g., noticing repeated knee pain to suggest a chat).
*   **Journal [37]:** "Expand to journal entry" pre-populates long-form text.
*   **Shared Tag Architecture:** Tags map directly to cross-domain tags (Screen 37) and habit/domain tags (Screen 38).
*   **Cross-Referencing (High Motivation):** CIA actively links note data to other domains, explicitly showing users when a note was referenced in other CIA conversations.
