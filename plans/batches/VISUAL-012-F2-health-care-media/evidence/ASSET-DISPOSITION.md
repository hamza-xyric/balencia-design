# F2 asset disposition

No new raster generation is required. `_IMAGE-SLOTS.md` makes these slots non-blocking, and code-native treatment is safer and deterministic for the privacy/medical constraints.

| Slot | Accepted implementation disposition |
|---|---|
| `HIFI-70-01` | Code-native abstract equipment/movement-path instructional geometry; no person, logo, diagnosis, or form-certification claim. Marker: `HIFI-70-01-code-native-instructional`. |
| `HIFI-86-01` | Code-native garment/fabric silhouette pair, shown only when source/render state supports it; no identifiable person. Marker: `HIFI-86-01-code-native-no-identifiable-person`. |
| `HIFI-87-01` | Code-native garment/swatch thumbnails with row-level source, retention, and render truth; no human form. Marker: `HIFI-87-01-code-native-no-identifiable-person`. |
| `HIFI-88-01` | Code-native abstract focus/20-20-20 exercise visual with explicit non-diagnostic accessible name. Marker: `HIFI-88-01-code-native-non-diagnostic`. |

All other F2 screens have no required image slot. Official logo policy is unaffected; no logo is generated or approximated.
