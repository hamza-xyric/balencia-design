# Functional Content Brief: Edit Profile

## 1. Purpose
Enables users to view and update their personal identity data (name, avatar, DOB, demographics, contact info). It acts as a focused, utility-driven form for making deltas to core account information and managing account deletion.

## 2. Entry and Exit Paths
*   **Entry:** Pushed from the "Me Main" screen via tapping the avatar or profile section.
*   **Primary Exit:** Returns to "Me Main" via back chevron, edge-swipe, or successful save.
*   **Secondary Exit:** System root reset to the Sign In screen (following successful account deletion).
*   **System Exits:** Presents native image picker and date picker modals.

## 3. Information Architecture
**Layout:** Vertical ScrollView. Tab bar is hidden to maximize form utility space. 
**Hierarchy (Top-to-Bottom):**
1.  **Navigation Header:** Back chevron + "Edit profile" title.
2.  **Avatar Section:** Identity anchor. Circular avatar, camera overlay, "change photo" link.
3.  **Profile Completeness Module:** "PROFILE" eyebrow, numerical count, progress bar, contextual caption.
4.  **Identity Fields Group:** First Name, Last Name.
5.  **Contact Fields Group:** Email (Read-Only), Phone Number (+ country code).
6.  **Demographics Group:** Date of Birth, Gender, Timezone.
7.  **Primary Action:** "Save changes" button (Disabled until form is dirty).
8.  **Destructive Action:** "Delete account" link (separated by generous whitespace).

## 4. Features and Capabilities
*   **Profile Editing:** Input/modify first name, last name, DOB, gender, phone number, and timezone.
*   **Avatar Management:** Upload a new photo via camera or library, crop to 1:1 aspect ratio, or remove existing photo.
*   **Dirty Tracking:** Form snapshot taken on mount. Save button remains disabled until a delta is detected.
*   **Read-Only Email:** Display email for context with long-press to copy.
*   **Auto-Detection:** Timezone auto-populates from device settings (manual override available).
*   **Profile Completeness Tracking:** Client-side calculation of filled vs. total fields to encourage profile completion (non-shaming).
*   **Account Deletion:** Explicit typed confirmation ("DELETE") to trigger irreversible account and data wipe.
*   **Offline Editing:** Form allows editing while offline; changes sync later.

## 6. Data Fields and Metrics
| Field / Metric | Source | Notes |
| :--- | :--- | :--- |
| **Avatar** | `POST /api/upload/avatar` | Local camera/library. |
| **First Name** | `PATCH /api/auth/profile` | 2-50 char limit. |
| **Last Name** | `PATCH /api/auth/profile` | 2-50 char limit. |
| **Email** | `GET /api/auth/me` | Read-only. Displayed for context. |
| **Date of Birth** | `PATCH /api/auth/profile` | Must calculate to age 18+. |
| **Gender** | `PATCH /api/auth/profile` | Options: Male, Female, Non-binary, Prefer not to say. |
| **Phone Number** | `PATCH /api/auth/profile` | Validated against E.164 format. |
| **Timezone** | Device OS / `PATCH /api/auth/profile` | Auto-detected if null; IANA timezone format. |
| **Profile Completeness** | Client-derived | Derived from count of non-empty profile slots divided by total slots. |

## 7. Screen States
*   **Cold-Start (Day 1):** Pre-filled from sign-up; completeness bar shows true partial value; Save CTA disabled.
*   **Loading:** Skeleton placeholders in fields; completeness bar shows ghost track only.
*   **Partial/Dirty:** Edited fields show focus borders; Save CTA transitions to active.
*   **Complete:** Profile 100% filled; completeness bar reaches arrival state.
*   **Error (Validation):** Red borders on offending fields, inline error text below.
*   **Error (Network/Load):** Completeness bar hidden; inline error toasts/banners.
*   **Success:** Green glow flash on Save CTA; automatic stack pop.
*   **Offline:** Fields editable, Save CTA disabled, offline banner displayed.
*   **Camera/Library Permission Denied:** Action sheet options greyed out with settings prompt.

## 8. Interactions and Gestures
*   **Scroll:** Vertical pan to navigate form.
*   **Tap:** Focus inputs, open bottom sheets, trigger CTAs.
*   **Edge Swipe (Right):** Stack pop back to Me Main.
*   **Long-press:** Copy email to clipboard (read-only email field).
*   **Keyboard Cycling:** "Next" button shifts focus sequentially through text/number inputs.
*   **Motion Intent (Entrance):** Avatar fades in -> Completeness bar draws horizontally -> Form fields stagger fade-up -> Save CTA fades in. 
*   **Motion Intent (Success):** Button success glow flash -> pause -> horizontal slide-out stack pop.
*   **Motion Intent (Reduced Motion):** All elements render instantly at final state; bar draws instantly to final width.

## 9. Free vs. Premium Gating
*   **Gating Status:** **None.** Explicitly documented as a core account feature available to all tiers. Profile management is never gated.

## 10. Cross-Domain Hooks
*   **CIA (Coach Persona) Data Integration:** Profile fields (especially name, DOB, timezone) serve as foundational identity and scheduling hooks for the broader CIA memory, goals, and progress ecosystems across the app. Account deletion explicitly wipes the "CIA memory."
*   **System Settings Handoff:** Deep links provided to native OS settings for camera/library permission remediation.
