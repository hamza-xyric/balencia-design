# Functional Content Brief: Initial Plan Summary

## 1. Purpose
To present the user’s AI-generated, cross-domain life plan for the first time, transforming conversational inputs into a structured, actionable, and gamified roadmap. It serves as the emotional "reveal" moment to motivate the user to accept their plan and enter the main app.

## 2. Entry and Exit Paths
*   **Entry Paths:** 
    *   Standard user: Crossfade transition from the CIA Onboarding Conversation (Screen 07).
    *   Edge case: Direct route if user skips conversation (generates a starter plan).
*   **Exit Paths:**
    *   Primary Exit: Tap "start your journey" CTA → triggers a root reset (onboarding stack destroyed, main tab navigator loads). Lands on Home Screen (Screen 12) in the Today tab.
    *   Secondary Exit: Tap "customize" or individual edit icons → enters inline editing mode (stays on screen).

## 3. Complete Information Architecture
**Scroll behavior:** Vertical ScrollView (content exceeds viewport). No global tab bar visible.

**Top-to-Bottom Module Stack:**
1.  **Status Bar Zone:** Transparent overlay.
2.  **CIA Header:** CIA Avatar (small), main heading, and coaching note preamble.
3.  **Starting Profile Radar (Hero):** Top focal point. A radar chart showing the user's starting baseline across chosen domains, anchored by the central "Life Power" score. Optional dashed CIA projection vector toward a target.
4.  **RPG Status Band:** A horizontal progress bar displaying the starting Level and XP. Includes a sub-caption framing the start of the journey.
5.  **Starting Domain StatBars:** A compact, legible companion list beneath the radar showing precise baseline values for each chosen domain.
6.  **Goal Plan Cards (Vertical Stack):** One card per established goal. Contains:
    *   Domain Tag Chip(s) & Goal Name.
    *   Edit affordance (pencil icon).
    *   Expandable Action List (checkboxes).
    *   Milestone Timeline (horizontal path with nodes).
    *   Cross-Domain Connection link (if applicable).
7.  **CTA Area:** Primary action button ("start your journey") with secondary text link ("customize") beneath.

## 4. Features and Capabilities
*   **AI Plan Generation:** Translates conversational onboarding into a multi-tiered plan (Goals → Actions → Milestones).
*   **Starting Profile Visualization:** Renders a baseline life-profile across 3–5 chosen domains. Un-assessed domains render as ghosted axes rather than zero values.
*   **RPG Initialization:** Establishes the user's starting gamification state (Level 1, 0 XP).
*   **Inline Goal Customization:** Users can tap a pencil icon on individual goals to edit text fields or change the domain tag via a dropdown.
*   **Action Expansion:** Users can tap to expand truncated action lists within a goal card.
*   **Preview Interactions:** Action checkboxes can be toggled as a non-persisting "preview" of the app's functionality before the plan is officially accepted.
*   **Cross-Domain Tooltips:** Tapping a connection link surfaces an explanation of how goals support each other.
*   **Milestone Tracking Setup:** Visualizes the upcoming steps for each goal as a timeline path.

## 6. Data Fields and Metrics
*   **Plan Summary Count:** `[N] life areas` (Source: CIA onboarding conversation).
*   **Life Power Score:** Starting baseline metric (Source: RPG engine / Onboarding calculation).
*   **RPG Level:** Static `1` (Source: App state).
*   **RPG XP:** Static `0` (Source: App state).
*   **Domain Baselines:** Numeric values per domain (e.g., Fitness: 18) (Source: Onboarding self-assessment/CIA derivation).
*   **Goal Name:** e.g., "Run a half marathon" (Source: CIA generated from user input).
*   **Action Items:** e.g., "Run 3x/week" (Source: CIA decomposed from goal).
*   **Milestones:** e.g., "5K base" (Source: CIA decomposed from goal).
*   **Cross-Domain Mappings:** e.g., "connects to nutrition" (Source: CIA cross-domain logic).

## 7. Screen States
*   **Cold-start / Day-1 (Default):** RPG bar at honest 0, all radar axes mapped to baselines (or ghosted if no-data), all timeline nodes in "upcoming" state with the first node pulsing as "next".
*   **Empty / No-Goals (Edge Case):** User skipped onboarding. Renders 1-2 CIA starter goals. Radar shows minimal axes. Non-shaming microcopy used.
*   **Loading:** Skeletons with radial shimmer morph into drawn data. Radar spokes and timeline paths are visible prior to data fill.
*   **Error (Fetch Failed):** Plan data hidden. CIA error message and "retry" link displayed. Color/icons used for errors, never alone.
*   **Offline:** Cached plan renders. Offline banner displayed. CTA remains active but queues locally.
*   **Success (Transition):** CTA glow flashes green, screen crossfades to Home Screen [12].
*   **Variants:** High/Medium/Low motivation (impacts the number of visible actions and milestone complexity). Default is Medium.

## 8. Interactions, Gestures, and Motion Intents
*   **Tap ("start your journey" CTA):** Triggers root reset and main app transition.
*   **Tap ("customize" link):** Toggles inline edit mode across all goal cards. Changes link text to "done editing".
*   **Tap (Edit icon):** Opens inline edit for a specific goal card. Icon morphs to a checkmark.
*   **Tap (Cross-domain link):** Opens a tooltip detailing the CIA connection logic.
*   **Tap (Action Checkbox):** Preview interaction. Shows a brief check animation that reverts (does not persist).
*   **Tap ("and [N] more"):** Expands hidden actions with a height growth animation.
*   **Scroll:** Standard vertical scroll to reveal additional goal cards.
*   **Motion Intent (Draw-First Choreography):** Upon screen entry, the Constellation Radar hero draws itself first, followed by the count-up of the Life Power score. Next, the RPG MomentumBar's "ready" shimmer travels across the empty track. Goal cards fade-up staggered as they enter the viewport. 
*   **Motion Intent (Continuous):** The CTA maintains a subtle idle pulse. The first milestone node on each goal card maintains a looping "you are here" pulse.

## 9. Free vs. Premium Gating
*   *None explicitly defined on this screen.* All elements (CIA plan generation, radar visualization, milestones) are presented to the user during the standard onboarding flow without referencing premium paywalls. 

## 10. Cross-Domain Hooks (Correlations, AI Insights, Links)
*   **Cross-Domain Connections:** Each goal card features a text link highlighting how completing this goal supports another life domain (e.g., a fitness goal "connects to" nutrition). 
*   **CIA Projected Momentum:** An optional, brand-sanctioned dashed visual vector on the radar chart pointing toward a 90-day target ring, representing the CIA's AI forecast for the user's life profile.
*   **Knowledge Graph Deep-Linking:** While kept textual on this screen to maintain a calm UI, cross-domain links conceptually tie into the broader Life Knowledge Graph (Screen 72) for later exploration.
