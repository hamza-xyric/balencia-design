# 2. Purpose
A comprehensive, at-a-glance view of the user's financial health (income, expenses, budgets, savings) that integrates cross-pillar life-system intelligence. It connects spending patterns with other life domains (like stress), making this a holistic life-system dashboard rather than a standalone finance tracker.

# 3. Entry & Exit
- **Entry Paths:** 
  - Explore Section (Stack push)
  - CIA Deep-Link (Stack push from chat tab)
- **Exit Paths:**
  - Transaction / Budget Detail (Stack push via row tap)
  - CIA Tab (Tab switch via coaching note tap)
  - Goal Detail (Stack push via savings goal tap)
  - RPG Character Screen (Stack push via domain level badge tap)
  - Modals (Receipt scanner / Add Transaction via FAB)

# 4. Layout anatomy
The screen uses a vertical `ScrollView` (~2.5 viewport heights) over a warm dark base.

1. **TopBar:** Transparent header with back chevron, "Finance" title, and domain level badge (Lv.8).
2. **CIA Coaching Note:** Quiet preamble card containing a cross-domain insight.
3. **Spend by Category (Hero):** Interactive donut chart visualizing part-of-whole spend composition.
4. **Monthly Overview Strip:** Three side-by-side `KPIRow` mini-stats (Income, Spent, Saved) with net summary footer.
5. **Budget Categories Card:** `SolidCard` list of 3-4 budgets with capped `ProgressBar` tracks.
6. **Recent Transactions List:** `SolidCard` list of 3-5 transactions supporting swipe-to-delete.
7. **Savings Goals Card:** `SolidCard` with flat savings progress and optional sparkline.
8. **Spending Trend Chart:** `TrendChart` showing living spend line and dashed CIA projection.
9. **Floating Action Button (FAB):** Overlaid `FABQuickLog` element for manual adds/scanning.

# 9. All states
- **Default:** Full data rendered over warm dark atmosphere with breathing CIA glow.
- **Skeleton:** Shimmer blocks (`--surface-3` base, 1.2s sweep). Donut renders as a ghost ring. Trend chart skeleton is an axis with a single ghost line.
- **Empty / Partial:** First-use state. KPIs read `$0` with `—` delta. Ghosted donut outline with "Log spending..." prompt. No trends drawn. Suggestion chips for budget creation are active.
- **Error:** Specific section failures independent of others (e.g., "Couldn't load budgets"). Red error tints are replaced with warning glyphs and muted text.
- **Success:** Budget saved or transaction added via FAB. Triggers a quiet `+40 XP · Finance` toast and a brief sweep of the donut arc.
- **Disabled:** Swipe-to-delete disabled if offline; rows drop to 50% opacity with "pending" label.

# 10. Motion & interaction
- **Physical easing:** Charts draw, donut arcs sweep largest-to-smallest, and budget bars rise from 0 using spring physics (`spring(stiffness: 300, damping: 30)`). Never linear fades.
- **Feedback (150-250ms):** Tapping a row scales to .98 and brightens the inner glow. FAB tap scales to .95.
- **Glow behavior:** The `CIAInsightCard` purple glow breathes (4s ease). The `DonutChart` orange glow brightens strictly when a slice is touched to cross-highlight the corresponding budget bar.
- **Haptics:** Light impact on donut slice tap. Medium impact on FAB expand. Success haptic on transaction log.
- **Gestures:** 
  - Swipe-left on transaction row reveals delete. 
  - Touch-and-hold on Trend Chart triggers a scrubbing crosshair tooltip.
  - Pull-to-refresh forces reload with "CIA is reading your month..." loading copy.
- **Reduced-motion path:** All charts instantly render at final state. Breathing glows freeze. Continuous strokes are replaced by simple opacity reveals.

# 11. Motivation-tier adaptation
- **Low density:** Simplified 2-card KPI strip (Income, Spent). Top 2 budgets only. Savings and Trend Chart sections collapsed into a single quiet line. Gentler CIA tone: "Let's set up your *finances*."
- **Medium density (Default):** 3 KPIs (Income, Spent, Saved). 3-4 active budgets. 3-5 recent transactions. Single savings goal with sparkline.
- **High density:** Expanded KPIs (adds daily average/projected). Full inline budget list. Dual-chart overlays. Deep cross-domain spending breakdown revealed inside the `CIAInsightCard`. 

# 12. Accessibility
- **AA+ contrast:** Text uses paper-100 (#FEFAF3) on `--surface-2` (#211008) for a 16.8:1 ratio. Low-confidence data at 64% opacity maintains strict 4.8:1 contrast.
- **44px targets:** KPI tiles, transaction rows, and budget rows exceed the 44px min height. 
- **Screen-reader labels:** The donut chart groups into a single `accessibilityElement` reading: "Spend by category. Two thousand, one hundred and fifty dollars total. Top category: Dining." Glyph-only FAB and TopBar icons have explicit `accessibilityLabel`s (e.g., "Add transaction").
