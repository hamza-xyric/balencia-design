# FUNCTIONAL CONTENT BRIEF: OTP Verification

## 1. Purpose
Completes the user registration process by collecting a 4-digit OTP code sent to the user's email. Verifies the code to create the account and advance to the consent screen, ensuring a quick, frictionless authentication experience.

## 2. Entry and Exit Paths
*   **Entry Path (Arrives from):** Welcome / Sign Up screen [03] via stack push (triggered after the user submits the sign-up form).
*   **Primary Exit Path:** Consent screen [03c] via stack push (triggered upon successful OTP verification and account creation).
*   **Secondary Exit Path:** Welcome / Sign Up screen [03] via stack pop (triggered by tapping the back button to correct an entered email).
*   **Overall Registration Flow:** Sign Up [03] → OTP Verification [03b] → Consent [03c] → CIA Onboarding [07].

## 3. Complete Information Architecture
**Scroll Behavior:** None (fixed screen; content fits on all device sizes, including small screens, without scrolling).
**Tab Bar:** Hidden (pre-auth flow).

**Top-to-Bottom Component Stack:**
1.  **Status Bar Zone:** System status bar.
2.  **Back Button Row:** Navigation control to return to the previous screen.
3.  **Logo Area:** Brand anchor (symbol only, centered).
4.  **Heading:** States the screen's core intent.
5.  **Subtitle:** Contextual text displaying the masked email address where the code was sent.
6.  **OTP Input Group:** The primary task area consisting of 4 individual square input boxes.
7.  **Resend Code Module:** Comprised of the Resend Code Link and a continuous, depleting progress bar (MomentumBar) that visualizes the resend countdown.
8.  **Primary CTA (Verify):** The main submission button.
9.  **Lower Spacer:** Flexible empty space to push content upwards.
10. **Home Indicator Zone:** System home indicator.

## 4. Features and Capabilities
*   **4-Digit OTP Entry:** Collects a 4-digit numeric code via 4 dedicated input boxes.
*   **Masked Email Display:** Shows a partially masked version of the user's email (e.g., "j***@email.com") to confirm the destination without compromising full privacy.
*   **Auto-Focus & Keyboard Handling:** Automatically focuses the first input box and raises the numeric-only keyboard on screen mount.
*   **Auto-Advance Input:** Automatically advances focus to the next input box when a digit is typed.
*   **Backspace Navigation:** Clears the current digit; if the current box is empty, moves focus to the previous box and clears it.
*   **Clipboard Paste Support:** Auto-populates all 4 input boxes simultaneously if a valid 4-digit string is pasted into any box.
*   **Completion Gating:** The Primary CTA ("verify.") remains disabled until exactly 4 digits are entered.
*   **Resend Cooldown Mechanism:** Enforces a 60-second cooldown timer on the Resend link to prevent abuse. Visualized by both text and a depleting progress bar.
*   **Rate Limiting:** Disables all interactive elements for 5 minutes if too many invalid attempts are made.
*   **Offline Tolerance:** Allows digit entry while offline, displaying a cached banner to inform the user.

## 6. Data Fields and Metrics
| Field / Metric | Data Source | Description |
| :--- | :--- | :--- |
| **Masked Email** | User Input (passed from Sign Up [03]) | Passed dynamically from the previous screen; masked locally to show only the first letter and domain. |
| **OTP Digits (1-4)** | User Input (numeric pad) / Clipboard | Locally captured user keystrokes. Sent to server upon submission. |
| **Resend Cooldown Timer** | Local System Clock | 60-second countdown initiating on screen mount or after a resend request. |
| **Rate Limit Cooldown Timer** | Server Response (API) | 5-minute (300 seconds) countdown initiated by the backend rate-limiting response. |

## 7. Screen States
*   **Cold-start / Day-1 (Default):** First box auto-focused with numeric keyboard raised; all boxes empty; Resend countdown active; CTA disabled.
*   **Partial Entry:** Digits visible in boxes; CTA remains disabled until 4 digits are present.
*   **Loading (Verify API Pending):** CTA shows inline spinner; text changes to "Verifying..."; input boxes remain interactive.
*   **Resend Loading:** Resend text replaces with a small inline spinner.
*   **Resend Success:** Resend text changes to "Code sent"; cooldown progress bar fills green; reverts to countdown after 3 seconds.
*   **Success (OTP Verified):** Green glow radiates outward from the CTA button for 600ms, followed immediately by navigation to the next screen.
*   **Error (Invalid Code):** 2pt red borders applied to all 4 boxes; boxes shake horizontally (3 oscillations); error text appears below; boxes clear and focus returns to box 1.
*   **Error (Expired Code):** 2pt red borders applied to all 4 boxes (NO shake); error text appears; Resend cooldown is bypassed and visually completes; link turns orange immediately; boxes clear.
*   **Error (Too Many Attempts):** Top-of-screen toast appears; all interactive elements (CTA, OTP boxes, Resend link) set to 0.4 opacity and non-interactive; toast displays a live countdown.
*   **Error (Network Failure):** Top-of-screen toast appears; CTA reverts to default; entered digits are preserved (not cleared).
*   **Offline:** Interactive elements remain active; informational banner appears.

## 8. Interactions, Gestures, and Motion Intents
*   **Tap (Back Button):** Stack pop to Sign Up [03].
*   **Swipe Right (Screen Edge):** iOS back gesture to stack pop.
*   **Tap (Outside OTP Boxes):** Dismisses the numeric keyboard.
*   **Tap (Specific OTP Box):** Moves focus to that specific box.
*   **Type (Numeric Pad):** Fills focused box, auto-advances.
*   **Paste:** Auto-fills all 4 boxes.
*   **Motion Intent - Arrival:** On screen mount, all content elements stagger fade-in and slide up (translateY 12pt to 0).
*   **Motion Intent - Digit Entry:** Digits scale up from 0.5 to 1.0 (never fading).
*   **Motion Intent - Focus:** Border transitions from thin to thick accent color. (Pulse animation, no shake on standard focus).
*   **Motion Intent - Error:** Horizontal oscillation (shake) reserved specifically for invalid attempts. Calm transition to red borders for system errors (expired).
*   **Motion Intent - Success:** Outward radiation glow.
*   *Accessibility Note:* All motion obeys `prefers-reduced-motion` (instant transitions, no shakes, no glows).
