### 2. Purpose
To answer the pre-signup hesitation "what would this app actually look like for me?" by letting hesitant users experience a fully populated, *illustrative* app environment with zero friction (just a name and 1-3 interests). It visually proves the app's whole-life philosophy via the preview setup, creating a direct bridge to signup.

### 3. Entry & exit
- **Entry Points:** Stack push from Welcome/Sign Up [03] via the "Try without an account" route.
- **Primary Exit:** Converts to registered user by pushing to Welcome/Sign Up [03] via the persistent "sign up" banner or session-end overlay (carrying the user's entered name).
- **Secondary Exit:** Exits to Sign In [04] via stack push using the "sign in" link.
- **System Exit:** Standard iOS edge swipe or back button to return to [03].

### 8. Data & honesty states
*Correction applied:* Per Honesty Invariant (Canon §7), an illustrative radar chart cannot pose as real user data. It must be explicitly labeled or treated as an honest-null/preview state. We classify this as an illustrative preview.

- **State 1: Illustrative Preview (This Screen)**
  - **Metric:** 0-3 Domain Nodes activated. 
  - **Provenance Chip Text:** `demo · illustrative` (forced onto the chart).
  - **Honest-Null Copy:** "(0 selected)"
- **State 2: Low-confidence (N/A for this screen)**
  - Not applicable. We do not estimate or project data for an unnamed user.
- **State 3: Honest-Null (Pre-selection)**
  - **Metric:** Radar is blank. 
  - **Designed Empty Copy:** "pick a few areas to see your map"

### 9. All states
- **Default (Cold-start):** Empty name field. All 9 domain chips unselected. Radar shows 0 nodes. "explore" CTA is at 40% opacity and non-interactive.
- **Validation / Disabled:** CTA remains disabled until name contains ≥1 character AND ≥1 domain chip is selected. 
- **Error (Validation):** Tapping a 4th chip triggers a brief 150ms shake animation and the toast: "Pick up to 3 areas".
- **Loading:** CTA text swaps to a spinner. Text reads "Loading…".
- **Error (Network/Init Failure):** CTA reverts to default. Toast appears: "Couldn't start your preview. Your internet might be busy — pull to refresh or try again in a moment."
- **Success / Demo Transition:** Entry form crossfades out (opacity 1→0) while standard app UI (Today tab) crossfades in.

### 10. Motion & interaction
- **Entry Form Mount:** Staggered fade-in (opacity 0→1 + translateY 12→0) sequenced back button → logo → heading → text → input → chips → CTA → link. 200ms intervals.
- **Chip Selection/Deselection:** Tap triggers physical scale oscillation (1→1.05→1 select, 1→0.95→1 deselect) using spring easing, and background/border crossfade to domain color tint.
- **Radar Reaction:** Stars draw in via continuous-stroke SVG path animation (500ms ease-out).
- **Glow behavior:** `--glow-cia` on the radar breathes (opacity 50% ↔ 70%, 4s ease-in-out infinite). 
- **Haptics:** Light selection haptic on chip tap. Medium success haptic on CTA press.
- **Reduced-motion path:** All translateY and scale oscillations fallback to instant opacity crossfades. SVG drawing becomes an instant opacity reveal.

### 11. Motivation-tier adaptation
*Note: As this is an Auth/Onboarding screen, density tiers do not dynamically change the UI based on motivation. Instead, they dictate the initial seed density of the next screen.*
- **Low Density:** Generates 1 active goal and a 3-day streak in the Demo Browsing phase.
- **Medium Density:** Generates 3 active goals (cross-domain) and a 12-day streak. (Default).
- **High Density:** Generates 5 active goals, a 30-day streak, and pre-populates the CIA chat with 3 inline artifact cards.

### 12. Accessibility
- **AA+ Contrast:** "explore" button text (paper-50 `#FDFDFB` on Burnt Orange `#FF5E00` = 5.2:1). Ghost links meet 4.5:1 on `--surface-1`.
- **Touch Targets (Correction applied):** The brief specifies 36pt chips. iOS HIG requires 44px. We are wrapping the 36px visual chip in a 44px invisible touch target container (`BtnGhost` padding mechanics) to solve the Medium accessibility finding without visually bloating the 3x3 grid.
- **Screen-reader labels:** 
  - Name input: "Text field, your name."
  - Radar chart: "Illustrative preview of life areas."
  - Disabled Explore button: "Explore. Requires a name and at least 1 area selected." (via `aria-label`).
