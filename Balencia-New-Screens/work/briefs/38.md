# FUNCTIONAL CONTENT BRIEF: Habits Screen

## 1. Purpose
The daily habit dashboard answering: "what do I need to do today and how consistent have I been?" It acts as a satisfying, non-shaming checklist that feeds directly into the app's RPG system (earning XP and driving leaderboard rank).

## 2. Entry and Exit Paths
*   **Entry Paths:**
    *   Explore screen grid card (Stack push).
    *   CIA deep-link (Actionable suggestion to start a morning routine).
    *   Home Screen action cards.
*   **Exit Paths:**
    *   Back button (Stack pop to Explore).
    *   CIA Chat (Tab switch via CIA suggestion tap).
    *   Add/Edit Habit (Modal).
    *   Habit Analytics (Stack push via Week/Month view dives).

## 3. Complete Information Architecture (Top-to-Bottom)
1.  **Screen Header:** Title ("Habits") and Back navigation.
2.  **Completion Rate Bar (Hero Focal):** Daily completion text, percentage, and continuous progress bar.
3.  **Segmented Control:** View toggle for Today / Week / Month.
4.  **Habit Checklist (Variable height):** Grouped by time of day (Morning, Afternoon, Evening). Contains interactive habit rows.
5.  **Weekly Trend Sparkline:** *(High-motivation tier only)* Ambient trend line above the heatmap.
6.  **Calendar Heatmap Card:** 4-week consistency grid.
7.  **XP Summary Card:** RPG feedback and encouragement.
8.  **Floating Action Button (FAB):** Persistent "add habit" action.
9.  **Tab Bar:** Global navigation.

## 4. Features and Capabilities
*   **Daily Checklist:** Toggle habit completion (earns XP instantly).
*   **Time-of-Day Grouping:** Habits automatically grouped into Morning, Afternoon, Evening.
*   **Data Visualization:** 
    *   Continuous daily MomentumBar (0-100%).
    *   7-day daily completion BarChart (Week view).
    *   28-day consistency Calendar Heatmap (Today/Month view).
    *   Per-row 7-day micro-heatmaps trailing each habit.
    *   7-point weekly trend Sparkline.
*   **Habit Management:** 
    *   Add habit via modal (define name, domain, time of day, frequency).
    *   Long-press to reorder (edit mode).
    *   Swipe-left to reveal edit/delete quick actions.
*   **Pull-to-Refresh:** Force reload habit data and completion stats.
*   **CIA Starter Suggestions:** Option to auto-populate 3-5 starter habits based on user goals.
*   **Offline Queuing:** Checklists can be ticked offline; actions queue and sync when reconnected.
*   **Motivation Adaptation:** System adapts UI and habit visibility based on the user's tracked motivation level.

## 5. UI Copy Worth Keeping
*   **Headers:** "Habits", "MORNING", "AFTERNOON", "EVENING"
*   **Interactions:** "add habit", "save", "cancel"
*   **Progress/Feedback:** "5 of 8 today", "62%", "+10 XP", "+75 XP earned today"
*   **Non-Shaming Nudges (Gentler-Streak Framework):**
    *   "all done. solid day" (Full completion)
    *   "0 of 8 — pick one to start" (Zero completion)
    *   "your streak paused — pick it back up today" (Broken streak)
    *   "your consistency story starts today" (Heatmap Day 1)
    *   "just pick one. that's enough." (Low motivation nudge)
*   **Errors/States:** "couldn't load habits — pull to refresh", "you're offline — showing your last sync", "habit started Wednesday — building from here" (Sparse week view).

## 6. Data Fields and Metrics
*   **Daily Completion Count & Rate (e.g., 5 of 8, 62%):** *Source: Calculated from today's checked habits API.*
*   **Streak Count (e.g., 🔥 21 days):** *Source: User's habits API.*
*   **Daily/Weekly/Monthly Consistency Heatmaps (5-step intensity):** *Source: Daily completion rate aggregated over 28 days API.*
*   **Weekly Trend (7-point data):** *Source: Last 7 days' completion rate API.*
*   **XP Earned Today (e.g., +75 XP):** *Source: Calculated from today's checked habits in the RPG system.*
*   **Domain Tag (e.g., [wellbeing], [finance]):** *Source: User's assigned habit metadata.*

## 7. Screen States
*   **Loading:** Depth-preserving skeletons that morph into drawn data. Copy: "CIA is reading your habits — one moment."
*   **Cold-Start (Day 1):** Ghosted empty progress bar ("0 of 0 today"). CIA suggestion card appears ("based on your goals — want to start with a few habits?").
*   **All-Done (Zero State):** MomentumBar arrives at 100% green. "all done. solid day." 
*   **Error (Network/Load):** "could not load habits" + retry link. Cached data shown if available. Toggle failure results in a bounce-back animation and toast: "could not save — try again".
*   **Offline:** Cached data displays with offline banner. Queued completions show a small pending clock icon.
*   **Sparse Data:** Pre-habit days explicitly ghosted/dashed to differentiate from true zero-completion days.
*   **Motivation Tiers (Variants):**
    *   *Low:* Low-priority habits auto-hidden (showing 2-3 max). Amplified XP visuals.
    *   *Medium:* Standard experience. All habits visible.
    *   *High:* Exact day counts shown on streaks. Additional analytics (Sparkline, domain breakdowns) unhide.

## 8. Interactions, Gestures, and Motion
*   **Gestures:** 
    *   Tap checkbox (toggle habit).
    *   Tap segmented control (switch views).
    *   Tap heatmap cell/bar chart day (reveal specific tooltip).
    *   Long-press row (enter drag-to-reorder mode).
    *   Swipe-left (reveal edit/delete buttons).
    *   Pull down (pull-to-refresh).
*   **Motion/Choreography:**
    *   Draw-first hierarchy: MomentumBar animates first -> Sections fade-up -> Sparkline draws left-to-right -> Heatmap cells stagger -> XP counts up.
    *   Checkbox check: Checkmark stroke draws in, row text mutes to 50%, "+10 XP" floats up and fades.
    *   Non-shaming design: No aggressive red flashing or loss-aversion triggers. A broken streak never turns red.

## 9. Free vs. Premium Gating
*   *Explicit screen-level gating is not detailed in the source spec.*
*   *Implicit:* Access to social/leaderboard competitions and accountability features (unlocked via Plus) are fed by this screen's RPG/XP outputs, but standard habit tracking functionality operates without explicit mention of a premium paywall on this specific screen.

## 10. Cross-Domain Hooks
*   **RPG & Leaderboards:** Habit completion is a primary driver of the user's leaderboard rank, directly minting XP into the broader RPG system.
*   **CIA AI Integration:** CIA actively monitors behavior patterns to suggest starter habits, adapt the list over time, and provide high/low motivation nudges.
*   **Cross-Life Area Tagging:** Habits are intrinsically linked to broader domains via mandatory tags (Productivity, Wellbeing, Faith, Nutrition, Finance, etc.), feeding into overall life-balance dashboards.

---
### ⚠️ Source Contradictions Flagged
1.  **Week View Implementation:** The legacy spec claims the "Week" segment shows "7-day completion bars." However, the visual audit explicitly flags that the Week segment is currently a **no-op that wrongfully re-renders the Today checklist**. The functional requirement is to build the promised 7-day BarChart.
2.  **Streak UI Representation:** The base spec calls for "flame + text only" streaks. The Design Elevation pass directly contradicts this, mandating an additive **micro 7-cell CalendarHeatmap strip** trailing each row to provide instant per-row instruments. The Elevation pass supersedes the base spec.
3.  **Cold-Start Paradox:** The spec notes a "0 of 0 today" state for new users, but immediately contradicts this by stating "this shouldn't happen if CIA suggests starters." The functional reality relies on the CIA intervention to prevent true zero-states.
