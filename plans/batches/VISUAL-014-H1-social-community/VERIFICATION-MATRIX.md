# H1 verification matrix

- Tie-breaker: live code/contracts, active H1 specs, current canon/social/RPG terminology; archived audit is evidence only.
- Product gates: exact ten-screen ownership, 390×844 containment, 44px controls, 16px fields, 125% text, reduced motion, semantic/focus/dialog state, honest local-only capabilities, privacy/moderation/safety truth, deterministic distinct state proofs.
- Integrity gates: H1 product/API/verifier fingerprints stable start/end; accepted-through-G1 90-file sentinel union stable; empty isolated storage/cookies; zero console/page/capability/external-request events.
- Repository gates: `npm run check`, root validator `104/104`, accepted sentinels, root and read-only submodule `git diff --check`.
- Manual lenses: CLEAR; design/source; accessibility/privacy/moderation trust; Sol native-pixel inspection.
- Acceptance: three fresh independent reviews at C0/H0/M0; durable DVF-21 closeout only afterward.
- Stop: source conflict, unsafe or coercive social flow, unsupported real capability, accepted-byte drift, nondeterministic repeated proof, or two equivalent failures.
