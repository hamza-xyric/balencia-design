## Contracts (implement exactly)

**Storage** (`session.ts`), SecureStore key unchanged `balencia.mobile.session.v1`:
```ts
export type StoredSession = {
  accessToken: string;
  refreshToken: string;              // REQUIRED now
  accessTokenExpiresAt: number;      // epoch ms — computed at store time: Date.now() + expiresIn*1000
  user: PublicUserProfileDto;
  storedAt: string;                  // ISO
  schemaVersion: 1;
};
export async function saveSession(input: { user: PublicUserProfileDto; tokens: AuthTokensDto }): Promise<StoredSession>;
export async function getStoredSession(): Promise<StoredSession | null>;  // validates schemaVersion === 1 AND all required fields present; anything else → deleteItemAsync + return null (legacy sessions are discarded, never trusted)
export async function clearSession(): Promise<void>;
export function isTokenStale(s: StoredSession, skewMs?: number): boolean; // default SKEW_MS = 60_000; stale when Date.now() >= accessTokenExpiresAt - skew
```

**Machine** (`session-machine.ts`) — pure, unit-testable:
```ts
export type SessionStatus = 'booting'|'unauthenticated'|'authenticating'|'authenticated'|'refreshing'|'expired';
export type SessionState = { status: SessionStatus; user: PublicUserProfileDto | null; error: string | null };
export type SessionEvent =
  | { type: 'HYDRATED'; user: PublicUserProfileDto }      // stored session found at boot
  | { type: 'NO_SESSION' }                                 // nothing stored / invalid
  | { type: 'SIGN_IN_START' } | { type: 'SIGN_IN_SUCCESS'; user: PublicUserProfileDto } | { type: 'SIGN_IN_FAILURE'; error: string }
  | { type: 'REFRESH_START' } | { type: 'REFRESH_SUCCESS' } | { type: 'REFRESH_FAILURE' }   // failure = rotation mismatch/expired → 'expired'
  | { type: 'USER_UPDATED'; user: PublicUserProfileDto }
  | { type: 'SIGNED_OUT' };
export const initialSessionState: SessionState; // { status:'booting', user:null, error:null }
export function sessionReducer(state: SessionState, event: SessionEvent): SessionState;
```
Transition rules: `REFRESH_FAILURE` → `{status:'expired', user: keep, error:'session-expired'}`; `SIGNED_OUT`/`NO_SESSION` → `unauthenticated` (user null); `SIGN_IN_FAILURE` → `unauthenticated` with error; events that don't apply to the current status return state unchanged (defensive).

**Provider** (`session-provider.tsx`):
```ts
export type SessionContextValue = {
  status: SessionStatus; user: PublicUserProfileDto | null; error: string | null;
  signIn(email: string, password: string): Promise<void>;   // POST /auth/login {email,password} skipAuth → saveSession → SIGN_IN_SUCCESS
  signOut(): Promise<void>;                                   // best-effort POST /auth/logout (ignore failure) → clearSession → SIGNED_OUT → onAuthCleared callback
  refreshUser(): Promise<void>;                               // GET /auth/me → USER_UPDATED + update stored user
};
export function SessionProvider(props: { children: ReactNode; onSignedIn?: () => void; onAuthCleared?: () => void }): JSX
export function useSession(): SessionContextValue;            // throws outside provider
```
Provider responsibilities:
1. **Boot**: read `getStoredSession()`; none → `NO_SESSION`. Found → dispatch `HYDRATED` (optimistic authenticated), then background-validate `GET /auth/me`; success → `USER_UPDATED` (+persist user); `SessionExpiredError` → `REFRESH_FAILURE`.
2. **Register client hooks on mount** (from P1): `setAuthTokenProvider` (returns stored access token or null), `setRefreshHandler` (performs `refreshSession()` below), `setStaleGuard` (if stored session stale per `isTokenStale`, await `refreshSession()` — swallow failure; the request path will 401→handle).
3. **`refreshSession(): Promise<boolean>`** (exported from `session.ts` or provider module, single-flight): POST `/auth/refresh` with `{refreshToken}` (skipAuth); success → `saveSession(new pair)` + `REFRESH_SUCCESS` → true; 401 (mismatch/expired) → `clearSession()` + `REFRESH_FAILURE` → false. Share ONE in-flight promise across concurrent callers.
4. `signIn` also calls `props.onSignedIn?.()` (P4 wires query invalidation); `signOut`/`REFRESH_FAILURE` path calls `props.onAuthCleared?.()`.
5. Multi-device caveat (documented in code comment): server stores ONE refresh token per user — refresh mismatch means another device rotated; we transition to `expired`, UI copy: "Your session ended. Sign in to continue."

## Acceptance criteria
- `tsc --noEmit` clean. Reducer file has ZERO react/react-native/expo imports (pure — Vitest-testable in node env).
- Legacy/invalid stored payload (missing `schemaVersion` or fields) → discarded, `NO_SESSION`.
- Refresh rotates and re-stores; old-token replay (server 401 "Refresh token mismatch") → `expired`.
- Sign-out: best-effort server logout, local clear ALWAYS happens, `onAuthCleared` fires.
- No token value ever logged.
