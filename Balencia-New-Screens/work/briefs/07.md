# Functional Content Brief: CIA Onboarding Conversation

## 1. Purpose
Delivers the critical "it gets me" emotional moment within the first 60 seconds by establishing the app's collaborative, non-form vibe. The screen pairs a dynamic visual brainstorming canvas with a conversational chat to collect baseline assessments, life domains, goals, integrations, and preferences.

## 2. Entry and Exit Paths
*   **Entry Path:** Stack push from Consent [03c] (following Sign Up [03] → OTP [03b] → Consent). It is a linear onboarding flow with no back button (the commitment point).
*   **Exit Path:** Crossfade transition to Initial Plan Summary [08].

## 3. Information Architecture
**Global Zones (Top-to-Bottom):**
1.  **Status Bar Zone:** Device status.
2.  **Visual Brainstorming Area (Hero Focal):** Dynamic canvas reacting to conversation stages. Houses the continuous-stroke draw, domain bubbles, and goal example cards.
3.  **Progress Indicator:** Radial momentum dial wrapping the CIA orb (with an accessible dot-strip fallback underneath).
4.  **Subtle Divider:** Separates the visual canvas from the chat interface.
5.  **Chat Message Area:** Scrollable transcript of CIA (left-aligned) and User (right-aligned) messages.
6.  **Suggestion Chip Row:** Horizontally scrolling quick-response pills.
7.  **Chat Input Bar:** Text field and conditional send button.
8.  **Home Indicator Zone:** Device gesture area.

## 4. Features and Capabilities
*   **Conversational Onboarding:** Replaces traditional forms with a chat interface that adaptively collects assessment data, goal preferences, and coaching styles.
*   **Dynamic Visual Brainstorming:** A highly interactive top canvas where elements (domain bubbles, goal cards) animate, drift, and respond based on the user's chat input.
*   **Tap-to-Select Interactions:** Tapping visual elements (domain bubbles) or text chips automatically mirrors the selection into the chat as a user message.
*   **Auto-Fill Goal Templating:** Tapping floating goal example cards drops the text directly into the user's chat input for easy editing/sending.
*   **Progress Visualization:** A radial dial (wrapping the CIA orb) continuously tracks the 7-stage onboarding progress.
*   **Integrated OAuth Prompts:** Allows users to launch provider connections (Apple Health, WHOOP, etc.) mid-conversation via deep links.

## 6. Data Fields and Metrics
*   **`onboarding_status` (Enum):** Server-side metric tracking pipeline (`registered` → `consent_pending` → `assessment_pending` → `goals_pending` → `integrations_pending` → `preferences_pending` → `plan_pending` → `completed`).
*   **Baseline Assessment Data:** User's current state (fitness level, sleep quality, stress level, dietary habits). *Source: User selection via chips/free-text.*
*   **Selected Life Domains:** 2-4 core focus areas. *Source: User tap on visual domain bubbles or chips.*
*   **Structured Goals:** Specific targets per domain (e.g., timeline, 90-day vision). *Source: User free-text or auto-filled from goal example cards.*
*   **Integration Providers:** Authorized health data sources. *Source: User chip selection → OAuth flow.*
*   **Coach Preferences:** Desired coaching style and check-in frequency. *Source: User chip selection.*

## 7. Screen States
*   **Day 1 / Cold Start:** The default state for every new user. Canvas displays fully drawn stroke, bubbles float ready. CIA proactively initiates conversation.
*   **Loading (CIA Thinking):** Chat bubble contains 3 pulsing dots. Input field dims to 60%, blocks typing, and displays "CIA is thinking..."
*   **Partial Selection:** Selected domain bubbles glow brightly and drift toward the center; unselected fade to 50% opacity and recede to edges. Goal cards appear.
*   **Disabled (OAuth in Progress):** Input field dims, typing blocked, placeholder reads "Connecting to [provider]..."
*   **Error (Generation / Network):** Soft-error copy replaces generic system alerts. Uses non-alarming borders (calm orange, not red) and retry chips.
*   **Offline:** Cached messages display. Banner reads "You're offline. Your responses have been saved locally..."
*   **Reduced Motion:** All ambient drift and pulse animations halt. Visual elements appear static and fully settled. Transition skips convergence morph; uses simple crossfade.

## 8. Interactions, Gestures, Motion Intents
*   **Tap (Domain Bubble/Chip):** Selects/deselects an area. Triggers a fly-and-morph animation where the chip/bubble content flies down and transforms into a right-aligned user message bubble.
*   **Tap (Goal Example Card):** Auto-fills the chat input bar with the goal text.
*   **Tap (Outside Input):** Dismisses the keyboard.
*   **Vertical Scroll:** Navigates up through chat history.
*   **Motion Intent (Signature Draw):** The continuous-stroke draws itself on screen mount (1200ms flow) — establishes the collaborative brand identity.
*   **Motion Intent (Transition):** Upon completion, all visual elements converge into the center, morph into a pulse ring, and crossfade to the next screen.

## 9. Free vs Premium Gating
*   None on this screen. All domains, suggestions, and onboarding capabilities are open to establish the foundational user graph. Premium upsell occurs post-onboarding.

## 10. Cross-Domain Hooks
*   **AI Systemic Framing:** The core philosophy is explicitly stated in copy: *"I'm here to help you see your whole life as one connected system — not separate apps for separate things."*
*   **Cross-Domain Goal Mapping:** The visual area clusters multiple selected domain bubbles together, visually demonstrating how goals in one area (e.g., Finance) overlap with others (e.g., Wellbeing).
*   **Health Integrations:** Establishes hooks to external health APIs (Apple Health, WHOOP, Oura, etc.) to correlate physical data with the user's baseline assessment and chosen goals.
