# 2. Purpose
Provide an honest, premium, and immediate view of physical progress. The screen connects manual logging and wearable data into a single narrative, leaning on CIA to provide context rather than leaving the user to interpret raw numbers in isolation. 

# 3. Entry & exit
**Entry paths:**
- Fitness domain launcher → Progress (`/progress`)
- Today dashboard quick action → "Log weight"
- CIA chat deep-link (context: "Why did my weight spike?")

**Exit paths:**
- Tap `Add measurement` → Log measurement flow (Sheet)
- Tap CIA Insight card → `/ai-coach`
- Tap historical log row → Inline expansion

# 4. Layout anatomy
**Regions (top-to-bottom):**
1. **Atmosphere & Nav:** Warm dark background, top bar, floating glass nav.
2. **Timeframe selector:** Segmented control for temporal filtering.
3. **Hero metric visualization:** Large tabular KPI, delta indicator, and trend chart. Swipeable sub-tabs.
4. **CIA insight:** Cross-pillar AI analysis card.
5. **Active goals:** Progress bars mapping data to intent.
6. **Log history:** Honest, chronological ledger.

# 6. Visual treatment
- **Glass tiers:** Hero metric uses `.glass-card`. Timeframe selector, sub-tabs, and history list rows use `.glass-pill`. Background maintains `.glass-frost` behind the system status bar. 
- **Glow color & meaning:** 
  - **Hero Stat (Weight):** `--glow-you` (#FF5E00). Represents active user effort and the primary metric being tracked.
  - **CIA Insight Card:** `--glow-cia` (#7F24FF). Represents AI-derived, premium intelligence.
- **Background atmosphere:** `--bg-base` (#0A0A0F) base. Warm radial glow top-center (`rgba(255,94,0,.18)`). Subtle 3% grain overlay. No purple pool here to keep visual emphasis on the chart.
- **Hero type moment:** The 40px tabular weight value (`180 LBS`) centered in the viewport's upper third.

# 8. Data & honesty states
The brief requires syncing across multiple wearables, which introduces high variance in confidence. Every metric respects the 3-state honesty invariant.

**Metric 1: Weight (Primary)**
- **Real:** `180 LBS` · `via Apple Health` · `▲ +1.2 lbs vs last week`
- **Low-confidence:** `~180 LBS` (64% opacity) · `estimated · low confidence`
- **Honest-null:** Quiet state glyph · "Not enough data yet — 3 more days."

**Metric 2: BMI (Auto-calculated)**
- **Real:** `24.2` · `calculated from height`
- **Low-confidence:** `~24.2` (64% opacity) · `estimated · low confidence`
- **Honest-null:** "Add your height to calculate BMI." (Links to `/profile`).

**Metric 3: Circumferences (Waist/Chest)**
- **Real:** `32 IN` · `you logged`
- **Low-confidence:** N/A (manual logs are exact). If mismatched against a smart scale, reverts to Real.
- **Honest-null:** "Log your first measurement to start tracking."

*Correction to Brief:* The brief lists "Daily" in the timeframe control, but provides Weekly/Monthly/Yearly in the IA. The spec implements Weekly/Monthly/Yearly.

# 9. All states
- **Default:** Displaying real weight data and historical trend.
- **Skeleton:** Shimmer blocks (`--surface-3`) replacing the KPI and chart; axis lines ghost rendered.
- **Empty (First-use):** Illustration-free Display-small text: "Log your first measurement to start tracking your trends." with an orange BtnPrimary.
- **Error (Sync failure):** Inline glass-pill banner: `Failed to sync health data.` + BtnSecondary `Retry`. Never blames the user.
- **Success:** Top `XPToast` (`+20 XP · Fitness`) auto-dismisses after logging via FAB.
- **Disabled:** "Yearly" tab is visually present but disabled; tapping triggers a PaywallLock tooltip: "Unlock with premium."

# 10. Motion & interaction
- **Physical easing:** Standard ease-out for swipe transitions.
- **150-250ms feedback:** Sub-tab pills slide (150ms). Chart line draws progressively on load (800ms path animation, ease-in-out). 
- **Glow behavior:** `--glow-you` on the hero card "breathes" (4s sine wave, 10% opacity delta).
- **Haptics:** Light selection tick on sub-tab swipe. Success impact on log save.
- **Reduced-motion path:** Chart draw becomes an instant opacity fade. Glow breathing is disabled (static gradient). 

# 11. Motivation-tier adaptation
- **Low density:** Trend chart appears smaller; history list limits to last 3 entries to prevent overwhelm. CIA card hidden.
- **Medium density:** Default state as spec'd.
- **High density:** Full trend chart. CIA insight card expanded by default. History list renders unlimited entries. Quick-log FAB pulses gently if no weight logged in 7 days.

# 12. Accessibility
- **AA+ contrast pairs:** Paper-100 (#FEFAF3) on `--bg-base` (#0A0A0F) > 19:1. Paper-64% used for meta-data maintains > 4.5:1 on dark surfaces. 
- **44px targets:** Segmented tabs, history rows (min 56px), and nav buttons strictly adhere to 44px bounds. 
- **Screen-reader labels:** Chart requires VoiceOver/TalkBack string: "Line chart. Weight trend. 180 pounds, up 1.2 pounds from last week." Glyph-only '+' CTA labeled `Add a new measurement`.

# 13. Premium checklist (14-point gate)
1. **Connects:** Syncs with Apple Health/Wearables and routes to CIA for context.
2. **Honest:** Real data explicitly tagged via `ChipProvenance`.
3. **Premium:** Distinct glass cards and signature glows used; no flat black backgrounds.
4. **One hero color:** Burnt Orange (#FF5E00) dominates the active user line and CTA.
5. **60/30/10 rule:** Burnt orange (effort/tracking), Forest Green (milestones/positive), Purple (CIA insight).
6. **One Tiempos italic moment:** `*spiked*` in the CIA insight.
7. **Sentence case / no exclamations:** Verified.
8. **CIA never SIA:** Verified.
9. **Selective glass:** Data lists use solid/solid-framed pills; hero chart uses `.glass-card`.
10. **One semantic glow per card:** CIA uses purple; Hero chart uses orange.
11. **Tabular nums on metrics:** Verified (`180 LBS`, BMI `24.2`).
12. **Radii respected:** 28px cards, 999px pills.
13. **4px/8pt grid spacing:** Verified.
14. **Cross-cutting patterns:** FABQuickLog present, PaywallLock applied to premium AI insights, honest nulls designed for missing metrics.
