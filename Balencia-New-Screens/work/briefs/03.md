### 1. Purpose
Converts visitor interest into registered accounts by collecting the absolute minimum required data (email and password). Serves as the entry point for the authentication flow before introducing the user to the CIA coach or requiring further personal data.

### 2. Entry and Exit Paths
*   **Entry Paths:**
    *   Motion Carousel [02] (via stack push)
    *   Sign In [04] (via stack navigation)
*   **Exit Paths:**
    *   OTP Verification [03b] (via stack push, after successful form submission)
    *   Consent [03c] (via stack push, after social auth if no profile data is missing)
    *   Complete Profile [03d] (via stack push, after social auth if DOB/gender are missing)
    *   Sign In [04] (via stack push, via "sign in" escape hatch)
    *   Guest Mode Preview [06] (via stack push, via "Try without an account" escape hatch)

### 3. Complete Information Architecture
**Layout structure (Top-to-Bottom):**
1.  **Status Bar Zone:** System status.
2.  **Brand Anchor:** Logo symbol (floats centered).
3.  **Heading:** Intent statement.
4.  **Form Fields Group:** Email field, immediately followed by Password field and the live password progress bar.
5.  **Primary Action:** "sign up" CTA button.
6.  **Divider:** Separator with contextual text.
7.  **Social Auth:** Side-by-side Google and Apple buttons.
8.  **Navigation Links:** Escape hatches for returning users or guests.
9.  **Legal Footer:** Compliance links.
10. **Home Indicator:** System navigation.

### 4. Features and Capabilities
*   **Minimal Data Account Creation:** Captures only an email and password to minimize friction and reduce drop-off.
*   **Secure Password Composition:** Enforces password validation rules (length, uppercase, lowercase, number, special character).
*   **Real-time Password Feedback:** Displays a continuous, non-shaming momentum bar that fills as password rules are met.
*   **Secure Entry Management:** Toggle to mask/unmask password characters.
*   **Social Authentication:** One-tap account creation via Google or Apple OAuth providers.
*   **Deferred Onboarding:** Bypasses immediate collection of DOB, gender, and name (these are deferred to CIA onboarding or a "Complete Profile" step if OAuth fails to provide them).
*   **Guest Mode Browsing:** Allows users to explore the app without committing to an account.
*   **Legal Compliance:** Provides immediate access to Terms of Service and Privacy Policy.

### 6. Data Fields and Metrics
*   **Email Address:** User input (validates against malformed strings and disposable domains).
*   **Password:** User input (validated for 8+ chars, uppercase, lowercase, number, symbol).
*   **Password Strength Metric:** Derived locally from user input (displays as a continuous momentum bar moving from 0 to 4 rules met).
*   **OAuth Token:** System generated (derived from Google/Apple OAuth flow).

### 7. Screen States
*   **Cold-start / Empty (Day-1):** Form fields visible with placeholder text. CTA is disabled (0.4 opacity, no haptic on tap). Password progress bar is hidden until typing begins.
*   **Active / Focused:** Focused field displays a 2px brand-color border. Hint text fades. Keyboard overlays.
*   **Partially Filled:** CTA remains disabled until both email and password fields pass validation.
*   **Error - Single Field:** Failing field border turns 2px red, accompanied by an inline ✗ glyph and red caption text.
*   **Error - System Toast:** Recovable error (network, existing account) displays as a toast at the top of the screen. 
*   **Loading:** Form fields remain visible but read-only (0.5 opacity). CTA text is replaced by a spinner and "Creating your account..." text.
*   **Success:** CTA briefly flashes a green glow, then auto-navigates to the next screen.
*   **Offline:** CTA is dimmed. A banner reading "You're offline. Check your connection." is displayed.

### 8. Interactions, Gestures, Motion Intents
*   **Tap:** Focus input fields, trigger CTAs, toggle password visibility, select social auth.
*   **Keyboard Scrolling:** Viewport automatically scrolls to keep the active field and CTA visible above the system keyboard.
*   **Motion Intent - Entry:** Staggered fade-in and rise (12pt to 0) for logo, heading, inputs, CTA, and footer. (Instant if `prefers-reduced-motion`).
*   **Motion Intent - Error:** Inline error text slides down (0 to 16pt) and fades in. 
*   **Motion Intent - Success:** Brief 600ms green glow flash on the CTA before pushing the next screen.

### 9. Free vs. Premium Gating
*   *Not applicable on this screen.* Authentication and account creation are entirely free. No premium upsells or paywalls are presented pre-auth.

### 10. Cross-Domain Hooks
*   **CIA Onboarding Deferral:** The screen explicitly offloads life-domain data collection (DOB, gender, name) to the CIA (Complete Profile) phase to reduce initial friction. This ensures the user is introduced to CIA and health correlations only *after* they have successfully converted into an account holder.
