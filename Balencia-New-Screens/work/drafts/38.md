- **Name:** Habits

# 2. Purpose
The daily habit dashboard answers: "what do I do today, and how consistent am I?" It provides a satisfying, non-shaming checklist that directly feeds the app's XP system. The design prioritizes momentum over perfection, actively preventing loss-aversion triggers.

# 3. Entry & exit
- **Entry:** Stack push from Explore, deep-link from CIA chat, or tap from Home action card.
- **Exit:** Stack pop via TopBar back chevron. Stack push to `Habit Analytics` via chart dives. Modal push for `Add/Edit Habit`. Tab switch to `CIA` via insight card CTA. 

# 4. Layout anatomy
**Regions (top-to-bottom):**
1. **Atmosphere & TopBar:** Warm radial glow base. Transparent header with back chevron, H1 "Habits", and right-aligned settings glyph.
2. **Hero Summary Card:** Daily MomentumBar, completion count, and active streak. (Serves as the single hero moment).
3. **Segmented Control:** View toggle (Today / Week / Month).
4. **Habit Checklist:** Scrollable SolidCards grouped by Morning, Afternoon, Evening. Includes swipe and drag gestures.
5. **Analytics & Insights:** 4-week Calendar Heatmap, optional Trend Sparkline (high motivation only), and CIA Insight Card.
6. **FAB & Navigation:** Floating Quick Log action and bottom tab bar.

# 5. Components

- **SegmentedTabs** (View toggle)
- **SolidCard** (Checklist container, analytical surfaces)
- **ListRow** (Habit unit, modified for trailing data)
- **CalendarHeatmap** (28-day grid)
- **CIAInsightCard** (Purple-tinted coach nudge)
- **ChipProvenance** (e.g., `calculated today`)
- **ChipDomainTag** (Domain classification)
- **FABQuickLog** (Global quick add)
- **GlassNavBar** (Bottom navigation)
- **HabitRowCard** — **NEW:** A composite of `ListRow` + `ChipDomainTag` + inline `CalendarHeatmap` micro-strip. Rationale: The Elevation pass mandates a per-row 7-day heatmap trailing each habit to provide instant, per-row visual consistency without opening a separate analytics screen. 
- **WeeklyBarChart** — **NEW:** A 7-bar histogram representing daily completion percentages. Rationale: Required to fix the broken legacy "Week" segment which was a no-op incorrectly rendering the Today list.

# 6. Visual treatment
- **Glass Tier:** 
  - Hero Summary: `.glass-card` (elevated, immersive over atmosphere).
  - CIA Insight: `.glass-card` (purple-tinted).
  - Checklist / Heatmap: Solid `--surface-2` (data-density demands absolute legibility).
  - Inputs/Segments: `.glass-pill`.
- **Semantic Inner-Glow (one per card, meaning-driven):**
  - **Hero Summary (`--glow-you` `#FF5E00`):** Bottom-anchored bleed representing user *effort* and momentum for the current day.
  - **HabitRowCard (None on default, `--glow-you` on Long-press):** Glow isolates the single row being interacted with for drag-reordering.
  - **CIA Insight (`--glow-cia` `#7F24FF`):** Bottom-anchored bleed indicating AI-generated projected nudge.
- **Background Atmosphere:** `--bg-base` base with a top-center warm radial glow (`rgba(255,94,0,.18)`) and 3-4% grain overlay. 
- **Hero Type Moment:** The "62%" in the Hero GlassCard set in NM Medium 52px (Display).

# 9. All states
- **Default:** Active habits grouped by time. MomentumBar reflects current session.
- **Skeleton:** Depth-preserving `SkeletonState` blocks morphing into drawn data. Copy reads: "CIA is reading your habits — one moment."
- **Empty (Cold-Start):** Ghosted progress bar. `EmptyState` component renders CIA nudge: "based on your goals — want to start with a few habits?" *(Correction: Explicitly preventing the "0 of 0" state via this CIA intervention).*
- **Error (Network):** `ErrorState` block on metrics. "couldn't load habits — pull to refresh". Toggle failure results in bounce-back animation and toast: "could not save — try again".
- **Success (All-Done):** MomentumBar fills to 100% and flips to `--glow-done` (#34A853) with a 250ms sweep. Copy switches to: "all done. solid day."
- **Disabled:** Offline state disables FAB and toggles. Queued completions show a small pending clock icon. `OfflineBanner` displays at top.

# 10. Motion & interaction
- **Easing & Timing:** Physical easing (`cubic-bezier(0.4, 0.0, 0.2, 1)`). Feedback interactions resolve in 150-250ms.
- **Draw-first Hierarchy:** MomentumBar animates first -> Sections fade-up -> Heatmap cells stagger -> XP counts up.
- **Check Checkbox:** 150ms draw-in of checkmark stroke. Row text mutes to 50% opacity. "+10 XP" floats up 20px and fades. 
- **Glow Behavior:** Hero Summary "breathes" (4s ease infinite) to signify an active day. 
- **Gestures:** Swipe-left reveals edit/delete (red accent for delete only). Long-press enters drag-to-reorder mode (haptic heavy tick).
- **Haptics:** Light tick on habit toggle. Medium pop on 100% daily completion. 
- **Reduced Motion (`prefers-reduced-motion: reduce`):** Disables breathing glow, draw-first staggering, and XP float-ups. Transitions to instant crossfades (opacity-only).

# 11. Motivation-tier adaptation
- **Low Motivation:** Auto-hides low-priority habits (showing max 3). Amplifies XP visuals (oversized `+25 XP` float-ups). UI copy emphasizes non-shaming nudges: "just pick *one*. that's enough."
- **Medium Motivation:** Standard experience. All habits visible in standard type sizes. Standard XP gains (+10).
- **High Motivation:** Unlocks the exact day counts on streaks (e.g., "21 days, 14 hours"). Unhides the Trend Sparkline above the heatmap. Unlocks domain-breakdown analytics inside the heatmap tooltips.

# 12. Accessibility
- **Contrast:** Paper-100 (#FEFAF3) on `--surface-2` (#211008) exceeds AAA contrast. 
- **Targets:** All interactive elements (checkboxes, segmented tabs, habit rows) maintain ≥ 44x44px hit areas.
- **Screen-reader labels:** Glyph-only settings icon (`aria-label="habit settings"`). Checkbox state explicitly read (`aria-checked="true"`).
- **Color index:** Heatmap reliance is supplemented by distinct cell shapes (dashed for null, solid for data) to accommodate color-blindness.
