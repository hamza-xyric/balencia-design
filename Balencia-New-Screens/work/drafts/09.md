# 2. Purpose
To serve as the central, unified AI conversation interface where CIA proactively initiates dialogue, surfaces cross-domain intelligence, and processes natural language logging. It transforms the coach from a simple chatbot into a **connective** hub for the user’s whole life.

# 3. Entry & exit
- **Arrives from:** Bottom tab bar (CIA root), Home Screen greeting card, "Ask CIA" shortcuts.
- **Primary exit:** Feature/domain screens via rich inline artifact card taps (stack push).
- **Secondary exits:** Other tabs via bottom tab bar; full-screen voice mode via top-bar voice icon or long-press mic.
- **Correction to Brief:** The brief states the screen contains a bottom tab bar while simultaneously utilizing a pull-down history gesture and a sticky input bar. Rendering a floating bottom nav directly beneath a chat composer creates tap-target collision and visual clutter. **Resolution:** The bottom tab bar is omitted from this specific screen view. Navigation relies on standard iOS/Android edge-swipes or a top-bar back chevron if pushed contextually. 

# 4. Layout anatomy
**Regions top-to-bottom:**
1. **Top Bar Zone:** Title, Search, Voice icons. Gains `.glass-pill` backdrop on scroll.
2. **Chat Scroll View (Inverted FlatList):** Core conversation area.
3. **Suggestion Chip Row:** Horizontally scrolling quick-replies.
4. **Input Bar:** Text field and dynamic Mic/Send button.
5. **Home Indicator:** System gesture space.

# 8. Data & honesty states
*Every metric in InlineArtifactCards ships with three states.*
- **Chart Card (Sleep vs. Fitness Trend):**
  - **Real:** Solid orange line / dashed purple projection. Provenance chip: `via WHOOP` & `via Apple Health`.
  - **Low-confidence:** KPI value muted (64% opacity). Label: `estimated · low confidence`. Dashed purple line only.
  - **Honest-null:** Quiet glyph, copy: `Not enough data yet — 3 more days`.
- **Meal Plan Card (Macros):**
  - **Real:** Donut chart split (Protein/Carbs/Fat). Provenance chip: `you logged`.
  - **Low-confidence:** Gray donut segments. Label: `estimated from photo`.
  - **Honest-null:** Empty plate glyph. Copy: `No meals logged today`.
- **Connection Spotted Card (Correlation):**
  - **Real:** Correlation bars (+/- glyphs) fully filled. Provenance chip: `AI cross-analysis`.
  - **Low-confidence:** N/A (AI does not surface low-confidence correlations as "spotted").
  - **Honest-null:** Hidden entirely. CIA will not claim a connection exists without data.

# 9. All states
- **Default:** Active conversation view with recent history and contextual chips.
- **Cold-start / Day-1:** No history. Proactive greeting CIA bubble slides up from bottom (520ms). Minimal 1-2 chips ("tell me more", "add a goal"). 
- **Loading (Thinking):** `IntelligenceTimeline` component shows pulsing dots. Transitions to copy if >2s.
- **Partial Error (Inline):** Card shows error glyph and copy ("Couldn't load this insight. Pull to refresh.") via `ErrorState` component inside the bubble. Non-failed message text remains visible.
- **Send Error:** User bubble turns muted, displays error glyph, "Not sent — try again" text. Tap opens retry/delete menu.
- **Offline:** Glass-pill banner below TopBar: "CIA needs a connection to chat." Input bar disabled (40% opacity). History remains cached and scrollable.

# 10. Motion & interaction
- **Easing:** Physical, gravity-based easing curves (never linear).
- **Feedback:** 150-250ms scale/opacity transitions on chip taps and button presses.
- **Draw-in:** Inline viz charts draw progressively via stroke-dashoffset (520ms) rather than fading in.
- **Glow behavior:** CIA bubble glow "breathes" (4s ease) while the IntelligenceTimeline is active (thinking). 
- **Gestures:** Tap (send/select), Long-press bubble (copy text menu), Long-press mic (full-screen voice transition).
- **Reduced motion:** All proactive bounces disabled. Auto-scroll paused. Charts render instantly at final state. Thinking dots become static.

# 11. Motivation-tier adaptation
- **Low density:** Shorter CIA copy (max 2 sentences). Only 2 suggestion chips. Data cards omit trend charts, showing single KPI values only.
- **Medium density (Default):** Standard conversational length. 3-4 suggestion chips. Full rich inline cards (mini charts, goal rings).
- **High density:** Detailed, data-heavy CIA copy. Up to 6 advanced suggestion chips. Rich cards expand to show underlying data tables, exact macros, and deep historical comparisons.

# 12. Accessibility
- **Contrast:** AA+ maintained. Paper-100 (#FEFAF3) on `--bg-base` (#0A0A0F) for primary text. Paper-50 (#FDFDFB) on `--glow-you` (#FF5E00) for user bubbles.
- **Targets:** All suggestion chips, mic button, search icons, and rich card CTAs strictly enforce 44px minimum tap area.
- **Screen-reader:** Inline `ChipDomainTag` elements are grouped and read as "Tag: Fitness." Chart elements use `aria-label` describing the trend (e.g., "Line chart showing sleep duration increasing over 7 days").
- **Visual correction applied:** As flagged in the brief, decorative white/10 grid lines on the Chart Card are **omitted** entirely to satisfy WCAG 1.4.11 compliance. Chart relies purely on the solid orange/dashed purple data lines against the dark surface.
