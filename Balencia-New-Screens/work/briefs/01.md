### 1. Purpose
Acts as a sub-2-second premium brand handshake that covers cold-start initialization (auth checks, asset preloading). Delivers emotional impact through a brand-mark reveal where a continuous stroke line draws itself around the Balencia symbol.

### 2. Entry and Exit Paths
*   **Entry Paths:** System app launch (cold-start or warm-start).
*   **Primary Exit:** Crossfade to Motion Carousel (Screen 02) — *Condition: First-time user or no saved session.*
*   **Secondary Exit:** Crossfade to Home Screen (Screen 12) — *Condition: Returning user with a valid authenticated session.*
*   **Timeout Exit:** Forced transition after 4 seconds (network timeout) or 5 retries (auth fail) to fallback screens.

### 3. Complete Information Architecture
**Region 1: Status Bar Zone (Top)**
*   System status bar. Hidden/transparent during splash.

**Region 2: Upper Spacer**
*   Flexible spacing that pushes the brand cluster to the optical center (40% from the top).

**Region 3: Brand Cluster (Focal Point)**
*   **Hero Glow:** Atmospheric depth layer wrapping the brand cluster.
*   **Balencia Symbol:** The core brand mark and immediate visual anchor.
*   **Continuous Stroke Line:** Animated brand-mark reveal drawing itself organically.
*   **Wordmark:** "Balencia." text, acting as secondary confirmation.

**Region 4: Lower Spacer**
*   Flexible spacing (slightly larger than upper spacer) to maintain the optical center.

**Region 5: System Safe Area (Bottom)**
*   Home Indicator zone.

### 4. Every Feature and Capability
*   **System Auth Check:** Background process validating session tokens.
*   **Asset Preloading:** Background loading of app assets (with graceful degradation if it fails).
*   **Network Detection:** Ability to detect offline states and transition based on cached data.
*   **Auto-Advance Transition:** Time-based, hands-free screen progression.
*   **Accessibility Narration:** Screen reader announcement of loading status.
*   **Reduced-Motion Handling:** Detects user device preferences to skip animations.
*   **Session Retry Loop:** Automated background retrying of auth checks (up to 5 attempts).

### 5. UI Copy (Verbatim Strings)
*   **Wordmark:** `"Balencia."` *(Note: The period is part of the wordmark and is sacred).*
*   **Screen Reader on Mount:** `"Balencia. Loading."`
*   **Auth Retry Tooltip:** `"Checking your session… will retry"`
*   **Offline Toast (Returning User):** `"No connection — continuing with saved data"`
*   **Offline Toast (New User):** `"No connection — starting fresh"`

### 6. Data Fields and Metrics
*The Splash Screen contains zero data-bearing metrics, chart primitives, or user data fields. It is a pure pre-auth brand handshake.*
*   **Timer Durations (System):** Total animation duration ~1.8s. Network timeout threshold: 4s. Auth retry interval: 3s (max 5 attempts).
*   **Auth State Token:** *Data Source: Local device cache / Auth server.* (Used invisibly to determine exit path).

### 7. All Screen States
*   **Cold-start / Day-1 / Loading:** Identical visual for all users. Animation plays normally or renders instantly if reduced-motion is active. No skeletons or spinners.
*   **Error (Auth Fail):** Brand cluster remains fully visible. Symbol executes a subtle opacity pulse (80%–100% loop). No red colors or error icons shown.
*   **Offline (No Network):** Holds splash, pulses symbol. After 4 seconds, forces transition based on cached state while showing an offline toast.
*   **Reduced Motion:** Skips the 1.2s stroke draw completely; shows the final settled frame instantly, holding for 1.2s to preserve the total ~1.8s timing contract.
*   **Empty / Partial:** Not applicable (no data-driven content).

### 8. Interactions, Gestures, Motion Intents
*   **Gestures:** None. The screen is entirely passive; no user interaction is accepted.
*   **Motion Intent (Entrance):** 
    1. Symbol fades in.
    2. Hero glow begins fading in.
    3. Stroke line *draws itself* (using stroke-dashoffset, never opacity-fading) with a single organic curve.
    4. Wordmark fades in and translates upwards into place.
*   **Motion Intent (Exit):** Simultaneous crossfade to the downstream screen (Splash fades out, next screen fades in).
*   **Motion Intent (Error/Waiting):** Gentle opacity pulsing of the symbol to signify background waiting (not an alarm).

### 9. Free vs Premium Gating
*   **Gating:** None. This is a pre-authentication screen. All users (free, premium, new, returning) experience the exact same brand handshake.
