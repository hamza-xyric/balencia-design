# 2. Purpose
Reports Center translates whole-life data into structured, shareable summaries (weekly life, doctor, mission progress) without exposing private notes by default. It serves as a calm, editorial review and export surface, leveraging CIA to provide plain-language context rather than functioning as a raw data dump.

# 3. Entry & exit
- **Entry paths:** Stack push from Me Main [17], Intelligence Dashboard [48], Data Sources [84], Help Center [25], or via CIA deep-link.
- **Primary exits:** Tap "Share" to trigger native share sheet, or "Screenshot guide" for export tips.
- **Secondary exits:** Tap a report card to open the full Report Preview/Detail expansion. System back returns to the origin screen.

# 9. All states
- **Default:** Hydrated metrics, real deltas, breathing CIA glow.
- **Skeleton:** `SkeletonState` sweeps (1.2s) over report cards and KPI blocks. Charts show axis + ghost lines.
- **Empty:** `EmptyState` (first-use). Hero remains. List hides. KPIs hidden. CTA: `+ Create weekly report`.
- **Error:** `ErrorState` in place of failed chart. Copy: `Couldn't sync your latest data — pull to refresh.` Report cards get orange warning border.
- **Success:** "Share" button label changes to `Exported ✓` for 900ms, then reverts.
- **Disabled:** Offline mode. Bottom actions dimmed to 40% opacity. Banner: `offline — showing last sync 2h ago`.

# 10. Motion & interaction
- **Feedback:** BtnPrimary/Ghost/Card taps scale (0.98) over 150ms physical ease.
- **Draw-first rendering (Preview Modal):** Axes draw -> KPI counts up -> KPI cards rise -> Trend line draws left-to-right -> Donut arcs sweep clockwise -> Correlation matrix cells scale in row-by-row.
- **Glow behavior:** Report cards brighten inner-glow on press. CIA orb breathes (4s ease-in-out).
- **Gestures:** Long-press trend chart engages scrubbing crosshair (haptic tick per intercept). Tap matrix cell reveals readable correlation pill.
- **Reduced-motion path:** Draw-first animations bypass completely; final states render instantly. Breathing glows become static. Scrubbing crosshair requires drag instead of long-press hold.
