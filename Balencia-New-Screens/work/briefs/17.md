# FUNCTIONAL CONTENT BRIEIF: Me Main

## 1. Purpose
Me Main is the user's identity hub and central navigation gateway. It answers "who am I in this app?" at a glance via profile stats and RPG progression, while providing structured pathways to all personal sub-screens and AI-driven feature discovery.

## 2. Entry and Exit Paths
*   **Entry Points:** 
    *   Bottom tab bar ("Me" tab tap).
    *   Back navigation (stack pop) from any Me sub-screen.
*   **Exit Paths (Stack Pushes & Modals):**
    *   `Settings` [21] via top-right gear icon.
    *   `Profile Edit` [50] via modal (tap avatar).
    *   `RPG Character` [19] via RPG badge or Stats row tap.
    *   `Mission Journal` [73], `Personal Wiki` [20], `Connected Apps` [22], `Subscription` [23], `Progress Photos` [49], `Streak Details` [59], `Achievements` [71], `Notifications` [24], `Help Center` [25] via Quick Link cards.
    *   `Explore Section` [18] via "see all" link.
    *   Domain dashboards via Explore module cards.

## 3. Complete Information Architecture
**Top to Bottom Layout:**
1.  **Global Header / Floating Element:** Settings gear icon (top-right absolute positioning).
2.  **Profile Anchor:** Avatar (with photo upload indicator), User Name, RPG Level Badge, XP Progress Bar, Member-since text.
3.  **Progression Snapshot (Stats Row):** 4-cell horizontal grid showing current streak, missions completed, Life Power, and total XP.
4.  **Life Power Composition (Secondary Visualization):** "Composed of" header followed by the top 5 domain stat bars.
5.  **Navigation Hub (Quick Links Grid):** 2-column, 5-row grid containing 10 navigation cards with dynamic status subtitles.
6.  **Discovery (Explore Preview):** Section header with "see all" link, horizontally scrolling module cards.

## 4. Features and Capabilities
*   **Identity & Progression Tracking:** View current RPG level, XP progress to the next level, and "Member since" tenure.
*   **Life Power Aggregation:** View overall Life Power score alongside the top 5 domain stats that compose it.
*   **Dynamic Status Snapshots:** View personal counts and statuses directly on navigation cards (e.g., missions completed, active streaks, unread notifications, current subscription tier).
*   **Photo Upload:** Change or add a profile photo directly from the hub via an overlay camera icon.
*   **AI-Driven Discovery:** Surface contextual, AI-recommended modules based on recent user activity.
*   **Pull-to-Refresh:** Manually trigger a refresh of all stats, profile data, and AI suggestions.
*   **Adaptability:** Layout and microcopy adapt to the user's motivation level (e.g., simpler modules suggested for low motivation, weekly trends shown for high motivation).

## 7. Screen States
*   **Cold-start / Day 1:** Profile at Lv.1, 0 XP, 0 stats. Avatar uses first initial. StatBars show ghosted/dashed tracks for unstarted domains. Quick links adapt subtitles ("Lv.1 beginner", "choose a plan"). Explore shifts to "popular with Balencia". Hero ring shows honest 0% (faint full track, no degenerate point).
*   **Loading:** Skeleton shimmers morph into data (never blank boxes). 
*   **Empty / Partial Sync:** Ghosted/dashed StatBars tracks for un-synced domains (no-data ≠ zero). Missing stats render only present cards; others remain skeletons. Explore falls back to static popular modules.
*   **Error:** Cached data shown if available; otherwise skeletons. Genuine sync failures trigger a network banner / red outline on the affected zone. Avatar upload failure triggers a brief red flash over the camera overlay.
*   **Offline:** Pull-to-refresh is dimmed (50% opacity, no haptic). App displays cached data.
*   **Motivation Variants:** 
    *   *Low:* Encouraging CIA copy ("just checking in today counts"), simpler Explore modules.
    *   *High:* "This week" delta trends appear next to stats. Advanced Explore modules surface.

## 8. Interactions, Gestures, Motion Intents
*   **Gestures:** Tap (navigation/edit triggers), Horizontal scroll (Explore modules), Vertical scroll (full screen), Pull-to-refresh (reload data).
*   **Motion Choreography (Entrance):** Strict draw-first sequence. Profile fades in → Hero Life Power dial ring fills (`0→value`, 520ms) → XP bar draws (`0→value`, 520ms) → Stats count up → StatBars rise vertically (`0→value`, 520ms, 60ms stagger) → Quick links & Explore cards fade in (staggered).
*   **Micro-interactions:** Tap scale animations (`scale(0.95)` to `0.97` depending on element) with light haptic impact. Focus-visible rings (orange outline) for accessibility.
*   **Reduced Motion:** All elements appear at final state instantly. Count-ups and bar drawings are bypassed.

## 9. Free vs. Premium Gating
*   **Quick Link Display:** Current tier is dynamically displayed in the Subscription card subtitle (e.g., "Plus plan").
*   **Visualization Gating:** The secondary Life Power composition may render a basic StatBars list for free users, or a premium `ConstellationRadar` mini-variant for Plus/high-motivation users.
*   **Explore Gating:** Module cards distinguish included vs. locked states (per Audit Q34 resolution).
*   **Cross-Domain Analytics:** Life Areas comparison metrics are Plus-gated only after enough history exists (per Audit Q33 resolution).

## 10. Cross-Domain Hooks
*   **CIA Integration:** CIA's presence is deliberately subtle on this hub—appearing only via personalized insight cards in the Explore preview to contextually recommend the next action.
*   **Life Power Composition:** Directly links the user's overarching RPG score to granular domain performance (Top 5 domains shown visually, linking out to domains like Fitness, Sleep, Wellbeing, Nutrition, Relationships). 
*   **Weakness Nudges:** Instead of shaming low stats, the UI invites action (e.g., "grow your meditation →") linking the user directly to that specific life area dashboard.
*   **Historical Correlations:** High-motivation users unlock cross-domain analytics and correlation modules directly from the Explore preview section.
