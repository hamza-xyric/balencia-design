# Functional Content Brief: Create / Edit Mission

## 1. Purpose
Transforms a user's natural-language intention into a structured, actionable mission plan. CIA decomposes the text into mission type, domain assignments, tactical actions, milestones, and tracking signals, while allowing the user to edit and refine every element to maintain control.

## 2. Entry and Exit Paths
**Entry Paths (Modal Presentation)**
* **Create Mode:** Slides up from Mission Board [13] FAB "+".
* **Chain-Linked Create Mode:** Slides up from Mission Detail [14] via chain "modify" or "accept" action.
* **Edit Mode:** Slides up from Mission Detail [14] "edit" button.

**Exit Paths**
* **Create Success:** Dismisses down to Mission Board [13].
* **Chain Create Success:** Dismisses to the *new* Mission Detail [14].
* **Edit Save Success:** Dismisses to the *existing* Mission Detail [14].
* **Cancel:** Dismisses to previous screen via explicit "✕" close button or drag-down gesture.

---

## 3. Information Architecture
**Input State (Default)**
1. **Modal Handle & Header:** Drag handle, Close button, Screen Title.
2. **Natural Language Input:** Large free-text input area (the primary focal point of this state).
3. **Submit CTA:** Action button to trigger CIA structuring.
4. **Example Suggestions:** Cycling example goals to inspire the user.

**Structured Result State (Create/Edit)**
1. **Modal Handle & Header:** Drag handle, Close button, Screen Title (*changes to "edit mission" in edit mode*).
2. **Chain Context Banner:** *Conditional.* Shows parent chain link.
3. **User Input Summary:** Collapsed view of the original text prompt.
4. **Mission Type Suggestion:** CIA-recommended classification (daily, weekly, side, main, life) + reasoning.
5. **Domain Assignment:** Auto-detected life domains + add/remove capabilities.
6. **Actions List:** CIA-generated tactical breakdown + add/remove/reorder capabilities.
7. **Milestones List:** Checkpoints with target dates + sequence indicators.
8. **Tracking Signals:** Suggested metrics with toggle controls.
9. **Connections:** Cross-domain correlations detected by CIA.
10. **Strictness Toggle:** Control over CIA's coaching intensity.
11. **Mission Preview:** Mini-card showing how the mission will look on the board, including progress, difficulty selector, and XP estimates.
12. **Chain Suggestions:** *Conditional.* Follow-up mission ideas generated by CIA.
13. **Primary CTA:** Commit action to save/create the mission.

---

## 4. Features and Capabilities
* **Natural Language Processing (NLP) Goal Creation:** Type a plain-text goal to auto-generate a full mission plan.
* **Mission Type Auto-Classification:** CIA suggests a scope/duration type (Daily, Weekly, Side, Main, Life) based on the prompt.
* **Domain Management:** Auto-assigns life domains; users can add up to 3 domains or remove existing ones.
* **Action List Management:** Full CRUD capabilities for generated actions, including inline text editing, drag-to-reorder, and deletion.
* **Milestone Management:** Inline editing for milestone titles and native date pickers for target deadlines. Includes visual sequence indicators (step *n* of *m*).
* **Tracking Signal Toggles:** Opt-in/opt-out toggles for specific metrics CIA will monitor (e.g., weekly distance, pace).
* **Cross-Domain Mapping:** CIA displays informational links to other life areas (non-editable).
* **Coaching Strictness Control:** Segmented control (Lenient, Balanced, Strict) dictating CIA's accountability behavior for this mission.
* **Live Mission Preview & Gamification:** A mini-card reflecting the mission's current state. Includes a difficulty selector (Easy, Moderate, Hard) that drives a live, honest XP estimate and "level-up" progress bar.
* **Chain Generation & Context:** If creating from a chain, auto-populates fields. If creating a new mission, CIA suggests logical follow-up missions that can be linked as a sequence.
* **Accessibility & Ergonomics:** All interactive targets meet 44x44pt minimums. Status changes (like difficulty) are conveyed via text label and glyph, never color alone.

## 7. Screen States
* **Input (Cold-Start):** Default state. Large text area, cycling examples, disabled submit CTA.
* **Text Entered:** Submit CTA enables.
* **Processing:** Input shrinks; three pulsing dots appear with status text.
* **Structured Result:** Full screen populated with editable CIA-generated modules.
* **Edit Mode:** Pre-populated from existing data; displays real-time progress and earned/remaining XP instead of zeroed estimates.
* **Loading (Edit Fetch):** Skeletons with radial/L-to-R shimmers that morph into drawn data.
* **Error (Timeout/API/Network):** Processing stops; input re-expands with original text preserved; error copy displayed with a "try again" option. XP bar degrades gracefully to just the range figure if curve data is missing.
* **Empty Actions:** Primary CTA disables (40% opacity); subtle hint appears below.
* **Offline:** Inputs accessible, but a banner appears if save is attempted.
* **Success:** CTA flashes a brief green glow, modal slides down, and haptic success notification triggers.

## 8. Interactions, Gestures, & Motion
* **Modal Dismiss:** Drag down >120pt (follows finger, snaps if threshold crossed) or tap "✕".
* **Text Input:** Tap summary to re-expand input.
* **Domain Actions:** Tap chip "✕" to remove; tap "+ add" to open picker dropdown.
* **List Actions (Actions/Milestones):** Tap text for inline edit. Tap "✕" to collapse/delete. Drag handle to reorder (haptic on lift/drop). Tap "+ add action" to insert a new focused row.
* **Toggles (Tracking, Chain):** Tap to slide toggle right/left (haptic).
* **Segmented Controls (Type, Strictness, Difficulty):** Tap to slide active background pill to new position.
* **Motion Choreography:** 
  * Input -> Processing: Height shrinks (120->0pt, 280ms), dots fade in.
  * Processing -> Result: Dots fade out, sections stagger in (fade + translateY, 80ms stagger).
  * Mission Preview: Ring draws first (520ms) -> XP counts up (280ms) -> XP bar eases to new width (520ms).
  * *Reduced Motion:* Staggers collapse to instant; fills/counts snap to final state.

## 10. Cross-Domain Hooks (Correlations & AI Insights)
* **Connections Module:** CIA explicitly maps how a goal in one domain affects another. (e.g., A fitness goal like running a half marathon will auto-generate a non-editable visual link to the "Nutrition" domain with the insight: "Fueling supports endurance training.").
* **Chain Suggestions:** CIA predicts future evolution of the current goal across the same domain (e.g., "Run a half marathon" triggers a suggestion to "Enter a 10K race" or "Complete a marathon").
* **Gamification Correlation:** Direct, live link between mission difficulty/scope and the user's holistic profile (XP and leveling system), showing exactly how this single mission impacts broader life progression.
