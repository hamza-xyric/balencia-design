full CIA-planning result state. Architecture-plan.md ADR-4 ("Decision — create") scopes

  `'Anxiety management'`; `'health_wellness'` → `'Health wellness'`; `'spiritual'` →
  `'Spiritual'`. This is a pure string transform — do not hand-write a lookup table, and
  do not special-case any of the 14 values.
- `buildCreateBody`: returns `{ title: input.title.trim(), category: input.category }`,

## Design requirements

### Section order (S15 simplified per ADR-4 / plan §4.4)

1. **Modal chrome** — header row: centered title `"New mission"`, a 44×44 close control
   (glyph `✕`, `accessibilityRole="button"`, `accessibilityLabel="Close"`) that calls
   `router.back()`. Balance the row with an equal-width invisible spacer on the opposite
   side so the title stays visually centered.
2. **Title input** — `GlassPillInput` with `label="Title"`,
   `placeholder="What do you want to achieve"`, `variant="text"`, bound to local `title`
   state, `disabled={createMutation.isPending}`.
3. **Category selector** — section label `"Category"`, then a wrapping row
   (`flexDirection:'row', flexWrap:'wrap'`) of 14 `ChipDomainTag`s, one per
   `VALID_LIFE_GOAL_CATEGORIES` entry, `label={categoryLabel(cat)}`,
   `active={category === cat}`, single-select (`onPress` sets `category` to that value;
   `onPress={undefined}` while `createMutation.isPending}` to make the chips
   non-interactive during submission — do not add a `disabled` prop, `ChipDomainTagProps`
   has none).
4. **Mission type** — section label `"Mission type"`, one `SegmentedTabs` bound to local
   `missionType` state (`'main' | 'side'`, default `'side'` — mirrors the server default
   `isPrimary ?? false`), options `[{key:'main',label:'Main mission'},
   {key:'side',label:'Side mission'}]`. This is the ONLY mission-type control this batch
   ships — the hi-fi's `[daily][weekly][side][main]` 4-way tab is CIA-suggested UI that
   belongs to the deferred planning flow; a manual create form has no basis to guess
   daily/weekly cadence, so only the two fields the DTO actually accepts (`is_primary`
   true/false) are offered.
5. **Submit** — `BalenciaButton` (`tone="primary"`, the default) reading
   `"Create mission"` normally / `"Creating mission"` while
   `createMutation.isPending`, `accessibilityLabel="Create mission"` (constant, does not
   change with pending state), `disabled={!validateCreateInput({title, category}).valid || createMutation.isPending}`.

### Motion (every animated element gated on `useReducedMotion()` from `@/components/balencia`)

- **Processing shrink** (S15: "Input→processing shrink (280ms)"): wrap the Title input +
  category selector + mission type block in one `Animated.View`. On
  `createMutation.isPending` transitioning true/false, animate a `transform: [{ scale }]`
  from `1` to `0.97` (pending) / back to `1` (not pending) via
  `Animated.timing(scaleValue, { toValue, duration: MotionDuration.processingShrink, easing: Easing.bezier(...MotionEasing.physical), useNativeDriver: true })`
  in a `useEffect` keyed on `[createMutation.isPending, reduceMotion]`. **Reduced-motion
  variant:** skip the `Animated.timing` call entirely and call
  `scaleValue.setValue(1)` — no shrink, but the form still visually disables (see below).
  Transform/opacity only — never animate a layout property here.
- **Disable, independent of motion**: `GlassPillInput`'s `disabled` prop, the chip
  `onPress={undefined}` guard, and the `SegmentedTabs onChange` no-op guard
  (`if (!createMutation.isPending) setMissionType(key)`) all apply regardless of
  `reduceMotion` — "reduced-motion: disable only" means the shrink animation is skipped,
  not that the disable behavior is skipped.
- **Save success** (S15: "Save success: 200ms glow-done swap + success haptic"): on a
  successful `mutateAsync`, fire
  `Haptics.notificationAsync(Haptics.NotificationFeedbackType.Success).catch(() => undefined)`,
  then: if `!reduceMotion`, animate a static-`greenSoft`-colored absolute overlay
  (`opacity` only, from `0` to `1`, `duration: MotionDuration.successSwap`,
  `easing: Easing.bezier(...MotionEasing.physical)`, `useNativeDriver: true`) layered over
  the submit button, and call `router.back()` in the animation's completion callback (so
  the swap is visible before the modal dismisses). If `reduceMotion`, skip the overlay
  animation entirely and call `router.back()` immediately after the haptic fires — text
  updates and haptics still occur, per the reduced-motion contract; there is no lingering
  static state worth rendering for a screen that is about to unmount.

### Honesty states

This screen has **no metrics, no XP estimate, no CIA suggestions, and no provenance
chips** — it is a plain manual entry form (ADR-4 explicitly defers the CIA-planning
result state that would introduce estimated/low-confidence values). The only "honesty"

message via `ToastBanner` (`tone="error"`) — never a generic "mission created" assumption,
never a fabricated retry countdown, and the form must stay fully editable (do not lock
inputs after an error — they are only disabled while `createMutation.isPending` is true,
which becomes false again automatically once the mutation settles).

### `mission-create-logic.ts`

```typescript
import { VALID_LIFE_GOAL_CATEGORIES } from '@/services/api/dto/goals';
import type { CreateLifeGoalRequestDto, LifeGoalCategory } from '@/services/api/dto/goals';

export interface CreateMissionValidation {
  valid: boolean;
  reason?: 'empty-title' | 'invalid-category';
}

export function validateCreateInput(input: { title: string; category: string }): CreateMissionValidation {
  const trimmedTitle = input.title.trim();
  if (trimmedTitle.length === 0) {
    return { valid: false, reason: 'empty-title' };
  }
  if (!VALID_LIFE_GOAL_CATEGORIES.includes(input.category as LifeGoalCategory)) {
    return { valid: false, reason: 'invalid-category' };
  }
  return { valid: true };
}

export function categoryLabel(category: LifeGoalCategory): string {
  const spaced = category.replace(/_/g, ' ');
  return spaced.charAt(0).toUpperCase() + spaced.slice(1);
}

export interface BuildCreateBodyInput {
  title: string;
  category: LifeGoalCategory;
  isPrimary?: boolean;
}

export function buildCreateBody(input: BuildCreateBodyInput): CreateLifeGoalRequestDto {
  const body: CreateLifeGoalRequestDto = {
    title: input.title.trim(),
    category: input.category,
  };
  if (input.isPrimary !== undefined) {
    body.is_primary = input.isPrimary;
  }
  return body;
}
```

```typescript
export function MissionCreateScreen(): JSX.Element {

  const [successOpacity] = useState(() => new Animated.Value(0));

      return;

      duration: MotionDuration.processingShrink,
      easing: Easing.bezier(...MotionEasing.physical),
      useNativeDriver: true,

          category: category as LifeGoalCategory,
          isPrimary: missionType === 'main',

        easing: Easing.bezier(...MotionEasing.physical),

      }).start(() => {
        router.back();
      });

        setToast(submitError.message);

            style={styles.closeButton}
            testID="mission-create-close">
            <Text style={styles.closeGlyph}>✕</Text>
          </Pressable>
        </View>

          style={styles.scroll}
          contentContainerStyle={styles.content}
          keyboardShouldPersistTaps="handled"
          showsVerticalScrollIndicator={false}>
          {toast ? <ToastBanner message={toast} tone="error" onDismiss={() => setToast(null)} /> : null}

          <Animated.View style={{ transform: [{ scale: inputScale }] }}>
            <GlassPillInput
              label="Title"
              value={title}
              onChangeText={setTitle}
              variant="text"
              placeholder="What do you want to achieve"
              disabled={createMutation.isPending}
              testID="mission-create-title"
            />

            <View style={styles.section}>
              <Text style={styles.sectionLabel}>Category</Text>
              <View style={styles.chipGrid}>
                {VALID_LIFE_GOAL_CATEGORIES.map((cat) => (
                  <ChipDomainTag
                    key={cat}
                    label={categoryLabel(cat)}
                    active={category === cat}
                    onPress={createMutation.isPending ? undefined : () => setCategory(cat)}
                    testID={`mission-create-category-${cat}`}
                  />
                ))}
              </View>
            </View>

                testID="mission-create-type"
```
