# 8. Data & honesty states
*This screen features minimal data, but adheres to the honesty invariant.*

**Metric: Password Strength**
- **Real:** Momentum bar actively fills with `--glow-you` orange as local validation rules are met. Provenance is implicit (local keystroke). 
- **Low-confidence:** *Not applicable.* Validation is binary and local, not a prediction.
- **Honest-null:** Empty state. Bar remains hidden (or 0% width, faded) until the user begins typing, avoiding pre-judgment of their input.

**Metric: Auth Token (System derived)**
- **Real:** Pushes user to next screen upon success.
- **Low-confidence:** *Not applicable.*
- **Honest-null:** Displays network error toast: "We had a hiccup. Please try again."

# 9. All states
- **Default / Empty:** Form fields visible with placeholder text. CTA is disabled (40% opacity, no haptic). Password progress bar is hidden.
- **Active / Focused:** Focused field displays a 1px `--glow-you` orange border + subtle orange glow. Hint text fades. Keyboard overlays; layout shifts to keep CTA visible.
- **Partially Filled:** CTA remains disabled until both email structure is valid and password passes all local checks.
- **Error (Single Field):** Failing field border turns 1px red (#ef4444), accompanied by an inline ✗ glyph and red caption text.
- **Error (System Toast):** Recovable error (network, existing account) displays as a glass-pill toast at the top of the screen.
- **Loading:** Form fields read-only (50% opacity). CTA text replaced by spinner and "Creating your account..." text. Width locked.
- **Success:** CTA briefly flashes a green glow (`--glow-done`), then stack pushes to next screen.
- **Offline:** CTA is dimmed. A SyncStatus banner reads "offline — check your connection."
- **Disabled:** BtnPrimary ignores touch events, sits at 40% opacity.

# 10. Motion & interaction
- **Entry:** Staggered fade-in and rise (12pt to 0) over 200ms for logo, heading, inputs, CTA, and footer. Respects `prefers-reduced-motion` (instant fade if toggled).
- **Feedback:** BtnPrimary uses standard press = scale .98 + darken 6%. GlassPillInputs use 150ms border color transition.
- **Keyboard:** Native viewport scroll automatically adjusts to keep the active field and CTA visible.
- **Glow behavior:** `--glow-you` on the FrostCard uses the 4s "breathe" ease to feel alive. The CTA success state overrides this with a 600ms `--glow-done` flash.
- **Haptics:** Light selection haptic on password mask toggle; medium success haptic on account creation; warning haptic on error toast.

# 11. Motivation-tier adaptation
- **Low Density:** Default state. Escape hatches ("Try without an account") are present to reduce pressure.
- **Medium Density:** If user dwells on the screen for >15s without typing, the copy under the heading fades in: "It takes ten seconds to start."
- **High Density:** If user arrives from a deep-link invitation (e.g., Pod invite), a micro AvatarStack visually attaches to the CTA: "Join your *pod*."

# 12. Accessibility
- **AA+ Contrast:** Paper-100 (#FEFAF3) on `--bg-base` (#0A0A0F) ensures >16:1 contrast. 
- **Targets:** All CTAs, social buttons, and the password toggle eye exceed the 44px minimum touch target.
- **Screen-reader:** Password eye icon is labeled "Show password" / "Hide password" dynamically. Form inputs use `textContentType: username` / `password` for iOS keychain autofill. Heading tagged as `H1`.
