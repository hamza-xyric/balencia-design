# Functional Content Brief: Mobile Progress Measurements & Trend Dashboard

## 1. Purpose
Enables users to manually log and track physical body metrics (weight, BMI, circumferences) and visualize their historical progress via trends. Integrates with the CIA (Coach) to transform raw measurement data into actionable health and fitness insights.

## 2. Entry and Exit Paths
*   **Entry Paths:** 
    *   Global "Domains" launcher -> Fitness -> Progress (`/progress`).
    *   "Today" Dashboard quick actions -> "Log Weight" / "View Progress" shortcut.
    *   CIA (Coach) generated insight hyperlinks (contextual deep-linking to specific metrics).
*   **Exit Paths:**
    *   "Log Measurement" flow -> Save -> Returns to Dashboard with success state.
    *   Tapping an AI insight -> Routes to `/ai-coach` (CIA Chat) for deeper analysis.
    *   Standard global navigation (Today, Domains, Community, Profile).

## 3. Complete Information Architecture (Mobile)
*Mobile IA inferred from web feature inventory to prioritize immediate logging and data visualization.*

*   **Global Header**
    *   Screen Title: "Progress"
    *   Contextual Action: "Add Measurement" (primary CTA)
*   **Timeframe Selector Module**
    *   Segmented Control: `Weekly` | `Monthly` | `Yearly` | `All Time`
*   **Hero Metric Summary (Focus View)**
    *   Current Focus Metric Display (e.g., Weight)
    *   Trend Indicator (Delta vs previous period)
    *   Interactive Line/Area Chart (Timeline visualization)
    *   Metric Sub-tabs (Swipeable): `Weight` | `BMI` | `Body Measurements`
*   **CIA Insight Strip**
    *   AI-generated text insight based on recent trends.
    *   Action link: "Ask CIA for details"
*   **Active Goals Module**
    *   Progress bars for active body goals (e.g., "Lose 5kg", "Hit target waist").
*   **Measurement Log History (List View)**
    *   Grouped by Date
    *   Metric, Value, and Data Source badge (Manual, Whoop, Oura, Apple Health, etc.)

## 4. Features and Capabilities
*   **Manual Data Logging:** Ability to input new weight, BMI, and standard body measurements (waist, chest, hips, arms, etc.).
*   **Metric Segmentation:** Dedicated, focused views for distinct body metrics to avoid chart clutter.
*   **Trend Visualization:** Graphing of data points over selectable timeframes (Weekly, Monthly, Yearly).
*   **Goal Progress Tracking:** Visual mapping of current measurements against predefined physical goals.
*   **Historical Data Audit:** Chronological ledger of all logged measurements.
*   **Automated Data Sync (Aggregated):** Background ingestion of weight/BMI data from connected Health Data Sources (wearables/apps).

## 6. Data Fields and Metrics
| Field / Metric | Source / Provenance | Notes |
| :--- | :--- | :--- |
| **Weight** | User Manual Input / Wearable Sync (Whoop, Oura, Apple Health, Samsung) | Display in user's selected unit (kg/lbs). |
| **BMI** | Auto-calculated (requires Height from Profile + Weight entry) | Needs height data from `/profile` or `/onboarding`. |
| **Body Measurements** | User Manual Input (Circumferences) | Requires numerical input fields (e.g., waist, chest). |
| **Delta/Trend** | System Calculated | Percentage or absolute change from prior entry/period. |
| **Sync Source Tag** | Provider Metadata | Badge indicating origin of data point. |

## 7. Screen States
*   **Loading (Syncing):** Skeleton charts; "Syncing health data..." indicator if querying wearables.
*   **Empty:** "Log your first measurement..." illustration and CTA.
*   **Error:** "Failed to sync health data. Check connection or try again later."
*   **Success:** Brief toast confirmation ("Measurement logged successfully").
*   **Stale Data:** Warning indicator if no new data has been synced/logged in >X days.
*   **Disconnected:** Inline banner prompting user to connect a health provider to automate tracking.
*   **Data Source Variants:** UI badges must adapt based on where the data point originated (e.g., Apple Health logo vs. "Manual" text).

## 8. Interactions, Gestures, and Motion
*   **Horizontal Swipe:** Transition between metric sub-tabs (Weight, BMI, Measurements).
*   **Vertical Scroll:** Navigate down through charts, goals, and historical lists.
*   **Chart Drag:** Tap and drag across timeline charts to reveal specific data point tooltips.
*   **Tap to Expand:** Selecting a log entry expands row to show time, source, and notes.
*   **Motion Intent:** Smooth, easing transitions when swapping metrics; progressive line drawing animation for the trend chart on screen load.

## 9. Free vs Premium Gating
*   **Free Tier:** Manual logging for all measurements; Weekly and Monthly trend visualization.
*   **Premium Tier:** Unlocking Yearly/All-Time trends; Deep health analytics; Access to the "CIA Insight Strip" (AI-driven pattern recognition based on body metrics). *(Inference: Basic tracking is free, AI analysis is premium).*

## 10. Cross-Domain Hooks
*   **CIA (AI Coach):** The insight strip acts as a bridge. Selecting it deep-links to the `/ai-coach` with the metric context pre-loaded (e.g., "Why did my weight spike?").
*   **Fitness & Nutrition:** Measurements correlate directly with workout intensity and calorie logs. Visual hooks may appear here if the user is actively on a nutrition or fitness plan.
*   **Wearables (Health Connections):** Direct dependency on `/whoop` (to be evolved into provider-neutral "Health Connections") for passive weight scale imports.
*   **Goals (`/goals`):** Bi-directional link; body composition goals created in the Goals life area reflect their progress bars here.
