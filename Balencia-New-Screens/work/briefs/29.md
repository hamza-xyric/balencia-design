# Functional Content Brief: Meal Detail / Food Logger

### 1. Purpose
Displays the nutritional breakdown of a planned or logged meal, and provides a fast, search-first interface to log new food items. It operates via entry-point-determined modes: Meal View (reading macros) and Food Logging (adding items).

### 2. Entry and Exit Paths
*   **Entry Paths:**
    *   Meal View Mode: Tapping a meal row on the Nutrition Dashboard (Screen 28).
    *   Food Logging Mode: Tapping the FAB on the Nutrition Dashboard (Screen 28).
    *   Deep-link from CIA Chat (Screen 09).
    *   Action card from the Home Screen (Screen 12).
*   **Exit Paths:**
    *   Back button / swipe edge: Pops stack back to Screen 28.
    *   "Done" button: Saves logged items and pops stack to Screen 28.
    *   CIA insight tap: Navigates to CIA Chat (Screen 09).

### 3. Complete Information Architecture
The screen uses a Multi-Mode Pattern (entry-point determined, not sequential). The header remains stable while the content crossfades (520ms) when switching from Meal View to Food Logging via "Edit".

**Meal View Mode (Top-to-Bottom):**
1.  **Detail Header:** Back chevron, Meal Name (e.g., "Lunch"), "Edit" text button.
2.  **Meal Photo:** (Conditional) Visual representation.
3.  **Meal Info:** Meal Name (e.g., "Chicken salad wrap"), Date + Time metadata.
4.  **Nutrition Breakdown Card:** Macro donut chart, reference scale text, and 3 macro bars (Protein, Carbs, Fat).
5.  **CIA Insight Card:** AI nutritional commentary.
6.  **Ingredients List Card:** Itemized breakdown with per-ingredient macros and ambient micro-bars.

**Food Logging Mode (Top-to-Bottom):**
1.  **Detail Header:** Back chevron, "Log food" title, "Done" text button.
2.  **Search Input:** Primary interaction field with integrated scanner icons.
3.  **Meal Type Selector:** Segmented control (Breakfast, Lunch, Dinner, Snack).
4.  **Recent / Frequent Foods:** Quick-add lists (default state).
5.  **Search Results:** Dynamic list replacing recent/frequent (active search state).
6.  **Manual Entry Form:** Inline expandable form for custom entries.

### 4. Features and Capabilities
*   **Macro Visualization:** Honest donut chart sized by *calorie share* (not grams), with tap-to-isolate micro-interactions. Below it, continuous macro bars sized by absolute magnitude vs. a reference scale (daily target or meal max).
*   **Per-Ingredient Micro-Bars:** Ambient, 3-segment calorie-share visualization for each ingredient.
*   **Search-First Logging:** Debounced food database search returning results after 2+ characters.
*   **Quick-Add List:** Browse recent and frequent foods, complete with leading status dots indicating relative calorie magnitude.
*   **Expandable Quick-Add:** Tapping `[+]` on a food row expands it inline to select portion size and view live macro updates before confirming.
*   **Manual Food Entry:** Inline form to input food name, amount, unit, and macros (Cal, Protein, Carbs, Fat).
*   **Barcode Scanner:** Half-sheet camera overlay for instant food lookup via barcode.
*   **Receipt Scanner:** Full-frame camera overlay using AI OCR to extract multiple food items from a receipt, returning a checklist for the user to verify before bulk-adding.
*   **Time-Based Defaults:** Auto-selection of meal type (Breakfast, Lunch, etc.) based on the device's local time.

### 6. Data Fields and Metrics
| Field / Metric | Data Source |
| :--- | :--- |
| Meal Name & Time | User input / Meal plan API |
| Total Calories (e.g., 520 cal) | Derived (Sum of ingredient macros) |
| Macro Split (Protein, Carbs, Fat %) | Derived (Calorie share: P×4, C×4, F×9) |
| Absolute Macros (e.g., Protein 35g) | Derived (Sum of ingredient grams) |
| Ingredient Names & Portions | Food database (API) / Meal plan |
| Per-Ingredient Macros (cal·P·C·F) | Food database (API) |
| Search Results (Name, Cal, Protein) | Food database (API) |
| Personal History (Recent/Frequent) | User local history / cloud sync |

### 7. Screen States
*   **Cold-start (Meal View):** Planned meal un-logged. Donut renders as a faint full-ring outline ("Log this meal to see its split"). Macro bars at zero.
*   **Cold-start (Food Logging):** Day-1 user. Search focused. Recent foods replaced with invitational copy. Frequent hidden.
*   **Loading:** Depth-preserving skeleton shimmer that morphs into drawn data (donut arcs draw, macro bars rise). CIA text: "CIA is reading your meal — one moment."
*   **Empty / Partial:** Search yields 0 results. Missing ingredient macros render as "0" (no visual emphasis).
*   **Error:** "Could not load meal data" (retry), "Search failed. Try again.", "Not found in database. Try manual entry?"
*   **Offline:** Cached data shown. Search disabled ("You're offline — search is unavailable. Add manually or try later."). Scanners disabled. Pull-to-refresh dimmed.
*   **Motivation Variants:**
    *   *Low:* Simplified macros (cals only). Search shows recent only. CIA copy: "Any tracking is good tracking."
    *   *Medium:* Default experience (all features).
    *   *High:* Micronutrient breakdowns (fiber, sugar). Pre-expanded manual entry. Portion estimator tool.

### 8. Interactions, Gestures, and Motion
*   **Screen Entrance:** Stack push slide-in (280ms).
*   **Mode Transition:** Content crossfades below stable header (520ms, ease-out-soft).
*   **Meal View Entrance:** Donut arcs sweep clockwise from 12 o'clock (largest to smallest, 1200ms). Hub counts up to total calories (520ms). Macro bars rise with 80ms stagger. Ingredients fade in with 40ms stagger.
*   **Food Logging Entrance:** Elements fade in sequentially: Search -> Selector -> Lists (280ms each, 40ms stagger).
*   **Quick-Add Expand:** Tap `[+]` -> Row height expands 48pt to 120pt (280ms). Portion dropdown and confirm button fade in.
*   **Quick-Add Confirm:** Tap "Add to [meal]" -> Row collapses. Green checkmark overlay scales and fades (600ms). "+25 XP" toast slides down. Success haptic.
*   **Manual Entry Expand:** Tap "Add manually" -> Form height expands 0 to 320pt (520ms).
*   **Scanners:** Slide up from bottom (280ms). Drag down or tap X to slide down and dismiss.
*   **Accessibility/Motion Preferences:** Honors `prefers-reduced-motion`; donuts/bars render instantly at final state, entrances snap to full opacity.

### 9. Free vs. Premium Gating
*No explicit premium gating is defined for core food logging in this screen.* The functional spec notes that basic journal writing/search is free, but specific AI scanner capabilities may be subject to broader app-wide premium constraints (e.g., Receipt Scanner AI OCR), though not explicitly gated in this UI.

### 10. Cross-Domain Hooks
*   **CIA Correlations:** Tapping the CIA Insight card deep-links to CIA Chat (Screen 09) with the specific meal's nutrition context pre-loaded.
*   **Daily Target Integration:** When a nutrition goal exists, the donut backplate features a thin arrival arc showing this meal's share of the day, and macro bars scale proportionally against the daily target limit.

*Note on Contradiction Resolution:* The source documents contained a contradiction regarding the macro donut chart. The original wireframe sized donut slices by raw gram weight (P 35g / C 40g / F 15g) despite the hub displaying total calories. This brief adopts the corrected, "honest" visualization approach: slices are sized strictly by calorie share (Protein 32% / Carbs 37% / Fat 31%), with the unattributed calorie gap explicitly disclosed in the sub-text. All references to the old coach persona ("SIA") have been mapped to "CIA" as requested.
