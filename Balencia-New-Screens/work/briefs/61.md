# Functional Content Brief: Reminders & Tasks

## 1. Purpose
Acts as the user's centralized personal task manager and reminder hub. It answers "what do I need to do, when is it due, and what should I not forget?" by tracking health-related tasks and time-based reminders through a checklist-first experience bridging intention with execution.

## 2. Entry and Exit Paths
*   **Entry Paths (Stack Push):** 
    *   Me Main [17] via quick link grid
    *   Schedule [41] via "tasks" shortcut
    *   CIA Chat [09] via deep-link card ("here are your tasks for today")
    *   Home Screen [12] via task-related action cards
*   **Exit Paths:**
    *   **Primary:** Back button (stack pop) to previous screen.
    *   **Secondary:** Task Detail modal (create/edit), Reminder Detail modal (create/edit), Schedule [41] via "view in calendar" (stack push), CIA Chat [09] via CIA suggestion tap (tab switch).

## 3. Information Architecture (Top-to-Bottom)
1.  **Screen Header:** Title ("Reminders & tasks") + Back navigation.
2.  **Today's Tasks Section:** 
    *   *Completion Module:* Continuous progress bar + KPI numeric tiles (Done/Open).
    *   *Checklist:* Prioritized task rows with categories, due times, and checkboxes.
3.  **Upcoming Sections:** Task rows grouped by future dates (Tomorrow, This Week, Later).
4.  **Active Reminders Section:** Eyebrow with active count roll-up + enabled/disabled reminder rows.
5.  **Completed Tasks Section:** Collapsible list of done items.
6.  **CIA Suggestions Card:** AI-generated task suggestions based on goals/schedule.
7.  **Floating Action Button (FAB):** Persistent action to create new tasks/reminders.

## 4. Features and Capabilities
*   **Task Management:** Create, edit, complete, and delete personal health tasks. Supports categorizing via domains, prioritizing (low, medium, high), and assigning due dates/times. 
*   **Recurring Tasks:** Set recurrence patterns (daily, weekly, monthly, custom) with specific day-of-week selectors and optional end dates.
*   **Reminders System:** Create time-based notifications. Supports advance warnings ("at time", "5/15/30 min before", "1 hour before"), snooze durations, and auto-repeat if missed.
*   **Multi-Channel Notifications:** Configurable delivery channels per task/reminder (Push, Email, SMS).
*   **Smart Suggestions (CIA):** AI-driven contextual task recommendations (e.g., proposing a stretch before an appointment) that can be instantly converted to tasks or queried in chat.
*   **Offline Queuing:** Local caching of tasks/reminders. Users can complete tasks or toggle reminders offline; changes queue and sync automatically upon reconnection.
*   **Motivation Adaptation:** UI dynamically adjusts based on user motivation states (Low motivation hides past effort and limits suggestions; High motivation shows detailed metadata and stat expansions).

## 6. Data Fields and Metrics
*   **Today's Completion Ratio:** `done ÷ total` tasks for today. *(Source: `remindersTasks.today`)*
*   **Done Count / Open Count:** Today's completed tasks vs. remaining tasks. *(Source: `remindersTasks.today` flags + live `completed` state)*
*   **Task Fields:** Title, Description, Category (Domain), Priority (Low/Med/High), Due Time, Recurrence Pattern, Color Assignment, Tags. *(Source: `user_tasks` table)*
*   **Reminder Fields:** Title, Message, Type (One-time/daily/weekly/custom), Trigger Time, Snooze rules, Repeat-if-missed toggle, Active Channels, Timezone. *(Source: `scheduled_reminders` table)*
*   **Active Reminders Roll-up:** "N of M on" (e.g., "3 of 4 on"). *(Source: `reminderStates` toggles)*
*   **Last Synced Timestamp:** E.g., "Last updated 10 minutes ago". *(Source: Local cache metadata)*

## 7. Screen States
*   **Cold-start / Day 1:** Empty state card with clipboard icon. CIA card appears below if onboarding goals exist. Completion bar is hidden (requires ≥1 task).
*   **Loading:** Depth-preserving skeletons. Pill-shaped skeleton for completion bar, number-bar skeletons for KPIs, and full-row shimmer placeholders for lists.
*   **Error (API Failure):** Suppressed visualizations (no fake 0%). Shows specific error icon, copy ("Couldn't load your tasks"), and a "Retry" CTA. Falls back to cached data if available.
*   **Offline:** Orange-bordered offline banner. Cached lists rendered at full opacity. Action controls (FAB, toggles) are dimmed/disabled with inline "queued" or "saving..." labels on interaction.
*   **All Done (Success):** Completion bar reaches 100% with a green arrival glow. "OPEN" reads 0. All task text is muted/struck through. Expanded completed section shows "All done for today."
*   **Disabled Reminder:** Toggle is visually off, title is muted, next-trigger time is hidden, replaced with "paused" text.
*   **Overdue:** Task due time text turns red, left priority bar pulses gently.
*   **Motivation Variants:** 
    *   *Low:* Simplified list (1-2 items), collapsed upcoming, hidden completed section.
    *   *High:* Expanded metadata, detailed schedules, expanded completed stats.

## 8. Interactions, Gestures, and Motion Intents
*   **Taps:** Toggle checkboxes, open detail modals (Task/Reminder body tap), expand/collapse completed section, trigger FAB. 
*   **Swipes:** 
    *   *Swipe right (>30%):* Complete task (triggers green reveal background).
    *   *Swipe left:* Reveal edit/delete quick actions.
    *   *Horizontal swipe (CIA Card):* Paginate between multiple AI suggestions.
*   **Long-press (>500ms):** Enter drag-and-drop reorder mode within a section.
*   **Pull-to-refresh:** Force fetch from API.
*   **Motion/Choreography:** 
    *   Staggered fade-in for sections on mount (Today -> Upcoming -> Reminders -> CIA).
    *   *Completion Bar:* Fills from 0 to ratio (520ms ease-flow), draws first, then KPI numbers count up.
    *   *Task Completion Animation:* Checkmark stroke draws in, text mutes, row slides down to the Completed section after a brief delay.
    *   *FAB:* Scales in on mount, fades out on scroll down, fades in on scroll up/stop.
    *   *Reduced Motion:* All animations bypass transitions and render final static states instantly.

## 9. Free vs Premium Gating
*   **Free Tier:** Basic task management capabilities. Strictly limited to a maximum of 5 active reminders.
*   **Premium (Plus) Tier:** Unlocks unlimited task creation, unlimited active reminders, CIA smart suggestions engine, and multi-channel notification delivery (Push + Email + SMS).

## 10. Cross-Domain Hooks & AI Insights
*   **CIA Suggestion Engine:** AI scans upcoming schedule gaps, user habits, and active goals to proactively surface contextual suggestions (e.g., medical prep, fitness stretching) directly on the screen.
*   **Schedule Integration:** Tasks tagged to specific times or days correlate with the Schedule [41] calendar grid. Users can cross-navigate via the "view in calendar" exit path.
*   **Goal Linkage:** Tasks can be linked directly to specific user Goals (navigates to Goal Detail [14] via tap).
*   **Domain Categorization:** All tasks are tagged to health life areas (Wellbeing, Nutrition, Fitness), allowing overarching tracking across the Balencia ecosystem.
*   **Notification History:** Reminders configured here directly seed and link to the global Notification History [24] screen.

## 11. Source Contradictions & Flags
*   *High Priority Task Color:* The original spec outlines `#F44336` (red) for high-priority task indicators. The prototype route `/features/reminders` renders this in `stalled-amber`. The spec explicitly flags this for the visual redesign: *"either way it must stay glyph-paired status, never data ink."* Visual designers should standardize the urgency color and pair it with the mandated `⚠` warning glyph.
