# 2. Purpose
The daily command center and primary entry point for returning users. It answers "What is worth my attention today?" by curating a cross-domain, AI-driven action list, visualizing whole-life balance, and aggregating live vitals. It anchors the user's day in quiet premium aesthetics rather than dashboard anxiety.

# 3. Entry & exit
- **Entry Paths:** Splash screen (returning users) or Initial Plan Summary (first-time users).
- **Exits:** 
  - **Stack push:** Goal/Mission Detail, RPG Character, Schedule/Calendar, Create Mission, Domain Dashboards.
  - **Tab switch:** CIA Chat, Goals List.
  - **Deep-link:** Action cards route to native features (e.g., Breathing, Water, Journal).

# 9. All states
- **Default:** Populated layout with live metrics, radar, and curated actions.
- **Skeleton:** Depth-preserving skeletons. Radar spokes draw first (L→R stroke). Metric cards show ghost lines morphing into sparklines. Staged captions read "checking your sleep…".
- **Empty (Cold Start / Day 1):** Radar renders as faint full polygon with ghosted spokes. Hub reads "Building your balance". Displays 1-2 starter actions and a "Create your first mission" prompt. Schedule/insights hidden.
- **Error (Partial Sync / Offline):** `OfflineBanner` sits below TopBar reading "You're offline — showing your last sync." Cached metrics retained. Radar ghost spokes for missing domains (no-data ≠ 0).
- **Success (All-Done):** Action stack replaced by `CelebrationOverlay` or inline quiet state: centered green check, "Nothing left today," "Solid day. You earned it." Momentum bar arrives fully green (`--glow-done`).
- **Disabled:** N/A globally. Local `BtnPrimary` disabled at 40% opacity if action requires network sync and device is offline.

# 10. Motion & interaction
- **Physical easing:** `cubic-bezier(0.32, 0.72, 0, 1)` for all card entrances and sheet springs (never linear).
- **Feedback duration:** 150-250ms for UI target feedback (button presses scale .98, glow brightens).
- **Choreographed entrance:** Radar polygon strokes draw itself -> Star dots stagger in -> Hub number counts up -> Sparklines draw -> Momentum bar fills -> Cards fade-up on scroll.
- **Glow behavior:** `--glow-cia` breathes softly (4s ease infinite loop) on the Hero card. Dims to 30% opacity when scrolled away from.
- **Haptics:** 
  - *Light impact:* Checkbox taps, list scrolls.
  - *Medium impact:* Mood chip selection, pull-to-refresh release.
  - *Success/Warning:* Action complete vs. swipe-back.
- **Reduced-motion path (`prefers-reduced-motion: reduce`):** Choreographed entrances become instant. Radar simply fades in. Glow breathing stops, becomes static color.
