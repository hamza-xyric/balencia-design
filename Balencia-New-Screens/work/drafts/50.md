### 2. Purpose
A focused utility screen for users to view and update core identity data (name, avatar, DOB, demographics). It acts as the foundational data layer feeding the broader CIA (Whole-Life AI Coach) memory and personalized scheduling. Honors the "honest" north star by demanding explicit typed confirmation for irreversible data deletion, and the "premium" north star through tactile, glass-driven form architecture.

### 3. Entry & exit
- **Entry:** Pushed transition from "Me Main" screen tapping the avatar or profile row.
- **Primary exit:** Return to "Me Main" via top-left back chevron, iOS edge-swipe, or automatic stack pop upon successful save.
- **Secondary exit:** System root reset to Sign In (triggered exclusively after successful account deletion).
- **System exits:** Native image picker (modal/bottom sheet) and native date picker (bottom sheet/spinner).

### 4. Layout anatomy
The screen uses a vertical `ScrollView` with a 24px outer padding. The layout is anchored by a sticky header at the top and a sticky bottom action zone, keeping the primary CTA always visible above the fold.

**Regions top-to-bottom:**
1. **Navigation Header:** Sticky TopBar for orientation and exit.
2. **Avatar Section:** Centralized identity anchor with edit affordance.
3. **Completeness Module:** Single glass hero card tracking profile deltas.
4. **Identity Fields:** First and Last Name inputs.
5. **Contact Fields:** Read-only email and Phone input.
6. **Demographics Fields:** DOB, Gender, Timezone inputs.
7. **Destructive Zone:** Account deletion link.
8. **Bottom Action Zone:** Sticky glass container holding the primary save CTA.

### 8. Data & honesty states
Every metric on this screen adheres to the strict 3-state honesty invariant. 

**Metric: Profile Completeness (N of M complete)**
1. **Real:** "6 of 8 complete" + `ChipProvenance`: `you logged`. (Bottom-anchored `--glow-cia`).
2. **Low-confidence:** *Not applicable.* Completeness is calculated client-side from explicit local input keys; it is either filled or null. No estimation logic is permitted.
3. **Honest-null:** "0 of 8 complete" + `next: add a photo` (No fabricated baseline stats).

**Metric: Avatar Status**
1. **Real:** Image renders + `ChipProvenance`: `via camera roll`.
2. **Low-confidence:** *Not applicable.* Cannot partially sync a media file.
3. **Honest-null:** Empty state avatar ring + `tap to add photo` (HonestNullState visual).

**Metric: Primary Contact (Email)**
1. **Real:** `user@mail.com` + `ChipProvenance`: `email verified`.
2. **Low-confidence:** *Not applicable.* Inherited purely from backend auth token.
3. **Honest-null:** *Not applicable.* An account cannot exist in the app database without an auth email.

### 9. All states
- **Default:** Form is cleanly mounted. Scroll position top. CTA button `disabled`.
- **Skeleton:** `SkeletonState` sweeps `--surface-3` blocks over avatar, completeness card, and input geometries.
- **Empty:** `EmptyState` layout appearing on Day 1 with focus immediately snapped to the First Name input.
- **Error:** 
  - *Validation:* Input ring flashes `#FF5E00`, subtext reads inline error string.
  - *Network:* Form remains populated (offline editing enabled), `OfflineBanner` docks under TopBar, CTA disabled.
- **Success:** `BtnPrimary` flashes `--glow-done` (Forest Green) + subtle haptic. Pauses 250ms. Executes stack pop to Me Main.
- **Disabled:** Save changes button locked at 40% opacity. Tapping yields no response, but screen-reader reads "Save disabled, 2 fields left to complete." 

### 10. Motion & interaction
- **Physical Easing:** Standard `cubic-bezier(0.32, 0.72, 0, 1)` for sheet presentations and scroll lock.
- **Feedback Latency:** Input focus rings snap in 150ms. Avatar upload success pulse fires in 200ms.
- **Glow Behavior:** `Breathe` animation on the Completeness GlassStatCard (4s ease infinite) to signal CIA is actively learning from the user's input. Glow opacity shifts from 55% to 70%.
- **Haptics:** `IOSelectionFeedbackGenerator` light tap on every ListRow tap (Date/Gender/Timezone) and keyboard "Next" cycle. Heavy impact on successful account deletion confirmation.
- **Reduced Motion Path:** Entrance staggers and glowing breathe cease instantly. Progress bar wipes instantly to final width on load. Success stack pop removes the pause delay.

### 11. Motivation-tier adaptation
- **Low Density (Chillax):** 32px section rhythm. Focus strictly on First Name, Last Name, and Avatar. Timezone and DOB collapse behind a single "More details" `ListRow` to reduce visual friction. 
- **Medium Density (Default):** 24px section rhythm. All core fields (Identity, Contact, Demographics) are expanded in standard scroll view.
- **High Density (Power User):** 16px section rhythm. Form acts as a rapid audit list; focus borders lock sharply without soft transitions. Completeness card shrinks to a sticky top micro-progress bar so the user can rapidly tab through fields with external keyboard support.
