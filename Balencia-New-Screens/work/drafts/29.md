# 1. Header
- **Screen ID:** 29
- **Name:** Meal Detail / Food Logger

# 2. Purpose
Displays the true nutritional breakdown of a planned or logged meal (sized accurately by calorie share, not raw weight), and provides a fast, search-first interface to log new items. The screen operates via an entry-point-determined Multi-Mode Pattern: Meal View (reading macros) and Food Logging (adding items).

# 3. Entry & exit
- **Entry Paths:** 
  - Tapping a meal row on the Nutrition Dashboard (Screen 28) > Opens Meal View.
  - Tapping the FAB on the Nutrition Dashboard > Opens Food Logging.
  - Deep-link from CIA Chat (Screen 09) > Opens Meal View.
  - Action card from the Home Screen (Screen 12) > Opens Food Logging.
- **Exit Paths:**
  - Back chevron / edge swipe: Pops stack to Screen 28.
  - "Done" button: Saves logged items and pops to Screen 28.
  - CIA insight tap: Deep-links to CIA Chat (Screen 09).

# 5. Components
*   **TopBar**: Stable navigation.
*   **GlassStatCard** (`hero`): Used to frame the Meal Detail & metadata if no photo is present.
*   **SolidCard**: Data container for the Macro Breakdown and Ingredients list to ensure chart legibility.
*   **GlassPillInput** (`search` variant): Primary interaction in Food Logging mode.
*   **SegmentedTabs**: Meal type selector in Food Logging mode.
*   **ListRow**: Used for Ingredients and Quick-Add recent foods.
*   **ProgressRing**: Powers the calorie-share donut chart.
*   **ProgressBar**: Macro bars and per-ingredient micro-bars.
*   **CIAInsightCard**: Coach commentary with deep-link action.
*   **FABQuickLog**: Global logging button present on this Today-tab screen.
*   **NEW: MacroDonutViz**: Custom wrapper around `ProgressRing`. Rationale: The brief mandates an *honest* visualization where slices are sized strictly by calorie share (P×4, C×4, F×9), explicitly discarding the deceptive raw-gram sizing. This requires a dedicated math component to resolve macro percentages before passing them to the ring.

# 8. Data & honesty states
*Contradiction Resolved: Wireframes originally sized the donut by raw grams while displaying calories. Every macro is now calculated and displayed by honest calorie share. Unattributed calories are explicitly disclosed.*

**Metric 1: Total Calories (e.g., 520)**
1.  **Real:** "520 cal" + Provenance chip `via WHOOP` or `you logged`.
2.  **Low-confidence:** "520 cal" (text at 64% opacity) + Provenance chip `estimated · low confidence`.
3.  **Honest-null:** Empty donut outline + `Log this meal to see its split`.

**Metric 2: Macro Split (Protein, Carbs, Fat %)**
1.  **Real:** "Protein 32%" + ProgressBars sized by P×4, C×4, F×9. Chip: `derived`.
2.  **Low-confidence:** "Protein 32%" (muted) + label `estimated macros`.
3.  **Honest-null:** Macro bars at absolute zero. Label: `Macros not logged`.

**Metric 3: Unattributed Calories (The "Honesty Gap")**
1.  **Real:** Subtext "435 from macros" (acknowledging the 85 cal gap honestly without hiding it). 
2.  **Honest-null:** N/A (field simply hidden if math equals exactly 100%).

**Metric 4: Per-Ingredient Macros**
1.  **Real:** "Chicken salad wrap" + "220 cal" + Chip `verified database`.
2.  **Low-confidence:** "220 cal" muted + `portion estimated`.
3.  **Honest-null:** "0" value, zero visual emphasis (no faked charts).

# 9. All states
- **Default:** Meal View or Logging Mode based on entry point. Data populates normally.
- **Skeleton:** Depth-preserving shimmer. Donut chart renders as an axis + ghost line. Macro bars and ingredient lists show sweeping `--surface-3` blocks. CIA card reads: "CIA is reading your meal — one moment."
- **Empty (Meal View):** Planned meal un-logged. Honest null state for the donut. Copy: `Log this meal to see its split`.
- **Empty (Food Logging):** Day-1 user. Search focused. Copy: `No recent foods yet. Search or scan to get started.`
- **Error:** Meal load failure: `Could not load meal data` + BtnSecondary retry. Search failure: `Search failed. Try again.` Scanner failure: `Could not read receipt. Try a clearer photo?`
- **Success:** Quick-add logged. Row collapses. Green checkmark overlay scales/fades. `+25 XP` toast slides down. Success haptic.
- **Disabled:** Offline mode. Search input disabled. Copy: `You're offline — search is unavailable.` Scanners greyed out. Pull-to-refresh dimmed.

# 10. Motion & interaction
- **Screen Entrance:** Stack push slide-in (280ms, physical ease-out).
- **Mode Transition:** Content crossfades below the stable TopBar header (520ms, ease-out-soft).
- **Meal View Entrance:** Donut arcs sweep clockwise from 12 o'clock (largest to smallest, 1200ms). Hub counts up to total calories (520ms). Macro bars rise with 80ms stagger.
- **Food Logging Entrance:** Elements fade sequentially: Search -> Selector -> Lists (280ms each, 40ms stagger).
- **Quick-Add Expand:** Tap `[+]`. Row height expands 48pt to 120pt (280ms). Portion dropdown and confirm button fade in.
- **Scanners:** Slide up from bottom (280ms). Drag down or tap X to dismiss.
- **Haptics:** Light success haptic on quick-add confirm. Medium haptic on scanner success.
- **Reduced Motion:** Honors `prefers-reduced-motion`. Donuts and bars render instantly at final state. Entrances snap to full opacity. No counting up.

# 11. Motivation-tier adaptation
- **Low Density:** Simplified visuals (Calories only). Search hides the database and shows Recent foods exclusively to minimize friction. CIA copy adapts: `Any tracking is good tracking.`
- **Medium Density:** Default experience. Full macro visualization (Protein, Carbs, Fat). Full search, barcode scanner, and standard ingredient breakdowns.
- **High Density:** Pre-expanded manual entry form. Adds Micronutrient breakdowns (Fiber, Sugar) beneath core macros. Adds a live AI Portion Estimator tool to the scanner UI.

# 12. Accessibility
- **AA+ Contrast:** Paper-100 (`#FEFAF3`) on `--surface-2` data cards. Paper-50 on `--bg-base`. No low-confidence grey dropping below 4.5:1.
- **Targets:** All glyphs (Edit, Done, Back, `+`) sized to 44x44px minimum touch targets.
- **Screen-reader labels:** Glyph-only scanner buttons and `+` affixed with `aria-label` (e.g., "Add food manually", "Scan barcode").
- **Dynamic Type:** Text scales up to 200%. Macro donut charts and progress bars resize fluidly without clipping labels.
