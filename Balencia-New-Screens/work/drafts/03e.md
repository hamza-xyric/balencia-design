# 2. Purpose
To verify the user's phone number and activate the optional, proactive WhatsApp coaching channel driven by the CIA persona. It acts as a frictionless, skippable bridge between initial consent and the core CIA onboarding conversation. 

# 3. Entry & exit
- **Entry Paths:** Stack push from Consent screen [03c] (User toggled WhatsApp coaching on).
- **Primary Exit:** Stack push to CIA Onboarding Conversation [07] (Phone successfully verified via code).
- **Secondary Exit:** Stack push to CIA Onboarding Conversation [07] (User taps "skip" or back-taps out of Phase 2).
- *Correction to Brief:* The brief specifies "no scrolling" to fit small devices like iPhone SE. On a 390px reference frame, this creates massive, unpremium whitespace and violates the 24/32px section rhythm. I am applying a standard native scroll container to the screen body, ensuring elegant spacing on modern devices while gracefully compressing on smaller viewports.

# 4. Layout anatomy
The layout uses a vertically scrolling body anchored by a static header and floating bottom action area. Regions top-to-bottom:
1. **Top App Bar:** Transparent over the background. Holds skip (Phase 1) or back + skip (Phase 2).
2. **Brand Anchor:** Static Balencia wordmark, immune to crossfade phase transitions.
3. **Value / Hero Region:** Phase-dependent headings, subtitles, and privacy reassurance.
4. **Input Group:** GlassPillInput for phone (P1) or digit boxes for SMS (P2).
5. **Auxiliary Region:** Value preview list (P1) or Resend timer (P2).
6. **Fixed Bottom CTA Area:** Primary action button floating above the device home indicator.

# 5. Components
- **TopBar** (Catalog) - Transparent variant; 44px targets for back/skip.
- **GlassPillInput** (Catalog) - Container for the country code and phone number input.
- **ChipProvenance** (Catalog) - Used as a privacy/explicit consent indicator next to the input.
- **BtnPrimary** (Catalog) - Fixed at the bottom.
- **NEW: OtpBoxGroup** - A 6-digit input container. Rationale: Native mobile OTP inputs require an invisible underlying text field mapped to 6 static UI boxes to properly handle iOS/Android auto-fill, paste logic, and backspace chaining without triggering keyboard flickering.
- **NEW: TimerLink** - A hybrid BtnGhost and ProgressRing component. Rationale: The brief requires a circular progress indicator wrapping a text countdown link. ProgressRing does not natively wrap text/buttons in the catalog.

# 6. Visual treatment
- **Glass Tier:** Selective glass is used. The TopBar gains a `.glass-pill` backdrop on scroll. The inputs are `.glass-pill`. The bottom CTA sits on a solid `--surface-1` plate to separate it from the scrollable content. No `.glass-card` is used, maintaining a clean utility aesthetic rather than a dashboard one.
- **Semantic Glow:** 
  - **Input Focus (`--glow-you: #FF5E00`):** Active inputs bleed a 12px orange glow, meaning *user effort and attention*. 
  - **Verification Success (`--glow-done: #34A853`):** A 250ms flash on the CTA upon correct code entry, meaning *done/completion*.
- **Background Atmosphere:** Base `--bg-base` (#0A0A0F) with the mandatory warm radial glow top-center, paired with a 3% soft-light grain overlay. Because this is a CIA-specific enrollment screen, a subtle purple pool (`rgba(127, 36, 255, 0.08)`) anchors the bottom center near the CTA.
- **Hero Type Moment:** The Phase 1 heading "Get *CIA* on WhatsApp" is Neue Montreal Medium 34px, with "CIA" set in Tiempos Medium italic.

# 8. Data & honesty states
This screen does not display historical metrics, but it handles dynamic system data (timers/inputs). Honesty invariant is applied to network/state communication:
- **Real (Verified):** "Code sent. Check your messages." (Displayed via ChipProvenance state on inputs).
- **Low-Confidence (Network Latency):** Loading states use transparent language. CTA shows spinner; overlay copy: "Sending your code — one moment." 
- **Honest-Null (Spam/Fraud Lockdown):** Error (Too Many Attempts): "Too many attempts. Please try again in 5 minutes." Inputs are locked; the countdown timer is hardcoded to display the exact remaining lockout time without estimation.

# 9. All states
- **Default (P1):** Empty phone input, country code auto-detected, CTA disabled (40% opacity).
- **Default (P2):** SMS boxes empty, circular countdown timer active, verify CTA disabled.
- **Skeleton (Loading):** BtnPrimary shows spinner, width locked. SMS boxes show 1.2s sweep shimmer.
- **Empty:** Handled by Default (P1) state.
- **Error (Input):** Red borders (`#ef4444` at 60% opacity) on inputs; shake animation (3 oscillations, 150ms) for wrong SMS code; inputs clear and reset focus to the first box. Error text sits below in red.
- **Error (Network/Spam):** Toast banners slide down from TopBar using `.glass-pill`. Total input lockdown for 5-minute spam penalty.
- **Success:** Green glow flash (`--glow-done`) on CTA, followed by immediate stack push to [07].
- **Disabled:** Inputs and CTA drop to 40% opacity and ignore touches.

# 10. Motion & interaction
- **Physical Easing:** 150-250ms feedback for taps. Crossfade between Phase 1 and Phase 2 is 250ms ease-in-out. 
- **Anchoring:** The Brand Anchor ("Balencia") remains completely static (opacity 1, position fixed) during the Phase 1 -> Phase 2 crossfade to ground the user visually.
- **Glow behavior:** Breathing glow (4s ease) on the CTA when it becomes active/enabled. Input focus triggers immediate 150ms expand of `--glow-you`. 
- **Haptics:** Light native impact on digit auto-advance; medium native impact on error shake; heavy native impact on success/navigation.
- **Gestures:** Edge swipe right (iOS) in Phase 2 crossfades back to Phase 1. Disabled in Phase 1 to protect the entry state.
- **Reduced-motion path:** Crossfades become instant opacity swaps (0ms). Shake animations are removed (inputs simply clear and turn red). Circular progress ring is hidden; countdown relies purely on text format `Resend code (0:47)`.

# 12. Accessibility
- **AA+ Contrast:** All text uses paper-100 (`#FEFAF3`) or paper-64% on `--bg-base` (`#0A0A0F`), maintaining >7:1 contrast. Error red uses a brightened variant `#FF6B6B` on dark to meet AA against the background.
- **44px Targets:** TopBar glyphs, skip links, and the country code dropdown are strictly 44x44px hitzones.
- **Screen-reader labels:** The OtpBoxGroup maps to a single hidden `UITextField` with `textContentType="oneTimeCode"`. Screen readers will announce "Verification code, 6 digits" rather than reading 6 disjointed boxes.
