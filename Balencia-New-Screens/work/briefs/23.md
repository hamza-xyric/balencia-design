# Functional Content Brief: Subscription & Billing (Screen 23)

## 1. Purpose
Shows users their current subscription status, compares all 4 available tiers (Free, Plus, Pro, Max), and handles billing management, upgrades, and downgrades. Follows a "show everything, upsell via visibility" principle—this screen is never part of onboarding, users arrive only after experiencing Balencia's value.

## 2. Entry and Exit Paths
*   **Entry Paths (Stack Push):**
    *   Me Main Screen [17] via quick link grid.
    *   Settings Screen [21] via "manage subscription" row.
    *   Paywall Screen [43] via "see all plans" link.
*   **Exit Paths:**
    *   Native IAP flow (system sheet) via Upgrade/Resubscribe CTAs.
    *   Native App Store settings via Payment Method/Update Card CTAs.
    *   Previous screen via stack pop (Back button or edge swipe).

## 3. Information Architecture
**Global Navigation:** Sticky Nav Header (Back chevron, "Subscription & billing" title, route-aware) + Bottom Tab Bar ("Me" active).

**Top-to-Bottom Content Stack:**
1.  **Warning Banner (Conditional):** Only appears if payment has failed. Pushes all content downward.
2.  **Current Plan Card:** Immediate confirmation of current tier, price, renewal date, and AI message usage.
3.  **All Plans - Tier Card Rail:** Horizontally scrolling cards detailing the 4 tiers (Free, Plus, Pro, Max) with identity, price, feature bullets, and contextual CTAs.
4.  **Compare Plans Matrix (The Focal Hero):** A grid comparing 2-3 relevant tier columns (Current, Recommended/Current+1, Next) across gated features.
5.  **Billing Section Group:** Expandable rows for Payment Method, Billing History (with data visualizations), and Restore Purchases.
6.  **Destructive Actions:** Standalone rows for Downgrade and Cancel.

## 4. Features and Capabilities
*   **View Current Status:** See active plan tier, cost, and exact renewal date.
*   **AI Usage Monitoring:** View metered AI message consumption (e.g., "800 of 1,000 messages"). Uses a segmented ChargeMeter for metered tiers; Max tier shows an "unlimited" label.
*   **Toggle Billing Period:** Switch all visible tier card prices between Monthly and Annual.
*   **Compare Tiers:** Read cross-tier feature entitlements via the CompareGrid (glyph-paired included/excluded indicators).
*   **Upgrade Plan:** Trigger native IAP flow from tier cards. Handles mid-cycle proration logic.
*   **Manage Payment:** View payment method, update expired cards, or retry failed charges.
*   **View Billing History:** Expand billing row to view historical charges, spend cadence, and last-charge deltas.
*   **Restore Purchases:** Trigger App Store restore flow for previously purchased entitlements.
*   **Cancel/Downgrade:** Initiate deferred tier downgrade or subscription cancellation.

## 6. Data Fields and Metrics
*   **Current Tier Name** & **Price** *(Source: Subscription API)*
*   **Renewal Date** *(Source: Subscription API)*
*   **AI Messages Used** / **Limit** *(Source: Usage API)* — E.g., 800 used / 1000 limit.
*   **Card Brand** & **Last 4 Digits** *(Source: Billing API)* — E.g., Visa ····4242.
*   **Previous Subscription Tier** & **Downgrade Reason** *(Source: Subscription API)* — Triggers Restore flow if reason is `payment_failed_grace_expired`.
*   **Last Charge Amount** & **Billing Cycle Delta** *(Source: Billing API)* — Displayed as KPIStatTile, shows "—" delta for flat pricing.
*   **7-Point Charge History** *(Source: Billing API)* — Last 7 charges for spend trend.
*   **Proration Amount** & **Next Charge Date** *(Source: Native IAP/System)*

## 7. Screen States
*   **Cold-Start / Free User:** CompareGrid visible with Free as owned (green) and Plus as recommended (orange/glow). No usage meter shown. Billing section hidden. Downgrade/Cancel rows hidden.
*   **Established User (Paid):** Full usage meter. Billing section active. Downgrade/Cancel rows visible.
*   **Payment Failed (Grace Period):** Amber warning banner at top. Countdown timer (3, 2, 1 days). Current plan features remain fully active.
*   **Payment Failed (Post-Grace):** Banner turns to "paused" state. All premium features drop to Free tier instantly. "Upgrade" link triggers Restore from Downgrade modal.
*   **Loading:** Depth-preserving skeletons. CompareGrid cell glyphs settle top-to-bottom. Usage meter ticks light up sequentially. Prices fade to placeholders. "Loading your plan…" appears if delayed.
*   **Error:** Grid structure persists, cells collapse. "Could not load plans. Pull to retry." Usage meter hides fill, shows "Usage unavailable."
*   **Empty / Partial:** Billing history shows "No charges yet." If one charge exists, Sparkline renders a single dot with "—" delta.

## 8. Interactions, Gestures, Motion Intents
*   **Gestures:**
    *   Horizontal swipe to scroll Tier Card Rail.
    *   Tap CTAs to trigger modals or native IAP.
    *   Tap "Update" on warning banner to open bottom sheet.
    *   Swipe down or tap backdrop to dismiss bottom sheets/modals.
    *   Edge swipe right to navigate back.
*   **Motion & Choreography:**
    *   **Focal Intent:** The CompareGrid is the single focal point (features the only `glow-orange-md` bloom on the recommended column). All other elements are ambient.
    *   **Draw-First Motion:** As user scrolls to the grid, cells settle top-to-bottom. Usage meter fills 0→value. Billing Sparkline draws L→R. Prices count up.
    *   **Micro-interactions:** Toggle slides smoothly (no cross-fade). Success morphs change CTAs from orange to green briefly before dismissing.
    *   **Accessibility (Reduced Motion):** All animations jump to final settled state instantly. The canonical frame is fully readable without motion.

## 9. Free vs Premium Gating
*   **Tiers:** Free, Plus, Pro, Max. (All 4 visible on the tier rail; only 2-3 relevant shown in CompareGrid).
*   **Free Tier Limits:** Basic dashboard, limited AI messages, basic journaling/finance/habits. Displayed via neutral constructive text ("Pro raises this to 10,000"), never manufactured scarcity.
*   **Premium (Plus/Pro/Max) Features:** Full CIA coaching, all domains, cross-domain insights, RPG gamification, advanced analytics, unlimited CIA messages, priority processing, family/team features (Max).
*   **Dark Pattern Removal:** The legacy UI escalated colors (orange→amber→red) to weaponize loss aversion near AI limits. The redesign uses a single continuous non-alarming fill with neutral text labels to communicate limits ethically.

## 10. Cross-Domain Hooks
*   **CIA (Coach Persona):** Central to the tier matrix. Free gets limited CIA messages; Plus/Pro get full CIA coaching; Max gets unlimited CIA. *Note: No CIA UI presence (purple styling) exists directly on this transactional screen; CIA is only represented in the text/data matrix.*
*   **Gamification:** RPG gamification elements are listed as an entitlement unlocked at the Plus tier and above.
*   **Analytics:** Advanced analytics and real-time usage meters are gated capabilities unlocked at the Pro tier.
*   **Life Areas / Domains:** Plus tier gates the "All Domains" capability and unlocks cross-domain insights.
