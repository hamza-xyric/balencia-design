# FUNCTIONAL CONTENT BRIEF: Conversations Hub

## 1. Purpose
The Conversations Hub is the unified inbox where the CIA coach remains the central anchor, while direct messages, group chats, and community rooms are organized underneath. It transforms scattered conversation history into a structured command center, supporting social accountability without replacing the primary CIA coaching relationship.

## 2. Entry and Exit Paths
**Entry Paths:**
*   Stack push from CIA Chat [09] (conversation list affordance)
*   Community [40] (message CTA)
*   Accountability [46] (partner message CTA)
*   Social Buddy Profile [83]
*   Bottom tab bar navigation (CIA tab active)

**Exit Paths:**
*   Tap CIA Hero -> CIA Chat [09]

## 3. Information Architecture
**Screen Layout (Vertical Scroll):**
1.  **Header (Fixed):** Centered title "Conversations" with right-aligned Search and Voice icons.
2.  **CIA Hero (Focal Anchor):** Pinned CIA card containing presence, summary, and live signals.
3.  **Search Bar:** Real text input for querying content.
4.  **Filter Rail:** Horizontal single-select tab group.
5.  **Pinned Section:** Group of pinned conversation rows.
6.  **Recent Section:** Group of recent conversation rows.
7.  **Bottom Action (Fixed):** Primary CTA to start a new chat.
8.  **Tab Bar (Fixed):** Global navigation, CIA tab active.

## 4. Features and Capabilities
*   **CIA Coach Pinning:** The CIA thread is permanently anchored at the top of the inbox.
*   **Universal Search:** Text-based search across people, rooms, and CIA memory references.
*   **Inbox Filtering:** Single-select filtering by conversation category (All, CIA, People, Groups, Rooms).
*   **Conversation Grouping:** Segregation of threads into "Pinned" and "Recent" lists.
*   **Row Context Display:** Surfaces unread counts, timestamps, domain tags, chat kind, and CIA-assist presence.
*   **Quick Row Actions:** Long-press a row to Pin/Unpin, Mute, or Archive.
*   **Thread Initiation:** Create new Direct, Group, Room, or CIA threads via a bottom sheet picker.
*   **Voice Routing:** Direct access to Voice Mode for coaching.
*   **Offline Resilience:** Cached conversations remain visible; send/create actions gracefully block with messaging.

## 7. Screen States
*   **Cold-start / Empty:** CIA Hero is fully rendered. Pinned and Recent headers render, but lists are empty. A centered, non-shaming empty state CTA is displayed.
*   **Loading:** Skeleton cards (preserving layout depth) and text lines. CIA Hero skeleton is preserved with its earned left-border accent.
*   **Filtered Empty:** Preserves the active filter rail but displays a contextual empty message offering a path forward.
*   **Search Active/Partial:** Empty sections dynamically hide headers; matching rows populate under their respective sections.
*   **Error / Network:** Cached conversations remain visible. A recovery banner with an alert icon is injected below the header.
*   **Offline:** Cached conversations visible and muted. The "Start new chat" and message inputs are visually dimmed (50% opacity) with an explicit offline reason label.
*   **Reduced Motion:** All entrance staggers and scale feedback collapse; elements resolve to final state instantly. 

## 8. Interactions, Gestures, and Motion Intents
*   **Tap (CIA Hero/Rows):** 120ms scale-down feedback (0.96 - 0.98) before routing to destination.
*   **Long Press (Rows):** Opens a lightweight bottom sheet menu for chat management (Pin/Mute/Archive).
*   **Filter Tap:** Crossfades row groups over 180ms. Active state is glyph-paired (filled icon + background).
*   **Motion Choreography:** Content enters with a staggered fade-up: CIA Hero (0ms) -> Search/Filters (80ms) -> Pinned Rows (staggered 80ms+) -> Recent Rows (staggered 120ms+) -> Start New Chat FAB (160ms).

## 10. Cross-Domain Hooks (Correlations & AI Insights)
*   **CIA-Assist Sparkles:** Visually flags when the CIA is pulling data from or actively assisting inside a social/group conversation, linking community chatter to AI coaching context.
*   **CIA Cross-Domain Summary:** The Hero card actively synthesizes fragmented data (e.g., correlating "breakfast timing" with "budget" and "recovery") to provide a unified view of the user's current state.
*   **Domain Tags:** Social threads and group contexts are tagged with life-area domains (Fitness, Finance), creating structural bridges between social accountability and personal goal tracking.

## 11. Implementation Flags & Audit Resolutions
*   **Persona Rename Compliance:** "SIA" has been explicitly renamed to "CIA" throughout the content brief (CIA Hero, CIA Chat, CIA memory, etc.). Route paths (`/tabs/sia/conversations`) remain unchanged in underlying architecture references but are functionally represented under the new persona.
*   **Real Inputs (B05-F04/F05):** Search must be a real, focusable text input (not a tap-to-reveal modal), and the Filter Rail must be a strict, single-select semantic control.
*   **Honest Counters:** The "3 live signals" and unread message counts must remain honest count chips (number + glyph). They must *not* be elevated to abstract visual meters or dashboard charts, as this is a utility list, not an analytics screen.
