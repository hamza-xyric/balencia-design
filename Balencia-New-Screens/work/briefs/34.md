# FUNCTIONAL CONTENT BRIEF: Spirituality Dashboard

## 1. Purpose
Provides a calm, belief-adaptive hub for users to track daily spiritual practices, reading progress, fasting, and contemplation. Serves as an emotional anchor that gently coaches users (via CIA) on their spiritual journey without gamifying the practice into high-pressure metrics or issuing religious rulings. 

## 2. Entry & Exit Paths
**Entry Paths:**
*   Explore section (Screen 18) via stack push.
*   CIA chat (Screen 09) via deep-link.
*   Global Tab Bar navigation.

**Exit Paths:**
*   **CIA Tab:** Tap coaching note or reflection prompt.
*   **Journal (Screen 37):** Saving a reflection.
*   **Goal Detail (Screen 14):** Managing spirituality goals.
*   **RPG Character Screen (Screen 19):** Tapping the Level badge.
*   **Overlays:** Timer Modal, Log Reading Bottom Sheet, Reflection Entry Bottom Sheet.

## 3. Information Architecture (Top-to-Bottom)
1.  **Domain Header:** Identification & global user level.
2.  **CIA Coaching Note:** Cross-domain spiritual insight.
3.  **Prayer Schedule (Conditional):** Location-based calculation schedule.
4.  **Practice Tracker (Focal Interaction):** Daily checklist & consistency streak.
5.  **Reading Progress Card:** Text/book tracking.
6.  **Fasting Tracker (Conditional):** Active fast countdown.
7.  **Daily Reflection Card:** CIA-generated prompt.
8.  **Contemplation Timer Shortcuts:** Quick-launch dual cards.

## 4. Features & Capabilities
*   **Adaptive Belief System:** Content (labels, practices, texts) automatically adapts to user-stated beliefs (Muslim, Christian, Jewish, Buddhist, Hindu, Agnostic, Custom) while maintaining universal UI mechanics.
*   **Practice Tracking:** Checkboxes for daily prayers/practices. Supports late completion, skip, and notes.
*   **Location-Based Prayer Times:** Auto-calculated prayer times with manual method override (e.g., Muslim World League, ISNA) and per-prayer notification toggles.
*   **Reading Tracker:** Logging pages/chapters read, duration, and viewing progress against a daily target.
*   **Fasting Tracker:** Real-time countdown for active fasts (religious or secular/intermittent).
*   **Reflection Journaling:** Text entry to respond to daily CIA prompts.
*   **Contemplation Timers:** Launching modal overlays for meditation, breathing, or dhikr/prayer.
*   **Consistency Heatmap:** Honest visual history of practice consistency over time.

## 7. Screen States
*   **Cold-Start / Day 1:** No fabricated 0% pressure. Momentum bar absent. Suggestions provided. Heatmap shows empty grid with "your practice begins today".
*   **Low Motivation:** UI collapses secondary modules (Reading, Fasting, Timers) behind a "see more" affordance. Restricts view to top 3 practices and CIA note.
*   **High Motivation:** Reveals advanced analytics (on-time vs late tracking, focus/health correlations on fasts, reading mini-carousel, weekly stat tiles).
*   **Established User (Zero State):** "All practices complete today" / "Completed" badges.
*   **Loading:** Depth-preserving skeletons that morph into drawn fills. Copy: "SIA is reading your week — one moment."
*   **Partial/Sync:** Ghosted/dashed rows for un-synced data; distinct from true zero.
*   **Error:** Cached data retained where possible; inline failure text with specific actions (e.g., "pull to refresh"). Fasting card hides entirely on failure.
*   **Offline:** Actions honestly dimmed; cached data shown.

## 8. Interactions & Motion Intents
*   **Taps:** Toggle practice completion, open modal sheets (reading/reflection), launch timers, toggle notifications.
*   **Long-Press:** Edit configurations (practice times, fasting schedules, reading details, timer defaults).
*   **Gestures:** Pull-to-refresh, edge-swipe back, drag-down to dismiss bottom sheets.
*   **Motion Intent:** **Calm.** Deliberate absence of gamified "explosions." Continuous bar fills (520ms ease-flow), staggered row entrances, subtle pulsing on active timers. Un-completing a practice silently retracts the visual fill (non-shaming). 

## 9. Free vs. Premium Gating
*   **Reflection KPIStatTile (WoW delta):** Deferred / gated to **High Motivation Tier** by default to protect the calm.
*   **Fasting Focus Sparkline:** Health/Focus correlation trend visible only in **High Motivation Tier**.
*   **Basic logging, tracking, journaling, and prayer configuration:** Free.

## 10. Cross-Domain Hooks
*   **CIA Chat (Screen 09):** Deep contextual links from the coaching note and reflection prompt to continue existential/spiritual conversations.
*   **RPG Character (Screen 19):** Spirituality XP feeds the global avatar progression.
*   **Journal (Screen 37):** Reflection entries seamlessly log to the master journal.
*   **Health/Focus Domain:** Correlation between fasting schedules and cognitive/focus metrics.

---
### ⚠️ Source Contradictions Flagged
1.  **Persona Naming:** Source instructions demand renaming "SIA" to "CIA". However, the source's UI Copy and Wireframe ASCII embeds hard-coded strings still using "SIA" (e.g., "ask SIA →"). This requires a global string update by the copywriting team.
2.  **Religious Text Authentication:** Source notes that text references (Quran, Bible, etc.) require "qualified human authentication before CIA can reference them directly," yet the UI prototype shows CIA dynamically generating reading plans and quoting text status natively. 
3.  **Visualization Complexity:** The spec text labels this the "calmest dashboard" with "no viz hero," yet the integrated audit demands a high density of complex data viz primitives (MomentumBar, MetricCard status dots, GaugeRing dials, CalendarHeatmap, Sparklines, KPIStatTiles). The functional design must balance the *intent* of calm with the *density* of these required modules.
